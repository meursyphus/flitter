## 차트별 .md 가이드

각 `todo/{chart-name}.md` 구조:

### 1. 스타일 구현 (Toast / Ag 각각)
- config, factory, 컴포넌트들, plugin 등록

### 2. 스토리북 (Toast / Ag 각각)
- 기본, 변형, 다중 데이터셋, 커스텀 등

### 3. 예제 (공통 docs용)
- 스타일별 예제 코드

### 4. 노트
- 자유 기록 (구현 방안, 이슈, 아이디어 등)
