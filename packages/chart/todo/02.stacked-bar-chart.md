## Ag 스타일

> 참고: https://ag-grid.com/charts/gallery/ (Bar 탭 → Stacked/Grouped Stacked)
> 갤러리 예제:
>   - Stacked Bar: https://ag-grid.com/charts/gallery/stacked-bar/
>   - Grouped Stacked: https://ag-grid.com/charts/gallery/grouped-stacked-bar/
>   - Stacked Horizontal: https://ag-grid.com/charts/gallery/stacked-horizontal-bar/
> 리서치: `ag-style-research.md`

### 구현

- [x] `styles/ag/config.ts` — AgStackedBarChartConfig
  - bar cornerRadius: 0
  - 배경: white, grid: solid
- [x] `styles/ag/parts/bar.ts` — AG 스타일 스택 바 렌더러
  - fill: 10색 팔레트, stroke 없음
- [x] `styles/ag/parts/bar-group-box.ts` — 바 그룹 박스 (onMouseLeave 처리)
- [ ] `styles/ag/parts/data-label.ts` — 세그먼트 내부 라벨
- [x] `styles/ag/index.ts` — agStyleConfig
- [x] `plugin.ts` — StyleMap에 ag 등록
- [x] 호버 효과 (hover: 1.0, 같은 시리즈: 0.8, 나머지: 0.5, barGroupBox에서 mouseLeave)
- [x] 툴팁 (AG 스타일, 마우스 따라다니는 애니메이션 + 삼각형 화살표)
- [x] 애니메이션 제거
- [x] tick 렌더링 제거
