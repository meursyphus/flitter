### 구현

- [x] `styles/ag/config.ts` — AgBubbleChartConfig
  - bubble.fillOpacity (0.7)
  - bubble.strokeWidth (1)
  - maxRadius: 25 (toast 절반), minRadius: 3
  - 배경: white, grid: solid
  - axis 색상 = grid 색상, 양축 visible
- [x] `styles/ag/parts/bubble.ts` — AG 스타일 버블 렌더러
  - fill: 10색 팔레트 (반투명)
  - stroke: 10색 stroke
- [ ] `styles/ag/parts/data-label.ts` — 라벨 (버블 옆)
- [x] `styles/ag/index.ts` — agStyleConfig (legend markerShape: circle)
- [x] `plugin.ts` — StyleMap에 ag 등록
- [x] 호버 효과 (가까운 버블 opacity 강조)
- [x] 툴팁 (AG 스타일, AnimatedPositioned)
- [x] 애니메이션 제거
- [x] tick 렌더링 제거
