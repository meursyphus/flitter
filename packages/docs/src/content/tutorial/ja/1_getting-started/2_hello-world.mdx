インストールが完了したので、FlitterのコアウィジェットであるContainerとTextを使用して最初のアプリを作成しましょう。このチュートリアルを通して、ウィジェットツリーの基本概念とウィジェットの組み合わせ方を学びます。

- [ ] Containerウィジェットでボックスを作成

## 📚 コアコンセプト: ウィジェットとは？

Flitterでは、**ウィジェット**はUIを構築するための基本的なビルディングブロックです。すべてがウィジェットで作られており、ウィジェットを組み合わせて複雑なUIを作成できます。

### ウィジェットの特徴

1. **不変**: 一度作成されたウィジェットは変更できません
2. **コンポーザブル**: ウィジェットを他のウィジェット内にネストして複雑な構造を作成できます
3. **再利用可能**: 同じウィジェットを複数の場所で使用できます

## 🏗️ Containerウィジェットの理解

**Container**はFlitterの最も基本的なウィジェットの1つです。ボックスを作成し、スタイリングを適用するために使用されます。

### Containerの主要プロパティ

```typescript
Container({
  // サイズ設定
  width: 200,           // 幅（ピクセル）
  height: 100,          // 高さ（ピクセル）
  
  // 色とスタイル
  color: '#ff0000',     // 背景色（16進数コード）
  
  // 余白設定
  padding: EdgeInsets.all(16), // 内部余白
  margin: EdgeInsets.all(8),   // 外部余白
  
  // 子ウィジェット
  child: Text('Hello')  // 単一の子ウィジェット
})
```

### 余白設定方法

```typescript
// 全辺同じ余白
padding: EdgeInsets.all(16)

// 水平/垂直方向に異なる余白
padding: EdgeInsets.symmetric({ horizontal: 20, vertical: 10 })

// 各辺個別の余白
padding: EdgeInsets.only({ top: 8, right: 16, bottom: 8, left: 16 })
```

## 📝 Textウィジェットの理解

**Text**は画面にテキストを表示するウィジェットです。

### Textの基本的な使用法

```typescript
// シンプルなテキスト
Text('Hello, World!')

// スタイリングを適用したテキスト
Text('スタイル付きテキスト', {
  style: new TextStyle({
    fontSize: 20,        // フォントサイズ
    fontWeight: 'bold',  // フォントの太さ: 'normal', 'bold', '100'-'900'
    color: '#1e40af',    // テキストの色
    fontFamily: 'Arial'  // フォントファミリー
  })
})
```

### テキスト配置オプション

```typescript
Text('配置されたテキスト', {
  textAlign: 'center'  // 'left', 'center', 'right', 'justify'
})
```

  padding: EdgeInsets.all(20),

### ステップ3: 複数のテキストを追加

Columnウィジェットを使用して複数のテキストを縦に並べましょう：

```typescript

const widget = Container({
  color: '#f0f9ff',
  padding: EdgeInsets.all(20),
  child: Column({
    mainAxisAlignment: MainAxisAlignment.center,    // 垂直方向の中央揃え
    crossAxisAlignment: CrossAxisAlignment.center,   // 水平方向の中央揃え

      Text('Hello, Flitter!', {
        style: new TextStyle({
          fontSize: 28,
          fontWeight: 'bold',
          color: '#1e40af'
        })
      }),
      SizedBox({ height: 10 }),     // 10pxの高さの空白
      Text('私の最初のウィジェットアプリ', {
        style: new TextStyle({
          fontSize: 16,
          color: '#64748b'
        })
      })
    ]
  })
});
```

## 🎨 Columnウィジェットでレイアウトを作成

**Column**は複数のウィジェットを縦に並べるレイアウトウィジェットです。

### Columnの主要プロパティ

```typescript
Column({
  // 垂直方向の配置（メイン軸）
  mainAxisAlignment: MainAxisAlignment.center,
  
  // 水平方向の配置（クロス軸）
  crossAxisAlignment: CrossAxisAlignment.center,
  
  // 子ウィジェット
  children: [
    Text('最初'),
    Text('2番目'),
    Text('3番目')
  ]
})
```

### 配置オプションの説明

**mainAxisAlignment**（垂直方向）：
- `MainAxisAlignment.start`: 上揃え
- `MainAxisAlignment.center`: 中央揃え
- `MainAxisAlignment.end`: 下揃え
- `MainAxisAlignment.spaceBetween`: ウィジェット間の均等配置
- `MainAxisAlignment.spaceAround`: ウィジェットの周囲に均等配置
- `MainAxisAlignment.spaceEvenly`: すべての間隔が均等

**crossAxisAlignment**（水平方向）：
- `CrossAxisAlignment.start`: 左揃え
- `CrossAxisAlignment.center`: 中央揃え
- `CrossAxisAlignment.end`: 右揃え
- `CrossAxisAlignment.stretch`: すべての水平空間を埋める

## 🚨 よくある間違いと解決策

### 問題1: テキストが表示されない
**原因**: Containerに`child`が設定されていないか、Textウィジェットが正しく作成されていない

**解決策**： 
```typescript
// ❌ 間違った例
Container({ color: 'blue' })  // childなし

// ✅ 正しい例
Container({ 
  color: 'blue',
  child: Text('Hello')  // childを必ず設定
})
```

### 問題2: Columnでchildrenの代わりにchildを使用
**原因**: Columnには複数の子があるため、`children`配列を使用する必要がある

**解決策**：
```typescript
// ❌ 間違った例
Column({ child: Text('Hello') })

// ✅ 正しい例
Column({ children: [Text('Hello')] })
```

### 問題3: 色が適用されない
**原因**: 間違った色のフォーマットまたは引用符の欠落

**解決策**：
```typescript
// ❌ 間違った例
color: #ff0000     // 引用符なし
color: 'ff0000'    // #なし

// ✅ 正しい例
color: '#ff0000'   // 16進数コード
color: 'red'       // 色の名前
color: 'rgb(255, 0, 0)'  // RGB値
```

### 問題4: fontSizeが適用されない
**原因**: fontSizeが文字列として設定されているか、スタイルオブジェクトの構造が間違っている

**解決策**：
```typescript
// ❌ 間違った例
Text('Hello', { fontSize: '20px' })           // 直接のプロパティ
Text('Hello', { style: { fontSize: '20' } })  // 文字列

// ✅ 正しい例
Text('Hello', { style: { fontSize: 20 } })    // 数値として設定
```

## 🧠 ウィジェットツリーの理解

アプリのウィジェットツリー構造を見てみましょう：

```
Container（ルート）
├── color: '#f0f9ff'
├── padding: EdgeInsets.all(20)
└── child: Column
    ├── mainAxisAlignment: MainAxisAlignment.center
    ├── crossAxisAlignment: CrossAxisAlignment.center
    └── children:
        ├── Text('Hello, Flitter!')
        ├── SizedBox({ height: 10 })
        └── Text('私の最初のウィジェットアプリ')
```

### ウィジェットツリーの特徴

1. **親子関係**: ContainerがColumnを含み、Columnが複数のTextを含む
2. **単方向データフロー**: プロパティは親から子に渡される
3. **構成可能性**: シンプルなウィジェットを組み合わせて複雑なUIを構築

## 📏 サイズと制約の理解

### Containerがサイズを決定する方法

```typescript
// 1. 明示的なサイズ指定
Container({
  width: 200,
  height: 100,
  child: Text('固定サイズ')
})

// 2. 子のサイズに合わせる（デフォルト）
Container({
  padding: EdgeInsets.all(16),
  child: Text('子のサイズに合わせる')
})

// 3. 利用可能なすべての空間を取る（子なし）
Container({
  color: 'red'  // 子がない場合は最大サイズ
})
```
