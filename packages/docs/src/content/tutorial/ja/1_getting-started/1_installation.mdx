# インストールと環境設定

Flitterを初めて使う方のためのステップバイステップのインストールガイドです。このチュートリアルを完了すると、ReactプロジェクトでFlitterを使用できるようになります。

## 🎯 学習目標

このチュートリアルを完了すると、以下のことができるようになります：

- [ ] Node.jsとnpmの環境が正しく設定されていることを確認
- [ ] 新しいReactプロジェクトを作成
- [ ] Flitterパッケージをインストール
- [ ] 最初のFlitterウィジェットをレンダリング
- [ ] 開発サーバーを実行して結果を確認

## 📋 前提条件

- **Node.js 18以上** - [Node.js公式サイト](https://nodejs.org/)からダウンロード
- **npm、yarn、またはpnpm** - Node.jsと一緒に自動でインストールされます
- **Reactの基本知識** - JSXとコンポーネントの概念の理解

## 🚀 ステップ1: 環境チェック

まず、開発環境が正しく設定されているか確認しましょう。

ターミナルを開いて、以下のコマンドを実行してください：

```bash
# Node.jsのバージョンを確認（18以上である必要があります）
node --version

# npmのバージョンを確認
npm --version
```

期待される出力:
```
v20.10.0
10.2.3
```

> ⚠️ **Node.jsのバージョンが18未満の場合？**  
> [Node.js公式サイト](https://nodejs.org/)から最新のLTSバージョンをインストールしてください。

## 🏗️ ステップ2: 新しいプロジェクトの作成

Viteを使用して新しいReactプロジェクトを作成します：

```bash
# 新しいプロジェクトを作成
npm create vite@latest my-flitter-app -- --template react

# プロジェクトフォルダに移動
cd my-flitter-app

# 基本的な依存関係をインストール
npm install
```

## 📦 ステップ3: Flitterパッケージのインストール

さて、Flitter関連のパッケージをインストールしましょう：

```bash
# FlitterコアパッケージとReact統合パッケージをインストール
npm install @meursyphus/flitter @meursyphus/flitter-react
```

インストールされるパッケージ:
- `@meursyphus/flitter`: Flitterコアライブラリ
- `@meursyphus/flitter-react`: React統合用のコンポーネント

### 完成コード

```jsx
import React from 'react';
import { Widget } from '@meursyphus/flitter-react';
import { Container, Text } from '@meursyphus/flitter';

function App() {
  const widget = Container({
    color: '#e3f2fd',
    padding: { all: 20 },
    child: Text('🎉 Flitterのインストール完了！')
  });

  return (
    <div style={{ padding: '20px' }}>
      <h1>Flitterインストール成功！</h1>
      <Widget 
        widget={widget}
        renderer="canvas"
        style={{ 
          width: '300px', 
          height: '100px',
          border: '1px solid #ddd',
          borderRadius: '8px'
        }}
      />
    </div>
  );
}

export default App;
```

## 🏃 ステップ5: 開発サーバーの実行

さて、開発サーバーを実行して結果を確認しましょう：

```bash
npm run dev
```

ブラウザで`http://localhost:5173`を開くと、以下が表示されるはずです：

- "Flitterインストール成功！"タイトル
- "🎉 Flitterのインストール完了！"テキストを含む青い背景のボックス

## 🎯 期待される結果

インストールが正常に完了した場合：

1. **開発サーバーが正常に動作**: ターミナルに"Local: http://localhost:5173"が表示される
2. **Flitterウィジェットがレンダリング**: 画面に青い背景のボックスが表示される
3. **コンソールエラーなし**: ブラウザの開発者ツールにエラーメッセージが表示されない

## 🚨 よくある間違いと解決策

### 問題1: モジュールが見つからないエラー
```
Error: Cannot resolve module '@meursyphus/flitter'
```

**解決策**: パッケージが正しくインストールされているか確認：
```bash
npm install @meursyphus/flitter @meursyphus/flitter-react
```

### 問題2: 空白の画面が表示される
**原因**: ウィジェットが正しく作成されていないか、Widgetコンポーネントに渡されていない

**解決策**: 
- `widget`変数が`null`でないことを確認
- `widget`プロップがWidgetコンポーネントに渡されていることを確認

### 問題3: Node.jsバージョンエラー
```
Error: Node.js version 16.x is not supported
```

**解決策**: Node.js 18以上にアップデートしてください。
