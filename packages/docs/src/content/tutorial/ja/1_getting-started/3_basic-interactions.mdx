## 🤔 状態管理が必要な理由

これまで作成したウィジェットはすべて一度作成されると変化しない**静的ウィジェット**でした。しかし実際のアプリではユーザーの操作に応じて画面が変化する必要があります：

- ボタンをクリックして数値を増やす
- トグルボタンを押してオン/オフ状態を変更
- 入力フィールドに文字を入力して画面にテキストを表示

このような**動的な変化**のためには**状態**が必要です。

## 🏗️ StatefulWidgetの理解

**StatefulWidget**は状態を持つことができるウィジェットです。状態が変化すると画面が自動で再描画されます。

### StatefulWidget vs StatelessWidget

```typescript
// StatelessWidget - 状態なし、変化しない
class GreetingWidget extends StatelessWidget {
  build() {
    return Text('こんにちは！'); // 常に同じテキスト
  }
}

// StatefulWidget - 状態あり、変化する
class CounterWidget extends StatefulWidget {
  createState() {
    return new CounterWidgetState(); // 状態クラスを返す
  }
}

class CounterWidgetState extends State {
  count = 0; // 状態変数

  build() {
    return Text(`カウンター: ${this.count}`); // 状態に基づいて異なるテキスト
  }
}
```

### StatefulWidgetの基本構造

StatefulWidgetは2つのクラスで構成されます：

1. **ウィジェットクラス**: `StatefulWidget`を継承し、`createState()`メソッドを実装
2. **状態クラス**: `State`を継承し、実際の状態とUIロジックを含む

```typescript
// 1. ウィジェットクラス
class MyWidget extends StatefulWidget {
  createState() {
    return new MyWidgetState();
  }
}

// 2. 状態クラス
class MyWidgetState extends State {
  // 状態変数（クラスプロパティとして宣言）
  count = 0;
  isVisible = true;
  
  // UI構成メソッド
  build() {
    return Container({
      child: Text(`カウント: ${this.count}`)
    });
  }
}
```

### 重要な特徴

1. **状態変数はクラスプロパティ**: `this.count = 0`として宣言
2. **Reactフックは使用しない**: `useState`、`useEffect`などはFlitterでは使用しない
3. **setState()が必要**: 状態を変更する時は`setState()`を使用する必要がある

## 🎯 GestureDetectorでイベント処理

**GestureDetector**はユーザーのジェスチャー（クリック、ドラッグ、ホバーなど）を検出するウィジェットです。

### 基本的な使用法

```typescript
GestureDetector({
  onClick: () => {
    console.log('クリックされました！');
  },
  child: Container({
    child: Text('クリックして')
  })
})
```

### 主要なイベントプロパティ

```typescript
GestureDetector({
  // マウスイベント
  onClick: (e) => { /* クリック時 */ },
  onMouseDown: (e) => { /* マウスボタンを押した時 */ },
  onMouseUp: (e) => { /* マウスボタンを離した時 */ },
  onMouseEnter: (e) => { /* マウスが領域に入った時 */ },
  onMouseLeave: (e) => { /* マウスが領域を出た時 */ },
  
  // ドラッグイベント
  onDragStart: (e) => { /* ドラッグ開始 */ },
  onDragMove: (e) => { /* ドラッグ中 */ },
  onDragEnd: (e) => { /* ドラッグ終了 */ },
  
  // その他の設定
  cursor: 'pointer', // カーソルの形
  
  child: /* 子ウィジェット */
})
```

### カーソルの種類

```typescript
cursor: 'pointer'      // 手の形
cursor: 'default'      // デフォルト矢印
cursor: 'move'         // 移動表示
cursor: 'text'         // テキスト選択
cursor: 'wait'         // 待機表示
cursor: 'not-allowed'  // 禁止表示
cursor: 'grab'         // つかみ表示
cursor: 'grabbing'     // つかんでいる表示
```

## 🔧 練習: カウンターアプリの作成

今度はクリックするたびに数値が増えるカウンターアプリを作成しましょう。

### Step 1: Create StatefulWidget Class

First, let's create the basic structure of StatefulWidget:

```typescript
import { StatefulWidget, State } from '@meursyphus/flitter';

class CounterWidget extends StatefulWidget {
  createState() {
    return new CounterWidgetState();
  }
}

class CounterWidgetState extends State {
  count = 0; // Counter state variable
  
  build() {
    return Container({
      child: Text(`Counter: ${this.count}`)
    });
  }
}
```

### Step 2: Update State with setState()

Add a method to increase the counter when the button is clicked:

```typescript
class CounterWidgetState extends State {
  count = 0;
  
  // Counter increment method
  increment() {
    this.setState(() => {
      this.count++; // Change state inside setState
    });
  }
  
  build() {
    return Container({
      child: Text(`Counter: ${this.count}`)
    });
  }
}
```

### Step 3: Connect Click Event with GestureDetector

Now use GestureDetector to call the increment method on click:

```typescript
class CounterWidgetState extends State {
  count = 0;
  
  increment() {
    this.setState(() => {
      this.count++;
    });
  }
  
  build() {
    return Column({
      mainAxisAlignment: 'center',
      children: [
        Text(`Counter: ${this.count}`),
        GestureDetector({
          onClick: () => this.increment(), // Call increment on click
          child: Container({
            child: Text('Click me!')
          })
        })
      ]
    });
  }
}
```

### Step 4: Add Button Styling

## 🎨 Complete Counter App

Here's the complete counter app combining all steps:

```typescript
import React from 'react';
import Widget from '@meursyphus/flitter-react';
import { 
  StatefulWidget, 
  State, 
  Container, 
  Text, 
  Column, 
  GestureDetector, 
  SizedBox,
  EdgeInsets,
  BoxDecoration,
  BorderRadius,
  TextStyle,
  MainAxisAlignment,
  CrossAxisAlignment
} from '@meursyphus/flitter';

class CounterWidget extends StatefulWidget {
  createState() {
    return new CounterWidgetState();
  }
}

class CounterWidgetState extends State {
  count = 0;

  increment() {
    this.setState(() => {
      this.count++;
    });
  }

  build() {
    return Container({
      color: '#f8fafc',
      padding: EdgeInsets.all(30),
      child: Column({
        mainAxisAlignment: MainAxisAlignment.center,
        crossAxisAlignment: CrossAxisAlignment.center,
        children: [
          Text(`Counter: ${this.count}`, {
            style: new TextStyle({
              fontSize: 24,
              fontWeight: 'bold',
              color: '#1e293b'
            })
          }),
          SizedBox({ height: 20 }),
          GestureDetector({
            onClick: () => this.increment(),
            cursor: 'pointer',
            child: Container({
              padding: EdgeInsets.symmetric({ horizontal: 20, vertical: 12 }),
              decoration: new BoxDecoration({
                color: '#3b82f6',
                borderRadius: BorderRadius.circular(8)
              }),
              child: Text('Click me!', {
                style: new TextStyle({
                  color: 'white',
                  fontSize: 16,
                  fontWeight: 'bold'
                })
              })
            })
          })
        ]
      })
    });
  }
}

function App() {
  const widget = new CounterWidget();
  
  return (
    <Widget 
      widget={widget}
      renderer="canvas"
      style={{ width: '300px', height: '200px' }}
    />
  );
}
```

## 🎨 Advanced Understanding of setState()

### Role of setState()

```typescript
// ❌ Wrong way - UI won't update
this.count++; 

// ✅ Correct way - UI automatically updates
this.setState(() => {
  this.count++;
});
```

### Multiple State Changes within setState()

```typescript
this.setState(() => {
  this.count++;           // Multiple states can be
  this.isVisible = true;  // changed simultaneously
  this.message = 'Updated!';
});
```

### Callback After setState()

```typescript
this.setState(() => {
  this.count++;
}, () => {
  // Executed after state update is complete
  console.log('Counter updated:', this.count);
});
```

## 🚨 Common Mistakes and Solutions

### Problem 1: Changing State Without setState
```typescript
// ❌ Wrong example - UI won't update
increment() {
  this.count++; // No setState
}

// ✅ Correct example
increment() {
  this.setState(() => {
    this.count++;
  });
}
```

### Problem 2: Using React Hooks
```typescript
// ❌ Wrong example - Not available in Flitter
const [count, setCount] = useState(0); // React pattern

// ✅ Correct example - Flitter pattern
class MyState extends State {
  count = 0; // Declare state as class property
}
```

### Problem 3: Directly Exporting Class
```typescript
// ❌ Wrong example
export default CounterWidget; // Direct class export

// ✅ Correct example - Use by creating instance
function App() {
  const widget = new CounterWidget(); // Create instance with new keyword
  return <Widget widget={widget} />;
}
```

### Problem 4: Handling Events Without GestureDetector
```typescript
// ❌ Wrong example
Container({
  onClick: () => {}, // Container has no click event
  child: Text('Click')
})

// ✅ Correct example
GestureDetector({
  onClick: () => {},
  child: Container({
    child: Text('Click')
  })
})
```

## 🧠 Understanding Lifecycle Methods

StatefulWidget has several lifecycle methods:

### initState() - Initialization
```typescript
class CounterWidgetState extends State {
  count = 0;
  
  initState() {
    super.initState();
    console.log('Counter widget created');
    // Initialize animation controllers, timers, etc.
  }
}
```

### didUpdateWidget() - Update
```typescript
didUpdateWidget(oldWidget) {
  super.didUpdateWidget(oldWidget);
  // When parent widget's properties change
  console.log('Widget updated');
}
```

### dispose() - Cleanup
```typescript
dispose() {
  console.log('Counter widget removed');
  // Clean up timers, animations, etc.
  super.dispose();
}
```
