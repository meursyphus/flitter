# What are Widgets? - Everything is a Widget

In Flitter, everything you see on the screen is a **widget**. Text is a widget, buttons are widgets, and even padding and alignment are expressed as widgets. Understanding this powerful concept allows you to create complex UIs by combining simple widgets.

## The Widget Concept

Widgets are the fundamental building blocks of Flitter UI. Following Flutter's philosophy, we've adopted the principle that "everything is a widget."

### Widget Characteristics

1. **Immutable**: Once created, widgets don't change
2. **Composable**: Combine small widgets to create complex UIs
3. **Reusable**: Use the same widget in multiple places

> **💡 Core Concept: Widget Philosophy**
> 
> Widgets are "blueprints" for UI. They declaratively describe what to draw on screen.
> 
> In practice, you combine small widgets like LEGO blocks to build complex UIs.

## Types of Widgets

Flitter widgets fall into three main categories:

### 1. Layout Widgets
Widgets that arrange and align space:

```typescript
// Vertical arrangement
Column({
  children: [widget1, widget2, widget3]
})

// Horizontal arrangement
Row({
  children: [widget1, widget2, widget3]
})

// Overlapping arrangement
Stack({
  children: [backgroundWidget, foregroundWidget]
})
```

### 2. Visual Widgets
Widgets that draw directly on screen:

```typescript
// Display text
Text("Hello Flitter")

// Colored box
Container({
  width: 100,
  height: 100,
  color: Colors.blue
})

// Display image
Image({ src: "image.png" })
```

### 3. Structural Widgets
Widgets that wrap others to add specific functionality:

```typescript
// Add padding
Padding({
  padding: EdgeInsets.all(10),
  child: Text("Text with padding")
})

// Center alignment
Center({
  child: Text("Centered text")
})

// Size constraints
SizedBox({
  width: 200,
  height: 50,
  child: Container({ color: Colors.red })
})
```

## The Power of Widget Composition

The true power of widgets comes from composition. Let's create a complex UI by combining simple widgets:

```typescript
// Creating a card UI
Container({
  padding: EdgeInsets.all(16),
  decoration: BoxDecoration({
    color: Colors.white,
    borderRadius: 8,
    boxShadow: [/* shadow effects */]
  }),
  child: Column({
    crossAxisAlignment: CrossAxisAlignment.start,
    children: [
      Text("Title", {
        style: new TextStyle({ fontSize: 20, fontWeight: 'bold' })
      }),
      SizedBox({ height: 8 }),
      Text("Content goes here...", {
        style: new TextStyle({ color: Colors.gray[600] })
      })
    ]
  })
})
```

## Understanding the Widget Tree

Widgets form a tree structure. Parent widgets contain child widgets, and these relationships continue hierarchically:

```
Container
  └─ Padding
      └─ Column
          ├─ Text("Title")
          ├─ SizedBox
          └─ Row
              ├─ Icon
              └─ Text("Subtitle")
```

> **💡 Tip**: Drawing the widget tree helps understand UI structure. When creating complex UIs, try sketching the tree structure first!

## Practical Tips: Widget Design Principles

### 1. Single Responsibility Principle
Design each widget to handle only one role:
- ❌ Putting too many features in one widget
- ✅ Combining small widgets to implement complex features

### 2. Consider Reusability
Create custom widgets for frequently used patterns:
```typescript
// Reusable card widget
function MyCard({ title, content }) {
  return Container({
    // Card styling
    child: Column({
      children: [
        Text(title),
        Text(content)
      ]
    })
  });
}
```

### 3. Performance Considerations
- Avoid unnecessary nesting
- Create heavy widgets only when needed
- Use virtualized widgets for lists

## Comparison with Flutter

Flitter's widget system is modeled after Flutter but optimized for the web environment:

| Feature | Flutter | Flitter |
|---------|---------|---------|
| Rendering | Skia Engine | SVG/Canvas |
| Platform | Mobile/Desktop | Web Browser |
| Language | Dart | TypeScript/JavaScript |
| State Management | setState, Provider, etc | setState, Context |
