# Row and Column - Basics of Linear Layout

Row and Column are the most important layout widgets in Flitter. Mastering these two widgets alone enables you to create most UI layouts.

## What You'll Learn

- [ ] Arranging widgets horizontally with Row
- [ ] Arranging widgets vertically with Column
- [ ] Mastering main axis alignment with MainAxisAlignment
- [ ] Understanding cross axis alignment with CrossAxisAlignment
- [ ] Creating flexible layouts with Expanded and Flexible
- [ ] Common layout patterns used in practice

## Basic Concepts of Row and Column

### Understanding Axes

Row and Column have two axes:

- **Main Axis**: The direction in which widgets are arranged
  - Row: Horizontal (left → right)
  - Column: Vertical (top → bottom)

- **Cross Axis**: The direction perpendicular to the main axis
  - Row: Vertical
  - Column: Horizontal

> **💡 Key Concept: Importance of Axes**
> 
> To understand Row and Column alignment, you must clearly understand the concepts of main axis and cross axis.
> MainAxisAlignment handles alignment along the main axis, while CrossAxisAlignment handles alignment along the cross axis.

## Step 1: Row - Horizontal Layout

The simplest Row example:

```typescript
Row({
  children: [
    Text("First"),
    Text("Second"),
    Text("Third")
  ]
})
```

### Adding Spacing

```typescript
Row({
  children: [
    Container({ width: 50, height: 50, color: Colors.red }),
    SizedBox({ width: 10 }),  // Horizontal spacing
    Container({ width: 50, height: 50, color: Colors.green }),
    SizedBox({ width: 10 }),
    Container({ width: 50, height: 50, color: Colors.blue })
  ]
})
```

## Step 2: Column - Vertical Layout

Basic Column usage:

```typescript
Column({
  children: [
    Text("Top"),
    Text("Middle"),
    Text("Bottom")
  ]
})
```

### Adding Spacing

```typescript
Column({
  children: [
    Container({ width: 50, height: 50, color: Colors.red }),
    SizedBox({ height: 10 }),  // Vertical spacing
    Container({ width: 50, height: 50, color: Colors.green }),
    SizedBox({ height: 10 }),
    Container({ width: 50, height: 50, color: Colors.blue })
  ]
})
```

## Step 3: MainAxisAlignment - Main Axis Alignment

### MainAxisAlignment Options

```typescript
// 1. start (default) - Align to start
Row({
  mainAxisAlignment: MainAxisAlignment.start,
  children: [...]
})

// 2. end - Align to end
Row({
  mainAxisAlignment: MainAxisAlignment.end,
  children: [...]
})

// 3. center - Center alignment
Row({
  mainAxisAlignment: MainAxisAlignment.center,
  children: [...]
})

// 4. spaceBetween - Place at ends, distribute middle evenly
Row({
  mainAxisAlignment: MainAxisAlignment.spaceBetween,
  children: [...]
})

// 5. spaceEvenly - Distribute all spacing evenly
Row({
  mainAxisAlignment: MainAxisAlignment.spaceEvenly,
  children: [...]
})

// 6. spaceAround - Equal spacing around each widget
Row({
  mainAxisAlignment: MainAxisAlignment.spaceAround,
  children: [...]
})
```

> **🎯 Pro Tip: When to Use Which Alignment?**
> - **center**: When center placement is needed for titles, logos, etc.
> - **spaceBetween**: Navigation bars, toolbars, etc.
> - **spaceEvenly**: Tab bars, evenly spaced button groups
> - **start/end**: Text or icons that need left/right alignment

## Step 4: CrossAxisAlignment - Cross Axis Alignment

### CrossAxisAlignment Options

```typescript
// 1. start - Start of cross axis
Column({
  crossAxisAlignment: CrossAxisAlignment.start,
  children: [
    Container({ width: 100, height: 30, color: Colors.red }),
    Container({ width: 150, height: 30, color: Colors.green }),
    Container({ width: 80, height: 30, color: Colors.blue })
  ]
})

// 2. center (default) - Center of cross axis
// 3. end - End of cross axis
// 4. stretch - Stretch along cross axis
Column({
  crossAxisAlignment: CrossAxisAlignment.stretch,
  children: [...]
})
```

## Step 5: Expanded and Flexible

### Expanded - Fill Remaining Space

```typescript
Row({
  children: [
    Container({ width: 50, height: 50, color: Colors.red }),
    Expanded({
      child: Container({ height: 50, color: Colors.green })
    }),
    Container({ width: 50, height: 50, color: Colors.blue })
  ]
})
```

### Controlling Ratios with flex Property

```typescript
Row({
  children: [
    Expanded({
      flex: 2,  // 2x space
      child: Container({ height: 50, color: Colors.red })
    }),
    Expanded({
      flex: 1,  // 1x space
      child: Container({ height: 50, color: Colors.green })
    }),
    Expanded({
      flex: 1,  // 1x space
      child: Container({ height: 50, color: Colors.blue })
    })
  ]
})
```

## Nested Layout Tips

You can create complex layouts by nesting Row and Column:

```typescript
Column({
  children: [
    Row({
      mainAxisAlignment: MainAxisAlignment.spaceBetween,
      children: [/* header */]
    }),
    Expanded({
      child: Row({
        children: [
          /* sidebar */
          Expanded({
            child: Column({
              children: [/* main content */]
            })
          })
        ]
      })
    }),
    Row({
      children: [/* footer */]
    })
  ]
})
```
