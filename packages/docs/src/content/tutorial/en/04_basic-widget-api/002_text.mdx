# Text - Displaying and Styling Text

The Text widget is the most basic widget for displaying text on screen. While it looks simple, it enables countless expressions through TextStyle.

## What You'll Learn

- [ ] Basic usage of the Text widget
- [ ] Applying various styles with TextStyle
- [ ] Adjusting font size, weight, and color
- [ ] Text decoration effects (underline, strikethrough, etc.)
- [ ] Text alignment and spacing control
- [ ] Common text patterns used in practice

## Text Widget Basics

The simplest form of Text widget:

```typescript
Text("Hello, World!")
```

To add styling, use TextStyle:

```typescript
Text("Styled text", {
  style: new TextStyle({
    fontSize: 20,
    color: Colors.blue[600]
  })
})
```

> **💡 Key Concept: Text Widget Characteristics**
> 
> - Only single style can be applied (use RichText for multiple styles)
> - Displays as single line by default, wraps automatically when overflowing
> - Size is determined by parent widget's constraints

## Step 1: Text Size and Weight

### fontSize - Text Size

```typescript
Text("Large Title", {
  style: new TextStyle({ fontSize: 32 })
})

Text("Small Description", {
  style: new TextStyle({ fontSize: 14 })
})
```

### fontWeight - Text Weight

```typescript
// String method
Text("Bold text", {
  style: new TextStyle({ fontWeight: "bold" })
})

// Numeric method (w100 ~ w900)
Text("Medium weight", {
  style: new TextStyle({ fontWeight: "w500" })
})
```

Weight options:
- `"normal"` or `"w400"`: Default weight
- `"bold"` or `"w700"`: Bold
- `"w100"` ~ `"w900"`: Fine control

## Step 2: Color and Style

### color - Text Color

```typescript
Text("Blue text", {
  style: new TextStyle({ 
    color: Colors.blue[600] 
  })
})

// Opacity control
Text("Semi-transparent text", {
  style: new TextStyle({ 
    color: Colors.black.withOpacity(0.5) 
  })
})
```

### fontStyle - Italic

```typescript
Text("Italic text", {
  style: new TextStyle({ 
    fontStyle: "italic" 
  })
})
```

## Step 3: Text Decoration

### decoration - Underline, Strikethrough, etc.

```typescript
// Underline
Text("Underlined text", {
  style: new TextStyle({ 
    decoration: "underline",
    decorationColor: Colors.blue[400]
  })
})

// Strikethrough
Text("Cancelled item", {
  style: new TextStyle({ 
    decoration: "lineThrough",
    decorationColor: Colors.red[400]
  })
})

// Overline
Text("Overlined text", {
  style: new TextStyle({ 
    decoration: "overline"
  })
})
```

### decorationStyle - Decoration Line Style

```typescript
Text("Dotted underline", {
  style: new TextStyle({ 
    decoration: "underline",
    decorationStyle: "dotted"
  })
})
```

Style options:
- `"solid"`: Solid line (default)
- `"double"`: Double line
- `"dotted"`: Dotted line
- `"dashed"`: Dashed line
- `"wavy"`: Wavy line

## Step 4: Spacing and Height

### letterSpacing - Letter Spacing

```typescript
Text("Text with wide letter spacing", {
  style: new TextStyle({ 
    letterSpacing: 2.0 
  })
})
```

### wordSpacing - Word Spacing

```typescript
Text("Text with wide word spacing", {
  style: new TextStyle({ 
    wordSpacing: 5.0 
  })
})
```

### height - Line Height

```typescript
Text("Text with\nwide\nline spacing", {
  style: new TextStyle({ 
    height: 2.0  // Multiple of fontSize
  })
})
```

## Step 5: Text Alignment

### textAlign - Text Alignment

```typescript
Container({
  width: 300,
  child: Text("Center aligned", {
    textAlign: "center"
  })
})
```

Alignment options:
- `"left"`: Left align (default)
- `"right"`: Right align
- `"center"`: Center align
- `"justify"`: Justify

## Advanced Tip: Reusing TextStyle

Save frequently used styles as variables for reuse:

```typescript
// Define styles
const headingStyle = new TextStyle({
  fontSize: 20,
  fontWeight: "bold",
  color: Colors.gray[800]
});

const bodyStyle = new TextStyle({
  fontSize: 14,
  height: 1.5,
  color: Colors.gray[600]
});

// Use
Text("Title", { style: headingStyle })
Text("Body content", { style: bodyStyle })
```
