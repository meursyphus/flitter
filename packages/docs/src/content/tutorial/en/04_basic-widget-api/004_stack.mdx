# Stack - Widget Overlaying and Absolute Positioning

Stack is a powerful layout widget that allows you to overlay widgets on top of each other. It's essential for implementing various UI patterns like floating buttons, badges, and overlays.

## What You'll Learn

- [ ] Basic concepts of Stack and widget overlaying
- [ ] Absolute positioning with Positioned
- [ ] Relative alignment with Align
- [ ] Controlling overflow with clipBehavior
- [ ] Practical UI patterns using Stack
- [ ] Understanding z-index and rendering order

## Basic Concepts of Stack

Stack displays its children widgets overlapped:

- **Rendering order**: Earlier widgets are rendered below, later widgets on top
- **Size**: Follows the size of the largest child or parent's constraints
- **Position**: Aligned to top-left by default, adjustable with Positioned or Align

> **💡 Key Concept: Stack vs Row/Column**
> 
> - Row/Column: Arrange widgets side by side (linear layout)
> - Stack: Overlay widgets on top of each other (absolute layout)
> 
> Think of Stack as a layout that utilizes the z-axis (depth).

## Step 1: Basic Stack Usage

The simplest Stack example:

```typescript
Stack({
  children: [
    // Bottom (background)
    Container({
      width: 200,
      height: 200,
      color: Colors.blue[200]
    }),
    // Middle layer
    Container({
      width: 150,
      height: 150,
      color: Colors.green[200]
    }),
    // Top (foreground)
    Container({
      width: 100,
      height: 100,
      color: Colors.red[200]
    })
  ]
})
```

### Understanding Rendering Order

The order in the children array determines the rendering order:
- Index 0: Bottom-most
- Index 1: Above that
- Index 2: Top-most

## Step 2: Positioned - Absolute Positioning

With Positioned, you can specify exact positions within a Stack:

```typescript
Stack({
  children: [
    // Background
    Container({ color: Colors.gray[200] }),
    
    // 10 pixels from top-left
    Positioned({
      top: 10,
      left: 10,
      child: Container({
        width: 50,
        height: 50,
        color: Colors.red
      })
    }),
    
    // 10 pixels from bottom-right
    Positioned({
      bottom: 10,
      right: 10,
      child: Container({
        width: 50,
        height: 50,
        color: Colors.blue
      })
    })
  ]
})
```

### Positioned Properties

- **top**: Distance from top
- **bottom**: Distance from bottom
- **left**: Distance from left
- **right**: Distance from right
- **width/height**: Size specification (optional)

> **🎯 Pro Tip: Positioned Usage Rules**
> - Specifying both top and bottom auto-calculates height
> - Specifying both left and right auto-calculates width
> - Specifying all four fills the entire area

## Step 3: Align - Relative Alignment

Align allows more intuitive positioning using Alignment:

```typescript
Stack({
  children: [
    // Center
    Align({
      alignment: Alignment.center,
      child: Text("Center")
    }),
    
    // Top left
    Align({
      alignment: Alignment.topLeft,
      child: Text("Top Left")
    }),
    
    // Bottom right
    Align({
      alignment: Alignment.bottomRight,
      child: Text("Bottom Right")
    })
  ]
})
```

### Alignment Options

```typescript
// Basic alignment options
Alignment.topLeft      // Top left
Alignment.topCenter    // Top center
Alignment.topRight     // Top right
Alignment.centerLeft   // Center left
Alignment.center       // Center
Alignment.centerRight  // Center right
Alignment.bottomLeft   // Bottom left
Alignment.bottomCenter // Bottom center
Alignment.bottomRight  // Bottom right

// Custom alignment (x, y range from -1.0 to 1.0)
new Alignment(0.5, -0.5)  // x: 50% to right, y: 50% up
```

## Step 4: clipBehavior - Overflow Control

Determines how to handle widgets that extend beyond the Stack's boundaries:

```typescript
Stack({
  clipBehavior: "none",  // No clipping (default)
  children: [
    Container({
      width: 100,
      height: 100,
      color: Colors.blue
    }),
    Positioned({
      top: -10,  // Extends outside Stack area
      right: -10,
      child: Container({
        width: 30,
        height: 30,
        color: Colors.red
      })
    })
  ]
})
```

clipBehavior options:
- `"none"`: No clipping
- `"hardEdge"`: Sharp clipping
- `"antiAlias"`: Smooth clipping
- `"antiAliasWithSaveLayer"`: Smoother (higher performance cost)

## Step 5: Practical Example - Profile Card

```typescript
Container({
  width: 300,
  height: 200,
  child: Stack({
    children: [
      // Background image
      Positioned.fill({
        child: Container({
          decoration: new BoxDecoration({
            gradient: new LinearGradient({
              colors: [Colors.blue[400], Colors.purple[400]],
              begin: Alignment.topLeft,
              end: Alignment.bottomRight
            })
          })
        })
      }),
      
      // Gradient overlay
      Positioned.fill({
        child: Container({
          decoration: new BoxDecoration({
            gradient: new LinearGradient({
              colors: [
                Colors.transparent,
                "rgba(0, 0, 0, 0.7)"
              ],
              begin: Alignment.topCenter,
              end: Alignment.bottomCenter
            })
          })
        })
      }),
      
      // Profile info
      Positioned({
        bottom: 20,
        left: 20,
        right: 20,
        child: Column({
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Text("John Flutter", {
              style: new TextStyle({
                color: Colors.white,
                fontSize: 24,
                fontWeight: "bold"
              })
            }),
            SizedBox({ height: 4 }),
            Text("Flutter & Flitter Developer", {
              style: new TextStyle({
                color: "rgba(255, 255, 255, 0.8)",
                fontSize: 16
              })
            })
          ]
        })
      }),
      
      // Favorite button
      Positioned({
        top: 16,
        right: 16,
        child: Container({
          width: 40,
          height: 40,
          decoration: new BoxDecoration({
            color: "rgba(255, 255, 255, 0.2)",
            shape: BoxShape.circle
          }),
          child: Center({
            child: Text("⭐", { style: new TextStyle({ fontSize: 20 }) })

        })
      })
    ]
  })
})
```

## Advanced Pattern: IndexedStack

When you want to show only one widget among many:

```typescript
IndexedStack({
  index: currentIndex,  // 0, 1, 2...
  children: [
    // Visible only when index is 0
    Container({ color: Colors.red }),
    // Visible only when index is 1
    Container({ color: Colors.green }),
    // Visible only when index is 2
    Container({ color: Colors.blue })
  ]
})
```

## Stack Usage Considerations

1. **Performance**: Too many overlapping widgets can degrade performance
2. **Size**: Layout issues can occur if Stack size is unclear
3. **Accessibility**: Be careful that touch areas of overlapping widgets don't overlap
