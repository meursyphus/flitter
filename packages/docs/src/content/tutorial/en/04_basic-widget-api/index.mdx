# Chapter 4: Basic Widget API

In this chapter, we'll explore Flitter's most fundamental yet powerful widgets one by one. These widgets are the building blocks that form the foundation of every Flitter app.

## 🎯 Learning Objectives

By completing this chapter, you will:
- Master all features of Container, Text, Row/Column, and Stack
- Fully understand each widget's properties and usage patterns
- Acquire layout techniques you can immediately apply in practice
- Be able to implement complex UIs using combinations of basic widgets

## 📚 Chapter Structure

### [1. Container - The Foundation Box](./001_container)
- Setting size, color, padding, and margin
- Adding visual effects with BoxDecoration
- Using constraints effectively
- Building practical card UIs

### [2. Text - Displaying and Styling Text](./002_text)
- Mastering all TextStyle properties
- Font size, weight, color, and decoration effects
- Text alignment and spacing control
- Reusable text style patterns

### [3. Row and Column - Basics of Linear Layout](./003_row-column)
- Understanding Main Axis and Cross Axis
- 6 MainAxisAlignment options
- 4 CrossAxisAlignment options
- Flexible layouts with Expanded and Flexible

### [4. Stack - Widget Overlaying and Absolute Positioning](./004_stack)
- Layered layouts using the Z-axis
- Absolute positioning with Positioned
- Relative alignment with Align
- Implementing badges, overlays, and FABs

## 🛠 Hands-on Learning

Each tutorial includes:
- **Interactive Code Editor**: Run immediately and see results
- **Step-by-step Explanation**: From concepts to advanced usage
- **Practical Examples**: Patterns used in real apps
- **Practice Exercises**: Improve skills by solving on your own

## 💡 Learning Tips

1. **Learn in Order**: Each widget builds on previous content
2. **Modify Code Directly**: Experiment by changing values in the editor
3. **Challenge Practice Exercises**: Try before looking at hints
4. **Practice Combinations**: Create complex UIs by combining multiple widgets

## 🎨 What You'll Be Able to Build

- 🛒 Shopping app product lists
