# Align and Center - The Art of Alignment

Proper alignment is crucial for creating beautiful and professional UIs. The Align and Center widgets provide powerful tools for positioning widgets exactly where you want them.

## What You'll Learn

- [ ] Simple center alignment with Center widget
- [ ] 9 basic positions with Align widget
- [ ] Custom positioning with Alignment values
- [ ] Advanced patterns combining with Stack
- [ ] Performance considerations for alignment
- [ ] Common alignment patterns in UI design

## Center Widget - The Simplest Solution

The Center widget is the most straightforward way to center a child widget:

```typescript
Center({
  child: Text("Centered content")
})
```

### When to Use Center

- Simple center alignment needs
- Single widget centering
- Quick prototyping
- Clear intent expression

## Align Widget - Precise Control

The Align widget offers much more control over positioning:

```typescript
Align({
  alignment: Alignment.topRight,
  child: Text("Top right corner")
})
```

### 9 Basic Alignment Positions

```typescript
// Top row
Alignment.topLeft      // Top left corner
Alignment.topCenter    // Top center
Alignment.topRight     // Top right corner

// Middle row  
Alignment.centerLeft   // Middle left
Alignment.center       // Perfect center
Alignment.centerRight  // Middle right

// Bottom row
Alignment.bottomLeft   // Bottom left corner
Alignment.bottomCenter // Bottom center
Alignment.bottomRight  // Bottom right corner
```

## Custom Alignment - Pixel Perfect

Create custom positions using Alignment coordinates:

```typescript
// Custom alignment (x, y range from -1.0 to 1.0)
Align({
  alignment: new Alignment(0.5, -0.3),  // 50% right, 30% up from center
  child: MyWidget()
})
```

### Understanding Alignment Coordinates

- **X-axis**: -1.0 (far left) to 1.0 (far right)
- **Y-axis**: -1.0 (top) to 1.0 (bottom)
- **Center**: (0.0, 0.0)

## Practical Examples

### Navigation Bar Alignment

```typescript
Container({
  height: 60,
  padding: EdgeInsets.symmetric({ horizontal: 16 }),
  child: Row({
    children: [
      // Left side - Logo
      Align({
        alignment: Alignment.centerLeft,
        child: Text("Logo")
      }),
      // Right side - Menu
      Align({
        alignment: Alignment.centerRight,
        child: Row({
          children: [
            Text("Menu"),
            SizedBox({ width: 16 }),
            Text("Profile")
          ]
        })
      })
    ]
  })
})
```

### Floating Action Button

```typescript
Stack({
  children: [
    // Main content
    MyMainContent(),
    // FAB positioned at bottom right
    Align({
      alignment: Alignment.bottomRight,
      child: Container({
        margin: EdgeInsets.all(16),
        child: FloatingActionButton()
      })
    })
  ]
})
```

## Advanced Patterns

### Multiple Aligned Elements

```typescript
Stack({
  children: [
    // Background
    Container({ color: Colors.gray[200] }),
    // Top left badge
    Align({
      alignment: Alignment.topLeft,
      child: Container({
        margin: EdgeInsets.all(8),
        child: Badge("New")
      })
    }),
    // Bottom right action
    Align({
      alignment: Alignment.bottomRight,
      child: Container({
        margin: EdgeInsets.all(8),
        child: ActionButton()
      })
    }),
    // Center content
    Center({
      child: MainContent()
    })
  ]
})
```

## Performance Tips

1. **Use Center for simple cases**: More efficient than Align with center alignment
2. **Avoid unnecessary nesting**: Don't wrap in extra containers
3. **Prefer specific widgets**: Use Center instead of Align when possible

## Common Patterns

### Card with Corner Badge

```typescript
Stack({
  children: [
    // Main card
    Container({
      width: 200,
      height: 150,
      decoration: new BoxDecoration({
        color: Colors.white,
        borderRadius: BorderRadius.circular(8)
      }),
      child: Center({
        child: Text("Card Content")
      })
    }),
    // Corner badge
    Align({
      alignment: Alignment.topRight,
      child: Container({
        margin: EdgeInsets.all(8),
        padding: EdgeInsets.symmetric({ horizontal: 8, vertical: 4 }),
        decoration: new BoxDecoration({
          color: Colors.red,
          borderRadius: BorderRadius.circular(12)
        }),
        child: Text("Sale", {
          style: TextStyle({ color: Colors.white, fontSize: 12 })
        })
      })
    })
  ]
})
```
