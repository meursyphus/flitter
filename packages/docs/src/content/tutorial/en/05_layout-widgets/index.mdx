## 🏗 Layout Design Principles

### 1. Space Consistency
```typescript
// 8px-based spacing system
const spacing = {
  xs: 4,
  sm: 8,
  md: 16,
  lg: 24,
  xl: 32
};
```

### 2. Alignment Clarity
```typescript
// Express intent clearly
Center({ child: Logo() })  // Simple center alignment
Align({ alignment: Alignment.topRight })  // Specific position
```

### 3. Flexible Sizing
```typescript
// Fixed vs flexible
Row({
  children: [
    FixedWidth({ width: 100 }),  // Fixed
    Expanded({ child: FlexibleContent() })  // Flexible
  ]
})
```

### 4. Ratio Consistency
```typescript
// Design system ratios
AspectRatio({ aspectRatio: 16/9 })  // Video
AspectRatio({ aspectRatio: 1.0 })   // Square
AspectRatio({ aspectRatio: 1.618 }) // Golden ratio
```
