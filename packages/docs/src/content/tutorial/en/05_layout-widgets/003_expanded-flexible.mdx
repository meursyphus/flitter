# Expanded and Flexible - Space Distribution

Creating responsive and flexible layouts is essential for modern UI design. The Expanded and Flexible widgets provide powerful tools for distributing space intelligently among child widgets.

## What You'll Learn

- [ ] Fill remaining space with Expanded
- [ ] Control space ratios with flex property
- [ ] Understand differences between Flexible and Expanded
- [ ] Create responsive layouts
- [ ] Common flexible layout patterns
- [ ] Performance considerations

## Expanded Widget - Fill Available Space

The Expanded widget forces its child to fill all available space in the main axis:

```typescript
Row({
  children: [
    Container({ width: 100, height: 50, color: Colors.red }),
    Expanded({
      child: Container({ height: 50, color: Colors.green })
    }),
    Container({ width: 100, height: 50, color: Colors.blue })
  ]
})
```

### Key Characteristics

- **Forces expansion**: Child must fill available space
- **Main axis only**: Only affects the direction of Row/Column
- **Cannot shrink**: Will not be smaller than available space

## Flex Property - Control Ratios

Use the `flex` property to control how much space each Expanded widget gets:

```typescript
Row({
  children: [
    Expanded({
      flex: 1,  // Gets 1/6 of space
      child: Container({ color: Colors.red })
    }),
    Expanded({
      flex: 2,  // Gets 2/6 of space
      child: Container({ color: Colors.green })
    }),
    Expanded({
      flex: 3,  // Gets 3/6 of space
      child: Container({ color: Colors.blue })
    })
  ]
})
```

### Flex Ratio Calculation

- Total flex: 1 + 2 + 3 = 6
- First widget: 1/6 ≈ 16.7% of space
- Second widget: 2/6 ≈ 33.3% of space  
- Third widget: 3/6 = 50% of space

## Flexible Widget - Take Only What You Need

The Flexible widget allows its child to occupy available space but doesn't force it:

```typescript
Row({
  children: [
    Container({ width: 100, height: 50, color: Colors.red }),
    Flexible({
      child: Container({ height: 50, color: Colors.green, width: 50 })
    }),
    Container({ width: 100, height: 50, color: Colors.blue })
  ]
})
```

### Flexible vs Expanded

| Aspect | Flexible | Expanded |
|--------|----------|----------|
| **Space usage** | Only what child needs | All available space |
| **Can be smaller** | Yes | No |
| **Forces size** | No | Yes |
| **Use case** | Variable content | Space filling |

## Advanced Patterns

### Responsive Grid

```typescript
Row({
  children: [
    Expanded({
      flex: screenWidth > 768 ? 2 : 1,
      child: LeftPanel()
    }),
    if (screenWidth > 480) ...[
      SizedBox({ width: 16 }),
      Expanded({
        flex: 1,
        child: RightPanel()
      })
    ]
  ]
})
```

### Form Layout

```typescript
Column({
  children: [
    // Form fields take minimum space
    Flexible({
      child: Column({
        children: formFields.map((field) => 
          Padding({
            padding: EdgeInsets.only({ bottom: 16 }),
            child: TextFormField({ label: field.label })
          })
        )
      })
    }),
    // Spacer pushes buttons to bottom
    Expanded({
      child: SizedBox()
    }),
    // Action buttons (fixed at bottom)
    Row({
      children: [
        Expanded({
          child: SecondaryButton({ text: "Cancel" })
        }),
        SizedBox({ width: 16 }),
        Expanded({
          child: PrimaryButton({ text: "Submit" })
        })
      ]
    })
  ]
})
```

## Performance Tips

1. **Avoid unnecessary Expanded**: Only use when space distribution is needed
2. **Use Flexible for optional expansion**: When content might not need all space
3. **Consider intrinsic dimensions**: Some widgets have natural sizes
4. **Test on different screen sizes**: Ensure responsive behavior

## Common Patterns

### Three-Column Layout

```typescript
Row({
  children: [
    // Left sidebar (25%)
    Expanded({
      flex: 1,
      child: Sidebar()
    }),
    // Main content (50%)
    Expanded({
      flex: 2,
      child: MainContent()
    }),
    // Right panel (25%)
    Expanded({
      flex: 1,
      child: RightPanel()
    })
  ]
})
```

### Progressive Disclosure

```typescript
Column({
  children: [
    // Always visible summary
    SummaryCard(),
    SizedBox({ height: 16 }),
    // Expandable details
    if (showDetails) ...[
      Expanded({
        child: DetailView()
      })
    ] else ...[
      Flexible({
        child: PreviewCard()
      })
    ]
  ]
})
```
