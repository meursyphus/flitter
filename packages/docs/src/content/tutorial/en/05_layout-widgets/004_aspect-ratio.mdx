# AspectRatio - Maintaining Proportions

The AspectRatio widget ensures your UI elements maintain consistent width-to-height proportions across different screen sizes. This is essential for creating professional, visually pleasing layouts.

## What You'll Learn

- [ ] Maintain consistent width-to-height ratios
- [ ] Use common aspect ratios (16:9, 4:3, 1:1)
- [ ] Create responsive image containers
- [ ] Build professional gallery layouts
- [ ] Design proportional cards and media players
- [ ] Apply the golden ratio in UI design

## Understanding Aspect Ratios

An aspect ratio is the proportional relationship between width and height:

```typescript
AspectRatio({
  aspectRatio: 16/9,  // Width:Height = 16:9
  child: Container({
    color: Colors.blue,
    child: Center({
      child: Text("16:9 Video")
    })
  })
})
```

### Common Aspect Ratios

- **16:9** (1.778): Widescreen video, modern monitors
- **4:3** (1.333): Classic TV, presentations  
- **1:1** (1.0): Square images, profile pictures
- **3:4** (0.75): Portrait photos, mobile screens
- **1.618**: Golden ratio, aesthetically pleasing

## Basic Usage

The AspectRatio widget forces its child to maintain the specified ratio:

```typescript
AspectRatio({
  aspectRatio: 2.0,  // 2:1 ratio (twice as wide as tall)
  child: Container({
    color: Colors.green,
    child: Center({
      child: Text("2:1 Rectangle")
    })
  })
})
```

### How It Works

1. **Calculates dimensions**: Based on available space and ratio
2. **Constrains child**: Forces child to fit the calculated size
3. **Maintains ratio**: Regardless of parent container changes

## Responsive Design with AspectRatio

### Mobile-First Approach

```typescript
LayoutBuilder({
  builder: (context, constraints) => {
    final isMobile = constraints.maxWidth < 600;
    
    return AspectRatio({
      aspectRatio: isMobile ? 9/16 : 16/9,  // Portrait on mobile, landscape on desktop
      child: Container({
        color: Colors.blue,
        child: Center({
          child: Text(isMobile ? "Mobile View" : "Desktop View")
        })
      })
    });
  }
})
```

### Dynamic Grid

```typescript
GridView.builder({
```

## Performance Considerations

1. **Efficient constraints**: AspectRatio calculates optimal size efficiently
2. **Image optimization**: Use appropriate image sizes for aspect ratios
3. **Avoid deep nesting**: Keep AspectRatio close to content widgets
4. **Cache calculations**: Aspect ratio calculations are cached automatically

## Design Guidelines

### Choosing Aspect Ratios

- **Video content**: Use 16:9 for modern video players
- **Images**: 4:3 for classic photos, 1:1 for thumbnails
- **Cards**: Golden ratio (1.618) for aesthetically pleasing proportions
- **Banners**: 21:9 or 32:9 for wide hero sections

### Consistency Rules

```typescript
// Define ratios in a design system
class AspectRatios {
  static const double video = 16/9;
  static const double square = 1.0;
  static const double card = 1.618;  // Golden ratio
  static const double banner = 21/9;
}

// Use consistently throughout app
AspectRatio({
  aspectRatio: AspectRatios.video,
  child: VideoPlayer()
})
```
