# Development Tools Setup

Let's configure VS Code and various tools for efficient Flitter development. This setup will enable code completion, debugging, hot reload, and more.

## What You'll Learn

- [ ] Install and configure VS Code extensions
- [ ] Set up TypeScript support
- [ ] Configure debugging environment
- [ ] Automate code formatting
- [ ] Development productivity tips

## Step 1: Essential VS Code Extensions

Install these extensions:

### Required Extensions
1. **Prettier** - Code formatter
2. **ESLint** - Code quality checker
3. **TypeScript and JavaScript Language Features** - TS/JS support
4. **Path Intellisense** - File path autocomplete

### Recommended Extensions
- **Color Highlight** - Visualize color codes
- **Indent Rainbow** - Visualize indentation
- **Code Spell Checker** - Spell checking
- **TODO Highlight** - Highlight TODO comments

> **💡 Tip**: Create a `.vscode/extensions.json` file so team members can easily install recommended extensions.

## Step 2: TypeScript Configuration

Flitter provides full TypeScript support. Take advantage of type hints and autocomplete.

### Key tsconfig.json Settings
```json
{
  "compilerOptions": {
    "strict": true,              // Strict type checking
    "jsx": "react-jsx",          // JSX support
    "moduleResolution": "bundler", // Module resolution
    "resolveJsonModule": true    // JSON import support
  }
}
```

### Using Type Autocomplete
```typescript
import { Container, Text, Colors } from "@meursyphus/flitter";

// Autocomplete shows all Container props
Container({
  width: 200,    // number
  height: 100,   // number
  color: Colors. // Autocomplete shows all colors
});
```

## Step 3: Debugging Setup

Configure VS Code for direct debugging.

### Create launch.json
1. Press F5 or click Debug tab in VS Code
2. Select "create a launch.json file"
3. Choose Chrome
4. Replace with launch.json content above

### How to Debug
1. Set breakpoints (click left of line numbers)
2. Press F5 to start debugging
3. Chrome opens automatically
4. Check variable values and step through code in VS Code

> **🔥 Advanced**: Use with React DevTools to visually inspect widget tree and state.

## Step 4: Automated Code Formatting

Set up Prettier and ESLint for consistent code style.

### Prettier Configuration (.prettierrc)
```json
{
  "semi": true,              // Use semicolons
  "singleQuote": false,      // Use double quotes
  "tabWidth": 2,             // Tab size
  "trailingComma": "es5"     // ES5 compatible commas
}
```

### VS Code Auto-Formatting
Add to settings.json:
```json
{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode"
}
```

Now your code is automatically formatted on save!

## Step 5: Development Productivity Tips

### 1. Create Code Snippets
Create snippets for frequently used patterns:

```json
// .vscode/flitter.code-snippets
{
  "Stateful Widget": {
    "prefix": "stful",
    "body": [
      "class ${1:WidgetName} extends StatefulWidget {",
      "  createState() {",
      "    return new ${1:WidgetName}State();",
      "  }",
      "}",
      "",
      "class ${1:WidgetName}State extends State {",
      "  build(context) {",
      "    return Container({",
      "      child: Text('$2')",
      "    });",
      "  }",
      "}"
    ]
  }
}
```

### 2. Use Hot Reload
React's Fast Refresh supports Flitter widgets:
- Preserves state while updating UI
- See changes instantly
- Improves development speed

### 3. Set Up Terminal Commands
Add useful scripts to package.json:
```json
{
  "scripts": {
    "dev": "react-scripts start",
    "lint": "eslint src --fix",
    "format": "prettier --write src/**/*"
  }
}
```

## 🐛 Troubleshooting

### TypeScript errors persist
```bash
# Restart TypeScript server
Ctrl+Shift+P → "TypeScript: Restart TS Server"
```

### Autocomplete not working
```bash
# Reinstall node_modules
rm -rf node_modules package-lock.json
npm install
```

### Debugging not working
- Check if Chrome DevTools is already open
- Verify sourceMaps settings
- Ensure port numbers match (default: 3000)
