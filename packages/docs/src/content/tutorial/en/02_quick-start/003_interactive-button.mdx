    // State class manages the actual state
    class CounterButtonState extends State {
      count = 0;  // State variable
      
      // Click handler
      handleClick = () => {
        this.setState(() => {
          this.count++;
        });
      }
      
      build(context) {
        // Handle click events with GestureDetector
        return GestureDetector({
          onClick: this.handleClick,
          child: Container({
            width: 200,
            height: 60,
            padding: EdgeInsets.all(16),
            decoration: {
              color: Colors.blue[500],
              borderRadius: 8,
              boxShadow: [
                {

                  offset: { x: 0, y: 2 },
                  blurRadius: 4
                }
              ]
            },
            child: Center({
              child: Text(`Clicked: ${this.count} times`, {
                style: new TextStyle({
                  fontSize: 20,
                  fontWeight: 'bold',
                  color: Colors.white
                })
              })
            })
          })
        });
      }
    }

      const widget = new CounterButton();

# Creating a Simple Interactive Button

Let's create a button that interacts with users! We'll use Flitter's StatefulWidget and GestureDetector to build a button that increments a counter with each click.

## What You'll Learn

- [ ] Managing state with StatefulWidget
- [ ] Understanding State class and setState()
- [ ] Handling click events with GestureDetector
- [ ] Dynamically updating UI
- [ ] Advanced button styling

## Step 1: Understanding StatefulWidget

StatefulWidget is a widget that has mutable state. Use it when creating UI that changes based on user interaction or over time.

```typescript
class CounterButton extends StatefulWidget {
  createState() {
    return new CounterButtonState();
  }
}
```

> **💡 Core Concept: StatefulWidget vs StatelessWidget**
> 
> - **StatelessWidget**: Immutable widgets that don't change (e.g., logos, titles)
> - **StatefulWidget**: Widgets with state that can change (e.g., buttons, forms, animations)
> 
> StatefulWidget creates a State object through the createState() method.

## Step 2: Creating the State Class

The State class manages the actual state and builds the UI.

```typescript
class CounterButtonState extends State<CounterButton> {
  count = 0;  // State variable declaration
  
  build(context) {
    // Return UI
  }
}
```

### Declaring State Variables

Declare state as class properties:

```typescript
count = 0;  // Initial value 0
```

## Step 3: Updating State with setState()

Always use setState() when changing state. This tells Flitter to re-render the UI.

```typescript
handleClick = () => {
  this.setState(() => {
    this.count++;  // State change
  });
}
```

> **⚠️ Warning**: Changing state directly without setState() won't update the UI!
> ```typescript
> // ❌ Wrong way
> this.count++;
> 
> // ✅ Correct way
> this.setState(() => {
>   this.count++;
> });
> ```

## Step 4: Handling Events with GestureDetector

GestureDetector detects various gestures like taps, drags, and hovers.

```typescript
GestureDetector({
  onClick: this.handleClick,  // Click event handler
  child: Container({...})     // Clickable area
})
```

### Supported Events:
- `onClick`: Click/tap
- `onDoubleClick`: Double click
- `onMouseEnter`: Mouse hover start
- `onMouseLeave`: Mouse hover end
- `onMouseMove`: Mouse movement

## Step 5: Button Styling

Create a more attractive button using Container's decoration property:

```typescript
Container({
  decoration: {
    color: Colors.blue[500],
    borderRadius: 8,  // Rounded corners
    boxShadow: [      // Shadow effect
      {
        color: Colors.black.withOpacity(0.2),
        offset: { x: 0, y: 2 },
        blurRadius: 4
      }
    ]
  }
})
```
