    import ReactWidget from "@meursyphus/flitter-react";
    import { Container, Text, TextStyle, Colors, Center } from "@meursyphus/flitter";

    function App() {
      // Create basic layout with Container widget
      const widget = Container({
        width: 400,
        height: 200,
        color: Colors.green[200],
        child: Center({
          child: Text("🌟 Hello, Flitter World! 🌟", {

              fontWeight: 'bold',

# Your First "Hello World" App

Now let's create an actual working app using Flitter's basic widgets! We'll build a simple but functional Hello World app that introduces you to Flitter's core concepts.

## What You'll Learn

- [ ] Basic usage of Container widget
- [ ] Text widget and styling
- [ ] Center widget for alignment
- [ ] Using the Colors system
- [ ] Rendering Flitter widgets with ReactWidget

## Step 1: Understanding the Container Widget

Container is the most fundamental widget in Flitter. It can hold a single child widget and allows you to set dimensions, colors, padding, and more.

```typescript
Container({
  width: 400,     // Set width
  height: 200,    // Set height
  color: Colors.green[200],  // Set background color
  child: /* child widget */
})
```

> **💡 Core Concept: Container Widget**
> 
> Container works exactly like Flutter's Container. It operates on a box model and can have one child.
> 
> In real-world projects, it's used as the foundation for cards, buttons, sections, and other UI elements.

## Step 2: Text Widget and Styling

The Text widget displays text content. You can customize its appearance using TextStyle to set font size, color, weight, and more.

```typescript
Text("🌟 Hello, Flitter World! 🌟", {
  style: new TextStyle({
    fontSize: 28,
    fontWeight: 'bold',
    color: Colors.green[800]
  })
})
```

## Step 3: Center Widget for Alignment

The Center widget aligns its child to the center. It's simple but frequently used in layouts.

```typescript
Center({
  child: Text("Centered text")
})
```

## Step 4: Colors System

Flitter provides Material Design's color palette. Each color has shades from 50 to 900.

```typescript
Colors.green[200]  // Light green
Colors.green[800]  // Dark green
Colors.blue[500]   // Default blue
Colors.red[300]    // Light red
```

> **💡 Tip**: Use the Colors system for consistent design. Light colors (200-300) work great for backgrounds, while dark colors (700-900) are perfect for text!

## Step 5: Rendering with ReactWidget

Finally, wrap your Flitter widget with ReactWidget to render it in your React app.

```typescript
<ReactWidget widget={widget} />
```
