# Installation & Setup

Ready to create amazing charts and diagrams with Flitter? You'll be up and running in just 5 minutes!

## What You'll Learn

- [ ] Verify Node.js and npm environment
- [ ] Create a new React project
- [ ] Install Flitter packages
- [ ] Confirm development server is running

## Prerequisites

Before we start, make sure you have the following installed:

### Node.js (v16 or higher)
```bash
node --version
npm --version
```

If you haven't installed it yet, download the latest LTS version from [nodejs.org](https://nodejs.org/).

## Step 1: Create a New React Project

Open your terminal and run the following commands:

```bash
# Create a new project with Create React App
npx create-react-app my-flitter-app
cd my-flitter-app
```

> **💡 Tip**: You can change the project name to whatever you like. For example: `my-chart-project`, `dashboard-app`, etc.!

## Step 2: Install Flitter Packages

Now let's install the core Flitter packages:

```bash
# Flitter core library
npm install @meursyphus/flitter

# React integration package  
npm install @meursyphus/flitter-react

# Chart library (optional)
npm install @meursyphus/flitter-chart
```

> **🔥 Advanced**: If you're using TypeScript, no additional setup is required. Flitter provides full TypeScript support!

## Step 3: Verify Installation

Let's verify that everything is installed correctly. Modify your `src/App.js` file as follows:

```jsx
import ReactWidget from "@meursyphus/flitter-react";
import { Container, Text, TextStyle, Colors } from "@meursyphus/flitter";

function App() {
  // Create a simple Flitter widget
  const widget = Container({
    width: 300,
    height: 100,
    color: Colors.blue[100],
    child: Text("🎉 Flitter Setup Complete!", {
      style: new TextStyle({ 
        fontSize: 24,
        fontWeight: 'bold',
        color: Colors.blue[800]
      })
    })
  });

  return (
    <div style={{ padding: '20px' }}>
      <h1>Getting Started with Flitter</h1>
      <ReactWidget widget={widget} />
    </div>
  );
}

export default App;
```

## Step 4: Run the Development Server

Now start the development server:

```bash
npm start
```

Your browser should automatically open and you should see the following at `http://localhost:3000`:

- "Getting Started with Flitter" heading
- "🎉 Flitter Setup Complete!" message with a blue background

> **💡 Core Concept: ReactWidget**
> 
> `ReactWidget` is the bridge that allows you to use Flitter widgets within React components.
> 
> In real-world projects, you'll create complex charts or diagrams with Flitter and integrate them into React apps using ReactWidget.

## 🐛 Troubleshooting

### "Module not found" errors
```bash
# Delete node_modules and reinstall
rm -rf node_modules package-lock.json
npm install
```

### Development server won't start
```bash
# Check for port conflicts and use a different port
npm start -- --port 3001
```

### TypeScript errors
```bash
# For TypeScript projects, verify type definitions
npm install --save-dev @types/react @types/react-dom
```
