## 📚 核心概念：什么是组件？

在 Flitter 中，**Widget（组件）**是构建 UI 的基本单元。一切都由组件构成，您可以组合组件来创建复杂的 UI。

### 组件特性

1. **不可变性**：一旦创建，组件就不能更改
2. **可组合性**：组件可以嵌套在其他组件内部以创建复杂结构
3. **可重用性**：同一个组件可以在多个地方使用

## 🏗️ 理解 Container 组件

**Container** 是 Flitter 中最基础的组件之一。它用于创建盒子并应用样式。

### Container 的主要属性

```typescript
Container({
  // 尺寸设置
  width: 200,           // 宽度（像素）
  height: 100,          // 高度（像素）
  
  // 颜色和样式
  color: '#ff0000',     // 背景颜色（十六进制代码）
  
  // 边距设置
  padding: EdgeInsets.all(16), // 内边距
  margin: EdgeInsets.all(8),   // 外边距
  
  // 子组件
  child: Text('Hello')  // 单个子组件
})
```

### 边距设置方法

```typescript
// 所有边相同的边距
padding: EdgeInsets.all(16)

// 不同的水平/垂直边距
padding: EdgeInsets.symmetric({ horizontal: 20, vertical: 10 })

// 每边单独的边距
padding: EdgeInsets.only({ top: 8, right: 16, bottom: 8, left: 16 })
```

## 📝 理解 Text 组件

**Text** 是在屏幕上显示文本的组件。

### Text 的基本用法

```typescript
// 简单文本
Text('Hello, World!')

// 应用样式的文本
Text('样式化文本', {
  style: new TextStyle({
    fontSize: 20,        // 字体大小
    fontWeight: 'bold',  // 字体粗细：'normal', 'bold', '100'-'900'
    color: '#1e40af',    // 文本颜色
    fontFamily: 'Arial'  // 字体系列
  })
})
```

### 文本对齐选项

```typescript
Text('对齐的文本', {
  textAlign: 'center'  // 'left', 'center', 'right', 'justify'
})
```

## 🔧 练习：创建 Hello World 应用

现在让我们组合 Container 和 Text 来创建一个 "Hello World" 应用。

### 步骤 1：创建基本结构

首先，让我们创建一个带有蓝色背景的 Container：

```typescript
const widget = Container({
  color: '#f0f9ff',     // 浅蓝色背景
  padding: EdgeInsets.all(20), // 所有边 20px 内边距
  child: Text('Hello, Flitter!')
});
```

### 步骤 2：添加文本样式

现在让我们为文本添加样式：

```typescript
const widget = Container({
  color: '#f0f9ff',
  padding: EdgeInsets.all(20),
  child: Text('Hello, Flitter!', {
    style: new TextStyle({
      fontSize: 28,
      fontWeight: 'bold',
      color: '#1e40af'
    })
  })
});
```

### 步骤 3：添加多个文本

让我们使用 Column 组件垂直排列多个文本：

```typescript
import { Container, Text, Column, SizedBox, EdgeInsets, MainAxisAlignment, CrossAxisAlignment, TextStyle } from '@meursyphus/flitter';

const widget = Container({
  color: '#f0f9ff',
  padding: EdgeInsets.all(20),
  child: Column({
    mainAxisAlignment: MainAxisAlignment.center,    // 垂直居中对齐
    crossAxisAlignment: CrossAxisAlignment.center,   // 水平居中对齐
    children: [
      Text('Hello, Flitter!', {
        style: new TextStyle({
          fontSize: 28,
          fontWeight: 'bold',
          color: '#1e40af'
        })
      }),
      SizedBox({ height: 10 }),     // 10px 高度的空白间距
      Text('我的第一个组件应用', {
        style: new TextStyle({
          fontSize: 16,
          color: '#64748b'
        })
      })
    ]
  })
});
```

## 🎨 使用 Column 组件创建布局

**Column** 是垂直排列多个组件的布局组件。

### Column 的主要属性

```typescript
Column({
  // 垂直对齐（主轴）
  mainAxisAlignment: MainAxisAlignment.center,
  
  // 水平对齐（交叉轴）
  crossAxisAlignment: CrossAxisAlignment.center,
  
  // 子组件
  children: [
    Text('第一个'),
    Text('第二个'),
    Text('第三个')
  ]
})
```

### 对齐选项说明

**mainAxisAlignment**（垂直方向）：
- `MainAxisAlignment.start`：顶部对齐
- `MainAxisAlignment.center`：中心对齐
- `MainAxisAlignment.end`：底部对齐
- `MainAxisAlignment.spaceBetween`：组件之间平均分配间距
- `MainAxisAlignment.spaceAround`：组件周围平均分配间距
- `MainAxisAlignment.spaceEvenly`：所有间距相等

**crossAxisAlignment**（水平方向）：
- `CrossAxisAlignment.start`：左对齐
- `CrossAxisAlignment.center`：中心对齐
- `CrossAxisAlignment.end`：右对齐
- `CrossAxisAlignment.stretch`：填充所有水平空间

## 🚨 常见错误和解决方案

### 问题 1：文本不可见
**原因**：Container 没有设置 `child` 或 Text 组件创建不正确

**解决方案**：
```typescript
// ❌ 错误示例
Container({ color: 'blue' })  // 没有 child

// ✅ 正确示例
Container({ 
  color: 'blue',
  child: Text('Hello')  // 必须设置 child
})
```

### 问题 2：在 Column 中使用 child 而不是 children
**原因**：Column 有多个子组件，因此必须使用 `children` 数组

**解决方案**：
```typescript
// ❌ 错误示例
Column({ child: Text('Hello') })

// ✅ 正确示例
Column({ children: [Text('Hello')] })
```

### 问题 3：颜色未应用
**原因**：错误的颜色格式或缺少引号

**解决方案**：
```typescript
// ❌ 错误示例
color: #ff0000     // 没有引号
color: 'ff0000'    // 没有 #

// ✅ 正确示例
color: '#ff0000'   // 十六进制代码
color: 'red'       // 颜色名称
color: 'rgb(255, 0, 0)'  // RGB 值
```

### 问题 4：fontSize 未应用
**原因**：fontSize 设置为字符串或错误的样式对象结构

**解决方案**：
```typescript
// ❌ 错误示例
Text('Hello', { fontSize: '20px' })           // 直接属性
Text('Hello', { style: { fontSize: '20' } })  // 字符串

// ✅ 正确示例
Text('Hello', { style: { fontSize: 20 } })    // 设置为数字
```

## 🧠 理解组件树

让我们看看我们应用的组件树结构：

```
Container (根)
├── color: '#f0f9ff'
├── padding: EdgeInsets.all(20)
└── child: Column
    ├── mainAxisAlignment: MainAxisAlignment.center
    ├── crossAxisAlignment: CrossAxisAlignment.center
    └── children:
        ├── Text('Hello, Flitter!')
        ├── SizedBox({ height: 10 })
        └── Text('我的第一个组件应用')
```

### 组件树特性

1. **父子关系**：Container 包含 Column，Column 包含多个 Text
2. **单向数据流**：属性从父组件传递到子组件
3. **可组合性**：通过组合简单组件构建复杂 UI

## 📏 理解尺寸和约束

### Container 如何确定尺寸

```typescript
// 1. 显式尺寸指定
Container({
  width: 200,
  height: 100,
  child: Text('固定尺寸')
})

// 2. 适应子组件尺寸（默认）
Container({
  padding: EdgeInsets.all(16),
  child: Text('适应子组件尺寸')
})

// 3. 占用所有可用空间（无子组件）
Container({
  color: 'red'  // 如果没有子组件则最大尺寸
})
```
