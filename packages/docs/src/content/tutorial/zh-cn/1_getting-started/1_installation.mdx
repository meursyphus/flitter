# 安装与环境设置

这是为 Flitter 新手准备的分步安装指南。完成本教程后，您将能够在 React 项目中使用 Flitter。

## 🎯 学习目标

完成本教程后，您将能够：

- [ ] 验证 Node.js 和 npm 环境是否正确设置
- [ ] 创建新的 React 项目
- [ ] 安装 Flitter 包
- [ ] 渲染您的第一个 Flitter 组件
- [ ] 运行开发服务器并查看结果

## 📋 先决条件

- **Node.js 18 或更高版本** - 从 [Node.js 官方网站](https://nodejs.org/) 下载
- **npm、yarn 或 pnpm** - 随 Node.js 自动安装
- **基础 React 知识** - 了解 JSX 和组件概念

## 🚀 步骤 1：环境检查

首先，让我们验证您的开发环境是否正确设置。

打开终端并运行以下命令：

```bash
# 检查 Node.js 版本（应为 18 或更高）
node --version

# 检查 npm 版本
npm --version
```

预期输出：
```
v20.10.0
10.2.3
```

> ⚠️ **如果您的 Node.js 版本低于 18？**  
> 请从 [Node.js 官方网站](https://nodejs.org/) 安装最新的 LTS 版本。

## 🏗️ 步骤 2：创建新项目

使用 Vite 创建新的 React 项目：

```bash
# 创建新项目
npm create vite@latest my-flitter-app -- --template react

# 导航到项目文件夹
cd my-flitter-app

# 安装基础依赖
npm install
```

## 📦 步骤 3：安装 Flitter 包

现在安装 Flitter 相关包：

```bash
# 安装 Flitter 核心包和 React 集成包
npm install @meursyphus/flitter @meursyphus/flitter-react
```

正在安装的包：
- `@meursyphus/flitter`：Flitter 核心库
- `@meursyphus/flitter-react`：React 集成组件

### 完整代码

```jsx
import React from 'react';
import { Widget } from '@meursyphus/flitter-react';
import { Container, Text } from '@meursyphus/flitter';

function App() {
  const widget = Container({
    color: '#e3f2fd',
    padding: { all: 20 },
    child: Text('🎉 Flitter 安装完成！')
  });

  return (
    <div style={{ padding: '20px' }}>
      <h1>Flitter 安装成功！</h1>
      <Widget 
        widget={widget}
        renderer="canvas"
        style={{ 
          width: '300px', 
          height: '100px',
          border: '1px solid #ddd',
          borderRadius: '8px'
        }}
      />
    </div>
  );
}

export default App;
```

- 一个带有蓝色背景的框，包含 "🎉 Flitter 安装完成！" 文本

## 🔧 练习题

如果您已完成基础安装，请尝试以下练习：

### 练习 1：更改颜色
将 Container 的 `color` 属性更改为不同的颜色：
- `'#ffebee'`（浅红色）
- `'#f3e5f5'`（浅紫色）
- `'#e8f5e8'`（浅绿色）

### 练习 2：更改文本
将 Text 组件内容更改为您自己的消息。

### 练习 3：调整尺寸
更改 Widget 组件 `style` 属性中的 `width` 和 `height` 值。

## 🚨 常见问题和解决方案

### 问题 1：模块未找到错误
```
Error: Cannot resolve module '@meursyphus/flitter'
```

**解决方案**：验证包是否正确安装：
```bash
npm install @meursyphus/flitter @meursyphus/flitter-react
```

### 问题 2：出现空白屏幕
**原因**：组件未正确创建或未传递给 Widget 组件

**解决方案**：
- 检查 `widget` 变量不是 `null`
- 验证 `widget` 属性已传递给 Widget 组件

### 问题 3：Node.js 版本错误
```
Error: Node.js version 16.x is not supported
```

**解决方案**：更新到 Node.js 18 或更高版本。
