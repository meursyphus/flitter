## 🤔 为什么需要状态管理？

我们迄今为止创建的所有组件都是**静态组件**，一旦创建就不会改变。然而，在真实的应用中，屏幕需要根据用户操作而改变：

- 点击按钮增加数字
- 按下切换按钮改变开/关状态
- 在输入框中输入以在屏幕上显示文本

对于这种**动态变化**，我们需要**状态**。

## 🏗️ 理解 StatefulWidget

**StatefulWidget** 是一个可以拥有状态的组件。当状态改变时，屏幕会自动重新绘制。

### StatefulWidget vs StatelessWidget

```typescript
// StatelessWidget - 没有状态，不会改变
class GreetingWidget extends StatelessWidget {
  build() {
    return Text('你好！'); // 总是相同的文本
  }
}

// StatefulWidget - 有状态，可以改变
class CounterWidget extends StatefulWidget {
  createState() {
    return new CounterWidgetState(); // 返回状态类
  }
}

class CounterWidgetState extends State {
  count = 0; // 状态变量

  build() {
    return Text(`计数器：${this.count}`); // 根据状态显示不同的文本
  }
}
```

### StatefulWidget 的基本结构

StatefulWidget 由两个类组成：

1. **Widget 类**：继承自 `StatefulWidget` 并实现 `createState()` 方法
2. **State 类**：继承自 `State` 并包含实际的状态和 UI 逻辑

```typescript
// 1. Widget 类
class MyWidget extends StatefulWidget {
  createState() {
    return new MyWidgetState();
  }
}

// 2. State 类
class MyWidgetState extends State {
  // 状态变量（声明为类属性）
  count = 0;
  isVisible = true;
  
  // UI 组合方法
  build() {
    return Container({
      child: Text(`计数：${this.count}`)
    });
  }
}
```

### 重要特性

1. **状态变量是类属性**：声明为 `this.count = 0`
2. **不使用 React hooks**：在 Flitter 中不使用 `useState`、`useEffect` 等
3. **必须使用 setState()**：改变状态时必须使用 `setState()`

## 🎯 使用 GestureDetector 处理事件

**GestureDetector** 是一个检测用户手势（点击、拖动、悬停等）的组件。

### 基本用法

```typescript
GestureDetector({
  onClick: () => {
    console.log('点击了！');
  },
  child: Container({
    child: Text('点击我')
  })
})
```

### 主要事件属性

```typescript
GestureDetector({
  // 鼠标事件
  onClick: (e) => { /* 点击时 */ },
  onMouseDown: (e) => { /* 鼠标按下时 */ },
  onMouseUp: (e) => { /* 鼠标释放时 */ },
  onMouseEnter: (e) => { /* 鼠标进入区域时 */ },
  onMouseLeave: (e) => { /* 鼠标离开区域时 */ },
  
  // 拖动事件
  onDragStart: (e) => { /* 拖动开始 */ },
  onDragMove: (e) => { /* 拖动中 */ },
  onDragEnd: (e) => { /* 拖动结束 */ },
  
  // 其他设置
  cursor: 'pointer', // 光标形状
  
  child: /* 子组件 */
})
```

### 光标类型

```typescript
cursor: 'pointer'      // 手形
cursor: 'default'      // 默认箭头
cursor: 'move'         // 移动指示器
cursor: 'text'         // 文本选择
cursor: 'wait'         // 等待指示器
cursor: 'not-allowed'  // 禁止指示器
cursor: 'grab'         // 抓取指示器
cursor: 'grabbing'     // 抓取中指示器
```

## 🔧 练习：创建计数器应用

现在让我们创建一个计数器应用，每次点击时数字都会增加。

### 步骤 1：创建 StatefulWidget 类

首先，让我们创建 StatefulWidget 的基本结构：

```typescript
import { StatefulWidget, State } from '@meursyphus/flitter';

class CounterWidget extends StatefulWidget {
  createState() {
    return new CounterWidgetState();
  }
}

class CounterWidgetState extends State {
  count = 0; // 计数器状态变量
  
  build() {
    return Container({
      child: Text(`计数器：${this.count}`)
    });
  }
}
```

### 步骤 2：使用 setState() 更新状态

添加一个方法，在点击按钮时增加计数器：

```typescript
class CounterWidgetState extends State {
  count = 0;
  
  // 计数器增加方法
  increment() {
    this.setState(() => {
      this.count++; // 在 setState 内改变状态
    });
  }
  
  build() {
    return Container({
      child: Text(`计数器：${this.count}`)
    });
  }
}
```

### 步骤 3：使用 GestureDetector 连接点击事件

现在使用 GestureDetector 在点击时调用 increment 方法：

```typescript
class CounterWidgetState extends State {
  count = 0;
  
  increment() {
    this.setState(() => {
      this.count++;
    });
  }
  
  build() {
    return Column({
      mainAxisAlignment: 'center',
      children: [
        Text(`计数器：${this.count}`),
        GestureDetector({
          onClick: () => this.increment(), // 点击时调用 increment
          child: Container({
            child: Text('点击我！')
          })
        })
      ]
    });
  }
}
```

### 步骤 4：添加按钮样式

让我们让按钮更漂亮：

```typescript
GestureDetector({
  onClick: () => this.increment(),
  cursor: 'pointer', // 使光标变成手形
  child: Container({
    padding: EdgeInsets.symmetric({ horizontal: 20, vertical: 12 }), // 按钮内边距
    decoration: new BoxDecoration({
      color: '#3b82f6',           // 蓝色背景
      borderRadius: BorderRadius.circular(8)    // 圆角
    }),
    child: Text('点击我！', {
      style: new TextStyle({
        color: 'white',           // 白色文本

      })
    })
  })
})
```

```typescript
  build() {
    return Container({

      child: Column({
        mainAxisAlignment: MainAxisAlignment.center,

              fontSize: 24,

              color: '#1e293b'

          }),

            onClick: () => this.increment(),
            cursor: 'pointer',
            child: Container({
              padding: EdgeInsets.symmetric({ horizontal: 20, vertical: 12 }),

                style: new TextStyle({

                  fontSize: 16,

              })

}
```

## 🎨 深入理解 setState()

### setState() 的作用

```typescript
// ❌ 错误方式 - UI 不会更新
this.count++; 

// ✅ 正确方式 - UI 自动更新
this.setState(() => {
  this.count++;
});
```

### 在 setState() 内进行多个状态更改

```typescript
this.setState(() => {
  this.count++;           // 可以同时
  this.isVisible = true;  // 更改多个状态
  this.message = '已更新！';
});
```

### setState() 后的回调

```typescript
this.setState(() => {
  this.count++;
}, () => {
  // 状态更新完成后执行
  console.log('计数器已更新：', this.count);
});
```

## 🚨 常见错误和解决方案

### 问题 1：不使用 setState 更改状态
```typescript
// ❌ 错误示例 - UI 不会更新
increment() {
  this.count++; // 没有 setState
}

// ✅ 正确示例
increment() {
  this.setState(() => {
    this.count++;
  });
}
```

### 问题 2：使用 React Hooks
```typescript
// ❌ 错误示例 - Flitter 中不可用
const [count, setCount] = useState(0); // React 模式

// ✅ 正确示例 - Flitter 模式
class MyState extends State {
  count = 0; // 将状态声明为类属性
}
```

### 问题 3：直接导出类
```typescript
// ❌ 错误示例
export default CounterWidget; // 直接导出类

// ✅ 正确示例 - 通过创建实例使用
function App() {
  const widget = new CounterWidget(); // 使用 new 关键字创建实例
  return <Widget widget={widget} />;
}
```

### 问题 4：不使用 GestureDetector 处理事件
```typescript
// ❌ 错误示例
Container({
  onClick: () => {}, // Container 没有点击事件
  child: Text('点击')
})

// ✅ 正确示例
GestureDetector({
  onClick: () => {},
  child: Container({
    child: Text('点击')
  })
})
```

## 🧠 理解生命周期方法

StatefulWidget 有几个生命周期方法：

### initState() - 初始化
```typescript
class CounterWidgetState extends State {
  count = 0;
  
  initState() {
    super.initState();
    console.log('计数器组件已创建');
    // 初始化动画控制器、计时器等
  }
}
```

### didUpdateWidget() - 更新
```typescript
didUpdateWidget(oldWidget) {
  super.didUpdateWidget(oldWidget);
  // 当父组件的属性改变时
  console.log('组件已更新');
}
```

### dispose() - 清理
```typescript
dispose() {
  console.log('计数器组件已移除');
  // 清理计时器、动画等
  super.dispose();
}
```
