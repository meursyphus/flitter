# Installation et configuration de l'environnement

Ceci est un guide d'installation étape par étape pour ceux qui découvrent Flitter. Après avoir terminé ce tutoriel, vous pourrez utiliser Flitter dans des projets React.

## 🎯 Objectifs d'apprentissage

Après avoir terminé ce tutoriel, vous serez capable de :

- [ ] Vérifier que l'environnement Node.js et npm est correctement configuré
- [ ] Créer un nouveau projet React
- [ ] Installer les packages Flitter
- [ ] Afficher votre premier widget Flitter
- [ ] Lancer le serveur de développement et voir les résultats

## 📋 Prérequis

- **Node.js 18 ou supérieur** - Téléchargez depuis le [site officiel de Node.js](https://nodejs.org/)
- **npm, yarn ou pnpm** - Installé automatiquement avec Node.js
- **Connaissances de base en React** - Compréhension de JSX et des concepts de composants

## 🚀 Étape 1 : Vérification de l'environnement

Tout d'abord, vérifions que votre environnement de développement est correctement configuré.

Ouvrez un terminal et exécutez les commandes suivantes :

```bash
# Vérifier la version de Node.js (doit être 18 ou supérieure)
node --version

# Vérifier la version de npm
npm --version
```

Résultat attendu :
```
v20.10.0
10.2.3
```

> ⚠️ **Si votre version de Node.js est inférieure à 18 ?**  
> Veuillez installer la dernière version LTS depuis le [site officiel de Node.js](https://nodejs.org/).

## 🏗️ Étape 2 : Créer un nouveau projet

Créez un nouveau projet React en utilisant Vite :

```bash
# Créer un nouveau projet
npm create vite@latest my-flitter-app -- --template react

# Naviguer vers le dossier du projet
cd my-flitter-app

# Installer les dépendances de base
npm install
```

## 📦 Étape 3 : Installer les packages Flitter

Maintenant, installez les packages liés à Flitter :

```bash
# Installer le package principal Flitter et le package d'intégration React
npm install @meursyphus/flitter @meursyphus/flitter-react
```

Packages en cours d'installation :
- `@meursyphus/flitter` : Bibliothèque principale Flitter
- `@meursyphus/flitter-react` : Composant pour l'intégration React

### Code complet

```jsx
import React from 'react';
import { Widget } from '@meursyphus/flitter-react';
import { Container, Text } from '@meursyphus/flitter';

function App() {
  const widget = Container({
    color: '#e3f2fd',
    padding: { all: 20 },
    child: Text('🎉 Installation de Flitter terminée !')
  });

  return (
    <div style={{ padding: '20px' }}>
      <h1>Installation de Flitter réussie !</h1>
      <Widget 
        widget={widget}
        renderer="canvas"
        style={{ 
          width: '300px', 
          height: '100px',
          border: '1px solid #ddd',
          borderRadius: '8px'
        }}
      />
    </div>
  );
}

export default App;
```

## 🏃 Étape 5 : Lancer le serveur de développement

Maintenant, lancez le serveur de développement pour voir les résultats :

```bash
npm run dev
```

Ouvrez `http://localhost:5173` dans votre navigateur et vous devriez voir :

- Le titre "Installation de Flitter réussie !"
- Une boîte avec un fond bleu contenant le texte "🎉 Installation de Flitter terminée !"

## 🎯 Résultats attendus

Si l'installation est terminée avec succès :

1. **Le serveur de développement fonctionne normalement** : Le terminal affiche "Local: http://localhost:5173"
2. **Le widget Flitter s'affiche** : Une boîte avec un fond bleu apparaît à l'écran
3. **Aucune erreur dans la console** : Aucun message d'erreur dans les outils de développement du navigateur

## 🔧 Exercices pratiques

Si vous avez terminé l'installation de base, essayez ce qui suit :

### Exercice 1 : Changer les couleurs
Changez la propriété `color` du Container pour différentes couleurs :
- `'#ffebee'` (rouge clair)
- `'#f3e5f5'` (violet clair)
- `'#e8f5e8'` (vert clair)

### Exercice 2 : Changer le texte
Changez le contenu du widget Text avec votre propre message.

### Exercice 3 : Ajuster la taille
Changez les valeurs `width` et `height` dans la propriété `style` du composant Widget.

## 🚨 Erreurs courantes et solutions

### Problème 1 : Erreur de module introuvable
```
Error: Cannot resolve module '@meursyphus/flitter'
```

**Solution** : Vérifiez que les packages sont correctement installés :
```bash
npm install @meursyphus/flitter @meursyphus/flitter-react
```

### Problème 2 : Écran blanc
**Cause** : Widget non créé correctement ou non passé au composant Widget

**Solution** : 
- Vérifiez que la variable `widget` n'est pas `null`
- Vérifiez que la prop `widget` est passée au composant Widget

### Problème 3 : Erreur de version Node.js
```
Error: Node.js version 16.x is not supported
```

**Solution** : Mettez à jour vers Node.js 18 ou supérieur.
