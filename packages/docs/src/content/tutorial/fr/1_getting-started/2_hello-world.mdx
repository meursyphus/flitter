# Votre première application Flitter

Maintenant que l'installation est terminée, créons votre première application en utilisant les widgets principaux de Flitter : Container et Text. À travers ce tutoriel, vous apprendrez les concepts de base des arbres de widgets et comment combiner les widgets.

## 🎯 Objectifs d'apprentissage

Après avoir terminé ce tutoriel, vous serez capable de :

- [ ] Créer des boîtes avec le widget Container
- [ ] Afficher du texte avec le widget Text
- [ ] Imbriquer des widgets pour créer des structures arborescentes
- [ ] Appliquer une mise en page et un style de base
- [ ] Organiser les widgets verticalement avec Column

## 📚 Concept clé : Que sont les widgets ?

Dans Flitter, **Widget** est le bloc de construction de base pour construire une interface utilisateur. Tout est fait de widgets, et vous pouvez combiner des widgets pour créer des interfaces utilisateur complexes.

### Caractéristiques des widgets

1. **Immuables** : Une fois créés, les widgets ne peuvent pas être modifiés
2. **Composables** : Les widgets peuvent être imbriqués dans d'autres widgets pour créer des structures complexes
3. **Réutilisables** : Le même widget peut être utilisé à plusieurs endroits

## 🏗️ Comprendre le widget Container

**Container** est l'un des widgets les plus fondamentaux de Flitter. Il est utilisé pour créer des boîtes et appliquer des styles.

### Propriétés clés de Container

```typescript
Container({
  // Paramètres de taille
  width: 200,           // Largeur (pixels)
  height: 100,          // Hauteur (pixels)
  
  // Couleur et style
  color: '#ff0000',     // Couleur de fond (code hexadécimal)
  
  // Paramètres de marge
  padding: EdgeInsets.all(16), // Espacement intérieur
  margin: EdgeInsets.all(8),   // Espacement extérieur
  
  // Widget enfant
  child: Text('Bonjour')  // Widget enfant unique
})
```

### Méthodes de configuration des marges

```typescript
// Même marge de tous les côtés
padding: EdgeInsets.all(16)

// Marges horizontales/verticales différentes
padding: EdgeInsets.symmetric({ horizontal: 20, vertical: 10 })

// Marge individuelle pour chaque côté
padding: EdgeInsets.only({ top: 8, right: 16, bottom: 8, left: 16 })
```

## 📝 Comprendre le widget Text

**Text** est un widget qui affiche du texte à l'écran.

### Utilisation de base de Text

```typescript
// Texte simple
Text('Bonjour, le monde !')

// Texte avec style appliqué
Text('Texte stylisé', {
  style: new TextStyle({
    fontSize: 20,        // Taille de police
    fontWeight: 'bold',  // Poids de police : 'normal', 'bold', '100'-'900'
    color: '#1e40af',    // Couleur du texte
    fontFamily: 'Arial'  // Famille de polices
  })
})
```

### Options d'alignement du texte

```typescript
Text('Texte aligné', {
  textAlign: 'center'  // 'left', 'center', 'right', 'justify'
})
```

## 🔧 Pratique : Créer une application Hello World

Maintenant, combinons Container et Text pour créer une application "Hello World".

### Étape 1 : Créer la structure de base

D'abord, créons un Container avec un fond bleu :

```typescript
const widget = Container({
  color: '#f0f9ff',     // Fond bleu clair
  padding: EdgeInsets.all(20), // 20px de padding de tous les côtés
  child: Text('Bonjour, Flitter !')
});
```

### Étape 2 : Ajouter un style au texte

Maintenant, ajoutons un style au texte :

```typescript
const widget = Container({
  color: '#f0f9ff',
  padding: EdgeInsets.all(20),
  child: Text('Bonjour, Flitter !', {
    style: new TextStyle({
      fontSize: 28,
      fontWeight: 'bold',
      color: '#1e40af'
    })
  })
});
```

### Étape 3 : Ajouter plusieurs textes

Utilisons le widget Column pour organiser plusieurs textes verticalement :

```typescript
import { Container, Text, Column, SizedBox, EdgeInsets, MainAxisAlignment, CrossAxisAlignment, TextStyle } from '@meursyphus/flitter';

const widget = Container({
  color: '#f0f9ff',
  padding: EdgeInsets.all(20),
  child: Column({
    mainAxisAlignment: MainAxisAlignment.center,    // Alignement vertical au centre
    crossAxisAlignment: CrossAxisAlignment.center,   // Alignement horizontal au centre
    children: [
      Text('Bonjour, Flitter !', {
        style: new TextStyle({
          fontSize: 28,
          fontWeight: 'bold',
          color: '#1e40af'
        })
      }),
      SizedBox({ height: 10 }),     // Espace vide de 10px de hauteur
      Text('Ma première application widget', {
        style: new TextStyle({
          fontSize: 16,
          color: '#64748b'
        })
      })
    ]
  })
});
```

## 🎨 Créer une mise en page avec le widget Column

**Column** est un widget de mise en page qui organise plusieurs widgets verticalement.

### Propriétés clés de Column

```typescript
Column({
  // Alignement vertical (axe principal)
  mainAxisAlignment: MainAxisAlignment.center,
  
  // Alignement horizontal (axe transversal)
  crossAxisAlignment: CrossAxisAlignment.center,
  
  // Widgets enfants
  children: [
    Text('Premier'),
    Text('Deuxième'),
    Text('Troisième')
  ]
})
```

### Explication des options d'alignement

**mainAxisAlignment** (direction verticale) :
- `MainAxisAlignment.start` : Alignement en haut
- `MainAxisAlignment.center` : Alignement au centre
- `MainAxisAlignment.end` : Alignement en bas
- `MainAxisAlignment.spaceBetween` : Espacement égal entre les widgets
- `MainAxisAlignment.spaceAround` : Espacement égal autour des widgets
- `MainAxisAlignment.spaceEvenly` : Tous les espacements sont égaux

**crossAxisAlignment** (direction horizontale) :
- `CrossAxisAlignment.start` : Alignement à gauche
- `CrossAxisAlignment.center` : Alignement au centre
- `CrossAxisAlignment.end` : Alignement à droite
- `CrossAxisAlignment.stretch` : Remplir tout l'espace horizontal

## 🚨 Erreurs courantes et solutions

### Problème 1 : Texte non visible
**Cause** : Container n'a pas de `child` défini ou widget Text créé incorrectement

**Solution** : 
```typescript
// ❌ Mauvais exemple
Container({ color: 'blue' })  // Pas d'enfant

// ✅ Bon exemple
Container({ 
  color: 'blue',
  child: Text('Bonjour')  // L'enfant doit être défini
})
```

### Problème 2 : Utiliser child au lieu de children dans Column
**Cause** : Column a plusieurs enfants, donc le tableau `children` doit être utilisé

**Solution** :
```typescript
// ❌ Mauvais exemple
Column({ child: Text('Bonjour') })

// ✅ Bon exemple
Column({ children: [Text('Bonjour')] })
```

### Problème 3 : Couleurs non appliquées
**Cause** : Mauvais format de couleur ou guillemets manquants

**Solution** :
```typescript
// ❌ Mauvais exemples
color: #ff0000     // Pas de guillemets
color: 'ff0000'    // Pas de #

// ✅ Bons exemples
color: '#ff0000'   // Code hexadécimal
color: 'red'       // Nom de couleur
color: 'rgb(255, 0, 0)'  // Valeur RGB
```

### Problème 4 : fontSize non appliqué
**Cause** : fontSize défini comme chaîne ou mauvaise structure d'objet style

**Solution** :
```typescript
// ❌ Mauvais exemples
Text('Bonjour', { fontSize: '20px' })           // Propriété directe
Text('Bonjour', { style: { fontSize: '20' } })  // Chaîne

// ✅ Bon exemple
Text('Bonjour', { style: { fontSize: 20 } })    // Définir comme nombre
```

## 🧠 Comprendre l'arbre de widgets

Regardons la structure de l'arbre de widgets de notre application :

```
Container (racine)
├── color: '#f0f9ff'
├── padding: EdgeInsets.all(20)
└── child: Column
    ├── mainAxisAlignment: MainAxisAlignment.center
    ├── crossAxisAlignment: CrossAxisAlignment.center
    └── children:
        ├── Text('Bonjour, Flitter !')
        ├── SizedBox({ height: 10 })
        └── Text('Ma première application widget')
```

### Caractéristiques de l'arbre de widgets

1. **Relation parent-enfant** : Container contient Column, Column contient plusieurs Texts
2. **Flux de données unidirectionnel** : Les propriétés sont transmises du parent à l'enfant
3. **Composabilité** : Interface utilisateur complexe construite en combinant des widgets simples

## 📏 Comprendre la taille et les contraintes

### Comment Container détermine sa taille

```typescript
// 1. Spécification de taille explicite
Container({
  width: 200,
  height: 100,
  child: Text('Taille fixe')
})

// 2. S'adapter à la taille de l'enfant (par défaut)
Container({
  padding: EdgeInsets.all(16),
  child: Text('S\'adapter à la taille de l\'enfant')
})

// 3. Prendre tout l'espace disponible (pas d'enfant)
Container({
  color: 'red'  // Taille maximale si pas d'enfant
})
```
