# Interactions de base

Maintenant que nous savons créer des widgets statiques, apprenons comment ajouter de l'interactivité ! Ce tutoriel vous montrera comment créer un compteur simple en utilisant GestureDetector pour gérer les clics et StatefulWidget pour gérer les changements d'état.

## 🎯 Objectifs d'apprentissage

Après avoir terminé ce tutoriel, vous serez capable de :

- [ ] Utiliser StatefulWidget pour gérer l'état changeant
- [ ] Créer des boutons cliquables avec GestureDetector
- [ ] Mettre à jour l'interface utilisateur avec setState()
- [ ] Comprendre la différence entre StatelessWidget et StatefulWidget
- [ ] Ajouter des styles de base aux boutons

## 📚 Concept clé : StatefulWidget vs StatelessWidget

Jusqu'à présent, nous avons utilisé **StatelessWidget** qui affiche un contenu statique. Pour créer des interfaces utilisateur interactives qui changent avec le temps, nous avons besoin de **StatefulWidget**.

### StatelessWidget
- **Immutable** : Une fois créé, le contenu ne change jamais
- **Pas d'état** : Aucune donnée variable stockée
- **Usage** : Contenu statique comme des étiquettes, des icônes, des mises en page

### StatefulWidget
- **Mutable** : Le contenu peut changer avec le temps
- **A un état** : Stocke des données variables dans la classe State
- **Usage** : Contenu interactif comme des boutons, des formulaires, des compteurs

## 🏗️ Structure de StatefulWidget

Un StatefulWidget se compose de deux classes :

```typescript
// 1. Classe Widget : Définit la configuration
class MonWidget extends StatefulWidget {
  createState() {
    return new MonWidgetState();
  }
}

// 2. Classe State : Gère l'état et construit l'interface utilisateur
class MonWidgetState extends State {
  // Variables d'état
  maVariable = valeurInitiale;
  
  // Méthodes pour modifier l'état
  modifierEtat() {
    this.setState(() => {
      this.maVariable = nouvelleValeur;
    });
  }
  
  // Méthode de construction de l'interface utilisateur
  build(context) {
    return MonInterface();
  }
}
```

## 🔧 Comprendre GestureDetector

**GestureDetector** est un widget qui détecte les gestes utilisateur comme les clics, le survol, etc.

### Propriétés clés de GestureDetector

```typescript
GestureDetector({
  // Gestionnaires d'événements
  onClick: () => { /* logique de clic */ },
  onMouseEnter: () => { /* logique de survol */ },
  onMouseLeave: () => { /* logique de fin de survol */ },
  
  // Style du curseur
  cursor: 'pointer',  // 'default', 'pointer', 'text', etc.
  
  // Widget enfant
  child: MonWidget()
})
```

### Événements couramment utilisés

```typescript
// Événements de clic
onClick: () => console.log('Cliqué !'),

// Événements de survol
onMouseEnter: () => console.log('Survol commencé'),
onMouseLeave: () => console.log('Survol terminé'),

// Événements de glisser
onDragStart: () => console.log('Glisser commencé'),
onDragEnd: () => console.log('Glisser terminé'),
```

## 🔢 Créer une application compteur

Créons un compteur simple qui augmente quand on clique sur un bouton.

### Étape 1 : Créer StatefulWidget

```typescript
import { StatefulWidget, State } from '@meursyphus/flitter';

class CompteurWidget extends StatefulWidget {
  createState() {
    return new CompteurWidgetState();
  }
}

class CompteurWidgetState extends State {
  // Variable d'état pour stocker la valeur du compteur
  count = 0;
  
  build(context) {
    return Container({
      child: Text(`Compteur : ${this.count}`)
    });
```

Changez le style du bouton au survol :

```typescript
class CompteurWidgetState extends State {

  isHovered = false;  // État pour le survol
  
  build(context) {
    return GestureDetector({
      onClick: () => this.incrementer(),
      onMouseEnter: () => this.setState(() => { this.isHovered = true; }),
      onMouseLeave: () => this.setState(() => { this.isHovered = false; }),

    });
```

## 🚨 Erreurs courantes et solutions

### Problème 1 : Le compteur ne se met pas à jour
**Cause** : Oubli d'utiliser setState() pour modifier l'état

**Solution** :
```typescript
// ❌ Mauvais exemple
incrementer() {
  this.count++;  // L'interface utilisateur ne se met pas à jour
}

// ✅ Bon exemple
incrementer() {
  this.setState(() => {
    this.count++;  // L'interface utilisateur se met à jour
  });
}
```

### Problème 2 : Erreur "setState called after dispose"
**Cause** : Appel de setState après que le widget a été supprimé

**Solution** :
```typescript
incrementer() {
  if (this.mounted) {  // Vérifier si le widget est encore monté
    this.setState(() => {
      this.count++;
    });
  }
}
```

### Problème 3 : Le bouton ne répond pas aux clics
**Cause** : Oubli de définir onClick dans GestureDetector

**Solution** :
```typescript
// ❌ Mauvais exemple
GestureDetector({
  child: Text('Bouton')  // Pas de gestionnaire onClick
})

// ✅ Bon exemple
GestureDetector({
  onClick: () => this.incrementer(),  // Gestionnaire défini
  child: Text('Bouton')
})
```

### Problème 4 : Variables d'état non initialisées
**Cause** : Variables d'état pas initialisées dans la classe State

**Solution** :
```typescript
// ❌ Mauvais exemple
class MonState extends State {
  // count non initialisé
}

// ✅ Bon exemple
class MonState extends State {
  count = 0;  // Initialisation nécessaire
}
```

## 📊 Comprendre le cycle de vie de l'état

### Quand setState() est appelé :
1. **Mise à jour de l'état** : Les variables d'état changent
2. **Reconstruction** : La méthode build() est appelée à nouveau
3. **Mise à jour de l'interface utilisateur** : Les nouveaux widgets sont affichés

### Flux d'exécution :
```
Clic utilisateur → onClick() → setState() → build() → Interface utilisateur mise à jour
```
