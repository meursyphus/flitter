# 위젯 트리 구조 이해하기

위젯은 단독으로 존재하지 않습니다. 부모-자식 관계로 연결되어 **위젯 트리(Widget Tree)**를 형성합니다. 이 트리 구조를 이해하면 복잡한 UI도 체계적으로 구성할 수 있습니다.

## 이 튜토리얼에서 배울 것

- [ ] 위젯 트리의 개념과 중요성
- [ ] 부모-자식 관계 이해하기
- [ ] child와 children의 차이점
- [ ] 트리 구조 디버깅 방법
- [ ] 효율적인 트리 구성 패턴

## 위젯 트리란?

위젯 트리는 UI를 구성하는 위젯들의 계층 구조입니다. HTML의 DOM 트리와 비슷하지만, 더 선언적이고 구성 가능합니다.

### 간단한 트리 예시

```typescript
Container
  └─ Center
      └─ Text("Hello")
```

이 트리는 다음과 같이 코드로 표현됩니다:

```typescript
Container({
  child: Center({
    child: Text("Hello")
  })
})
```

> **💡 핵심 개념: 트리의 방향성**
> 
> 위젯 트리는 위에서 아래로 단방향으로 구성됩니다. 부모는 자식을 알지만, 자식은 부모를 직접 참조하지 않습니다.
> 
> 실무에서는 이 원칙 덕분에 위젯을 독립적으로 테스트하고 재사용할 수 있습니다.

## child vs children

위젯은 자식을 가질 때 두 가지 방식을 사용합니다:

### 1. child: 하나의 자식만 가능
```typescript
Container({
  child: Text("하나의 자식")
})

Center({
  child: Icon(Icons.star)
})

Padding({
  padding: EdgeInsets.all(8),
  child: Text("패딩이 적용된 텍스트")
})
```

### 2. children: 여러 자식 가능
```typescript
Column({
  children: [
    Text("첫 번째"),
    Text("두 번째"),
    Text("세 번째")
  ]
})

Row({
  children: [
    Icon(Icons.home),
    Text("홈"),
    Icon(Icons.arrow_forward)
  ]
})
```

## 트리 구조 시각화

복잡한 UI를 만들 때는 트리를 시각화하면 도움이 됩니다:

```
앱 화면
├─ AppBar
│   ├─ 제목 텍스트
│   └─ 액션 버튼들
└─ Body
    └─ Column
        ├─ 검색 바 (Row)
        │   ├─ TextField (Expanded)
        │   └─ 검색 버튼
        └─ 결과 목록 (ListView)
            ├─ 아이템 1
            ├─ 아이템 2
            └─ ...
```

## 효율적인 트리 구성 패턴

### 1. 깊이 제한하기
너무 깊은 트리는 성능과 가독성에 악영향을 줍니다:

```typescript
// ❌ 너무 깊은 중첩
Container({
  child: Padding({
    child: Center({
      child: Container({
        child: Padding({
          child: Text("너무 깊어요!")
        })
      })
    })
  })
})

// ✅ 필요한 것만 사용
Container({
  padding: EdgeInsets.all(16),
  alignment: Alignment.center,
  child: Text("간단하고 명확해요!")
})
```

### 2. 위젯 추출하기
복잡한 부분은 별도 함수나 위젯으로 추출:

```typescript
// ✅ 복잡한 부분을 함수로 추출
function buildSearchBar() {
  return Row({
    children: [
      Expanded({
        child: TextField({ /* ... */ })
      }),
      IconButton({ /* ... */ })
    ]
  });
}

function buildResultList(results) {
  return ListView({
    children: results.map(buildResultItem)
  });
}

// 메인 트리는 간단하게
Column({
  children: [
    buildSearchBar(),
    Expanded({
      child: buildResultList(results)
    })
  ]
})
```

### 3. 조건부 렌더링
트리 구조에서 조건부 렌더링 패턴:

```typescript
Column({
  children: [
    Text("항상 보이는 텍스트"),
    
    // 조건부 위젯
    isLoading 
      ? CircularProgressIndicator()
      : Text("로딩 완료"),
    
    // 조건부 추가
    ...(showDetails ? [
      Text("상세 정보 1"),
      Text("상세 정보 2")
    ] : [])
  ]
})
```

## 디버깅 팁

### 1. 트리 구조 출력하기
개발 중에는 트리 구조를 콘솔에 출력해보세요:

```typescript
function printWidgetTree(widget, depth = 0) {
  const indent = "  ".repeat(depth);
  console.log(`${indent}${widget.constructor.name}`);
  
  if (widget.child) {
    printWidgetTree(widget.child, depth + 1);
  }
  if (widget.children) {
    widget.children.forEach(child => 
      printWidgetTree(child, depth + 1)
    );
  }
}
```

### 2. 위젯 경계 표시
개발 모드에서 위젯 경계를 시각적으로 표시:

```typescript
// 디버그용 컨테이너
function DebugContainer({ child, label }) {
  return Container({
    decoration: BoxDecoration({
      border: Border.all({ color: Colors.red, width: 1 })
    }),
    child: Stack({
      children: [
        child,
        Positioned({
          top: 0,
          left: 0,
          child: Container({
            color: Colors.red,
            padding: EdgeInsets.all(2),
            child: Text(label, {
              style: new TextStyle({
                color: Colors.white,
                fontSize: 10
              })
            })
          })
        })
      ]
    })
  });
}
```

주어진 트리 구조를 코드로 구현해보세요:

```
Container (600x400, 연한 인디고 배경)
  └─ Padding (전체 24)
      └─ Column
          ├─ Text ("위젯 트리 구조", 크고 굵게)
          ├─ Container (구분선, 높이 2)
          └─ Row (Expanded)
              ├─ Expanded (왼쪽 패널)
              │   └─ 트리 다이어그램
              └─ Expanded (오른쪽 패널)
                  └─ 특징 설명
```

<details>
<summary>💡 힌트</summary>

1. `Expanded`를 사용해서 남은 공간 채우기
2. `CrossAxisAlignment.stretch`로 전체 너비 사용
3. 패널은 흰색 배경에 `borderRadius: 8` 적용
4. 텍스트 스타일링에 `TextStyle` 사용

</details>
