# 위젯이란? - 모든 것은 위젯이다

Flitter에서는 화면에 보이는 모든 것이 **위젯(Widget)**입니다. 텍스트도 위젯이고, 버튼도 위젯이며, 심지어 여백과 정렬조차도 위젯으로 표현됩니다. 이 강력한 개념을 이해하면 복잡한 UI도 간단한 위젯들의 조합으로 만들 수 있습니다.

## 위젯의 개념

위젯은 Flitter UI의 기본 구성 단위입니다. Flutter의 철학을 따라 "모든 것은 위젯이다"라는 원칙을 채택했습니다.

### 위젯의 특징

1. **불변성(Immutable)**: 위젯은 한 번 생성되면 변경되지 않습니다
2. **구성 가능(Composable)**: 작은 위젯들을 조합해 복잡한 UI를 만듭니다
3. **재사용 가능(Reusable)**: 한 번 만든 위젯은 여러 곳에서 사용할 수 있습니다

> **💡 핵심 개념: 위젯의 철학**
> 
> 위젯은 UI의 "설명서"입니다. 화면에 무엇을 그릴지 선언적으로 표현합니다.
> 
> 실무에서는 작은 위젯들을 레고 블록처럼 조합해서 복잡한 UI를 만듭니다.

## 위젯의 종류

Flitter의 위젯은 크게 세 가지로 분류됩니다:

### 1. 레이아웃 위젯
공간을 배치하고 정렬하는 위젯들입니다:

```typescript
// 수직 배치
Column({
  children: [위젯1, 위젯2, 위젯3]
})

// 수평 배치
Row({
  children: [위젯1, 위젯2, 위젯3]
})

// 겹쳐서 배치
Stack({
  children: [배경위젯, 전경위젯]
})
```

### 2. 시각적 위젯
화면에 직접 그려지는 위젯들입니다:

```typescript
// 텍스트 표시
Text("Hello Flitter")

// 색상 있는 박스
Container({
  width: 100,
  height: 100,
  color: Colors.blue
})

// 이미지 표시
Image({ src: "image.png" })
```

### 3. 구조적 위젯
다른 위젯들을 감싸서 특정 기능을 추가합니다:

```typescript
// 여백 추가
Padding({
  padding: EdgeInsets.all(10),
  child: Text("여백이 있는 텍스트")
})

// 가운데 정렬
Center({
  child: Text("가운데 정렬")
})

// 크기 제한
SizedBox({
  width: 200,
  height: 50,
  child: Container({ color: Colors.red })
})
```

## 위젯 조합의 힘

위젯의 진정한 힘은 조합에서 나옵니다. 간단한 위젯들을 조합해서 복잡한 UI를 만들어봅시다:

```typescript
// 카드 UI 만들기
Container({
  padding: EdgeInsets.all(16),
  decoration: BoxDecoration({
    color: Colors.white,
    borderRadius: 8,
    boxShadow: [/* 그림자 효과 */]
  }),
  child: Column({
    crossAxisAlignment: CrossAxisAlignment.start,
    children: [
      Text("제목", {
        style: new TextStyle({ fontSize: 20, fontWeight: 'bold' })
      }),
      SizedBox({ height: 8 }),
      Text("내용이 들어갑니다...", {
        style: new TextStyle({ color: Colors.grey[600] })
      })
    ]
  })
})
```

## 위젯 트리 이해하기

위젯들은 트리 구조로 구성됩니다. 부모 위젯은 자식 위젯을 포함하고, 이런 관계가 계층적으로 이어집니다:

```
Container
  └─ Padding
      └─ Column
          ├─ Text("제목")
          ├─ SizedBox
          └─ Row
              ├─ Icon
              └─ Text("부제목")
```

> **💡 팁**: 위젯 트리를 그려보면 UI 구조를 이해하기 쉽습니다. 복잡한 UI를 만들 때는 먼저 트리 구조를 스케치해보세요!

## 실무 팁: 위젯 설계 원칙

### 1. 단일 책임 원칙
각 위젯은 하나의 역할만 담당하도록 설계하세요:
- ❌ 너무 많은 기능을 하나의 위젯에 넣기
- ✅ 작은 위젯들을 조합해서 복잡한 기능 구현

### 2. 재사용성 고려
자주 사용되는 패턴은 커스텀 위젯으로 만들어두세요:
```typescript
// 재사용 가능한 카드 위젯
function MyCard({ title, content }) {
  return Container({
    // 카드 스타일
    child: Column({
      children: [
        Text(title),
        Text(content)
      ]
    })
  });
}
```

### 3. 성능 고려
- 불필요한 중첩 피하기
- 무거운 위젯은 필요할 때만 생성
- 리스트는 가상화 위젯 사용
