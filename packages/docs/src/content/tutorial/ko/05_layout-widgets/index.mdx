# Chapter 5: 레이아웃 위젯 마스터하기

이번 챕터에서는 더 정교하고 유연한 레이아웃을 만들기 위한 고급 위젯들을 다룹니다. 이 위젯들을 마스터하면 픽셀 단위의 정밀한 디자인과 반응형 레이아웃을 자유자재로 구현할 수 있습니다.

## 🎯 학습 목표

이 챕터를 완료하면:
- 공간과 간격을 정밀하게 제어할 수 있습니다
- 위젯을 원하는 위치에 정확히 배치할 수 있습니다
- 유연하고 반응형인 레이아웃을 구성할 수 있습니다
- 일관된 비율의 UI 컴포넌트를 만들 수 있습니다
- 프로페셔널한 수준의 레이아웃을 설계할 수 있습니다

## 🏗 레이아웃 설계 원칙

### 1. 공간의 일관성
```typescript
// 8px 기반 간격 시스템
const spacing = {
  xs: 4,
  sm: 8,
  md: 16,
  lg: 24,
  xl: 32
};
```

### 2. 정렬의 명확성
```typescript
// 의도를 명확히 표현
Center({ child: Logo() })  // 단순 중앙 정렬
Align({ alignment: Alignment.topRight })  // 특정 위치
```

### 3. 유연한 크기 조절
```typescript
// 고정 vs 유연
Row({
  children: [
    FixedWidth({ width: 100 }),  // 고정
    Expanded({ child: FlexibleContent() })  // 유연
  ]
})
```

### 4. 비율의 일관성
```typescript
// 디자인 시스템의 비율
AspectRatio({ aspectRatio: 16/9 })  // 비디오
AspectRatio({ aspectRatio: 1.0 })   // 정사각형
AspectRatio({ aspectRatio: 1.618 }) // 황금비
```
