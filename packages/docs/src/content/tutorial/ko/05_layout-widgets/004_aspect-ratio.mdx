# AspectRatio - 비율 유지하기

AspectRatio는 자식 위젯의 가로세로 비율을 유지하는 레이아웃 위젯입니다. 이미지, 비디오, 카드 등의 일관된 비율을 유지하는 데 필수적입니다.

- [ ] 반응형 디자인에서의 활용법
- [ ] 이미지 갤러리와 그리드 레이아웃
- [ ] 실전 UI 패턴 구현하기
- [ ] 성능 최적화 팁

## AspectRatio의 작동 원리

AspectRatio는 주어진 비율에 따라 자식 위젯의 크기를 결정합니다:

- **가로 제약이 있을 때**: 높이 = 가로 / aspectRatio
- **세로 제약이 있을 때**: 가로 = 세로 × aspectRatio

> **💡 핵심 개념: aspectRatio 계산**
> 
> aspectRatio = 가로 / 세로
> - 1.0 = 정사각형 (1:1)
> - 2.0 = 가로가 세로의 2배 (2:1)
> - 0.5 = 세로가 가로의 2배 (1:2)

## 1단계: 기본 사용법

### 정사각형 만들기

```typescript
Container({
  width: 200,  // 가로 크기만 지정
  child: AspectRatio({

      color: Colors.blue,
      child: Center({
        child: Text("정사각형")
      })
    })
  })
})

```

### 일반적인 화면 비율

## 6단계: 고급 패턴 - 적응형 비율

```typescript
class AdaptiveAspectRatio extends StatelessWidget {
  constructor(props) {
    super(props);
    this.child = props.child;
  }

  build(context) {
    const screenWidth = MediaQuery.of(context).size.width;
    
    // 화면 크기에 따라 비율 변경
    let aspectRatio;
    if (screenWidth < 600) {
      aspectRatio = 1.0;      // 모바일: 정사각형
    } else if (screenWidth < 1200) {
      aspectRatio = 4/3;      // 태블릿: 4:3
    } else {
      aspectRatio = 16/9;     // 데스크톱: 16:9
    }
    
    return AspectRatio({
      aspectRatio: aspectRatio,
      child: this.child
    });
  }
}
```

## 성능 최적화 팁

### 이미지 로딩 최적화

```typescript
AspectRatio({
  aspectRatio: 16/9,
  child: Container({
    decoration: new BoxDecoration({
      color: Colors.gray[300]  // 플레이스홀더
    }),
    child: Image.network(url, {
      fit: BoxFit.cover,
      loadingBuilder: (context, child, loadingProgress) => {
        if (loadingProgress == null) return child;
        return Center({
          child: CircularProgressIndicator()
        });
      }
    })
  })
})
```

### 비율 계산 캐싱

```typescript
// 자주 사용하는 비율은 상수로 정의
const ASPECT_RATIOS = {
  SQUARE: 1.0,
  VIDEO_16_9: 16/9,
  VIDEO_4_3: 4/3,
  GOLDEN: 1.618,
  INSTAGRAM_PORTRAIT: 4/5,
  INSTAGRAM_LANDSCAPE: 1.91
};

// 사용
AspectRatio({
  aspectRatio: ASPECT_RATIOS.VIDEO_16_9,
  child: VideoWidget()
})
```

## 핵심 정리

AspectRatio 마스터 체크리스트:

- ✅ **기본 원리**: 가로/세로 비율 유지
- ✅ **일반 비율**: 1:1, 16:9, 4:3, 황금비
- ✅ **반응형**: 화면 크기에 따른 비율 조정
- ✅ **그리드**: 일관된 비율의 아이템 배치
- ✅ **성능**: 이미지 로딩 최적화
