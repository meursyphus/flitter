# Align과 Center - 정렬의 예술

Align과 Center는 위젯을 원하는 위치에 정확히 배치하는 핵심 레이아웃 위젯입니다. 이 두 위젯을 마스터하면 픽셀 단위의 정밀한 UI를 만들 수 있습니다.

## 이 튜토리얼에서 배울 것

- [ ] Center 위젯으로 간단한 중앙 정렬
- [ ] Align 위젯의 9가지 기본 정렬 위치
- [ ] Alignment 클래스로 커스텀 위치 지정
- [ ] Stack과 함께 사용하는 고급 패턴
- [ ] 실전에서 자주 사용하는 정렬 테크닉
- [ ] 성능을 고려한 정렬 위젯 선택

## Center vs Align 이해하기

### Center 위젯

- **목적**: 오직 중앙 정렬만을 위한 특화 위젯
- **사용법**: 매우 간단하고 직관적
- **성능**: Align보다 약간 더 가벼움

### Align 위젯

- **목적**: 9가지 기본 위치 + 커스텀 위치 지정
- **유연성**: 다양한 정렬 옵션 제공
- **확장성**: 애니메이션과 함께 사용 가능

> **💡 핵심 개념: 좌표 시스템**
> 
> Alignment는 -1.0에서 1.0 사이의 좌표를 사용합니다:
> - x축: -1.0(왼쪽) ~ 0(중앙) ~ 1.0(오른쪽)
> - y축: -1.0(위) ~ 0(중앙) ~ 1.0(아래)

## 1단계: Center 위젯 마스터하기

### 기본 사용법

```typescript
Center({
  child: Text("정중앙에 위치")
})
```

### Center의 특징

1. **크기 확장**: 가능한 최대 크기로 확장
2. **단일 자식**: 하나의 child만 가능
3. **중앙 정렬**: 가로/세로 모두 중앙

```typescript
Container({
  width: 200,
  height: 200,
  color: Colors.blue[100],
  child: Center({
    child: Container({
      width: 50,
      height: 50,
      color: Colors.blue[500]
    })
  })
})
```

## 2단계: Align의 9가지 기본 정렬

### 기본 Alignment 상수들

```typescript
// 상단 정렬
Alignment.topLeft      // (-1.0, -1.0)
Alignment.topCenter    // (0.0, -1.0)
Alignment.topRight     // (1.0, -1.0)

// 중단 정렬
Alignment.centerLeft   // (-1.0, 0.0)
Alignment.center       // (0.0, 0.0)
Alignment.centerRight  // (1.0, 0.0)

// 하단 정렬
Alignment.bottomLeft   // (-1.0, 1.0)
Alignment.bottomCenter // (0.0, 1.0)
Alignment.bottomRight  // (1.0, 1.0)
```

### 사용 예제

```typescript
Align({
  alignment: Alignment.topRight,
  child: Container({
    padding: EdgeInsets.all(8),
    color: Colors.red,
    child: Text("우상단")
  })
})
```

## 3단계: 커스텀 Alignment

### 정밀한 위치 지정

```typescript
Align({
  alignment: new Alignment(0.5, -0.7),  // x: 약간 오른쪽, y: 위쪽
  child: MyWidget()
})
```

### 계산을 통한 동적 정렬

```typescript
// 원형 배치 예제
const angleToAlignment = (angle) => {
  const radian = angle * Math.PI / 180;
  return new Alignment(
    Math.cos(radian),
    Math.sin(radian)
  );
};

// 45도 각도에 위치
Align({
  alignment: angleToAlignment(45),
  child: MyWidget()
})
```

## 6단계: 반응형 정렬

### 화면 크기에 따른 정렬 변경

```typescript
class ResponsiveAlign extends StatelessWidget {
  constructor(props) {
    super(props);
    this.child = props.child;
  }

  build(context) {
    const screenWidth = MediaQuery.of(context).size.width;
    
    // 화면 크기에 따라 정렬 변경
    const alignment = screenWidth > 600 
      ? Alignment.centerRight 
      : Alignment.center;
    
    return Align({
      alignment: alignment,
      child: this.child
    });
  }
}
```

## 고급 팁: FractionalOffset

더 직관적인 위치 지정이 필요할 때:

```typescript
// Alignment 대신 FractionalOffset 사용
FractionalOffset(0.25, 0.75)  // 왼쪽에서 25%, 위에서 75%

// 퍼센트 기반 배치
Align({
  alignment: FractionalOffset(0.8, 0.2),  // 우측 80%, 상단 20%
  child: MyWidget()
})
```

## 애니메이션과 함께 사용

```typescript
class AnimatedAlignExample extends StatefulWidget {
  createState() {
    return new AnimatedAlignExampleState();
  }
}

class AnimatedAlignExampleState extends State {
  alignment = Alignment.topLeft;

  build(context) {
    return GestureDetector({
      onTap: () => {
        this.setState(() => {
          // 랜덤 위치로 이동
          this.alignment = new Alignment(
            Math.random() * 2 - 1,  // -1 to 1
            Math.random() * 2 - 1   // -1 to 1
          );
        });
      },
      child: Container({
        width: 300,
        height: 300,
        color: Colors.gray[200],
        child: AnimatedAlign({
          alignment: this.alignment,
          duration: Duration({ milliseconds: 500 }),
          curve: Curves.easeInOut,
          child: Container({
            width: 50,
            height: 50,
            color: Colors.blue
          })
        })
      })
    });
  }
}
```
