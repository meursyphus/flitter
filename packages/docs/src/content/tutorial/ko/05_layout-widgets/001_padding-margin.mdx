# Padding과 Margin - 공간 다루기

Padding과 margin은 UI 디자인에서 가장 중요한 개념 중 하나입니다. 적절한 간격은 사용성을 높이고 시각적으로 아름다운 인터페이스를 만드는 핵심입니다.

## 이 튜토리얼에서 배울 것

- [ ] Padding 위젯으로 내부 간격 만들기
- [ ] Container의 margin으로 외부 간격 만들기
- [ ] EdgeInsets의 다양한 생성 메서드 활용하기
- [ ] padding과 margin의 차이점 이해하기
- [ ] 실전에서 자주 사용하는 간격 패턴
- [ ] 반응형 간격 디자인 팁

## Padding vs Margin 이해하기

### 핵심 차이점

- **Padding (내부 간격)**: 위젯의 경계 안쪽 공간
  - 배경색이나 테두리 안쪽에 적용
  - 클릭/터치 영역에 포함됨
  
- **Margin (외부 간격)**: 위젯의 경계 바깥쪽 공간
  - 다른 위젯과의 거리
  - 클릭/터치 영역에 포함되지 않음

> **💡 핵심 개념: 언제 무엇을 사용할까?**
> 
> - **Padding 사용**: 버튼의 텍스트 주변 공간, 카드의 내용물 간격
> - **Margin 사용**: 카드 사이의 간격, 섹션 구분, 화면 가장자리와의 거리

## 1단계: Padding 위젯 사용하기

### 기본 사용법

```typescript
Padding({
  padding: EdgeInsets.all(16),
  child: Text("패딩이 적용된 텍스트")
})
```

### Padding의 특징

1. **단일 목적 위젯**: 오직 padding만을 위한 위젯
2. **성능 최적화**: Container보다 가벼움
3. **명시적 의도**: 코드를 읽기 쉽게 만듦

```typescript
// 좋은 예 - 목적이 명확함
Padding({
  padding: EdgeInsets.all(20),
  child: MyWidget()
})

// 비추천 - Container는 더 무거움
Container({
  padding: EdgeInsets.all(20),
  child: MyWidget()
})
```

## 2단계: Container의 margin 속성

### margin 사용법

```typescript
Container({
  margin: EdgeInsets.all(16),
  color: Colors.blue,
  child: Text("마진이 적용된 컨테이너")
})
```

### margin의 특징

1. **Container 전용**: 오직 Container에서만 사용 가능
2. **다른 속성과 조합**: color, decoration 등과 함께 사용
3. **레이아웃 영향**: 주변 위젯들의 배치에 영향

## 3단계: EdgeInsets 마스터하기

### EdgeInsets.all() - 모든 방향 동일

```typescript
EdgeInsets.all(20)  // 상하좌우 모두 20
```

### EdgeInsets.symmetric() - 대칭 간격

```typescript
EdgeInsets.symmetric({
  horizontal: 20,  // 좌우 20
  vertical: 10    // 상하 10
})
```

### EdgeInsets.fromLTRB() - 각 방향 개별 지정

```typescript
EdgeInsets.fromLTRB({
  left: 10,
  top: 20,
  right: 10,
  bottom: 30
})
```

### EdgeInsets.only() - 특정 방향만

```typescript
EdgeInsets.only({
  left: 20,
  top: 10
  // right와 bottom은 0
})
```

## 4단계: 실전 패턴 - 중첩 사용

```typescript
Container({
  margin: EdgeInsets.all(16),        // 외부 간격
  padding: EdgeInsets.all(20),       // 내부 간격
  decoration: new BoxDecoration({
    color: Colors.white,
    borderRadius: BorderRadius.circular(8),
    border: Border.all({
      color: Colors.grey[300],
      width: 1
    })
  }),
  child: Column({
    children: [
      Text("제목", {
        style: new TextStyle({ fontSize: 20, fontWeight: "bold" })
      }),
      Padding({
        padding: EdgeInsets.only({ top: 8 }),  // 제목과 본문 사이
        child: Text("본문 내용...")
      })
    ]
  })
})
```

## 5단계: 반응형 간격 디자인

### 화면 크기에 따른 간격 조정

```typescript
// 기본 간격 정의
const baseSpacing = 8;

// 배수로 일관성 있는 간격 사용
const spacing = {
  xs: baseSpacing * 0.5,   // 4
  sm: baseSpacing,         // 8
  md: baseSpacing * 2,     // 16
  lg: baseSpacing * 3,     // 24
  xl: baseSpacing * 4      // 32
};

// 사용 예
Padding({
  padding: EdgeInsets.symmetric({
    horizontal: spacing.lg,
    vertical: spacing.md
  }),
  child: MyContent()
})
```

## 고급 팁: 일관된 간격 시스템

```typescript
// 디자인 시스템 정의
class Spacing {
  static const double unit = 4;
  
  static EdgeInsets all(double multiplier) {
    return EdgeInsets.all(unit * multiplier);
  }
  
  static EdgeInsets horizontal(double multiplier) {
    return EdgeInsets.symmetric({ horizontal: unit * multiplier });
  }
  
  static EdgeInsets vertical(double multiplier) {
    return EdgeInsets.symmetric({ vertical: unit * multiplier });
  }
}

// 사용 예
Padding({
  padding: Spacing.all(4),      // 16px
  child: Container({
    margin: Spacing.vertical(2), // 8px 상하
    child: MyWidget()
  })
})
```

## 핵심 정리

Padding과 Margin 마스터 체크리스트:

- ✅ **Padding**: 내부 간격, 클릭 영역 포함
- ✅ **Margin**: 외부 간격, 위젯 간 거리
- ✅ **EdgeInsets**: all, symmetric, fromLTRB, only
- ✅ **성능**: 단순 padding은 Padding 위젯 사용
- ✅ **일관성**: 디자인 시스템으로 간격 통일
