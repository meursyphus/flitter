# Expanded와 Flexible - 공간 분배

Expanded와 Flexible은 Row, Column에서 자식 위젯들의 크기를 유연하게 조절하는 핵심 위젯입니다. 반응형 레이아웃을 만들 때 필수적인 도구입니다.

## 이 튜토리얼에서 배울 것

- [ ] Expanded로 남은 공간 채우기
- [ ] flex 속성으로 공간 비율 조절하기
- [ ] Flexible과 Expanded의 차이점 이해하기
- [ ] FlexFit으로 세밀한 크기 제어
- [ ] Row와 Column에서의 활용 패턴
- [ ] 실전 반응형 레이아웃 구현

## Expanded vs Flexible 핵심 차이

### Expanded
- **동작**: 남은 공간을 **모두** 차지
- **사용 시기**: 공간을 완전히 채우고 싶을 때
- **FlexFit**: tight (고정)

### Flexible
- **동작**: 필요한 만큼만 차지 (최대 가능한 크기까지)
- **사용 시기**: 컨텐츠 크기에 따라 유연하게 조절하고 싶을 때
- **FlexFit**: loose (유연)

> **💡 핵심 개념: Flex 레이아웃**
> 
> Expanded와 Flexible은 CSS Flexbox와 유사한 개념입니다.
> Row/Column의 주축 방향으로 공간을 분배합니다.

## 1단계: Expanded 기본 사용법

### 남은 공간 채우기

```typescript
Row({
  children: [
    Container({
      width: 100,
      height: 50,
      color: Colors.blue
    }),
    Expanded({
      child: Container({
        height: 50,
        color: Colors.green  // 남은 공간 모두 차지
      })
    }),
    Container({
      width: 100,
      height: 50,
      color: Colors.red
    })
  ]
})
```

### Expanded의 특징

1. **Row에서**: 가로 방향으로 확장
2. **Column에서**: 세로 방향으로 확장
3. **필수 부모**: Row, Column, Flex 안에서만 사용

## 2단계: flex 속성으로 비율 조절

### 공간 분배 비율

```typescript
Row({
  children: [
    Expanded({
      flex: 1,  // 전체의 1/6
      child: Container({ color: Colors.red })
    }),
    Expanded({
      flex: 2,  // 전체의 2/6
      child: Container({ color: Colors.green })
    }),
    Expanded({
      flex: 3,  // 전체의 3/6
      child: Container({ color: Colors.blue })
    })
  ]
})
```

### flex 계산 방법

- 총 flex = 1 + 2 + 3 = 6
- 빨강: 1/6 (약 16.7%)
- 초록: 2/6 (약 33.3%)
- 파랑: 3/6 (50%)

## 3단계: Flexible 이해하기

### 기본 사용법

```typescript
Row({
  children: [
    Flexible({
      child: Container({
        color: Colors.blue,
        child: Text("필요한 만큼만 차지")
      })
    }),
    Flexible({
      child: Container({
        color: Colors.green,
        child: Text("이것도 필요한 만큼만")
      })
    })
  ]
})
```

### FlexFit 옵션

```typescript
Flexible({
  fit: FlexFit.tight,  // Expanded와 동일
  child: MyWidget()
})

Flexible({
  fit: FlexFit.loose,  // 기본값, 필요한 만큼만
  child: MyWidget()
})
```

## 성능 최적화 팁

### Expanded vs SizedBox.expand

```typescript
// 단순히 공간만 채울 때
Expanded({
  child: SizedBox()  // 더 가벼움
})

// 복잡한 위젯을 채울 때
Expanded({
  child: ComplexWidget()
})
```

### 불필요한 중첩 피하기

```typescript
// 나쁜 예
Expanded({
  child: Container({
    child: Expanded({  // 오류!
      child: MyWidget()
    })
  })
})

// 좋은 예
Expanded({
  child: Container({
    child: MyWidget()
  })
})
```

## 핵심 정리

Expanded와 Flexible 마스터 체크리스트:

- ✅ **Expanded**: 남은 공간 모두 차지
- ✅ **Flexible**: 필요한 만큼만 차지
- ✅ **flex**: 공간 분배 비율 조절
- ✅ **부모 제약**: Row/Column 안에서만 사용
- ✅ **조합**: 고정 크기와 함께 사용
