      // 클릭 핸들러
      handleClick = () => {
        this.setState(() => {
          this.count++;
        });
      }
      
      build(context) {
        // GestureDetector로 클릭 이벤트 처리
        return GestureDetector({
          onClick: this.handleClick,

              color: Colors.blue[500],
              borderRadius: 8,

                }

                style: new TextStyle({
                  fontSize: 20,
                  fontWeight: 'bold',
                  color: Colors.white
                })
              })
            })
          })
        });
      }

# 간단한 인터랙티브 버튼 만들기

이제 사용자와 상호작용하는 버튼을 만들어보겠습니다! Flitter의 StatefulWidget과 GestureDetector를 사용해 클릭할 때마다 카운트가 증가하는 버튼을 구현해봅시다.

## 이 튜토리얼에서 배울 것

- [ ] StatefulWidget으로 상태 관리하기
- [ ] State 클래스와 setState() 이해하기
- [ ] GestureDetector로 클릭 이벤트 처리하기
- [ ] 동적으로 UI 업데이트하기
- [ ] 버튼 스타일링 심화

## 1단계: StatefulWidget 이해하기

StatefulWidget은 변경 가능한 상태를 가진 위젯입니다. 사용자 상호작용이나 시간에 따라 변하는 UI를 만들 때 사용합니다.

```typescript
class CounterButton extends StatefulWidget {
  createState() {
    return new CounterButtonState();
  }
}
```

> **💡 핵심 개념: StatefulWidget vs StatelessWidget**
> 
> - **StatelessWidget**: 한 번 생성되면 변하지 않는 위젯 (예: 로고, 제목)
> - **StatefulWidget**: 상태를 가지고 변할 수 있는 위젯 (예: 버튼, 폼, 애니메이션)
> 
> StatefulWidget은 createState() 메서드를 통해 State 객체를 생성합니다.

## 2단계: State 클래스 만들기

State 클래스는 실제 상태를 관리하고 UI를 빌드하는 역할을 합니다.

```typescript
class CounterButtonState extends State<CounterButton> {
  count = 0;  // 상태 변수 선언
  
  build(context) {
    // UI 반환
  }
}
```

### 상태 변수 선언

클래스 프로퍼티로 상태를 선언합니다:

```typescript
count = 0;  // 초기값 0
```

## 3단계: setState()로 상태 업데이트

상태를 변경할 때는 반드시 setState()를 사용해야 합니다. 이를 통해 Flitter가 UI를 다시 렌더링합니다.

```typescript
handleClick = () => {
  this.setState(() => {
    this.count++;  // 상태 변경
  });
}
```

> **⚠️ 주의**: setState() 없이 직접 상태를 변경하면 UI가 업데이트되지 않습니다!
> ```typescript
> // ❌ 잘못된 방법
> this.count++;
> 
> // ✅ 올바른 방법
> this.setState(() => {
>   this.count++;
> });
> ```

## 4단계: GestureDetector로 이벤트 처리

GestureDetector는 탭, 드래그, 호버 등 다양한 제스처를 감지합니다.

```typescript
GestureDetector({
  onClick: this.handleClick,  // 클릭 이벤트 핸들러
  child: Container({...})     // 클릭 가능한 영역
})
```

### 지원하는 이벤트들:
- `onClick`: 클릭/탭
- `onDoubleClick`: 더블클릭
- `onMouseEnter`: 마우스 호버 시작
- `onMouseLeave`: 마우스 호버 종료
- `onMouseMove`: 마우스 이동

## 5단계: 버튼 스타일링

Container의 decoration 속성으로 더 멋진 버튼을 만들 수 있습니다:

```typescript
Container({
  decoration: {
    color: Colors.blue[500],
    borderRadius: 8,  // 둥근 모서리
    boxShadow: [      // 그림자 효과
      {
        color: Colors.black.withOpacity(0.2),
        offset: { x: 0, y: 2 },
        blurRadius: 4
      }
    ]
  }
})
```

## 고급 도전 과제

버튼을 더 개선해보세요:

1. **리셋 버튼 추가**: 카운트를 0으로 초기화
2. **감소 버튼 추가**: 카운트를 1씩 감소 (0 이하로는 안 됨)
3. **호버 효과**: onMouseEnter/Leave로 호버 시 색상 변경
