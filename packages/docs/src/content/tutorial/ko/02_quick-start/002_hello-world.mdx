  App.js: |
    import ReactWidget from "@meursyphus/flitter-react";
    import { Container, Text, TextStyle, Colors, Center } from "@meursyphus/flitter";

    function App() {
      // Container 위젯으로 기본 레이아웃 생성
      const widget = Container({
        width: 400,
        height: 200,
        color: Colors.green[200],
        child: Center({
          child: Text("🌟 Hello, Flitter World! 🌟", {
            style: new TextStyle({
              fontSize: 28,
              fontWeight: 'bold',
              color: Colors.green[800]
            })
          })
        })
      });

      return (
        <div style={{ padding: '20px' }}>
          <h1>나의 첫 번째 Flitter 앱</h1>
          <div style={{ display: 'flex', justifyContent: 'center' }}>
            <ReactWidget widget={widget} />
          </div>
        </div>
      );
    }

# 첫 번째 "Hello World" 앱

이제 Flitter의 기본 위젯들을 사용해서 실제로 동작하는 앱을 만들어보겠습니다! 간단하지만 Flitter의 핵심 개념들을 체험할 수 있는 Hello World 앱을 만들어봅시다.

## 이 튜토리얼에서 배울 것

- [ ] Container 위젯의 기본 사용법
- [ ] Text 위젯과 스타일링
- [ ] Center 위젯으로 정렬하기
- [ ] Colors 시스템 활용하기
- [ ] ReactWidget으로 Flitter 위젯 렌더링하기

## 1단계: Container 위젯 이해하기

Container는 Flitter에서 가장 기본이 되는 위젯입니다. 하나의 자식 위젯을 담을 수 있고, 크기, 색상, 패딩 등을 설정할 수 있습니다.

```typescript
Container({
  width: 400,     // 너비 설정
  height: 200,    // 높이 설정
  color: Colors.green[200],  // 배경색 설정
  child: /* 자식 위젯 */
})
```

> **💡 핵심 개념: Container 위젯**
> 
> Container는 Flutter의 Container와 동일한 역할을 합니다. 박스 모델 기반으로 동작하며, 하나의 자식을 가질 수 있습니다.
> 
> 실무에서는 카드, 버튼, 섹션 등 다양한 UI 요소의 기본 틀로 사용됩니다.

## 2단계: Text 위젯과 스타일링

Text 위젯은 텍스트를 표시하는 위젯입니다. TextStyle을 통해 폰트 크기, 색상, 굵기 등을 설정할 수 있습니다.

```typescript
Text("🌟 Hello, Flitter World! 🌟", {
  style: new TextStyle({
    fontSize: 28,
    fontWeight: 'bold',
    color: Colors.green[800]
  })
})
```

## 3단계: Center 위젯으로 정렬

Center 위젯은 자식 위젯을 가운데로 정렬시켜줍니다. 매우 간단하지만 레이아웃에서 자주 사용되는 위젯입니다.

```typescript
Center({
  child: Text("가운데 정렬된 텍스트")
})
```

## 4단계: Colors 시스템

Flitter는 Material Design의 색상 팔레트를 제공합니다. 각 색상마다 50부터 900까지의 음영을 사용할 수 있습니다.

```typescript
Colors.green[200]  // 연한 초록색
Colors.green[800]  // 진한 초록색
Colors.blue[500]   // 기본 파란색
Colors.red[300]    // 연한 빨간색
```

> **💡 팁**: Colors 시스템을 활용하면 일관된 디자인을 쉽게 만들 수 있습니다. 연한 색상(200-300)은 배경에, 진한 색상(700-900)은 텍스트에 사용하세요!

## 5단계: ReactWidget으로 렌더링

마지막으로 만든 Flitter 위젯을 ReactWidget으로 감싸서 React 앱에 렌더링합니다.

```typescript
<ReactWidget widget={widget} />
```
