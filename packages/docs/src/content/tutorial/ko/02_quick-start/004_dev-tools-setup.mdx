# 개발 도구 설정

효율적인 Flitter 개발을 위해 VS Code와 각종 도구들을 설정해보겠습니다. 이 설정으로 코드 자동 완성, 디버깅, 핫 리로드 등을 활용할 수 있습니다.

## 이 튜토리얼에서 배울 것

- [ ] VS Code 확장 프로그램 설치 및 설정
- [ ] TypeScript 지원 구성
- [ ] 디버깅 환경 설정
- [ ] 코드 포매팅 자동화
- [ ] 개발 생산성 향상 팁

## 1단계: VS Code 필수 확장 프로그램

다음 확장 프로그램들을 설치하세요:

### 필수 확장 프로그램
1. **Prettier** - 코드 포매터
2. **ESLint** - 코드 품질 검사
3. **TypeScript and JavaScript Language Features** - TS/JS 지원
4. **Path Intellisense** - 파일 경로 자동완성

### 추천 확장 프로그램
- **Color Highlight** - 색상 코드 시각화
- **Indent Rainbow** - 들여쓰기 시각화
- **Code Spell Checker** - 맞춤법 검사
- **TODO Highlight** - TODO 주석 강조

> **💡 팁**: `.vscode/extensions.json` 파일을 만들면 팀원들이 권장 확장 프로그램을 쉽게 설치할 수 있습니다.

## 2단계: TypeScript 설정

Flitter는 완전한 TypeScript 지원을 제공합니다. 타입 힌트와 자동 완성을 활용하세요.

### tsconfig.json 주요 설정
```json
{
  "compilerOptions": {
    "strict": true,              // 엄격한 타입 검사
    "jsx": "react-jsx",          // JSX 지원
    "moduleResolution": "bundler", // 모듈 해석 방식
    "resolveJsonModule": true    // JSON 임포트 지원
  }
}
```

### 타입 자동 완성 활용
```typescript
import { Container, Text, Colors } from "@meursyphus/flitter";

// 자동완성이 Container의 모든 props를 보여줍니다
Container({
  width: 200,    // number
  height: 100,   // number
  color: Colors. // 자동완성으로 모든 색상 확인
});
```

## 3단계: 디버깅 설정

VS Code에서 직접 디버깅할 수 있도록 설정합니다.

### launch.json 생성
1. VS Code에서 F5 키 또는 디버깅 탭 클릭
2. "create a launch.json file" 선택
3. Chrome 선택
4. 위의 launch.json 내용으로 수정

### 디버깅 사용법
1. 코드에 중단점 설정 (줄 번호 왼쪽 클릭)
2. F5 키로 디버깅 시작
3. Chrome이 자동으로 열림
4. VS Code에서 변수 값 확인, 단계별 실행 가능

> **🔥 고급**: React DevTools와 함께 사용하면 위젯 트리와 상태를 시각적으로 확인할 수 있습니다.

## 4단계: 코드 포매팅 자동화

일관된 코드 스타일을 위해 Prettier와 ESLint를 설정합니다.

### Prettier 설정 (.prettierrc)
```json
{
  "semi": true,              // 세미콜론 사용
  "singleQuote": false,      // 큰따옴표 사용
  "tabWidth": 2,             // 탭 크기
  "trailingComma": "es5"     // ES5 호환 콤마
}
```

### VS Code 자동 포매팅
settings.json에 다음을 추가:
```json
{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode"
}
```

이제 파일을 저장할 때마다 자동으로 코드가 정리됩니다!

## 5단계: 개발 생산성 팁

### 1. 코드 스니펫 만들기
자주 사용하는 패턴을 스니펫으로 만들어보세요:

```json
// .vscode/flitter.code-snippets
{
  "Stateful Widget": {
    "prefix": "stful",
    "body": [
      "class ${1:WidgetName} extends StatefulWidget {",
      "  createState() {",
      "    return new ${1:WidgetName}State();",
      "  }",
      "}",
      "",
      "class ${1:WidgetName}State extends State {",
      "  build(context) {",
      "    return Container({",
      "      child: Text('$2')",
      "    });",
      "  }",
      "}"
    ]
  }
}
```

### 2. 핫 리로드 활용
React의 Fast Refresh가 Flitter 위젯도 지원합니다:
- 상태 유지하며 UI 업데이트
- 즉각적인 변경사항 확인
- 개발 속도 향상

### 3. 터미널 명령어 설정
package.json에 유용한 스크립트 추가:
```json
{
  "scripts": {
    "dev": "react-scripts start",
    "lint": "eslint src --fix",
    "format": "prettier --write src/**/*"
  }
}
```

## 🐛 문제해결

### TypeScript 에러가 계속 나타나는 경우
```bash
# TypeScript 서버 재시작
Ctrl+Shift+P → "TypeScript: Restart TS Server"
```

### 자동완성이 작동하지 않는 경우
```bash
# node_modules 재설치
rm -rf node_modules package-lock.json
npm install
```

### 디버깅이 작동하지 않는 경우
- Chrome 개발자 도구가 이미 열려있는지 확인
- sourceMaps 설정 확인
- 포트 번호가 일치하는지 확인 (기본: 3000)
