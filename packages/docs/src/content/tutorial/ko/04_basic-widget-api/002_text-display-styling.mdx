# Text - 텍스트 표시와 스타일링

Text 위젯은 화면에 텍스트를 표시하는 가장 기본적인 위젯입니다. 단순해 보이지만 TextStyle을 통해 다양한 시각적 효과를 줄 수 있습니다. 아름답고 읽기 쉬운 텍스트를 만드는 방법을 알아봅시다.

## 이 튜토리얼에서 배울 것

- [ ] Text 위젯의 기본 사용법
- [ ] TextStyle로 텍스트 꾸미기
- [ ] 크기, 굵기, 색상 조절하기
- [ ] 정렬과 오버플로 처리
- [ ] 고급 텍스트 효과 적용하기

## Text 위젯의 기본

가장 간단한 Text 위젯 사용법:

```typescript
Text("Hello, Flitter!")
```

두 번째 파라미터로 옵션을 전달할 수 있습니다:

```typescript
Text("스타일이 있는 텍스트", {
  style: new TextStyle({
    fontSize: 20,
    color: Colors.blue
  })
})
```

> **💡 핵심 개념: Text vs RichText**
> 
> - **Text**: 단일 스타일의 텍스트 표시
> - **RichText**: 한 문장 안에 여러 스타일 적용 가능
> 
> 대부분의 경우 Text 위젯으로 충분하며, 복잡한 스타일이 필요할 때만 RichText를 사용합니다.

## TextStyle - 텍스트 꾸미기

TextStyle은 텍스트의 모든 시각적 속성을 제어합니다:

### 크기와 굵기
```typescript
Text("크고 굵은 텍스트", {
  style: new TextStyle({
    fontSize: 24,              // 크기 (기본: 14)
    fontWeight: FontWeight.bold // 굵기
  })
})

// FontWeight 옵션들
FontWeight.w100  // Thin
FontWeight.w200  // Extra Light  
FontWeight.w300  // Light
FontWeight.w400  // Regular (normal)
FontWeight.w500  // Medium
FontWeight.w600  // Semi Bold
FontWeight.w700  // Bold
FontWeight.w800  // Extra Bold
FontWeight.w900  // Black
```

### 색상
```typescript
Text("컬러풀한 텍스트", {
  style: new TextStyle({
    color: Colors.purple[600],
    // 투명도 적용
    // color: Colors.black.withOpacity(0.5)
  })
})
```

### 폰트 패밀리
```typescript
Text("다른 폰트", {
  style: new TextStyle({
    fontFamily: 'Roboto',  // 또는 'monospace', 'serif' 등
    fontSize: 18
  })
})
```

## 텍스트 장식

### 밑줄과 취소선
```typescript
// 밑줄
Text("밑줄 텍스트", {
  style: new TextStyle({
    decoration: TextDecoration.underline,
    decorationColor: Colors.red,
    decorationThickness: 2
  })
})

// 취소선
Text("취소된 텍스트", {
  style: new TextStyle({
    decoration: TextDecoration.lineThrough,
    decorationColor: Colors.gray
  })
})

// 점선 스타일
Text("점선 밑줄", {
  style: new TextStyle({
    decoration: TextDecoration.underline,
    decorationStyle: TextDecorationStyle.dotted
  })
})
```

### 그림자 효과
```typescript
Text("그림자가 있는 텍스트", {
  style: new TextStyle({
    fontSize: 24,
    color: Colors.white,
    shadows: [{
      color: Colors.black.withOpacity(0.5),
      offset: { x: 2, y: 2 },
      blurRadius: 4
    }]
  })
})
```

## 텍스트 정렬

### TextAlign
```typescript
Container({
  width: 300,
  child: Text("가운데 정렬된 텍스트", {
    textAlign: TextAlign.center,
    style: new TextStyle({ fontSize: 18 })
  })
})

// 정렬 옵션들
TextAlign.left    // 왼쪽 정렬 (기본)
TextAlign.center  // 가운데 정렬
TextAlign.right   // 오른쪽 정렬
TextAlign.justify // 양쪽 정렬
```

> **⚠️ 주의**: TextAlign은 Text 위젯이 차지하는 공간 내에서만 작동합니다. Container의 width를 지정하거나 부모 위젯이 충분한 공간을 제공해야 합니다.

## 텍스트 오버플로 처리

긴 텍스트가 공간을 초과할 때 처리 방법:

### 말줄임표 (...)
```typescript
Container({
  width: 200,
  child: Text("이것은 매우 긴 텍스트입니다. 공간이 부족하면 말줄임표로 표시됩니다.", {
    overflow: TextOverflow.ellipsis,
    maxLines: 1
  })
})
```

### 여러 줄 제한
```typescript
Container({
  width: 200,
  child: Text("여러 줄의 긴 텍스트입니다. 최대 2줄까지만 표시하고 나머지는 말줄임표로 처리합니다.", {
    overflow: TextOverflow.ellipsis,
    maxLines: 2,
    style: new TextStyle({
      fontSize: 16,
      height: 1.5  // 줄 간격
    })
  })
})
```

### 오버플로 옵션들
```typescript
TextOverflow.clip     // 잘라내기 (기본)
TextOverflow.fade     // 페이드 아웃
TextOverflow.ellipsis // 말줄임표 (...)
TextOverflow.visible  // 오버플로 허용
```

## 성능 고려사항

### 1. 복잡한 TextStyle 재사용
```typescript
// 자주 사용하는 스타일은 상수로 정의
const titleStyle = new TextStyle({
  fontSize: 24,
  fontWeight: FontWeight.bold,
  color: Colors.gray[900]
});

// 여러 곳에서 재사용
Text("제목 1", { style: titleStyle });
Text("제목 2", { style: titleStyle });
```

### 2. 긴 텍스트 처리
```typescript
// 긴 텍스트는 필요한 부분만 표시
Text(longText, {
  maxLines: 3,
  overflow: TextOverflow.ellipsis
})
```

## 접근성 고려사항

### 1. 충분한 대비
텍스트와 배경 사이에 충분한 대비를 유지하세요:
```typescript
// ✅ 좋은 예: 높은 대비
Container({
  color: Colors.white,
  child: Text("읽기 쉬운 텍스트", {
    style: new TextStyle({ color: Colors.black })
  })
})

// ❌ 나쁜 예: 낮은 대비
Container({
  color: Colors.gray[300],
  child: Text("읽기 어려운 텍스트", {
    style: new TextStyle({ color: Colors.gray[400] })
  })
})
```

### 2. 적절한 크기
본문 텍스트는 최소 14px 이상을 권장합니다:
```typescript
Text("읽기 편한 본문", {
  style: new TextStyle({
    fontSize: 16,  // 권장 크기
    height: 1.5    // 충분한 줄 간격
  })
})
```
