# Chapter 4: 기본 위젯 API 탐험

이번 챕터에서는 Flitter의 가장 기본적이면서도 강력한 위젯들을 하나씩 깊이 있게 살펴봅니다. 이 위젯들은 모든 Flitter 앱의 기초가 되는 빌딩 블록입니다.

## 🎯 학습 목표

이 챕터를 완료하면:
- Container, Text, Row/Column, Stack의 모든 기능을 마스터하게 됩니다
- 각 위젯의 속성과 사용 패턴을 완벽히 이해하게 됩니다
- 실전에서 바로 활용할 수 있는 레이아웃 기술을 습득합니다
- 복잡한 UI도 기본 위젯들의 조합으로 구현할 수 있게 됩니다

## 📚 챕터 구성

### [1. Container - 모든 것을 담는 기본 상자](./001_container)
- 크기, 색상, 패딩, 마진 설정
- BoxDecoration으로 시각 효과 추가
- 제약조건(constraints) 활용법
- 실전 카드 UI 만들기

### [2. Text - 텍스트 표시와 스타일링](./002_text)
- TextStyle의 모든 속성 마스터
- 폰트 크기, 굵기, 색상, 장식 효과
- 텍스트 정렬과 간격 조절
- 재사용 가능한 텍스트 스타일 패턴

### [3. Row와 Column - 선형 배치의 기본](./003_row-column)
- 주축(MainAxis)과 교차축(CrossAxis) 이해
- MainAxisAlignment의 6가지 정렬 옵션
- CrossAxisAlignment의 4가지 정렬 옵션
- Expanded와 Flexible로 유연한 레이아웃

### [4. Stack - 위젯 겹치기와 절대 위치](./004_stack)
- Z축을 활용한 레이어드 레이아웃
- Positioned로 절대 위치 지정
- Align으로 상대적 정렬
- 배지, 오버레이, FAB 구현

## 🛠 실습 중심 학습

각 튜토리얼은:
- **대화형 코드 에디터**: 바로 실행하고 결과를 확인
- **단계별 설명**: 개념부터 고급 활용까지
- **실전 예제**: 실제 앱에서 사용하는 패턴들
- **연습 과제**: 스스로 해결하며 실력 향상

## 💡 학습 팁

1. **순서대로 학습하기**: 각 위젯은 이전 내용을 기반으로 합니다
2. **코드 직접 수정하기**: 에디터에서 값을 바꿔가며 실험해보세요
3. **연습 과제 도전하기**: 힌트를 보기 전에 먼저 시도해보세요
4. **조합 연습하기**: 여러 위젯을 조합해서 복잡한 UI를 만들어보세요
