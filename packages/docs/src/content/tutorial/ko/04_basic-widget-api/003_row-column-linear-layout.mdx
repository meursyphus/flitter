# Row와 Column - 선형 배치의 기본

Row와 Column은 Flitter에서 가장 기본적이면서도 중요한 레이아웃 위젯입니다. Row는 위젯들을 가로로, Column은 세로로 배치합니다. 이 두 위젯을 마스터하면 대부분의 UI 레이아웃을 구성할 수 있습니다.

## 이 튜토리얼에서 배울 것

- [ ] Row와 Column의 기본 사용법
- [ ] MainAxisAlignment로 주축 정렬하기
- [ ] CrossAxisAlignment로 교차축 정렬하기
- [ ] Expanded와 Flexible로 공간 분배하기
- [ ] Spacer로 간격 만들기

## Row - 수평 배치

Row는 자식 위젯들을 가로로 나란히 배치합니다:

```typescript
Row({
  children: [
    Container({ width: 50, height: 50, color: Colors.red }),
    Container({ width: 50, height: 50, color: Colors.green }),
    Container({ width: 50, height: 50, color: Colors.blue })
  ]
})
```

> **💡 핵심 개념: 주축과 교차축**
> 
> - **주축(Main Axis)**: Row에서는 가로 방향
> - **교차축(Cross Axis)**: Row에서는 세로 방향
> 
> Column에서는 반대로 세로가 주축, 가로가 교차축이 됩니다.

## Column - 수직 배치

Column은 자식 위젯들을 세로로 배치합니다:

```typescript
Column({
  children: [
    Text("첫 번째"),
    Text("두 번째"),
    Text("세 번째")
  ]
})
```

## MainAxisAlignment - 주축 정렬

주축 방향으로 자식들을 어떻게 배치할지 결정합니다:

### Row에서의 MainAxisAlignment
```typescript
// 시작점에 정렬 (기본값)
Row({
  mainAxisAlignment: MainAxisAlignment.start,
  children: [/*...*/]
})

// 중앙 정렬
Row({
  mainAxisAlignment: MainAxisAlignment.center,
  children: [/*...*/]
})

// 끝점에 정렬
Row({
  mainAxisAlignment: MainAxisAlignment.end,
  children: [/*...*/]
})

// 균등 분배 (양 끝 포함)
Row({
  mainAxisAlignment: MainAxisAlignment.spaceBetween,
  children: [/*...*/]
})

// 균등 분배 (양 끝 제외)
Row({
  mainAxisAlignment: MainAxisAlignment.spaceAround,
  children: [/*...*/]
})

// 완전 균등 분배
Row({
  mainAxisAlignment: MainAxisAlignment.spaceEvenly,
  children: [/*...*/]
})
```

### 시각적 차이
```
start:        [A][B][C]____________
center:       ______[A][B][C]______
end:          ____________[A][B][C]
spaceBetween: [A]______[B]______[C]
spaceAround:  __[A]____[B]____[C]__
spaceEvenly:  ___[A]___[B]___[C]___
```

## CrossAxisAlignment - 교차축 정렬

교차축 방향으로 자식들을 어떻게 정렬할지 결정합니다:

### Row에서의 CrossAxisAlignment
```typescript
Container({
  height: 100,
  child: Row({
    crossAxisAlignment: CrossAxisAlignment.start,    // 상단 정렬
    // CrossAxisAlignment.center,  // 중앙 정렬 (기본값)
    // CrossAxisAlignment.end,     // 하단 정렬
    // CrossAxisAlignment.stretch, // 전체 높이로 늘리기
    children: [
      Container({ width: 50, height: 30, color: Colors.red }),
      Container({ width: 50, height: 50, color: Colors.green }),
      Container({ width: 50, height: 40, color: Colors.blue })
    ]
  })
})
```

### baseline 정렬
텍스트의 기준선에 맞춰 정렬:
```typescript
Row({
  crossAxisAlignment: CrossAxisAlignment.baseline,
  textBaseline: TextBaseline.alphabetic,
  children: [
    Text("Big", { style: new TextStyle({ fontSize: 30 }) }),
    Text("Medium", { style: new TextStyle({ fontSize: 20 }) }),
    Text("Small", { style: new TextStyle({ fontSize: 15 }) })
  ]
})
```

## MainAxisSize - 주축 크기

Row/Column이 주축 방향으로 얼마나 공간을 차지할지 결정:

```typescript
// 최소 크기만 차지 (자식들 크기의 합)
Row({
  mainAxisSize: MainAxisSize.min,
  children: [/*...*/]
})

// 가능한 최대 크기 차지 (기본값)
Row({
  mainAxisSize: MainAxisSize.max,
  children: [/*...*/]
})
```

## Expanded - 남은 공간 채우기

Expanded는 Row/Column의 남은 공간을 채웁니다:

### 기본 사용법
```typescript
Row({
  children: [
    Container({ width: 100, height: 50, color: Colors.blue }),
    Expanded({
      child: Container({ height: 50, color: Colors.green })
    }),
    Container({ width: 100, height: 50, color: Colors.red })
  ]
})
```

### flex 속성으로 비율 조절
```typescript
Row({
  children: [
    Expanded({
      flex: 2,  // 2/3 공간 차지
      child: Container({ height: 50, color: Colors.blue })
    }),
    Expanded({
      flex: 1,  // 1/3 공간 차지
      child: Container({ height: 50, color: Colors.green })
    })
  ]
})
```

## Flexible - 유연한 공간 차지

Flexible은 Expanded와 비슷하지만 더 유연합니다:

```typescript
Row({
  children: [
    Flexible({
      flex: 1,
      fit: FlexFit.loose,  // 필요한 만큼만 차지
      child: Container({ width: 100, height: 50, color: Colors.blue })
    }),
    Flexible({
      flex: 1,
      fit: FlexFit.tight,  // Expanded와 동일
      child: Container({ height: 50, color: Colors.green })
    })
  ]
})
```

## Spacer - 빈 공간 만들기

Spacer는 Row/Column에서 빈 공간을 만드는 간편한 방법입니다:

```typescript
Row({
  children: [
    Text("왼쪽"),
    Spacer(),  // 남은 공간을 모두 차지
    Text("오른쪽")
  ]
})

// flex로 비율 조절
Row({
  children: [
    Text("A"),
    Spacer(flex: 2),
    Text("B"),
    Spacer(flex: 1),
    Text("C")
  ]
})
```
