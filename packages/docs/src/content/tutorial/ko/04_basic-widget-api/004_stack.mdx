# Stack - 위젯 겹치기와 절대 위치

Stack은 위젯을 겹쳐서 배치할 수 있는 강력한 레이아웃 위젯입니다. 플로팅 버튼, 배지, 오버레이 등 다양한 UI 패턴을 구현할 때 필수적입니다.

## 이 튜토리얼에서 배울 것

- [ ] Stack의 기본 개념과 위젯 겹치기
- [ ] Positioned로 절대 위치 지정하기
- [ ] Align으로 상대적 정렬하기
- [ ] clipBehavior로 오버플로우 제어하기
- [ ] Stack을 활용한 실전 UI 패턴들
- [ ] z-index와 렌더링 순서 이해하기

## Stack의 기본 개념

Stack은 children의 위젯들을 겹쳐서 표시합니다:

- **렌더링 순서**: 먼저 나온 위젯이 아래에, 나중 위젯이 위에 그려짐
- **크기**: 가장 큰 자식의 크기를 따르거나, 부모의 제약조건을 따름
- **위치**: 기본적으로 좌상단 정렬, Positioned나 Align으로 조정 가능

> **💡 핵심 개념: Stack vs Row/Column**
> 
> - Row/Column: 위젯을 나란히 배치 (선형 레이아웃)
> - Stack: 위젯을 겹쳐서 배치 (절대 레이아웃)
> 
> Stack은 z축(깊이)을 활용한 레이아웃이라고 생각하면 됩니다.

## 1단계: Stack 기본 사용법

가장 간단한 Stack 예제:

```typescript
Stack({
  children: [
    // 맨 아래 (배경)
    Container({
      width: 200,
      height: 200,
      color: Colors.blue[200]
    }),
    // 중간 레이어
    Container({
      width: 150,
      height: 150,
      color: Colors.green[200]
    }),
    // 맨 위 (전경)
    Container({
      width: 100,
      height: 100,
      color: Colors.red[200]
    })
  ]
})
```

### 렌더링 순서 이해하기

children 배열의 순서가 렌더링 순서를 결정합니다:
- 인덱스 0: 가장 아래
- 인덱스 1: 그 위에
- 인덱스 2: 가장 위에

## 2단계: Positioned - 절대 위치 지정

Positioned를 사용하면 Stack 내에서 정확한 위치를 지정할 수 있습니다:

```typescript
Stack({
  children: [
    // 배경
    Container({ color: Colors.grey[200] }),
    
    // 좌상단에서 10픽셀 떨어진 위치
    Positioned({
      top: 10,
      left: 10,
      child: Container({
        width: 50,
        height: 50,
        color: Colors.red
      })
    }),
    
    // 우하단에서 10픽셀 떨어진 위치
    Positioned({
      bottom: 10,
      right: 10,
      child: Container({
        width: 50,
        height: 50,
        color: Colors.blue
      })
    })
  ]
})
```

### Positioned의 속성들

- **top**: 위에서부터의 거리
- **bottom**: 아래에서부터의 거리
- **left**: 왼쪽에서부터의 거리
- **right**: 오른쪽에서부터의 거리
- **width/height**: 크기 지정 (선택적)

> **🎯 실전 팁: Positioned 사용 규칙**
> - top과 bottom을 동시에 지정하면 height가 자동 계산됨
> - left와 right를 동시에 지정하면 width가 자동 계산됨
> - 4개 모두 지정하면 전체 영역을 채움

## 3단계: Align - 상대적 정렬

Align은 Alignment를 사용해 더 직관적으로 위치를 지정할 수 있습니다:

```typescript
Stack({
  children: [
    // 중앙
    Align({
      alignment: Alignment.center,
      child: Text("Center")
    }),
    
    // 좌상단
    Align({
      alignment: Alignment.topLeft,
      child: Text("Top Left")
    }),
    
    // 우하단
    Align({
      alignment: Alignment.bottomRight,
      child: Text("Bottom Right")
    })
  ]
})
```

### Alignment 옵션들

```typescript
// 기본 정렬 옵션들
Alignment.topLeft      // 좌상단
Alignment.topCenter    // 상단 중앙
Alignment.topRight     // 우상단
Alignment.centerLeft   // 좌측 중앙
Alignment.center       // 정중앙
Alignment.centerRight  // 우측 중앙
Alignment.bottomLeft   // 좌하단
Alignment.bottomCenter // 하단 중앙
Alignment.bottomRight  // 우하단

// 커스텀 정렬 (x, y는 -1.0 ~ 1.0)
new Alignment(0.5, -0.5)  // x: 우측으로 50%, y: 위로 50%
```

## 4단계: clipBehavior - 오버플로우 제어

Stack의 영역을 벗어나는 위젯들을 어떻게 처리할지 결정합니다:

```typescript
Stack({
  clipBehavior: "none",  // 잘리지 않음 (기본값)
  children: [
    Container({
      width: 100,
      height: 100,
      color: Colors.blue
    }),
    Positioned({
      top: -10,  // Stack 영역 밖으로 나감
      right: -10,
      child: Container({
        width: 30,
        height: 30,
        color: Colors.red
      })
    })
  ]
})
```

clipBehavior 옵션:
- `"none"`: 잘리지 않음
- `"hardEdge"`: 날카롭게 자름
- `"antiAlias"`: 부드럽게 자름
- `"antiAliasWithSaveLayer"`: 더 부드럽게 (성능 비용 높음)

## 고급 패턴: IndexedStack

여러 위젯 중 하나만 보여주고 싶을 때:

```typescript
IndexedStack({
  index: currentIndex,  // 0, 1, 2...
  children: [
    // index가 0일 때만 보임
    Container({ color: Colors.red }),
    // index가 1일 때만 보임
    Container({ color: Colors.green }),
    // index가 2일 때만 보임
    Container({ color: Colors.blue })
  ]
})
```

## Stack 사용 시 주의사항

1. **성능**: 너무 많은 위젯을 겹치면 성능 저하
2. **크기**: Stack의 크기가 명확하지 않으면 레이아웃 문제 발생
3. **접근성**: 겹친 위젯들의 터치 영역이 겹치지 않도록 주의

## 핵심 정리

Stack 마스터 체크리스트:

- ✅ **기본 겹치기**: children 순서로 z-index 결정
- ✅ **절대 위치**: Positioned로 정확한 위치 지정
- ✅ **상대 정렬**: Align으로 직관적인 정렬
- ✅ **오버플로우**: clipBehavior로 영역 밖 처리
- ✅ **실전 활용**: 배지, 오버레이, FAB 등
