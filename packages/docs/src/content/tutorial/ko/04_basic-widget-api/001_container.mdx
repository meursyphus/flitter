# Container - 모든 것을 담는 기본 상자

Container는 Flitter에서 가장 많이 사용되는 기본 위젯입니다. 단순한 상자처럼 보이지만, 크기 조절, 패딩, 마진, 색상, 정렬 등 다양한 기능을 제공하는 만능 위젯입니다.

## 이 튜토리얼에서 배울 것

- [ ] Container의 기본 속성들 (width, height, color)
- [ ] 패딩(padding)과 마진(margin)의 차이와 활용법
- [ ] EdgeInsets를 사용한 다양한 간격 설정
- [ ] 제약조건(constraints)을 활용한 유연한 크기 설정
- [ ] Container를 활용한 실전 레이아웃 구성

## Container란 무엇인가?

Container는 다음과 같은 역할을 하는 기본 위젯입니다:

1. **레이아웃의 기본 단위**: 다른 위젯을 담는 상자 역할
2. **스타일링**: 배경색, 테두리, 그림자 등 시각적 효과 추가
3. **간격 조절**: 패딩과 마진으로 공간 배치
4. **크기 지정**: 고정 크기나 제약조건으로 크기 제어

> **💡 핵심 개념: Container의 렌더링 순서**
> 
> Container는 다음 순서로 속성을 적용합니다:
> 1. 제약조건(constraints) 적용
> 2. 크기(width/height) 적용
> 3. 마진(margin) 적용
> 4. 패딩(padding) 적용
> 5. 자식 위젯 배치

## 1단계: 기본 Container 만들기

가장 간단한 Container부터 시작해봅시다:

```typescript
Container({
  width: 200,
  height: 100,
  color: Colors.blue[300],
  child: Text("Hello Container!")
})
```

### 주요 속성들:

- **width/height**: 고정 크기 지정
- **color**: 배경색 설정
- **child**: 담을 위젯 (단 하나만 가능)

## 2단계: 패딩(Padding) 이해하기

패딩은 Container의 경계와 내부 콘텐츠 사이의 간격입니다:

```typescript
Container({
  color: Colors.green[300],
  padding: EdgeInsets.all(20),  // 모든 방향에 20픽셀 패딩
  child: Text("패딩이 있는 텍스트")
})
```

### EdgeInsets의 다양한 사용법:

```typescript
// 모든 방향에 동일한 패딩
EdgeInsets.all(16)

// 가로/세로 각각 다른 패딩
EdgeInsets.symmetric({ horizontal: 20, vertical: 10 })

// 각 방향마다 다른 패딩
EdgeInsets.fromLTRB({ left: 10, top: 20, right: 10, bottom: 30 })

// 특정 방향만 패딩
EdgeInsets.only({ left: 20, right: 20 })
```

## 3단계: 마진(Margin) 활용하기

마진은 Container 외부의 다른 위젯들과의 간격입니다:

```typescript
Container({
  margin: EdgeInsets.all(10),  // 외부 간격
  padding: EdgeInsets.all(20), // 내부 간격
  color: Colors.purple[300],
  child: Text("마진과 패딩")
})
```

> **🎯 실전 팁: 마진 vs 패딩**
> - **패딩**: 배경색이나 테두리 안쪽의 간격. 클릭 영역에 포함됨.
> - **마진**: 다른 위젯과의 간격. 클릭 영역에 포함되지 않음.

## 4단계: 제약조건(Constraints) 활용

고정 크기 대신 유연한 크기 설정이 필요할 때 사용합니다:

```typescript
Container({
  constraints: {
    minWidth: 100,   // 최소 너비
    maxWidth: 300,   // 최대 너비
    minHeight: 50,   // 최소 높이
    maxHeight: 150   // 최대 높이
  },
  color: Colors.orange[300],
  child: Text("유연한 크기의 Container")
})
```

이렇게 하면 내용물의 크기에 따라 Container가 자동으로 조절됩니다!

## 5단계: 실전 예제 - 카드 UI 만들기

Container를 활용해서 실제로 사용할 수 있는 카드 UI를 만들어봅시다:

```typescript
Container({
  width: 300,
  margin: EdgeInsets.all(16),
  padding: EdgeInsets.all(20),
  decoration: new BoxDecoration({
    color: Colors.white,
    borderRadius: BorderRadius.circular(12),
    boxShadow: [
      {
        color: Colors.black.withOpacity(0.1),
        blurRadius: 10,
        offset: { x: 0, y: 4 }
      }
    ]
  }),
  child: Column({
    crossAxisAlignment: CrossAxisAlignment.start,
    children: [
      Text("카드 제목", {
        style: new TextStyle({ 
          fontSize: 20, 
          fontWeight: 'bold' 
        })
      }),
      SizedBox({ height: 8 }),
      Text("카드 내용이 여기에 들어갑니다.", {
        style: new TextStyle({ 
          color: Colors.grey[600] 
        })
      })
    ]
  })
})
```

## 연습 과제

다음 요구사항을 만족하는 Container들을 만들어보세요:

1. **신호등 만들기**
   - 세로로 배치된 3개의 원형 Container
   - 빨강, 노랑, 초록색 사용
   - 각각 적절한 간격 배치

2. **프로필 카드**
   - 이미지를 위한 공간 (회색 Container)
   - 이름과 설명 텍스트
   - 전체를 감싸는 카드 스타일 Container

3. **버튼 스타일 Container**
   - 가로 패딩 24, 세로 패딩 12
   - 둥근 모서리 (BorderRadius.circular(8))
   - 호버 효과를 위한 그림자

## 핵심 정리

Container는 단순하지만 강력한 위젯입니다:

- ✅ **크기 조절**: width, height, constraints
- ✅ **간격 조절**: padding(내부), margin(외부)
- ✅ **시각 효과**: color, decoration
- ✅ **레이아웃**: 다른 위젯을 담는 기본 단위
