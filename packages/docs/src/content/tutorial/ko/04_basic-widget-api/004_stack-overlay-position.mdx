# Stack - 위젯 겹치기와 절대 위치

Stack은 위젯들을 겹쳐서 배치할 수 있게 해주는 강력한 레이아웃 위젯입니다. 카드 위의 배지, 이미지 위의 텍스트, 플로팅 버튼 등 다양한 UI를 만들 때 필수적입니다. Z축(깊이)을 활용한 레이아웃을 배워봅시다.

## 이 튜토리얼에서 배울 것

- [ ] Stack의 기본 개념과 사용법
- [ ] alignment로 위젯 정렬하기
- [ ] Positioned로 절대 위치 지정하기
- [ ] clipBehavior로 오버플로 제어하기
- [ ] 실용적인 Stack 패턴들

## Stack의 기본 개념

Stack은 자식 위젯들을 겹쳐서 표시합니다. 먼저 추가된 위젯이 아래에, 나중에 추가된 위젯이 위에 그려집니다:

```typescript
Stack({
  children: [
    Container({ width: 200, height: 200, color: Colors.red }),    // 맨 아래
    Container({ width: 150, height: 150, color: Colors.green }),  // 중간
    Container({ width: 100, height: 100, color: Colors.blue })    // 맨 위
  ]
})
```

> **💡 핵심 개념: Z-순서**
> 
> Stack의 children 배열에서 인덱스가 클수록 위에 그려집니다.
> - 인덱스 0: 가장 아래 (배경)
> - 인덱스 1, 2, ...: 점점 위로
> - 마지막 인덱스: 가장 위 (전경)
> 
> CSS의 z-index와 비슷한 개념입니다.

## Alignment - 위젯 정렬

alignment 속성으로 Positioned가 아닌 자식들의 정렬을 제어합니다:

### 기본 정렬
```typescript
Stack({
  alignment: Alignment.center,  // 기본값
  children: [
    Container({ width: 200, height: 200, color: Colors.blue[200] }),
    Container({ width: 100, height: 100, color: Colors.blue[600] }),
    Container({ width: 50, height: 50, color: Colors.blue[900] })
  ]
})
```

### 정렬 옵션들
```typescript
Alignment.topLeft      // 왼쪽 상단
Alignment.topCenter    // 상단 중앙
Alignment.topRight     // 오른쪽 상단
Alignment.centerLeft   // 왼쪽 중앙
Alignment.center       // 정중앙 (기본값)
Alignment.centerRight  // 오른쪽 중앙
Alignment.bottomLeft   // 왼쪽 하단
Alignment.bottomCenter // 하단 중앙
Alignment.bottomRight  // 오른쪽 하단

// 커스텀 정렬 (-1.0 ~ 1.0)
Alignment(0.5, -0.5)  // x: 오른쪽으로 조금, y: 위로 조금
```

## Positioned - 절대 위치 지정

Positioned를 사용하면 Stack 내에서 위젯의 정확한 위치를 지정할 수 있습니다:

### 기본 사용법
```typescript
Stack({
  children: [
    // 배경
    Container({ width: 300, height: 200, color: Colors.gray[300] }),
    
    // 왼쪽 상단에서 20px 떨어진 위치
    Positioned({
      left: 20,
      top: 20,
      child: Container({
        width: 80,
        height: 80,
        color: Colors.red
      })
    }),
    
    // 오른쪽 하단에서 20px 떨어진 위치
    Positioned({
      right: 20,
      bottom: 20,
      child: Container({
        width: 80,
        height: 80,
        color: Colors.blue
      })
    })
  ]
})
```

### Positioned 속성들
```typescript
Positioned({
  left: 10,    // 왼쪽에서의 거리
  top: 10,     // 위에서의 거리
  right: 10,   // 오른쪽에서의 거리
  bottom: 10,  // 아래에서의 거리
  width: 100,  // 너비 (선택사항)
  height: 50,  // 높이 (선택사항)
  child: Widget
})
```

### 전체 영역 채우기
```typescript
// 방법 1: 모든 방향 0
Positioned({
  left: 0,
  top: 0,
  right: 0,
  bottom: 0,
  child: Container({ color: Colors.black.withOpacity(0.5) })
})

// 방법 2: Positioned.fill 사용
Positioned.fill({
  child: Container({ color: Colors.black.withOpacity(0.5) })
})
```

## ClipBehavior - 오버플로 제어

Stack 영역을 벗어나는 위젯들을 어떻게 처리할지 결정합니다:

```typescript
Stack({
  clipBehavior: Clip.none,  // 잘리지 않음 (기본값)
  // Clip.hardEdge,  // 날카롭게 자름
  // Clip.antiAlias, // 부드럽게 자름 (성능 비용)
  children: [
    Container({ width: 100, height: 100, color: Colors.blue }),
    Positioned({
      right: -20,  // Stack 영역 밖으로 나감
      top: -20,
      child: Container({
        width: 40,
        height: 40,
        color: Colors.red
      })
    })
  ]
})
```

## IndexedStack - 한 번에 하나만 표시

IndexedStack은 여러 자식 중 하나만 표시합니다:

```typescript
IndexedStack({
  index: currentIndex,  // 표시할 자식의 인덱스
  children: [
    Container({ color: Colors.red }),    // index: 0
    Container({ color: Colors.green }),  // index: 1
    Container({ color: Colors.blue })    // index: 2
  ]
})
```

## 성능 고려사항

### 1. 불필요한 Stack 피하기
```typescript
// ❌ 단순 정렬을 위한 Stack
Stack({
  alignment: Alignment.center,
  children: [Text("중앙 정렬")]
})

// ✅ Center 사용
Center({ child: Text("중앙 정렬") })
```

### 2. 복잡한 Stack 최적화
```typescript

Stack({
  children: [
    // 정적인 배경 (const로 최적화)

    // 동적인 콘텐츠
```

## 주의사항

### 1. Positioned는 Stack의 직접 자식이어야 함
```typescript
// ❌ 에러 발생
Stack({
  children: [
    Container({
      child: Positioned({ /* ... */ })  // 에러!
    })
  ]
})

// ✅ 올바른 사용
Stack({
  children: [
    Positioned({
      child: Container({ /* ... */ })
    })
  ]
})
```

### 2. Stack 크기 결정
Stack의 크기는 non-positioned 자식들에 의해 결정됩니다:
```typescript
Stack({
  children: [
    Container({ width: 200, height: 200 }),  // Stack 크기 결정
    Positioned({ /* 크기에 영향 없음 */ })
  ]
})
```
