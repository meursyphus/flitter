# Container - 모든 것을 담는 기본 상자

Container는 Flitter에서 가장 많이 사용되는 위젯입니다. 단순한 상자처럼 보이지만, 크기, 여백, 장식, 정렬 등 다양한 기능을 제공하는 만능 위젯입니다. Container를 마스터하면 대부분의 레이아웃을 구현할 수 있습니다.

## 이 튜토리얼에서 배울 것

- [ ] Container의 기본 속성과 사용법
- [ ] 크기(width, height)와 제약(constraints) 설정
- [ ] 여백(padding, margin) 다루기
- [ ] BoxDecoration으로 시각적 효과 추가
- [ ] alignment로 자식 위젯 정렬하기

## Container의 기본 개념

Container는 하나의 자식 위젯을 포함할 수 있는 상자입니다. CSS의 div와 비슷하지만 더 많은 기능을 내장하고 있습니다.

### 가장 간단한 사용법
```typescript
Container({
  child: Text("Hello Container!")
})
```

> **💡 핵심 개념: Container의 크기 결정**
> 
> Container의 크기는 다음 우선순위로 결정됩니다:
> 1. width/height가 지정되면 해당 크기 사용
> 2. child가 있고 크기가 지정되지 않으면 child 크기에 맞춤
> 3. child가 없고 크기도 없으면 가능한 최대 크기로 확장
> 
> 실무에서는 명시적으로 크기를 지정하는 것이 예측 가능한 레이아웃을 만듭니다.

## 크기 설정

### 고정 크기
```typescript
Container({
  width: 200,
  height: 100,
  color: Colors.blue,
  child: Text("200x100 크기")
})
```

### 제약 조건 (Constraints)
```typescript
Container({
  constraints: BoxConstraints({
    minWidth: 100,
    maxWidth: 300,
    minHeight: 50,
    maxHeight: 200
  }),
  color: Colors.green,
  child: Text("유연한 크기")
})
```

### 무한 크기
```typescript
Container({
  width: double.infinity,  // 가능한 최대 너비
  height: 50,
  color: Colors.red,
  child: Text("전체 너비")
})
```

## 여백 다루기

### Padding (내부 여백)
padding은 Container의 경계와 child 사이의 공간입니다:

```typescript
Container({
  color: Colors.blue,
  padding: EdgeInsets.all(20),  // 모든 방향 20
  child: Text("패딩이 있는 텍스트")
})

// 방향별 패딩
Container({
  padding: EdgeInsets.only({
    left: 10,
    top: 20,
    right: 10,
    bottom: 30
  }),
  child: Text("방향별 패딩")
})

// 대칭 패딩
Container({
  padding: EdgeInsets.symmetric({
    horizontal: 20,  // 좌우
    vertical: 10    // 상하
  }),
  child: Text("대칭 패딩")
})
```

### Margin (외부 여백)
margin은 Container 외부의 공간입니다:

```typescript
Container({
  margin: EdgeInsets.all(10),
  color: Colors.green,
  child: Text("마진이 있는 컨테이너")
})
```

## BoxDecoration - 시각적 효과

decoration 속성으로 Container를 아름답게 꾸밀 수 있습니다:

### 기본 장식
```typescript
Container({
  width: 200,
  height: 100,
  decoration: new BoxDecoration({
    color: Colors.white,
    borderRadius: BorderRadius.circular(12),
    border: Border.all({
      color: Colors.blue,
      width: 2
    })
  }),
  child: Center({
    child: Text("장식된 컨테이너")
  })
})
```

### 그림자 효과
```typescript
Container({
  width: 200,
  height: 100,
  decoration: new BoxDecoration({
    color: Colors.white,
    borderRadius: BorderRadius.circular(8),
    boxShadow: [
      new BoxShadow({
        color: "rgba(0, 0, 0, 0.1)",
        blurRadius: 10,
        offset: { x: 0, y: 5 }
      })
    ]
  }),
  child: Center({
    child: Text("그림자가 있는 카드")
  })
})
```

### 그라데이션
```typescript
Container({
  width: 200,
  height: 100,
  decoration: new BoxDecoration({
    gradient: LinearGradient({
      colors: [Colors.blue[400], Colors.purple[400]],
      begin: Alignment.topLeft,
      end: Alignment.bottomRight
    })
  }),
  child: Center({
    child: Text("그라데이션", {
      style: new TextStyle({
        color: Colors.white,
        fontWeight: 'bold'
      })
    })
  })
})
```

> **⚠️ 주의**: color 속성과 decoration을 동시에 사용할 수 없습니다. color를 사용하려면 decoration.color로 설정하세요.

## Alignment - 자식 위젯 정렬

alignment 속성으로 child의 위치를 조절할 수 있습니다:

### 기본 정렬
```typescript
Container({
  width: 200,
  height: 200,
  color: Colors.gray[300],
  alignment: Alignment.center,  // 중앙 정렬
  child: Container({
    width: 50,
    height: 50,
    color: Colors.red
  })
})
```

### 정렬 옵션들
```typescript
// 미리 정의된 정렬
Alignment.topLeft      // 좌상단
Alignment.topCenter    // 상단 중앙
Alignment.topRight     // 우상단
Alignment.centerLeft   // 좌측 중앙
Alignment.center       // 정중앙
Alignment.centerRight  // 우측 중앙
Alignment.bottomLeft   // 좌하단
Alignment.bottomCenter // 하단 중앙
Alignment.bottomRight  // 우하단

// 커스텀 정렬 (-1.0 ~ 1.0)
Alignment(-0.5, 0.5)  // 좌측으로 조금, 아래로 조금
```

## 실전 예제: 카드 UI 만들기

Container의 모든 기능을 활용한 카드 UI:

```typescript
Container({
  width: 300,
  margin: EdgeInsets.all(16),
  padding: EdgeInsets.all(20),
  decoration: new BoxDecoration({
    color: Colors.white,
    borderRadius: BorderRadius.circular(16),
    boxShadow: [
      new BoxShadow({
        color: "rgba(0, 0, 0, 0.1)",
        blurRadius: 20,
        offset: { x: 0, y: 10 }
      })
    ]
  }),
  child: Column({
    crossAxisAlignment: CrossAxisAlignment.start,
    mainAxisSize: MainAxisSize.min,
    children: [
      Container({
        width: 60,
        height: 60,
        decoration: new BoxDecoration({
          color: Colors.blue[100],
          shape: BoxShape.circle
        }),
        alignment: Alignment.center,
        child: Text("📦", {
          style: new TextStyle({ fontSize: 30 })
        })
      }),
      Container({ height: 16 }),
      Text("Container 마스터", {
        style: new TextStyle({
          fontSize: 20,
          fontWeight: 'bold'
        })
      }),
      Container({ height: 8 }),
      Text("모든 UI의 기본이 되는 Container 위젯을 완벽하게 이해했습니다!", {
        style: new TextStyle({
          fontSize: 14,
          color: Colors.gray[600],
          height: 1.5
        })
      })
    ]
  })
})
```

## 성능 팁

### 1. 불필요한 Container 피하기
```typescript
// ❌ 불필요한 중첩
Container({
  child: Container({
    child: Container({
      child: Text("과도한 중첩")
    })
  })
})

// ✅ 필요한 속성만 사용
Container({
  padding: EdgeInsets.all(20),
  color: Colors.blue,
  child: Text("간단하게")
})
```

### 2. const 활용
```typescript
// 변하지 않는 Container는 const로
const emptyBox = Container({
  width: 20,
  height: 20
});
```

## 자주 하는 실수

### 1. color와 decoration 충돌
```typescript
// ❌ 에러 발생
Container({
  color: Colors.blue,
  decoration: new BoxDecoration({
    borderRadius: BorderRadius.circular(8)
  })
})

// ✅ decoration.color 사용
Container({
  decoration: new BoxDecoration({
    color: Colors.blue,
    borderRadius: BorderRadius.circular(8)
  })
})
```

### 2. 크기 지정 없이 정렬
```typescript
// ❌ 작동하지 않음 (Container가 child 크기로 축소)
Container({
  color: Colors.blue,
  alignment: Alignment.centerRight,
  child: Text("정렬 안됨")
})

// ✅ 크기 지정 필요
Container({
  width: 200,
  color: Colors.blue,
  alignment: Alignment.centerRight,
  child: Text("정렬됨")
})
```
