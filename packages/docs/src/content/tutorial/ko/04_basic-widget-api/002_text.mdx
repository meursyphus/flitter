# Text - 텍스트 표시와 스타일링

Text 위젯은 화면에 텍스트를 표시하는 가장 기본적인 위젯입니다. 단순해 보이지만 TextStyle을 통해 무궁무진한 표현이 가능합니다.

## 이 튜토리얼에서 배울 것

- [ ] Text 위젯의 기본 사용법
- [ ] TextStyle로 다양한 스타일 적용하기
- [ ] 폰트 크기, 굵기, 색상 조절
- [ ] 텍스트 장식 효과 (밑줄, 취소선 등)
- [ ] 텍스트 정렬과 간격 조절
- [ ] 실전에서 자주 사용하는 텍스트 패턴

## Text 위젯의 기본

가장 간단한 형태의 Text 위젯입니다:

```typescript
Text("Hello, World!")
```

스타일을 추가하려면 TextStyle을 사용합니다:

```typescript
Text("스타일이 있는 텍스트", {
  style: new TextStyle({
    fontSize: 20,
    color: Colors.blue[600]
  })
})
```

> **💡 핵심 개념: Text 위젯의 특징**
> 
> - 단일 스타일만 적용 가능 (여러 스타일이 필요하면 RichText 사용)
> - 기본적으로 한 줄로 표시되며, 넘치면 자동 줄바꿈
> - 부모 위젯의 제약조건에 따라 크기가 결정됨

## 1단계: 텍스트 크기와 굵기

### fontSize - 텍스트 크기

```typescript
Text("큰 제목", {
  style: new TextStyle({ fontSize: 32 })
})

Text("작은 설명", {
  style: new TextStyle({ fontSize: 14 })
})
```

### fontWeight - 텍스트 굵기

```typescript
// 문자열 방식
Text("굵은 텍스트", {
  style: new TextStyle({ fontWeight: "bold" })
})

// 숫자 방식 (w100 ~ w900)
Text("중간 굵기", {
  style: new TextStyle({ fontWeight: "w500" })
})
```

굵기 옵션:
- `"normal"` 또는 `"w400"`: 기본 굵기
- `"bold"` 또는 `"w700"`: 굵게
- `"w100"` ~ `"w900"`: 세밀한 조절

## 2단계: 색상과 스타일

### color - 텍스트 색상

```typescript
Text("파란색 텍스트", {
  style: new TextStyle({ 
    color: Colors.blue[600] 
  })
})

// 투명도 조절
Text("반투명 텍스트", {
  style: new TextStyle({ 
    color: Colors.black.withOpacity(0.5) 
  })
})
```

### fontStyle - 기울임체

```typescript
Text("이탤릭체 텍스트", {
  style: new TextStyle({ 
    fontStyle: "italic" 
  })
})
```

## 3단계: 텍스트 장식

### decoration - 밑줄, 취소선 등

```typescript
// 밑줄
Text("밑줄 텍스트", {
  style: new TextStyle({ 
    decoration: "underline",
    decorationColor: Colors.blue[400]
  })
})

// 취소선
Text("취소된 항목", {
  style: new TextStyle({ 
    decoration: "lineThrough",
    decorationColor: Colors.red[400]
  })
})

// 위줄
Text("위줄 텍스트", {
  style: new TextStyle({ 
    decoration: "overline"
  })
})
```

### decorationStyle - 장식선 스타일

```typescript
Text("점선 밑줄", {
  style: new TextStyle({ 
    decoration: "underline",
    decorationStyle: "dotted"
  })
})
```

스타일 옵션:
- `"solid"`: 실선 (기본값)
- `"double"`: 이중선
- `"dotted"`: 점선
- `"dashed"`: 대시선
- `"wavy"`: 물결선

## 4단계: 간격과 높이

### letterSpacing - 글자 간격

```typescript
Text("글자 간격이 넓은 텍스트", {
  style: new TextStyle({ 
    letterSpacing: 2.0 
  })
})
```

### wordSpacing - 단어 간격

```typescript
Text("단어 간격이 넓은 텍스트", {
  style: new TextStyle({ 
    wordSpacing: 5.0 
  })
})
```

### height - 줄 높이

```typescript
Text("줄 간격이\n넓은\n텍스트", {
  style: new TextStyle({ 
    height: 2.0  // fontSize의 배수
  })
})
```

## 5단계: 텍스트 정렬

### textAlign - 텍스트 정렬

```typescript
Container({
  width: 300,
  child: Text("가운데 정렬", {
    textAlign: "center"
  })
})
```

정렬 옵션:
- `"left"`: 왼쪽 정렬 (기본값)
- `"right"`: 오른쪽 정렬
- `"center"`: 가운데 정렬
- `"justify"`: 양쪽 정렬

## 고급 팁: TextStyle 재사용

자주 사용하는 스타일은 변수로 저장해서 재사용하세요:

```typescript
// 스타일 정의
const headingStyle = new TextStyle({
  fontSize: 20,
  fontWeight: "bold",
  color: Colors.grey[800]
});

const bodyStyle = new TextStyle({
  fontSize: 14,
  height: 1.5,
  color: Colors.grey[600]
});

// 사용
Text("제목", { style: headingStyle })
Text("본문 내용", { style: bodyStyle })
```

## 핵심 정리

Text 위젯과 TextStyle로 할 수 있는 것들:

- ✅ **크기와 굵기**: fontSize, fontWeight
- ✅ **색상과 스타일**: color, fontStyle
- ✅ **장식**: decoration, decorationColor, decorationStyle
- ✅ **간격**: letterSpacing, wordSpacing, height
- ✅ **정렬**: textAlign
