# Row와 Column - 선형 배치의 기본

Row와 Column은 Flitter에서 가장 중요한 레이아웃 위젯입니다. 이 두 위젯만 잘 다루어도 대부분의 UI 레이아웃을 구성할 수 있습니다.

## 이 튜토리얼에서 배울 것

- [ ] Row로 위젯을 가로로 배치하기
- [ ] Column으로 위젯을 세로로 배치하기
- [ ] MainAxisAlignment로 주축 정렬 마스터하기
- [ ] CrossAxisAlignment로 교차축 정렬 이해하기
- [ ] Expanded와 Flexible로 유연한 레이아웃 만들기
- [ ] 실전에서 자주 사용하는 레이아웃 패턴

## Row와 Column의 기본 개념

### 축(Axis) 이해하기

Row와 Column은 두 개의 축을 가집니다:

- **주축(Main Axis)**: 위젯이 배치되는 방향
  - Row: 가로 (왼쪽 → 오른쪽)
  - Column: 세로 (위 → 아래)

- **교차축(Cross Axis)**: 주축에 수직인 방향
  - Row: 세로
  - Column: 가로

> **💡 핵심 개념: 축의 중요성**
> 
> Row와 Column의 정렬을 이해하려면 주축과 교차축의 개념을 확실히 알아야 합니다. 
> MainAxisAlignment는 주축 방향의 정렬을, CrossAxisAlignment는 교차축 방향의 정렬을 담당합니다.

## 1단계: Row - 가로 배치

가장 간단한 Row 예제:

```typescript
Row({
  children: [
    Text("첫 번째"),
    Text("두 번째"),
    Text("세 번째")
  ]
})
```

### 간격 추가하기

```typescript
Row({
  children: [
    Container({ width: 50, height: 50, color: Colors.red }),
    SizedBox({ width: 10 }),  // 가로 간격
    Container({ width: 50, height: 50, color: Colors.green }),
    SizedBox({ width: 10 }),
    Container({ width: 50, height: 50, color: Colors.blue })
  ]
})
```

## 2단계: Column - 세로 배치

Column의 기본 사용법:

```typescript
Column({
  children: [
    Text("위"),
    Text("중간"),
    Text("아래")
  ]
})
```

### 간격 추가하기

```typescript
Column({
  children: [
    Container({ width: 50, height: 50, color: Colors.red }),
    SizedBox({ height: 10 }),  // 세로 간격
    Container({ width: 50, height: 50, color: Colors.green }),
    SizedBox({ height: 10 }),
    Container({ width: 50, height: 50, color: Colors.blue })
  ]
})
```

## 3단계: MainAxisAlignment - 주축 정렬

### MainAxisAlignment 옵션들

```typescript
// 1. start (기본값) - 시작점에 정렬
Row({
  mainAxisAlignment: MainAxisAlignment.start,
  children: [...]
})

// 2. end - 끝점에 정렬
Row({
  mainAxisAlignment: MainAxisAlignment.end,
  children: [...]
})

// 3. center - 가운데 정렬
Row({
  mainAxisAlignment: MainAxisAlignment.center,
  children: [...]
})

// 4. spaceBetween - 양 끝 배치, 중간 균등 분배
Row({
  mainAxisAlignment: MainAxisAlignment.spaceBetween,
  children: [...]
})

// 5. spaceEvenly - 모든 간격 균등 분배
Row({
  mainAxisAlignment: MainAxisAlignment.spaceEvenly,
  children: [...]
})

// 6. spaceAround - 각 위젯 주변에 균등한 간격
Row({
  mainAxisAlignment: MainAxisAlignment.spaceAround,
  children: [...]
})
```

> **🎯 실전 팁: 언제 어떤 정렬을 사용할까?**
> - **center**: 제목, 로고 등 중앙 배치가 필요할 때
> - **spaceBetween**: 네비게이션 바, 툴바 등
> - **spaceEvenly**: 탭 바, 균등한 버튼 그룹
> - **start/end**: 좌측/우측 정렬이 필요한 텍스트나 아이콘

## 4단계: CrossAxisAlignment - 교차축 정렬

### CrossAxisAlignment 옵션들

```typescript
// 1. start - 교차축의 시작점
Column({
  crossAxisAlignment: CrossAxisAlignment.start,
  children: [
    Container({ width: 100, height: 30, color: Colors.red }),
    Container({ width: 150, height: 30, color: Colors.green }),
    Container({ width: 80, height: 30, color: Colors.blue })
  ]
})

// 2. center (기본값) - 교차축의 중앙
// 3. end - 교차축의 끝점
// 4. stretch - 교차축 방향으로 늘리기
Column({
  crossAxisAlignment: CrossAxisAlignment.stretch,
  children: [...]
})
```

## 5단계: Expanded와 Flexible

### Expanded - 남은 공간 채우기

```typescript
Row({
  children: [
    Container({ width: 50, height: 50, color: Colors.red }),
    Expanded({
      child: Container({ height: 50, color: Colors.green })
    }),
    Container({ width: 50, height: 50, color: Colors.blue })
  ]
})
```

### flex 속성으로 비율 조절

```typescript
Row({
  children: [
    Expanded({
      flex: 2,  // 2배 공간
      child: Container({ height: 50, color: Colors.red })
    }),
    Expanded({
      flex: 1,  // 1배 공간
      child: Container({ height: 50, color: Colors.green })
    }),
    Expanded({
      flex: 1,  // 1배 공간
      child: Container({ height: 50, color: Colors.blue })
    })
  ]
})
```

## 연습 과제

다음과 같은 레이아웃을 만들어보세요:

1. **네비게이션 바**
   - 로고(왼쪽), 메뉴 아이템들(중앙), 프로필(오른쪽)
   - MainAxisAlignment.spaceBetween 활용

2. **통계 대시보드**
   - 3개의 통계 카드를 가로로 배치
   - 각 카드는 아이콘, 수치, 레이블을 세로로 배치
   - Expanded로 균등한 너비

3. **채팅 메시지 UI**
   - 프로필 이미지와 메시지를 가로 배치
   - 메시지는 Expanded로 남은 공간 채우기
   - 시간 표시는 오른쪽 정렬

<details>
<summary>💡 힌트</summary>

1. 네비게이션 바는 Row + MainAxisAlignment.spaceBetween
2. 통계 카드는 Row 안에 Expanded된 Column들
3. 채팅 UI는 Row + CrossAxisAlignment.start가 핵심

</details>

## 중첩 레이아웃 팁

Row와 Column을 중첩해서 복잡한 레이아웃을 만들 수 있습니다:

```typescript
Column({
  children: [
    Row({
      mainAxisAlignment: MainAxisAlignment.spaceBetween,
      children: [/* 헤더 */]
    }),
    Expanded({
      child: Row({
        children: [
          /* 사이드바 */
          Expanded({
            child: Column({
              children: [/* 메인 콘텐츠 */]
            })
          })
        ]
      })
    }),
    Row({
      children: [/* 푸터 */]
    })
  ]
})
```

## 핵심 정리

Row와 Column 마스터 체크리스트:

- ✅ **기본 배치**: Row(가로), Column(세로)
- ✅ **주축 정렬**: MainAxisAlignment의 6가지 옵션
- ✅ **교차축 정렬**: CrossAxisAlignment의 4가지 옵션
- ✅ **유연한 크기**: Expanded와 Flexible
- ✅ **간격 조절**: SizedBox 활용
