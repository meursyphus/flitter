# Flitter의 Animation Controller

애니메이션은 매력적이고 동적인 사용자 인터페이스를 만드는 데 중요한 부분입니다. Flitter에서 AnimationController는 애니메이션을 관리하는 핵심 클래스입니다. 애니메이션의 지속 시간, 속도, 방향을 제어할 수 있어 부드럽고 사용자 지정 가능한 애니메이션 경험을 제공합니다.

## AnimationController 이해하기

AnimationController는 기기의 화면이 새 프레임을 표시할 준비가 될 때마다 새 값을 생성합니다. 일반적으로 이는 초당 60회 발생합니다.

### 주요 개념

1. **Duration(지속 시간)**: 애니메이션이 지속되어야 하는 시간의 길이.
2. **Value(값)**: 0.0에서 1.0 범위의 double로, 애니메이션의 현재 상태를 나타냅니다.
3. **Forward(전진)**: 시작부터 끝까지 애니메이션을 재생.
4. **Reverse(역방향)**: 끝에서 시작까지 애니메이션을 재생.

## 기본 사용법

AnimationController를 생성하고 사용하는 간단한 예제입니다:

```typescript
import {
  StatefulWidget,
  State,
  AnimationController,
  Duration,
} from "@meursyphus/flitter";

class AnimatedWidget extends StatefulWidget {
  createState() {
    return new AnimatedWidgetState();
  }
}

class AnimatedWidgetState extends State<AnimatedWidget> {
  private controller: AnimationController;

  initState() {
    super.initState();
    this.controller = new AnimationController({
      duration: 1000, // milliseconds
      lowerBound: 0,
      upperBound: 1,
    });
    this.controller.forward();
  }

  dispose() {
    this.controller.dispose();
    super.dispose();
  }

  build() {
    return /* Your widget tree here */;
  }
}
```

이 예제에서는 1초 지속 시간을 가진 AnimationController를 생성하고 `initState` 메서드에서 즉시 시작합니다.

## 위젯 애니메이션

AnimationController를 사용하여 위젯에 애니메이션을 적용하려면 일반적으로 Tween과 함께 사용합니다:

```typescript
import { AnimatedBuilder, Tween, Container } from '@meursyphus/flitter';

// ... inside your build method
build() {
  return AnimatedBuilder({
    animation: this.controller,
    builder: (context, child) => {
      return Container({
        width: Tween({ begin: 0, end: 200 }).evaluate(this.controller),
        height: 100,
        color: 'blue'
      });
    }
  });
}
```

이것은 1초 동안 컨테이너의 너비를 0에서 200으로 애니메이션합니다.

## 고급 사용법

### 반복 애니메이션

`repeat` 메서드를 사용하여 반복 애니메이션을 만들 수 있습니다:

```typescript
this.controller = new AnimationController({
  duration: 2000, // milliseconds
  lowerBound: 0,
  upperBound: 1,
});
this.controller.repeat(reverse: true);
```

이것은 앤d다갔다 하는 핑퐁 애니메이션을 만듭니다.

### 곡선 애니메이션

Curve 클래스를 사용하여 비선형 애니메이션 곡선을 적용할 수 있습니다:

```typescript
import { CurvedAnimation, Curves } from "@meursyphus/flitter";

const curvedAnimation = new CurvedAnimation({
  parent: this.controller,
  curve: Curves.easeInOut,
});
```

### 시차 애니메이션

다른 지연 시간을 가진 여러 AnimationController를 사용하여 시차 애니메이션을 만들 수 있습니다:

```typescript
this.controller1 = new AnimationController({
  duration: 500, // milliseconds
});
this.controller2 = new AnimationController({
  duration: 500, // milliseconds
});

this.controller1.forward();
this.controller1.addStatusListener((status) => {
  if (status === AnimationStatus.completed) {
    this.controller2.forward();
  }
});
```

## 모범 사례

1. **적절한 해제**: 메모리 누수를 방지하기 위해 항상 `dispose` 메서드에서 AnimationController를 해제하세요.

2. **const 생성자 사용**: 가능한 경우 성능 향상을 위해 Tween과 Animation에 const 생성자를 사용하세요.

3. **부드러운 애니메이션 유지**: 애니메이션을 간단하고 최적화하여 60fps를 목표로 하세요.

4. **기기에서 테스트**: 부드러운 성능을 보장하기 위해 항상 실제 기기에서 애니메이션을 테스트하세요.

5. **내장 위젯 사용**: Flitter는 AnimatedContainer, AnimatedOpacity 등 많은 사전 빌드된 애니메이션 위젯을 제공합니다. 가능한 경우 더 간단한 코드를 위해 이들을 사용하세요.

## 결론

AnimationController는 부드럽고 사용자 지정 가능한 애니메이션을 만드는 Flitter의 강력한 도구입니다. Tween과 Curve 같은 개념과 함께 사용법을 마스터하면 매력적이고 동적인 사용자 인터페이스를 만들 수 있습니다. Flitter 애플리케이션에서 애니메이션을 구현할 때 항상 성능과 사용자 경험을 고려하세요.
