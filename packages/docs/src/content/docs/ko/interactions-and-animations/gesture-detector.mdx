# Flitter의 제스처 감지

제스처 감지는 Flitter에서 대화형 사용자 인터페이스를 만드는 데 중요한 측면입니다. 탭, 드래그, 스크롤과 같은 다양한 사용자 입력에 애플리케이션이 응답할 수 있게 해줍니다. Flitter는 이러한 상호작용을 처리하기 위해 GestureDetector라는 강력한 위젯을 제공합니다.

## GestureDetector 위젯

GestureDetector 위젯은 시각적 표현이 없지만 대신 자식 위젯에서 만들어진 제스처를 감지합니다.

### 기본 사용법

GestureDetector를 사용하는 간단한 예제입니다:

```typescript
import { GestureDetector, Container, Text } from "@meursyphus/flitter";

const gestureExample = GestureDetector({
  onClick: (e) => {
    console.log("컨테이너가 클릭되었습니다!");
  },
  child: Container({
    width: 200,
    height: 100,
    color: "blue",
    child: Text("클릭하세요!", { style: new TextStyle({ color: "white" }) }),
  }),
});
```

## 일반적인 제스처 유형

GestureDetector는 다양한 유형의 제스처를 처리할 수 있습니다. 다음은 가장 일반적으로 사용되는 것들입니다:

### 1. 클릭 (탭)

사용자가 화면을 탭할 때를 감지합니다.

```typescript
GestureDetector({
  onClick: (e) => {
    console.log('탭 위치: ', e.clientX, e.clientY);
  },
  child: /* your widget here */
})
```

### 2. 더블 클릭 (더블 탭)

사용자가 화면을 더블 탭할 때를 감지합니다.

```typescript
GestureDetector({
  onDoubleClick: (e) => {
    console.log('더블 탭되었습니다!');
  },
  child: /* your widget here */
})
```

### 3. 드래그

사용자가 화면을 가로질러 손가락을 드래그할 때를 감지합니다.

```typescript
GestureDetector({
  onDragStart: (e) => {
    console.log('드래그 시작');
  },
  onDragUpdate: (e) => {
    console.log('드래그 위치: ', e.clientX, e.clientY);
  },
  onDragEnd: (e) => {
    console.log('드래그 종료');
  },
  child: /* your widget here */
})
```

### 4. 마우스 이벤트

웹 애플리케이션의 경우 특정 마우스 이벤트도 처리할 수 있습니다:

```typescript
GestureDetector({
  onMouseEnter: (e) => {
    console.log('마우스 진입');
  },
  onMouseLeave: (e) => {
    console.log('마우스 이탈');
  },
  onMouseMove: (e) => {
    console.log('마우스 이동 위치: ', e.clientX, e.clientY);
  },
  child: /* your widget here */
})
```

## 고급 사용법: 제스처 결합하기

단일 GestureDetector에서 여러 제스처 인식기를 결합할 수 있습니다:

```typescript
import {
  GestureDetector,
  Container,
  Text,
  setState,
} from "@meursyphus/flitter";

class InteractiveBox extends StatefulWidget {
  createState() {
    return new InteractiveBoxState();
  }
}

class InteractiveBoxState extends State<InteractiveBox> {
  private color: string = "blue";
  private text: string = "저와 상호작용하세요!";

  build() {
    return GestureDetector({
      onClick: () => {
        this.setState(() => {
          this.color = "red";
          this.text = "클릭됨!";
        });
      },
      onMouseEnter: () => {
        this.setState(() => {
          this.color = "yellow";
          this.text = "마우스 진입!";
        });
      },
      onMouseLeave: () => {
        this.setState(() => {
          this.color = "blue";
          this.text = "마우스 이탈!";
        });
      },
      child: Container({
        width: 200,
        height: 100,
        color: this.color,
        child: Text(this.text, { style: new TextStyle({ color: "black" }) }),
      }),
    });
  }
}
```

이 예제는 다양한 사용자 상호작용에 따라 색상과 텍스트가 변경되는 대화형 상자를 만듭니다.

## 모범 사례

1. **반응성 있게 만들기**: 사용자 경험을 향상시키기 위해 앱이 제스처에 대해 즉각적인 피드백을 제공하도록 합니다.

2. **적절한 제스처 사용**: 수행되는 동작에 직관적인 제스처를 선택합니다.

3. **시각적 피드백 제공**: 제스처가 인식될 때 항상 사용자에게 시각적 단서를 제공합니다.

4. **접근성 고려**: 장애가 있는 사용자를 위해 대체 입력 방법으로 앱을 사용할 수 있도록 합니다.

5. **철저한 테스트**: 제스처 상호작용은 때때로 까다로울 수 있으므로 다양한 기기와 화면 크기에서 앱을 철저히 테스트합니다.

## 결론

제스처 감지는 대화형이고 반응형 Flitter 애플리케이션을 만드는 강력한 도구입니다. GestureDetector 위젯을 마스터하고 다양한 유형의 제스처를 이해함으로써 사용자 입력에 직관적으로 반응하는 풍부한 사용자 경험을 만들 수 있습니다. 동적이고 대화형 UI를 만들기 위해 제스처 감지를 상태 관리와 결합하는 것을 잊지 마세요.
