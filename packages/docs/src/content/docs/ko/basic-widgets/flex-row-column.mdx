# Flitter의 Flex, Row, Column 위젯

Flex 위젯과 그 하위 클래스인 Row와 Column은 Flitter에서 유연한 레이아웃을 만드는 데 기본적입니다. 이러한 위젯을 사용하면 다양한 정렬 및 크기 조정 옵션과 함께 자식 위젯을 한 행 또는 열로 배치할 수 있습니다.

## Flex 위젯

Flex 위젯은 Row와 Column의 기본 클래스입니다. 레이아웃의 방향(수평 또는 수직)을 지정할 수 있습니다.

### 주요 속성

- `direction`: 레이아웃이 수평인지 수직인지 지정합니다.
- `children`: 배치할 자식 위젯의 목록입니다.
- `mainAxisAlignment`: 주축을 따라 자식이 어떻게 정렬되는지 결정합니다.
- `crossAxisAlignment`: 교차축을 따라 자식이 어떻게 정렬되는지 결정합니다.
- `mainAxisSize`: 주축에서 Flex가 차지해야 하는 공간을 결정합니다.

## Row 위젯

Row 위젯은 자식을 수평으로 배치하는 특수한 Flex입니다.

### 기본 사용법

```typescript
import { Row, Container } from "@meursyphus/flitter";

const myRow = Row({
  children: [
    Container({ width: 50, height: 50, color: "red" }),
    Container({ width: 50, height: 50, color: "green" }),
    Container({ width: 50, height: 50, color: "blue" }),
  ],
});
```

### 시각적 표현

```
┌──────────────────────────────┐
│ ┌────┐ ┌────┐ ┌────┐         │
│ │빨강 │ │초록 │ │파랑│         │
│ └────┘ └────┘ └────┘         │
└──────────────────────────────┘
```

## Column 위젯

Column 위젯은 자식을 수직으로 배치하는 특수한 Flex입니다.

### 기본 사용법

```typescript
import { Column, Container } from "@meursyphus/flitter";

const myColumn = Column({
  children: [
    Container({ width: 100, height: 50, color: "red" }),
    Container({ width: 100, height: 50, color: "green" }),
    Container({ width: 100, height: 50, color: "blue" }),
  ],
});
```

### 시각적 표현

```
┌──────────────┐
│ ┌──────────┐ │
│ │   빨강    │ │
│ └──────────┘ │
│ ┌──────────┐ │
│ │   초록    │ │
│ └──────────┘ │
│ ┌──────────┐ │
│ │   파랑    │ │
│ └──────────┘ │
└──────────────┘
```

## 고급 사용법

### MainAxisAlignment

MainAxisAlignment는 주축을 따라 자식이 배치되는 방법을 결정합니다. Row를 사용한 예제입니다:

```typescript
import { Row, Container, MainAxisAlignment } from "@meursyphus/flitter";

const spacedRow = Row({
  mainAxisAlignment: MainAxisAlignment.spaceBetween,
  children: [
    Container({ width: 50, height: 50, color: "red" }),
    Container({ width: 50, height: 50, color: "green" }),
    Container({ width: 50, height: 50, color: "blue" }),
  ],
});
```

시각적 표현:

```
┌──────────────────────────────┐
│ ┌────┐     ┌────┐     ┌────┐ │
│ │빨강 │     │초록 │     │파랑│ │
│ └────┘     └────┘     └────┘ │
└──────────────────────────────┘
```

### CrossAxisAlignment

CrossAxisAlignment는 교차축을 따라 자식이 배치되는 방법을 결정합니다. Column을 사용한 예제입니다:

```typescript
import { Column, Container, CrossAxisAlignment } from "@meursyphus/flitter";

const alignedColumn = Column({
  crossAxisAlignment: CrossAxisAlignment.start,
  children: [
    Container({ width: 100, height: 50, color: "red" }),
    Container({ width: 75, height: 50, color: "green" }),
    Container({ width: 50, height: 50, color: "blue" }),
  ],
});
```

시각적 표현:

```
┌──────────────┐
│ ┌──────────┐ │
│ │   빨강    │ │
│ └──────────┘ │
│ ┌────────┐   │
│ │  초록   │   │
│ └────────┘   │
│ ┌────┐       │
│ │파랑│       │
│ └────┘       │
└──────────────┘
```

## 모범 사례

1. **유연한 크기 조정에 Expanded 사용**: 자식이 사용 가능한 공간을 채우기를 원할 때 Expanded 위젯으로 감싸세요.

2. **사용자 지정 flex 요소에 Flex 고려**: 자식 간에 공간이 분배되는 방식을 더 세밀하게 제어해야 할 때 Flex를 사용하세요.

3. **다른 레이아웃 위젯과 결합**: Row와 Column은 더 복잡한 레이아웃을 위해 Container와 SizedBox 같은 다른 레이아웃 위젯과 잘 작동합니다.

4. **오버플로우 주의**: 자식이 사용 가능한 공간에 맞지 않는 경우 ListView와 같은 스크롤 가능한 위젯 사용을 고려하세요.

## 결론

Flex, Row, Column 위젯은 Flitter에서 유연한 레이아웃을 만드는 데 필수적입니다. 이러한 위젯을 효과적으로 사용하는 방법을 이해하면 반응형이고 잘 조직된 사용자 인터페이스를 만들 수 있습니다. 애플리케이션에 원하는 레이아웃을 달성하기 위해 다양한 정렬 및 크기 조정 옵션을 실험해 보세요.
