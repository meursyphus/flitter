# Flitter의 Text 위젯

Flitter의 Text 위젯은 단일 스타일로 텍스트를 표시하는 데 사용됩니다. 사용자 인터페이스를 만드는 데 가장 기본적인 위젯 중 하나이며 애플리케이션에서 모든 텍스트 정보를 표시하는 데 필수적입니다.

## 개요

Text 위젯은 단일 스타일로 텍스트 문자열을 표시합니다. 표시할 텍스트는 위젯의 첫 번째 매개변수를 사용하여 제공되며, 다양한 스타일 속성을 사용하여 모양을 사용자 지정할 수 있습니다.

## 기본 사용법

Text 위젯을 사용하는 간단한 예제입니다:

```typescript
import { Text } from "@meursyphus/flitter";

const simpleText = Text("Hello, Flitter!");
```

이것은 기본 스타일링으로 기본 텍스트 표시를 만듭니다.

## 텍스트 스타일링

텍스트에 스타일을 지정하려면 TextStyle 객체를 받는 `style` 속성을 사용할 수 있습니다:

```typescript
import { Text, TextStyle } from "@meursyphus/flitter";

const styledText = Text("Styled Text", {
  style: new TextStyle({
    fontSize: 20,
    fontWeight: "bold",
    color: "blue",
  }),
});
```

## 주요 TextStyle 속성

- `fontSize`: 글꼴 크기를 설정합니다.
- `fontWeight`: 글꼴 두께를 설정합니다 (예: 'normal', 'bold').
- `fontStyle`: 글꼴 스타일을 설정합니다 (예: 'normal', 'italic').
- `color`: 텍스트 색상을 설정합니다.
- `letterSpacing`: 글자 간 간격을 설정합니다.
- `wordSpacing`: 단어 간 간격을 설정합니다.
- `textDecoration`: 텍스트에 장식을 추가합니다 (예: 'underline', 'overline', 'line-through').
- `fontFamily`: 사용할 글꼴 패밀리를 지정합니다.

## 고급 사용법

### 텍스트 정렬

부모 컨테이너 내에서 텍스트를 정렬할 수 있습니다:

```typescript
import { Text, TextAlign } from "@meursyphus/flitter";

const alignedText = Text("Centered Text", {
  textAlign: TextAlign.center,
});
```

### 텍스트 오버플로우

경계 내에 맞지 않을 수 있는 텍스트 처리:

```typescript
import { Text, TextOverflow } from "@meursyphus/flitter";

const overflowText = Text("This is a very long text that might overflow...", {
  overflow: TextOverflow.ellipsis,
  maxLines: 1,
});
```

### 텍스트 너비 기준

텍스트 너비가 계산되는 방법 제어:

```typescript
import { Text, TextWidthBasis } from "@meursyphus/flitter";

// 가장 긴 줄의 너비 사용
const longLineText = Text("여러 줄 텍스트\n다양한 길이로", {
  textWidthBasis: TextWidthBasis.longestLine,
});

// 부모의 너비를 기준으로 사용
const parentBasedText = Text("부모 너비를 따라가는 텍스트", {
  textWidthBasis: TextWidthBasis.parent,
});
```

### 풍부한 텍스트

여러 스타일이 있는 텍스트의 경우 `TextSpan` 위젯을 사용할 수 있습니다:

```typescript
import { Text, TextSpan, TextStyle } from "@meursyphus/flitter";

const richText = Text.rich(
  new TextSpan({
    children: [
      new TextSpan({ text: "Hello ", style: new TextStyle({ color: "blue" }) }),
      new TextSpan({
        text: "Flitter",
        style: new TextStyle({ color: "red", fontWeight: "bold" }),
      }),
      new TextSpan({ text: "!", style: new TextStyle({ fontSize: 24 }) }),
    ],
  }),
);
```

## 모범 사례

1. **적절한 글꼴 크기 사용**: 다양한 기기 크기에서 텍스트를 읽을 수 있도록 합니다.

2. **접근성 고려**: 모든 사용자가 텍스트에 접근할 수 있도록 충분한 색상 대비와 글꼴 크기를 사용합니다.

3. **일관성 유지**: 통일된 외관을 위해 애플리케이션 전체에서 일관된 텍스트 스타일을 유지합니다.

4. **텍스트 테마 사용**: 대규모 애플리케이션의 경우 앱 전체에서 일관된 스타일을 쉽게 유지하기 위해 텍스트 테마 설정을 고려합니다.

5. **다양한 길이로 테스트**: 항상 다양한 콘텐츠 길이로 텍스트 위젯을 테스트하여 오버플로우를 올바르게 처리하는지 확인합니다.

## 결론

Text 위젯은 Flitter 애플리케이션에서 정보를 표시하는 기본 구성 요소입니다. 사용법과 스타일링 옵션을 마스터함으로써 시각적으로 매력적이고 읽기 쉽은 텍스트 표시를 만들 수 있습니다. UI 디자인에서 텍스트로 작업할 때 가독성, 접근성, 일관성과 같은 요소를 고려하는 것을 잊지 마세요.
