# Flitter의 Container 위젯

Container 위젯은 Flitter에서 가장 다재다능하고 일반적으로 사용되는 위젯 중 하나입니다. 일반적인 페인팅, 위치 지정 및 크기 조정 위젯을 하나의 편리한 위젯으로 결합합니다.

## 개요

Container 위젯을 사용하면 직사각형 시각적 요소를 만들 수 있습니다. 배경색, 테두리 또는 이미지로 장식할 수 있습니다. 또한 패딩, 여백 및 제약 조건과 같은 다양한 속성을 사용하여 모양을 변환할 수도 있습니다.

## 주요 속성

- `width`와 `height`: 컨테이너의 크기를 설정합니다.
- `color`: 배경색을 설정합니다.
- `padding`: 내부 패딩을 추가합니다.
- `margin`: 외부 여백을 추가합니다.
- `alignment`: 컨테이너 내에서 자식을 정렬합니다.
- `decoration`: 컨테이너에 BoxDecoration을 적용합니다.
- `child`: 컨테이너 내부에 배치할 위젯입니다.

## 기본 사용법

Container를 사용하는 간단한 예제입니다:

```typescript
import { Container, Colors } from "@meursyphus/flitter";

const myContainer = Container({
  width: 100,
  height: 100,
  color: "blue",
});
```

이것은 100x100 픽셀 크기의 파란색 정사각형 컨테이너를 만듭니다.

## 고급 사용법

여러 속성을 가진 더 복잡한 컨테이너를 만들어 보겠습니다:

```typescript
import {
  Container,
  Text,
  Colors,
  BoxDecoration,
  BorderRadius,
  EdgeInsets,
  Alignment,
} from "@meursyphus/flitter";

const advancedContainer = Container({
  width: 200,
  height: 100,
  margin: EdgeInsets.all(10),
  padding: EdgeInsets.symmetric({ vertical: 15, horizontal: 20 }),
  decoration: new BoxDecoration({
    color: "green",
    borderRadius: BorderRadius.circular(10),
    boxShadow: [{ color: "grey", blurRadius: 5, offset: { x: 0, y: 2 } }],
  }),
  alignment: Alignment.center,
  child: Text("Hello, Flitter!", {
    style: new TextStyle({ color: "white", fontSize: 18 }),
  }),
});
```

이것은 그림자가 있는 둥근 녹색 컨테이너를 만들고, 중앙에 흰색 텍스트를 포함합니다.

## 시각적 표현

위 컨테이너의 간단한 ASCII 표현입니다:

```
   ┌─────────────────────────────┐
   │                             │
   │   ╔═════════════════════╗   │
   │   ║                     ║   │
   │   ║   Hello, Flitter!   ║   │
   │   ║                     ║   │
   │   ╚═════════════════════╝   │
   │                             │
   └─────────────────────────────┘
     ^                         ^
     │                         │
   여백                       여백
```

- 외부 사각형: 여백(Margin)
- 중간 사각형: 둥근 모서리가 있는 컨테이너
- 내부 콘텐츠: 패딩과 중앙 정렬된 텍스트

## 모범 사례

1. **시각적 구조에 사용**: 컨테이너는 카드나 섹션과 같은 UI의 시각적 구조를 만드는 데 적합합니다.

2. **너무 깊게 중첩하지 않기**: 컨테이너는 다재다능하지만, 너무 깊게 중첩하면 성능 문제가 발생할 수 있습니다.

3. **간단한 크기 조정에는 SizedBox 고려**: 다른 스타일링 없이 너비나 높이만 설정해야 하는 경우 대신 SizedBox를 사용하는 것을 고려하세요.

4. **제약 조건을 현명하게 사용**: 컨테이너는 부모에 의해 제약될 수 있습니다. 제약 조건이 위젯 트리에서 어떻게 전달되는지 주의하세요.

## 결론

Container 위젯은 Flitter의 기본 구성 요소입니다. 그 유연성은 간단한 색상 상자부터 복잡하고 스타일이 지정된 구성 요소까지 다양한 UI 요소를 만들 수 있게 합니다. Container 위젯을 마스터하면 Flitter 애플리케이션을 구조화하고 스타일을 지정하는 강력한 도구를 갖게 됩니다.
