import { Widget } from '@meursyphus/flitter-svelte';
import { Container, Column, Row, Text, TextStyle, Center, EdgeInsets, BorderRadius, Stack, Positioned } from '@meursyphus/flitter';

# 그라디언트 배경

그라디언트는 UI에 깊이감과 시각적 흥미를 더하는 효과적인 방법입니다. Flitter에서는 선형, 방사형, 스위프 그라디언트를 모두 지원합니다.

## 선형 그라디언트

가장 일반적인 형태의 그라디언트로, 한 방향에서 다른 방향으로 색상이 변화합니다.

<Widget name="cookbook-gradient-linear">
  {(() => {
    const examples = [
      {
        title: '수평 그라디언트',
        gradient: {
          type: 'linear',
          colors: ['#667eea', '#764ba2'],
          begin: 'centerLeft',
          end: 'centerRight'
        }
      },
      {
        title: '수직 그라디언트',
        gradient: {
          type: 'linear',
          colors: ['#f093fb', '#f5576c'],
          begin: 'topCenter',
          end: 'bottomCenter'
        }
      },
      {
        title: '대각선 그라디언트',
        gradient: {
          type: 'linear',
          colors: ['#4facfe', '#00f2fe'],
          begin: 'topLeft',
          end: 'bottomRight'
        }
      },
      {
        title: '다중 색상',
        gradient: {
          type: 'linear',
          colors: ['#fa709a', '#fee140', '#30cfd0'],
          begin: 'topCenter',
          end: 'bottomCenter'
        }
      }
    ];
    
    return Container({
      width: 400,
      padding: EdgeInsets.all(20),
      color: '#f8f9fa',
      child: Column({
        children: examples.map(example => 
          Container({
            margin: EdgeInsets.only({ bottom: 16 }),
            child: Column({
              crossAxisAlignment: 'start',
              children: [
                Text(example.title, {
                  style: TextStyle({
                    fontSize: 16,
                    fontWeight: 'bold',
                    color: '#212529'
                  })
                }),
                SizedBox({ height: 8 }),
                Container({
                  height: 80,
                  decoration: {
                    gradient: example.gradient,
                    borderRadius: BorderRadius.circular(12)
                  },
                  child: Center({
                    child: Text('그라디언트', {
                      style: TextStyle({
                        color: 'white',
                        fontSize: 18,
                        fontWeight: 'bold'
                      })
                    })
                  })
                })
              ]
            })
          })
        )
      })
    });
  })()}
</Widget>

```typescript
Container({

    gradient: {
      type: 'linear',
      colors: ['#667eea', '#764ba2'],
      begin: 'topLeft',
      end: 'bottomRight'
    }

})
```

## 방사형 그라디언트

중심에서 바깥쪽으로 퍼지는 그라디언트입니다.

## 그라디언트 애니메이션

<Widget name="cookbook-gradient-animated">
  {(() => {
    const [isActive, setIsActive] = React.useState(false);
    
    return Container({
      width: 350,

        child: GestureDetector({

</Widget>

## 구현 팁

### 1. 색상 선택
- 보색이나 유사색을 사용하여 조화로운 그라디언트 생성
- 너무 많은 색상은 피하고 2-3개가 적당

### 2. 방향 설정
```typescript
// 사전 정의된 방향
begin: 'topLeft'
end: 'bottomRight'

// 커스텀 방향
begin: Alignment(0.0, -1.0)
end: Alignment(0.0, 1.0)
```

### 3. 투명도 활용
```typescript
colors: [
  'rgba(255,255,255,0)',
  'rgba(255,255,255,1)'
]
```

## 성능 고려사항

1. **복잡한 그라디언트**: 많은 색상이나 정지점은 성능에 영향
2. **애니메이션**: 그라디언트 애니메이션은 부드럽게 유지
3. **모바일**: 모바일 기기에서는 단순한 그라디언트 사용 권장
