# 기본 라인 차트

라인 차트는 시간에 따른 데이터의 변화를 표현하는 가장 효과적인 방법입니다. CustomPaint를 사용하여 부드러운 라인 차트를 구현해봅시다.

## 간단한 라인 차트

기본적인 라인 차트 구현입니다.

<Widget name="cookbook-simple-line-chart">
  {(() => {
    const data = [
      { month: '1월', value: 30 },
      { month: '2월', value: 45 },
      { month: '3월', value: 35 },
      { month: '4월', value: 50 },
      { month: '5월', value: 65 },
      { month: '6월', value: 55 },
      { month: '7월', value: 70 },
      { month: '8월', value: 85 }
    ];
    
    const maxValue = Math.max(...data.map(d => d.value));
    const minValue = Math.min(...data.map(d => d.value));
    
    const LineChartPainter = {
      paint: (canvas, size) => {
        const padding = 40;
        const chartWidth = size.width - padding * 2;
        const chartHeight = size.height - padding * 2;
        
        // 그리드 그리기
        const gridPaint = Paint();
        gridPaint.color = '#e9ecef';
        gridPaint.strokeWidth = 1;
        gridPaint.style = 'stroke';
        
        // 수평 그리드
        for (let i = 0; i <= 5; i++) {
          const y = padding + (chartHeight / 5) * i;
          canvas.drawLine(
            { x: padding, y },
            { x: size.width - padding, y },
            gridPaint
          );
        }
        
        // 수직 그리드
        data.forEach((_, index) => {
          const x = padding + (index / (data.length - 1)) * chartWidth;
          canvas.drawLine(
            { x, y: padding },
            { x, y: size.height - padding },
            gridPaint
          );
        });
        
        // 라인 그리기
        const linePaint = Paint();
        linePaint.color = '#4c6ef5';
        linePaint.strokeWidth = 3;
        linePaint.style = 'stroke';
        linePaint.strokeCap = 'round';
        linePaint.strokeJoin = 'round';
        
        const path = Path();
        data.forEach((item, index) => {
          const x = padding + (index / (data.length - 1)) * chartWidth;
          const y = padding + (1 - (item.value - minValue) / (maxValue - minValue)) * chartHeight;
          
          if (index === 0) {
            path.moveTo(x, y);
          } else {
            path.lineTo(x, y);
          }
        });
        
        canvas.drawPath(path, linePaint);
        
        // 데이터 포인트 그리기
        const pointPaint = Paint();
        pointPaint.color = '#4c6ef5';
        pointPaint.style = 'fill';
        
        const pointBorderPaint = Paint();
        pointBorderPaint.color = 'white';
        pointBorderPaint.style = 'fill';
        
        data.forEach((item, index) => {
          const x = padding + (index / (data.length - 1)) * chartWidth;
          const y = padding + (1 - (item.value - minValue) / (maxValue - minValue)) * chartHeight;
          
          // 외곽 원
          canvas.drawCircle({ x, y }, 6, pointBorderPaint);
          // 내부 원
          canvas.drawCircle({ x, y }, 4, pointPaint);
        });
        
        // X축 레이블
        const textPaint = Paint();
        textPaint.color = '#495057';
        textPaint.fontSize = 12;
        
        data.forEach((item, index) => {
          const x = padding + (index / (data.length - 1)) * chartWidth;
          canvas.drawText(
            item.month,
            { x: x - 15, y: size.height - 15 },
            textPaint
          );
        });
        
        // Y축 레이블
        for (let i = 0; i <= 5; i++) {
          const value = minValue + ((maxValue - minValue) / 5) * (5 - i);
          const y = padding + (chartHeight / 5) * i;
          
          textPaint.color = '#868e96';
          canvas.drawText(
            Math.round(value).toString(),
            { x: 5, y: y - 5 },
            textPaint
          );
        }
      }
    };
    
    return Container({
      width: 450,
      height: 300,
      padding: EdgeInsets.all(20),
      color: '#f8f9fa',
      child: Column({
        children: [
          Text('월별 매출 추이', {
            style: TextStyle({
              fontSize: 18,
              fontWeight: 'bold',
              color: '#212529'
            })
          }),
          SizedBox({ height: 20 }),
          Expanded({
            child: CustomPaint({
              painter: LineChartPainter
            })
          })
        ]
      })
    });
  })()}
</Widget>

## 인터랙티브 라인 차트

마우스 호버로 값을 확인할 수 있는 라인 차트입니다.

<Widget name="cookbook-interactive-line-chart">
  {(() => {
    const [hoveredIndex, setHoveredIndex] = React.useState(null);
    const [mousePosition, setMousePosition] = React.useState({ x: 0, y: 0 });
    
    const data = [
      { date: '1일', desktop: 45, mobile: 65 },
      { date: '5일', desktop: 52, mobile: 58 },
      { date: '10일', desktop: 48, mobile: 72 },
      { date: '15일', desktop: 58, mobile: 68 },
      { date: '20일', desktop: 62, mobile: 75 },
      { date: '25일', desktop: 55, mobile: 82 },
      { date: '30일', desktop: 68, mobile: 78 }
    ];
    
    const series = [
      { key: 'desktop', label: '데스크톱', color: '#4c6ef5' },
      { key: 'mobile', label: '모바일', color: '#51cf66' }
    ];
    
    const maxValue = Math.max(...data.flatMap(d => [d.desktop, d.mobile]));
    
    const InteractiveLineChartPainter = {
      paint: (canvas, size) => {
        const padding = 40;
        const chartWidth = size.width - padding * 2;
        const chartHeight = size.height - padding * 2;
        
        // 배경
        const bgPaint = Paint();
        bgPaint.color = 'white';
        bgPaint.style = 'fill';
        canvas.drawRect(
          Rect.fromLTWH(padding, padding, chartWidth, chartHeight),
          bgPaint
        );
        
        // 그리드
        const gridPaint = Paint();
        gridPaint.color = '#f1f3f5';
        gridPaint.strokeWidth = 1;
        gridPaint.style = 'stroke';
        
        for (let i = 0; i <= 4; i++) {
          const y = padding + (chartHeight / 4) * i;
          canvas.drawLine(
            { x: padding, y },
            { x: size.width - padding, y },
            gridPaint
          );
        }
        
        // 호버 라인
        if (hoveredIndex !== null) {
          const x = padding + (hoveredIndex / (data.length - 1)) * chartWidth;
          
          const hoverPaint = Paint();
          hoverPaint.color = '#dee2e6';
          hoverPaint.strokeWidth = 1;
          hoverPaint.style = 'stroke';
          hoverPaint.dashArray = [5, 5];
          
          canvas.drawLine(
            { x, y: padding },
            { x, y: size.height - padding },
            hoverPaint
          );
        }
        
        // 라인 그리기
        series.forEach(serie => {
          const linePaint = Paint();
          linePaint.color = serie.color;
          linePaint.strokeWidth = 3;
          linePaint.style = 'stroke';
          linePaint.strokeCap = 'round';
          linePaint.strokeJoin = 'round';
          
          const path = Path();
          data.forEach((item, index) => {
            const x = padding + (index / (data.length - 1)) * chartWidth;
            const y = padding + (1 - item[serie.key] / maxValue) * chartHeight;
            
            if (index === 0) {
              path.moveTo(x, y);
            } else {
              path.lineTo(x, y);
            }
          });
          
          canvas.drawPath(path, linePaint);
          
          // 데이터 포인트
          const pointPaint = Paint();
          pointPaint.style = 'fill';
          
          data.forEach((item, index) => {
            const x = padding + (index / (data.length - 1)) * chartWidth;
            const y = padding + (1 - item[serie.key] / maxValue) * chartHeight;
            
            pointPaint.color = 'white';
            canvas.drawCircle({ x, y }, 5, pointPaint);
            
            pointPaint.color = serie.color;
            canvas.drawCircle({ x, y }, 3, pointPaint);
            
            // 호버 시 강조
            if (hoveredIndex === index) {
              pointPaint.color = serie.color + '40'; // 투명도 추가
              canvas.drawCircle({ x, y }, 8, pointPaint);
            }
          });
        });
        
        // X축 레이블
        const textPaint = Paint();
        textPaint.color = '#495057';
        textPaint.fontSize = 11;
        
        data.forEach((item, index) => {
          const x = padding + (index / (data.length - 1)) * chartWidth;
          canvas.drawText(
            item.date,
            { x: x - 15, y: size.height - 15 },
            textPaint
          );
        });
        
        // Y축 레이블
        for (let i = 0; i <= 4; i++) {
          const value = (maxValue / 4) * (4 - i);
          const y = padding + (chartHeight / 4) * i;
          
          canvas.drawText(
            Math.round(value).toString(),
            { x: 5, y: y - 5 },
            textPaint
          );
        }
      }
    };
    
    return Container({
      width: 500,
      height: 350,
      padding: EdgeInsets.all(20),
      color: '#f8f9fa',
      child: Column({
        children: [
          Row({
            mainAxisAlignment: 'spaceBetween',
            children: [
              Text('일별 방문자 추이', {
                style: TextStyle({
                  fontSize: 18,
                  fontWeight: 'bold',
                  color: '#212529'
                })
              }),
              Row({
                children: series.map(serie => 
                  Container({
                    margin: EdgeInsets.only({ left: 16 }),
                    child: Row({
                      children: [
                        Container({
                          width: 12,
                          height: 3,
                          color: serie.color
                        }),
                        SizedBox({ width: 6 }),
                        Text(serie.label, {
                          style: TextStyle({
                            fontSize: 12,
                            color: '#495057'
                          })
                        })
                      ]
                    })
                  })
                )
              })
            ]
          }),
          SizedBox({ height: 20 }),
          Expanded({
            child: Stack({
              children: [
                GestureDetector({
                  onPointerMove: (e) => {
                    const rect = e.currentTarget.getBoundingClientRect();
                    const x = e.clientX - rect.left;
                    const padding = 40;
                    const chartWidth = rect.width - padding * 2;
                    
                    const index = Math.round(((x - padding) / chartWidth) * (data.length - 1));
                    if (index >= 0 && index < data.length) {
                      setHoveredIndex(index);
                      setMousePosition({ x: e.clientX - rect.left, y: e.clientY - rect.top });
                    }
                  },
                  onPointerLeave: () => setHoveredIndex(null),
                  child: CustomPaint({
                    painter: InteractiveLineChartPainter
                  })
                }),
                // 툴팁
                if (hoveredIndex !== null) Positioned({
                  left: mousePosition.x + 10,
                  top: mousePosition.y - 60,
                  child: Container({
                    padding: EdgeInsets.all(8),
                    decoration: {
                      color: 'rgba(0,0,0,0.8)',
                      borderRadius: BorderRadius.circular(4)
                    },
                    child: Column({
                      crossAxisAlignment: 'start',
                      children: [
                        Text(data[hoveredIndex].date, {
                          style: TextStyle({
                            color: 'white',
                            fontSize: 12,
                            fontWeight: 'bold'
                          })
                        }),
                        ...series.map(serie => 
                          Row({
                            children: [
                              Container({
                                width: 8,
                                height: 8,
                                decoration: {
                                  color: serie.color,
                                  shape: 'circle'
                                }
                              }),
                              SizedBox({ width: 4 }),
                              Text(`${serie.label}: ${data[hoveredIndex][serie.key]}`, {
                                style: TextStyle({
                                  color: 'white',
                                  fontSize: 11
                                })
                              })
                            ]
                          })
                        )
                      ]
                    })
                  })
                })
              ]
            })
          })
        ]
      })
    });
  })()}
</Widget>

## 부드러운 곡선 라인 차트

베지어 곡선을 사용한 부드러운 라인 차트입니다.

<Widget name="cookbook-smooth-line-chart">
  {(() => {
    const [animationProgress, setAnimationProgress] = React.useState(0);
    
    React.useEffect(() => {
      const startTime = Date.now();
      const duration = 1500;
      
      const animate = () => {
        const elapsed = Date.now() - startTime;
        const progress = Math.min(elapsed / duration, 1);
        
        setAnimationProgress(progress);
        
        if (progress < 1) {
          requestAnimationFrame(animate);
        }
      };
      
      requestAnimationFrame(animate);
    }, []);
    
    const data = [
      { hour: '00', temp: 18 },
      { hour: '04', temp: 16 },
      { hour: '08', temp: 19 },
      { hour: '12', temp: 24 },
      { hour: '16', temp: 26 },
      { hour: '20', temp: 22 },
      { hour: '24', temp: 19 }
    ];
    
    const maxTemp = Math.max(...data.map(d => d.temp));
    const minTemp = Math.min(...data.map(d => d.temp));
    
    const SmoothLineChartPainter = {
      paint: (canvas, size) => {
        const padding = 40;
        const chartWidth = size.width - padding * 2;
        const chartHeight = size.height - padding * 2;
        
        // 그라디언트 배경
        const bgGradient = {
          type: 'linear',
          colors: ['#e3f2fd', '#bbdefb'],
          begin: { x: 0, y: 0 },
          end: { x: 0, y: chartHeight }
        };
        
        const bgPaint = Paint();
        bgPaint.shader = Gradient.linear(
          { x: padding, y: padding },
          { x: padding, y: padding + chartHeight },
          ['#e3f2fd', '#bbdefb']
        );
        canvas.drawRect(
          Rect.fromLTWH(padding, padding, chartWidth, chartHeight),
          bgPaint
        );
        
        // 데이터 포인트 계산
        const points = data.map((item, index) => ({
          x: padding + (index / (data.length - 1)) * chartWidth,
          y: padding + (1 - (item.temp - minTemp) / (maxTemp - minTemp)) * chartHeight
        }));
        
        // 영역 그리기 (애니메이션)
        if (animationProgress > 0) {
          const areaPath = Path();
          areaPath.moveTo(points[0].x, padding + chartHeight);
          
          points.forEach((point, index) => {
            const animatedY = padding + chartHeight - (point.y - padding) * animationProgress;
            
            if (index === 0) {
              areaPath.lineTo(point.x, animatedY);
            } else {
              const prevPoint = points[index - 1];
              const cp1x = prevPoint.x + (point.x - prevPoint.x) / 2;
              const cp1y = prevPoint.y;
              const cp2x = prevPoint.x + (point.x - prevPoint.x) / 2;
              const cp2y = point.y;
              
              areaPath.cubicTo(
                cp1x, padding + chartHeight - (cp1y - padding) * animationProgress,
                cp2x, padding + chartHeight - (cp2y - padding) * animationProgress,
                point.x, animatedY
              );
            }
          });
          
          areaPath.lineTo(points[points.length - 1].x, padding + chartHeight);
          areaPath.close();
          
          const areaPaint = Paint();
          areaPaint.shader = Gradient.linear(
            { x: padding, y: padding },
            { x: padding, y: padding + chartHeight },
            ['rgba(76,110,245,0.3)', 'rgba(76,110,245,0.05)']
          );
          areaPaint.style = 'fill';
          
          canvas.drawPath(areaPath, areaPaint);
        }
        
        // 부드러운 라인 그리기
        if (animationProgress > 0) {
          const linePath = Path();
          const visiblePoints = Math.floor(points.length * animationProgress);
          
          if (visiblePoints > 0) {
            linePath.moveTo(points[0].x, points[0].y);
            
            for (let i = 1; i < visiblePoints; i++) {
              const prevPoint = points[i - 1];
              const currPoint = points[i];
              
              const cp1x = prevPoint.x + (currPoint.x - prevPoint.x) / 2;
              const cp1y = prevPoint.y;
              const cp2x = prevPoint.x + (currPoint.x - prevPoint.x) / 2;
              const cp2y = currPoint.y;
              
              linePath.cubicTo(cp1x, cp1y, cp2x, cp2y, currPoint.x, currPoint.y);
            }
            
            const linePaint = Paint();
            linePaint.color = '#4c6ef5';
            linePaint.strokeWidth = 3;
            linePaint.style = 'stroke';
            linePaint.strokeCap = 'round';
            
            canvas.drawPath(linePath, linePaint);
          }
        }
        
        // 데이터 포인트
        points.forEach((point, index) => {
          if (index < points.length * animationProgress) {
            const pointPaint = Paint();
            pointPaint.color = 'white';
            pointPaint.style = 'fill';
            canvas.drawCircle({ x: point.x, y: point.y }, 5, pointPaint);
            
            pointPaint.color = '#4c6ef5';
            canvas.drawCircle({ x: point.x, y: point.y }, 3, pointPaint);
            
            // 온도 레이블
            const textPaint = Paint();
            textPaint.color = '#1976d2';
            textPaint.fontSize = 11;
            textPaint.fontWeight = 'bold';
            
            canvas.drawText(
              `${data[index].temp}°`,
              { x: point.x - 10, y: point.y - 15 },
              textPaint
            );
          }
        });
        
        // X축 레이블
        const labelPaint = Paint();
        labelPaint.color = '#64748b';
        labelPaint.fontSize = 11;
        
        data.forEach((item, index) => {
          const x = padding + (index / (data.length - 1)) * chartWidth;
          canvas.drawText(
            item.hour,
            { x: x - 10, y: size.height - 15 },
            labelPaint
          );
        });
        
        // 타이틀
        const titlePaint = Paint();
        titlePaint.color = '#1e293b';
        titlePaint.fontSize = 14;
        titlePaint.fontWeight = 'bold';
        
        canvas.drawText(
          '일일 기온 변화',
          { x: padding, y: 15 },
          titlePaint
        );
      }
    };
    
    return Container({
      width: 450,
      height: 300,
      color: 'white',
      child: CustomPaint({
        painter: SmoothLineChartPainter
      })
    });
  })()}
</Widget>

## 구현 핵심

### 1. 데이터 정규화
```typescript
const normalizedY = (1 - (value - minValue) / (maxValue - minValue)) * chartHeight;
```

### 2. 부드러운 곡선 (베지어)
```typescript
path.cubicTo(cp1x, cp1y, cp2x, cp2y, endX, endY);
// 또는
path.quadraticBezierTo(cpx, cpy, endX, endY);
```

### 3. 애니메이션 진행
```typescript
const visiblePoints = Math.floor(totalPoints * animationProgress);
// 보이는 포인트만 그리기
```

### 4. 그라디언트 영역
```typescript
// 라인 아래 영역을 그라디언트로 채우기
const gradient = Gradient.linear(start, end, colors);
```

## 고급 기능

1. **다중 Y축**: 서로 다른 단위의 데이터 표시
2. **줌/팬**: 특정 구간 확대 및 이동
3. **데이터 포인트 애니메이션**: 값 변경 시 부드러운 전환
4. **범위 선택**: 드래그로 특정 구간 선택
5. **실시간 업데이트**: 스트리밍 데이터 표시

## 성능 최적화

1. **포인트 단순화**: 많은 데이터는 다운샘플링
2. **뷰포트 클리핑**: 보이는 영역만 그리기
3. **Path 재사용**: 자주 그리는 경로는 캐싱
