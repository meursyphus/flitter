# 카운터 앱

카운터 앱은 상태 관리의 기본을 이해하는 데 가장 좋은 예제입니다. 버튼을 눌러 숫자를 증가시키거나 감소시키는 간단한 앱을 만들어봅시다.

## 기본 카운터

가장 간단한 형태의 카운터 앱입니다.

<Widget name="cookbook-counter-basic">
  {(() => {
    const [count, setCount] = React.useState(0);
    
    return Container({
      width: 300,
      height: 200,
      color: '#ecf0f1',
      child: Column({
        mainAxisAlignment: 'center',
        children: [
          Text(`카운트: ${count}`, {
            style: TextStyle({
              fontSize: 32,
              fontWeight: 'bold'
            })
          }),
          SizedBox({ height: 20 }),
          Row({
            mainAxisAlignment: 'center',
            children: [
              GestureDetector({
                onTap: () => setCount(count - 1),
                child: Container({
                  width: 60,
                  height: 40,
                  decoration: {
                    color: '#e74c3c',
                    borderRadius: BorderRadius.circular(8)
                  },
                  child: Center({
                    child: Text('-', {
                      style: TextStyle({
                        color: 'white',
                        fontSize: 24,
                        fontWeight: 'bold'
                      })
                    })
                  })
                })
              }),
              SizedBox({ width: 20 }),
              GestureDetector({
                onTap: () => setCount(count + 1),
                child: Container({
                  width: 60,
                  height: 40,
                  decoration: {
                    color: '#2ecc71',
                    borderRadius: BorderRadius.circular(8)
                  },
                  child: Center({
                    child: Text('+', {
                      style: TextStyle({
                        color: 'white',
                        fontSize: 24,
                        fontWeight: 'bold'
                      })
                    })
                  })
                })
              })
            ]
          })
        ]
      })
    });
  })()}
</Widget>

```typescript
const CounterApp = () => {
  const [count, setCount] = useState(0);
  
  return Column({
    mainAxisAlignment: 'center',
    children: [
      Text(`카운트: ${count}`, {
        style: TextStyle({
          fontSize: 32,
          fontWeight: 'bold'
        })
      }),
      Row({
        mainAxisAlignment: 'center',
        children: [
          GestureDetector({
            onTap: () => setCount(count - 1),
            child: Container({
              padding: EdgeInsets.all(8),
              color: '#e74c3c',
              child: Text('-')
            })
          }),
          GestureDetector({
            onTap: () => setCount(count + 1),
            child: Container({
              padding: EdgeInsets.all(8),
              color: '#2ecc71',
              child: Text('+')
            })
          })
        ]
      })
    ]
  });
};
```

## 증가 단위를 선택할 수 있는 카운터

증가/감소 단위를 선택할 수 있는 고급 카운터입니다.

<Widget name="cookbook-counter-advanced">
  {(() => {
    const [count, setCount] = React.useState(0);
    const [step, setStep] = React.useState(1);
    
    return Container({
      width: 350,
      height: 450,
      color: '#f8f9fa',
      child: Column({
        mainAxisAlignment: 'center',
        children: [
          Text('고급 카운터', {
            style: TextStyle({
              fontSize: 28,
              fontWeight: 'bold',
              color: '#495057'
            })
          }),
          SizedBox({ height: 20 }),
          Container({
            padding: EdgeInsets.symmetric({ vertical: 16, horizontal: 32 }),
            decoration: {
              color: 'white',
              borderRadius: BorderRadius.circular(12),
              boxShadow: [
                BoxShadow({
                  color: 'rgba(0,0,0,0.05)',
                  blurRadius: 10,
                  offset: { x: 0, y: 2 }
                })
              ]
            },
            child: Text(`현재 값: ${count}`, {
              style: TextStyle({
                fontSize: 24,
                fontWeight: 'bold',
                color: '#364fc7'
              })
            })
          }),
          SizedBox({ height: 30 }),
          Text('증가 단위 선택:', {
            style: TextStyle({
              fontSize: 16,
              color: '#868e96'
            })
          }),
          SizedBox({ height: 10 }),
          Row({
            mainAxisAlignment: 'center',
            children: [1, 5, 10].map(value => 
              GestureDetector({
                onTap: () => setStep(value),
                child: Container({
                  width: 60,
                  height: 40,
                  margin: EdgeInsets.symmetric({ horizontal: 8 }),
                  decoration: {
                    color: step === value ? '#364fc7' : 'white',
                    borderRadius: BorderRadius.circular(8),
                    border: {
                      color: step === value ? '#364fc7' : '#dee2e6',
                      width: 2
                    }
                  },
                  child: Center({
                    child: Text(`±${value}`, {
                      style: TextStyle({
                        color: step === value ? 'white' : '#495057',
                        fontWeight: 'bold'
                      })
                    })
                  })
                })
              })
            )
          }),
          SizedBox({ height: 30 }),
          Row({
            mainAxisAlignment: 'center',
            children: [
              GestureDetector({
                onTap: () => setCount(count - step),
                child: Container({
                  width: 100,
                  height: 50,
                  margin: EdgeInsets.only({ right: 10 }),
                  decoration: {
                    color: '#fa5252',
                    borderRadius: BorderRadius.circular(12)
                  },
                  child: Center({
                    child: Text(`-${step}`, {
                      style: TextStyle({
                        color: 'white',
                        fontSize: 20,
                        fontWeight: 'bold'
                      })
                    })
                  })
                })
              }),
              GestureDetector({
                onTap: () => setCount(count + step),
                child: Container({
                  width: 100,
                  height: 50,
                  margin: EdgeInsets.only({ left: 10 }),
                  decoration: {
                    color: '#40c057',
                    borderRadius: BorderRadius.circular(12)
                  },
                  child: Center({
                    child: Text(`+${step}`, {
                      style: TextStyle({
                        color: 'white',
                        fontSize: 20,
                        fontWeight: 'bold'
                      })
                    })
                  })
                })
              })
            ]
          }),
          SizedBox({ height: 20 }),
          GestureDetector({
            onTap: () => {
              setCount(0);
              setStep(1);
            },
            child: Text('모두 초기화', {
              style: TextStyle({
                color: '#868e96',
                fontSize: 14,
                decoration: 'underline'
              })
            })
          })
        ]
      })
    });
  })()}
</Widget>

## 핵심 개념

### 1. 상태 관리
```typescript
const [count, setCount] = useState(0);
```
- `useState`를 사용하여 컴포넌트의 상태를 관리합니다
- 상태가 변경되면 UI가 자동으로 업데이트됩니다

### 2. 이벤트 처리
```typescript
GestureDetector({
  onTap: () => setCount(count + 1),
  child: // 터치 가능한 위젯
})
```
- `GestureDetector`로 터치 이벤트를 감지합니다
- `onTap` 콜백에서 상태를 업데이트합니다

### 3. 조건부 스타일링
```typescript
decoration: {
  color: isActive ? '#364fc7' : 'white'
}
```
- 상태에 따라 동적으로 스타일을 변경할 수 있습니다

## 확장 아이디어

1. **최대/최소값 설정**: 카운터가 특정 범위를 벗어나지 않도록 제한
2. **애니메이션 추가**: 숫자가 변경될 때 애니메이션 효과
3. **히스토리 기능**: 이전 값들의 기록 보기
4. **키보드 단축키**: 키보드로 카운터 조작
5. **로컬 저장**: 앱을 다시 열어도 값이 유지되도록
