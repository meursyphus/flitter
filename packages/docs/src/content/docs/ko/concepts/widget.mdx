# 위젯이란 무엇인가?

Flitter에서 위젯은 애플리케이션 사용자 인터페이스의 기본 구성 요소입니다. Flutter에서 영감을 받아, Flitter 앱에서 화면에 표시되는 모든 것은 위젯입니다. 위젯을 이해하는 것은 Flitter를 사용하여 데이터 시각화와 대화형 인터페이스를 효과적으로 만드는 데 중요합니다.

## 위젯의 정의

Flitter에서 위젯은 사용자 인터페이스의 일부에 대한 불변 설명입니다. 위젯은 다음을 설명할 수 있습니다:

- 구조적 요소 (컨테이너나 행 같은)
- 스타일 요소 (색상이나 글꼴 같은)
- 레이아웃 측면 (패딩이나 정렬 같은)
- 그리고 더 복잡한 기능 (제스처나 애니메이션 같은)

## 위젯의 종류

Flitter는 다음과 같이 광범위하게 분류되는 여러 유형의 위젯을 제공합니다:

1. **기본 위젯**: `Container`, `Text`, `Image` 같은.
2. **레이아웃 위젯**: `Row`, `Column`, `Stack` 같은.
3. **대화형 위젯**: `GestureDetector`와 `Button`을 포함.
4. **페인팅 및 효과 위젯**: 예를 들어, `Transform`과 `Opacity`.
5. **Stateful 위젯**: 사용자 상호작용이나 다른 요인에 따라 시간이 지남에 따라 변경될 수 있는 위젯.

## 위젯 사용하기

Flitter에서 위젯이 어떻게 사용되는지에 대한 간단한 예제입니다:

```typescript
import {
  Container,
  Text,
  Center,
  TextStyle,
  Colors,
} from "@meursyphus/flitter";

const MyWidget = Container({
  width: 200,
  height: 100,
  color: Colors.blue[500],
  child: Center({
    child: Text("Hello, Flitter!", {
      style: new TextStyle({ color: Colors.white, fontSize: 20 }),
    }),
  }),
});
```

이 예제에서는 `Container`, `Center`, `Text` 위젯을 사용하여 중앙에 흰색 텍스트가 있는 파란색 사각형을 만듭니다.

## 위젯 트리

Flitter의 위젯은 트리 구조로 배열됩니다. 이 트리는 사용자 인터페이스의 계층 구조를 나타냅니다. 예를 들어:

```
       App
        │
    Container
        │
      Center
        │
       Text
```

트리의 각 위젯은 자식 위젯을 가질 수 있어 전체 UI를 정의하는 중첩 구조를 만듭니다.

## 구성 vs 상속

Flitter는 사용자 지정 위젯을 만들 때 상속보다 구성을 선호합니다. 이는 기존 위젯을 서브클래싱하는 대신 일반적으로 기존 위젯을 결합하여 새 위젯을 만든다는 것을 의미합니다.

## Stateless vs Stateful 위젯

Flitter에는 두 가지 주요 위젯 유형이 있습니다:

1. **Stateless 위젯**: 불변입니다. 한 번 구축되면 속성을 변경할 수 없습니다.
2. **Stateful 위젯**: 내부 상태가 변경될 때 스스로를 다시 구축할 수 있습니다.

두 가지 모두의 예를 살펴보겠습니다:

### Stateless 위젯 예제

Stateless 위젯은 변경되는 상태를 관리할 필요가 없을 때 더 간단하고 효율적입니다. 예제는 다음과 같습니다:

```typescript
import {
  StatelessWidget,
  Container,
  Text,
  TextStyle,
  Colors,
} from "@meursyphus/flitter";

class Greeting extends StatelessWidget {
  private name: string;

  constructor(name: string) {
    super();
    this.name = name;
  }

  build() {
    return Container({
      padding: EdgeInsets.all(16),
      color: Colors.blue[100],
      child: Text(`Hello, ${this.name}!`, {
        style: new TextStyle({ color: Colors.black, fontSize: 24 }),
      }),
    });
  }
}

// Usage
const myGreeting = new Greeting("Alice");
```

이 예제에서 `Greeting`은 인사 메시지를 표시하는 stateless 위젯입니다. 이름을 매개변수로 받아 인사말을 만드는 데 사용합니다. 한 번 생성되면 인사말은 변경되지 않습니다.

### Stateful 위젯 예제

Stateful 위젯은 위젯이 시간이 지남에 따라 변경될 수 있는 상태를 유지해야 할 때 사용됩니다. 간단한 카운터의 예제입니다:

```typescript
import {
  StatefulWidget,
  State,
  Container,
  Text,
  TextStyle,
  Colors,
  GestureDetector,
} from "@meursyphus/flitter";

class Counter extends StatefulWidget {
  createState() {
    return new CounterState();
  }
}

class CounterState extends State<Counter> {
  private count: number = 0;

  incrementCounter() {
    this.setState(() => {
      this.count++;
    });
  }

  build() {
    return Container({
      padding: EdgeInsets.all(16),
      color: Colors.blue[100],
      child: GestureDetector({
        onTap: () => this.incrementCounter(),
        child: Text(`Count: ${this.count}`, {
          style: new TextStyle({ color: Colors.black, fontSize: 24 }),
        }),
      }),
    });
  }
}

// Usage
const myCounter = new Counter();
```

이 예제에서 `Counter`는 카운트 상태를 유지하는 stateful 위젯입니다. `CounterState` 클래스는 상태를 관리하고 카운터를 증가시키는 메서드를 제공합니다. `build` 메서드는 탭했을 때 카운트를 증가시키는 `GestureDetector`로 감싸진 현재 카운트의 텍스트 표시를 만듭니다.

## 결론

Stateless와 Stateful 위젯의 차이를 이해하는 것은 효율적인 Flitter 개발에 중요합니다. 구성 정보와 현재 테마에만 의존하는 UI 부분에는 stateless 위젯을 사용하고, 사용자 상호작용이나 기타 요인에 따라 동적으로 변경해야 하는 UI 부분에는 stateful 위젯이 완벽합니다.

다음 섹션에서는 특정 유형의 위젯과 그 상태를 더 효과적으로 관리하는 방법에 대해 더 깊이 다룰 것입니다.

Stateless와 stateful 위젯의 차이는 상태 관리 섹션에서 더 깊이 탐구할 것입니다.
