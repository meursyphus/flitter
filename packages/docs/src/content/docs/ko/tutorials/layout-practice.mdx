# 레이아웃 구성하기 실습

Flitter의 강력한 레이아웃 시스템을 활용하여 차트 대시보드를 구성하는 방법을 실습해봅시다. 기본 레이아웃부터 복잡한 반응형 대시보드까지 단계별로 만들어봅니다.

## 레이아웃 기초

### Row와 Column

가장 기본적인 레이아웃 위젯들입니다.

<Widget name="layout-row-column">
  {(() => {
    const ChartCard = ({ title, value, color, icon }) => Container({

### Stack과 Positioned

위젯을 겹치는 레이아웃입니다.

<Widget name="layout-stack-positioned">
  {(() => {
    const data = [30, 45, 35, 50, 40, 55, 45];
    const maxValue = Math.max(...data);
    
    return Container({
      width: 450,
      height: 250,
      padding: EdgeInsets.all(20),
      color: 'white',
      child: Stack({
        children: [
          // 배경 그리드
          ...Array.from({ length: 5 }, (_, i) => 
            Positioned({
              top: i * 40,
              left: 0,
              right: 0,
              child: Container({
                height: 1,
                color: '#f1f3f5'
              })
            })
          ),
          // 차트 영역
          Positioned({
            top: 0,
            left: 0,
            right: 0,
            bottom: 30,
            child: Row({
              mainAxisAlignment: 'spaceEvenly',
              crossAxisAlignment: 'end',
              children: data.map((value, index) => 
                Container({
                  width: 40,
                  height: (value / maxValue) * 160,
                  decoration: {
                    gradient: {
                      type: 'linear',
                      colors: ['#4c6ef5', '#5c7cfa'],
                      begin: 'topCenter',
                      end: 'bottomCenter'

                    borderRadius: BorderRadius.only({

### AspectRatio로 비율 유지

<Widget name="layout-aspect-ratio">
  {(() => {
    const charts = [
      { title: '원형 차트', ratio: 1, icon: '🥧', color: '#4c6ef5' },
      { title: '가로 차트', ratio: 16/9, icon: '📊', color: '#51cf66' },
      { title: '세로 차트', ratio: 3/4, icon: '📈', color: '#ff922b' }
    ];
    
    return Container({
      width: 500,
      height: 300,
      padding: EdgeInsets.all(20),
      color: '#f8f9fa',
      child: Row({
        mainAxisAlignment: 'spaceEvenly',
        children: charts.map(chart => 
          Column({
            children: [
              Text(chart.title, {
                style: TextStyle({
                  fontSize: 14,
                  fontWeight: 'bold',
                  color: '#495057'
                })
              }),
              SizedBox({ height: 8 }),
              Container({
                width: 120,
                child: AspectRatio({
                  aspectRatio: chart.ratio,
                  child: Container({
                    decoration: {
                      color: chart.color + '20',
                      borderRadius: BorderRadius.circular(8),
                      border: {
                        color: chart.color,
                        width: 2
                      }
                    },
                    child: Center({
                      child: Column({
                        mainAxisSize: 'min',
                        children: [
                          Text(chart.icon, {
                            style: TextStyle({ fontSize: 32 })
                          }),
                          SizedBox({ height: 4 }),
                          Text(`${chart.ratio}`, {
                            style: TextStyle({
                              fontSize: 12,
                              color: chart.color,
                              fontWeight: 'bold'
                            })
                          })
                        ]
                      })
                    })
                  })
                })
              })
            ]
          })
        )
      })
    });
  })()}
</Widget>

모든 개념을 종합한 완전한 대시보드 예제입니다.

<Widget name="layout-dashboard">
  {(() => {
    const [selectedMetric, setSelectedMetric] = React.useState('revenue');
    
    const metrics = {
      revenue: { label: '매출', value: '₩12.5M', change: '+15%', color: '#51cf66' },
      users: { label: '사용자', value: '45.2K', change: '+8%', color: '#4c6ef5' },
      conversion: { label: '전환율', value: '3.2%', change: '-2%', color: '#ff922b' }
    };
    
    const chartData = [65, 78, 82, 91, 85, 88, 95];
    
    return Container({
      width: 600,
      height: 400,
      color: '#f8f9fa',
      child: Column({
        children: [
          // 헤더
          Container({
            padding: EdgeInsets.all(20),
            color: 'white',
            child: Row({
              mainAxisAlignment: 'spaceBetween',
              children: [
                Text('실시간 대시보드', {
                  style: TextStyle({
                    fontSize: 24,
                    fontWeight: 'bold',
                    color: '#212529'
                  })
                }),
                Text(new Date().toLocaleTimeString('ko-KR'), {
                  style: TextStyle({
                    fontSize: 14,
                    color: '#868e96'
                  })
                })
              ]
            })
          }),
          // 메인 콘텐츠
          Expanded({
            child: Container({
              padding: EdgeInsets.all(20),
              child: Row({
                children: [
                  // 왼쪽: 메트릭 카드
                  Container({
                    width: 180,
                    child: Column({
                      children: Object.entries(metrics).map(([key, metric]) => 
                        GestureDetector({
                          onTap: () => setSelectedMetric(key),
                          child: AnimatedContainer({
                            duration: 200,
                            margin: EdgeInsets.only({ bottom: 12 }),
                            padding: EdgeInsets.all(16),
                            decoration: {
                              color: selectedMetric === key ? metric.color + '10' : 'white',
                              borderRadius: BorderRadius.circular(8),
                              border: selectedMetric === key ? {
                                color: metric.color,
                                width: 2
                              } : null,
                              boxShadow: [{

                                blurRadius: 4,
                                offset: { x: 0, y: 2 }
                              }]
                            },
                            child: Column({
                              crossAxisAlignment: 'start',
                              children: [
                                Text(metric.label, {
                                  style: TextStyle({
                                    fontSize: 12,
                                    color: '#868e96'
                                  })
                                }),
                                SizedBox({ height: 4 }),
                                Row({
                                  mainAxisAlignment: 'spaceBetween',
                                  children: [
                                    Text(metric.value, {
                                      style: TextStyle({
                                        fontSize: 20,
                                        fontWeight: 'bold',
                                        color: selectedMetric === key ? metric.color : '#212529'
                                      })
                                    }),
                                    Container({
                                      padding: EdgeInsets.symmetric({ horizontal: 6, vertical: 2 }),
                                      decoration: {
                                        color: metric.change.startsWith('+') ? '#51cf66' : '#ff6b6b',
                                        borderRadius: BorderRadius.circular(4)
                                      },
                                      child: Text(metric.change, {
                                        style: TextStyle({
                                          fontSize: 11,
                                          color: 'white',
                                          fontWeight: 'bold'
                                        })
                                      })
                                    })
                                  ]
                                })
                              ]
                            })
                          })
                        })
                      )
                    })
                  }),
                  SizedBox({ width: 20 }),
                  // 오른쪽: 차트 영역
                  Expanded({
                    child: Container({
                      padding: EdgeInsets.all(20),
                      decoration: {
                        color: 'white',
                        borderRadius: BorderRadius.circular(12)
                      },
                      child: Column({
                        crossAxisAlignment: 'start',
                        children: [
                          Row({
                            mainAxisAlignment: 'spaceBetween',
                            children: [
                              Text(`${metrics[selectedMetric].label} 트렌드`, {
                                style: TextStyle({
                                  fontSize: 18,
                                  fontWeight: 'bold',
                                  color: '#212529'
                                })

## 레이아웃 팁과 모범 사례

### 1. 일관된 여백 사용
```typescript
const spacing = {
  xs: 4,
  sm: 8,
  md: 16,
  lg: 24,
  xl: 32
};

EdgeInsets.all(spacing.md)
```

### 2. 반응형 디자인 원칙
```typescript
// 화면 크기에 따라 레이아웃 변경
const isSmallScreen = screenWidth < 600;

isSmallScreen 
  ? Column({ children: widgets })
  : Row({ children: widgets })
```

### 3. 성능 최적화
```typescript
// 불필요한 중첩 피하기
// 나쁜 예 ❌
Container({
  child: Container({
    child: Container({
      child: Text('깊은 중첩')
    })
  })
})

// 좋은 예 ✅
Container({
  padding: EdgeInsets.all(16),
  decoration: { /* 모든 스타일 */ },
  child: Text('단순한 구조')
})
```

## 연습 과제

1. **적응형 그리드**: 화면 크기에 따라 열 수가 변하는 그리드
2. **탭 레이아웃**: 여러 차트를 탭으로 전환
3. **분할 뷰**: 드래그로 크기 조절 가능한 패널
4. **대시보드 템플릿**: 다양한 차트를 포함한 완전한 대시보드
