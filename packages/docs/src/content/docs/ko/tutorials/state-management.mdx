# 상태 관리 기초

동적인 차트와 인터랙티브한 데이터 시각화를 만들기 위해서는 상태 관리가 필수입니다. 이 튜토리얼에서는 Flitter에서 상태를 효과적으로 관리하는 방법을 배워봅시다.

## 상태란 무엇인가?

상태(State)는 시간에 따라 변할 수 있는 데이터입니다. 차트에서는 다음과 같은 것들이 상태가 될 수 있습니다:

- 차트 데이터
- 선택된 항목
- 필터 조건
- 애니메이션 진행 상황
- 사용자 입력

## React Hooks를 사용한 상태 관리

Flitter는 React와 함께 사용할 때 React Hooks를 활용하여 상태를 관리합니다.

### useState - 기본 상태 관리

가장 기본적인 상태 관리 방법입니다.

<Widget name="state-basic-useState">
  {(() => {
    const [count, setCount] = React.useState(0);
    const [color, setColor] = React.useState('#4c6ef5');
    
    const colors = ['#4c6ef5', '#51cf66', '#ff6b6b', '#f9ca24', '#845ef7'];
    
    return Container({
      width: 400,
      height: 250,
      padding: EdgeInsets.all(20),
      color: '#f8f9fa',
      child: Column({
        mainAxisAlignment: 'center',
        children: [
          Text('클릭 카운터', {
            style: TextStyle({
              fontSize: 18,
              fontWeight: 'bold',
              color: '#212529'
            })
          }),
          SizedBox({ height: 20 }),
          GestureDetector({
            onTap: () => {
              setCount(count + 1);
              setColor(colors[count % colors.length]);
            },
            child: AnimatedContainer({
              duration: 200,
              width: 120,
              height: 120,
              decoration: {
                color: color,
                shape: 'circle'
              },
              child: Center({
                child: Text(count.toString(), {
                  style: TextStyle({
                    fontSize: 32,
                    fontWeight: 'bold',
                    color: 'white'
                  })
                })
              })
            })
          }),
          SizedBox({ height: 20 }),
          Row({
            mainAxisAlignment: 'spaceEvenly',
            children: [
              GestureDetector({
                onTap: () => setCount(Math.max(0, count - 1)),
                child: Container({
                  padding: EdgeInsets.symmetric({ horizontal: 16, vertical: 8 }),
                  decoration: {
                    color: '#868e96',
                    borderRadius: BorderRadius.circular(4)
                  },

                    style: TextStyle({ color: 'white' })

                    color: '#ff6b6b',
                    borderRadius: BorderRadius.circular(4)

                    style: TextStyle({ color: 'white' })

                })
              })
            ]
          })
        ]
      })
    });
  })()}
</Widget>

### useEffect - 부수 효과 관리

컴포넌트의 생명주기나 외부 데이터와 상호작용할 때 사용합니다.

<Widget name="state-useEffect">
  {(() => {
    const [data, setData] = React.useState([30, 45, 35, 50]);
    const [isAnimating, setIsAnimating] = React.useState(false);
    
    // 주기적으로 데이터 업데이트
    React.useEffect(() => {
      const interval = setInterval(() => {
        setIsAnimating(true);
        setTimeout(() => {
          setData(prev => prev.map(() => Math.random() * 80 + 20));
          setIsAnimating(false);
        }, 300);
      }, 3000);
      
      return () => clearInterval(interval);
    }, []);
    
    const maxValue = Math.max(...data);
    
    return Container({
      width: 450,
      height: 250,
      padding: EdgeInsets.all(20),
      color: 'white',
      child: Column({
        children: [
          Row({
            mainAxisAlignment: 'spaceBetween',
            children: [
              Text('실시간 데이터 차트', {
                style: TextStyle({
                  fontSize: 18,
                  fontWeight: 'bold',
                  color: '#212529'
                })
              }),
              Container({
                width: 8,
                height: 8,
                decoration: {
                  color: isAnimating ? '#ff6b6b' : '#51cf66',
                  shape: 'circle'
                }
              })
            ]
          }),
          SizedBox({ height: 20 }),
          Expanded({
            child: Row({
              mainAxisAlignment: 'spaceEvenly',
              crossAxisAlignment: 'end',
              children: data.map((value, index) => 
                AnimatedContainer({
                  duration: 500,
                  width: 60,
                  height: (value / maxValue) * 150,
                  decoration: {
                    gradient: {
                      type: 'linear',
                      colors: ['#4c6ef5', '#5c7cfa'],
                      begin: 'topCenter',
                      end: 'bottomCenter'
                    },
                    borderRadius: BorderRadius.only({
                      topLeft: 8,
                      topRight: 8
                    }),
                    opacity: isAnimating ? 0.5 : 1
                  },
                  child: Stack({
                    children: [
                      Positioned({
                        top: -25,

                        right: 0,

                          child: AnimatedOpacity({

                            duration: 200,

                                color: '#4c6ef5'

                })

            })

            style: TextStyle({
              fontSize: 12,
              color: '#868e96'
            })
          })
        ]
      })

  })()}

### useReducer - 복잡한 상태 로직

상태 업데이트 로직이 복잡할 때 useReducer를 사용할 수 있습니다.

<Widget name="state-useReducer">
  {(() => {
    const initialState = {
      data: [
        { id: 1, label: 'Q1', value: 30, visible: true },
        { id: 2, label: 'Q2', value: 45, visible: true },
        { id: 3, label: 'Q3', value: 35, visible: true },
        { id: 4, label: 'Q4', value: 50, visible: true }
      ],
      selectedId: null,
      filter: 'all'
    };
    
    const chartReducer = (state, action) => {
      switch (action.type) {
        case 'SELECT_ITEM':
          return {
            ...state,
            selectedId: state.selectedId === action.id ? null : action.id
          };
        case 'TOGGLE_VISIBILITY':
          return {
            ...state,
            data: state.data.map(item =>
              item.id === action.id
                ? { ...item, visible: !item.visible }
                : item
            )
          };
        case 'UPDATE_VALUE':
          return {
            ...state,
            data: state.data.map(item =>
              item.id === action.id
                ? { ...item, value: action.value }
                : item
            )
          };
        case 'SET_FILTER':
          return {
            ...state,
            filter: action.filter
          };
        default:
          return state;
      }
    };
    
    const [state, dispatch] = React.useReducer(chartReducer, initialState);
    
    const visibleData = state.data.filter(item => 
      state.filter === 'all' || 
      (state.filter === 'visible' && item.visible) ||
      (state.filter === 'hidden' && !item.visible)
    );
    
    const maxValue = Math.max(...state.data.map(d => d.value));
    
    return Container({
      width: 550,
      height: 400,
      padding: EdgeInsets.all(20),
      color: '#f8f9fa',
      child: Column({
        children: [
          // 제어 패널
          Container({
            padding: EdgeInsets.all(16),
            decoration: {
              color: 'white',
              borderRadius: BorderRadius.circular(8)
            },
            child: Column({
              crossAxisAlignment: 'start',
              children: [
                Text('차트 제어', {
                  style: TextStyle({
                    fontSize: 16,
                    fontWeight: 'bold',
                    color: '#212529'
                  })
                }),
                SizedBox({ height: 12 }),
                // 필터
                Row({
                  children: [
                    Text('필터: ', {
                      style: TextStyle({
                        fontSize: 12,
                        color: '#868e96'
                      })
                    }),
                    ...['all', 'visible', 'hidden'].map(filter => 
                      GestureDetector({
                        onTap: () => dispatch({ type: 'SET_FILTER', filter }),
                        child: Container({
                          margin: EdgeInsets.only({ right: 8 }),
                          padding: EdgeInsets.symmetric({ horizontal: 8, vertical: 4 }),
                          decoration: {
                            color: state.filter === filter ? '#4c6ef5' : '#e9ecef',
                            borderRadius: BorderRadius.circular(4)
                          },
                          child: Text(
                            filter === 'all' ? '전체' : 
                            filter === 'visible' ? '표시' : '숨김',
                            {
                              style: TextStyle({
                                fontSize: 10,
                                color: state.filter === filter ? 'white' : '#495057'
                              })
                            }
                          )
                        })
                      })
                    )
                  ]
                }),
                SizedBox({ height: 8 }),
                // 데이터 항목 제어
                Wrap({
                  spacing: 8,
                  runSpacing: 4,
                  children: state.data.map(item => 
                    Row({
                      mainAxisSize: 'min',
                      children: [
                        GestureDetector({
                          onTap: () => dispatch({ 
                            type: 'TOGGLE_VISIBILITY', 
                            id: item.id 
                          }),
                          child: Container({
                            width: 12,
                            height: 12,
                            decoration: {
                              border: {
                                color: '#4c6ef5',
                                width: 1
                              },
                              borderRadius: BorderRadius.circular(2),
                              color: item.visible ? '#4c6ef5' : 'transparent'
                            },
                            child: item.visible ? Center({
                              child: Text('✓', {
                                style: TextStyle({
                                  fontSize: 8,
                                  color: 'white'
                                })
                              })
                            }) : null
                          })
                        }),
                        SizedBox({ width: 4 }),
                        Text(item.label, {
                          style: TextStyle({
                            fontSize: 11,
                            color: item.visible ? '#495057' : '#adb5bd'
                          })

                      ]
                    })
                  )
                })

          SizedBox({ height: 16 }),
          // 차트
          Expanded({
            child: Container({
              padding: EdgeInsets.all(16),
              decoration: {
                color: 'white',
                borderRadius: BorderRadius.circular(8)
              },

```typescript
// useChartData.js
const useChartData = (initialData) => {
  const [data, setData] = React.useState(initialData);
  const [selectedIndex, setSelectedIndex] = React.useState(null);
  const [isLoading, setIsLoading] = React.useState(false);
  
  const updateData = async (newData) => {
    setIsLoading(true);
    try {
      // 데이터 유효성 검사
      if (!Array.isArray(newData)) {
        throw new Error('Data must be an array');
      }
      
      setData(newData);
      setSelectedIndex(null); // 선택 초기화
    } catch (error) {
      console.error('Failed to update data:', error);
    } finally {
      setIsLoading(false);
    }
  };
  
  const selectItem = (index) => {
    setSelectedIndex(selectedIndex === index ? null : index);
  };
  
  const maxValue = React.useMemo(() => 
    Math.max(...data.map(d => d.value)), 
    [data]
  );
  
  return {
    data,
    selectedIndex,
    isLoading,
    maxValue,
    updateData,
    selectItem
  };
};

// 사용법
```

## 상태 관리 모범 사례

### 1. 상태 최소화
```typescript
// 나쁜 예 ❌
const [data, setData] = React.useState([]);
const [maxValue, setMaxValue] = React.useState(0);
const [minValue, setMinValue] = React.useState(0);

// 좋은 예 ✅
const [data, setData] = React.useState([]);
const maxValue = React.useMemo(() => Math.max(...data.map(d => d.value)), [data]);
const minValue = React.useMemo(() => Math.min(...data.map(d => d.value)), [data]);
```

### 2. 불변성 유지
```typescript
// 나쁜 예 ❌
const updateItem = (index, newValue) => {
  data[index].value = newValue; // 직접 수정
  setData(data);
};

// 좋은 예 ✅
const updateItem = (index, newValue) => {
  setData(prev => prev.map((item, i) => 
    i === index ? { ...item, value: newValue } : item
  ));
};
```

### 3. 적절한 의존성 배열
```typescript
React.useEffect(() => {
  updateChart();
```
