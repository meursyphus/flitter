# Flitter에서 RenderObject 사용자 지정하기

Flitter에서 커스텀 RenderObject를 만들면 레이아웃과 페인팅 모두에 대해 세밀한 제어가 가능합니다. 이 가이드는 커스텀 레이아웃 로직을 구현하는 방법과 SVG 및 Canvas 렌더링을 위한 별도의 페인터를 만드는 방법을 포함하여 커스텀 RenderObject를 만드는 과정을 안내합니다.

## 개요

커스텀 RenderObject를 만들 때 일반적으로 다음이 필요합니다:

1. 커스텀 Widget 클래스 만들기
2. 커스텀 RenderObject 클래스 만들기
3. 커스텀 레이아웃 로직 구현하기
4. 커스텀 SVG 및 Canvas 페인터 만들기

예제와 함께 각 단계를 살펴보겠습니다.

## 1. 커스텀 위젯 만들기

먼저 커스텀 RenderObject를 사용할 커스텀 위젯을 만들어야 합니다:

```typescript
import { SingleChildRenderObjectWidget } from "@meursyphus/flitter";

class CustomWidget extends SingleChildRenderObjectWidget {
  // 추가 속성을 여기에 추가하세요

  constructor(props: {
    /* 당신의 props */
  }) {
    super(props);
    // 속성 초기화
  }

  createRenderObject(): RenderCustomObject {
    return new RenderCustomObject(/* 필요한 props 전달 */);
  }

  updateRenderObject(renderObject: RenderCustomObject): void {
    // 필요한 경우 렌더 객체 속성 업데이트
  }
}
```

## 2. 커스텀 RenderObject 만들기

다음으로 커스텀 RenderObject를 만듭니다:

```typescript
import { SingleChildRenderObject } from "@meursyphus/flitter";

class RenderCustomObject extends SingleChildRenderObject {
  constructor(props: {
    /* 당신의 props */
  }) {
    super({ isPainter: true }); // 이 객체가 스스로를 페인트하는 경우 true로 설정
    // 속성 초기화
  }

  // 필요에 따라 메서드 오버라이드
}
```

## 3. 커스텀 레이아웃 로직 구현하기

커스텀 레이아웃 로직을 구현하려면 `performLayout` 메서드를 오버라이드합니다:

```typescript
class RenderCustomObject extends SingleChildRenderObject {
  // ...

  protected override performLayout(): void {
    // 여기에 커스텀 레이아웃 로직 구현
    // 예시:
    if (this.child) {
      this.child.layout(this.constraints);
      this.size = this.child.size;
    } else {
      this.size = this.constraints.biggest;
    }
  }
}
```

## 4. 커스텀 페인터 만들기

커스텀 페인팅을 위해 SVG와 Canvas용 별도의 페인터를 만들어야 합니다:

```typescript
import {
  SvgPainter,
  CanvasPainter,
  SvgPaintContext,
  CanvasPaintingContext,
  Offset,
} from "@meursyphus/flitter";

class CustomSvgPainter extends SvgPainter {
  protected override performPaint(context: {
    [key: string]: SVGElement;
  }): void {
    // SVG 페인팅 로직 구현
    const { rect } = context;
    rect.setAttribute("fill", "blue");
    rect.setAttribute("width", `${this.size.width}`);
    rect.setAttribute("height", `${this.size.height}`);
  }

  override createDefaultSvgEl({ createSvgEl }: SvgPaintContext): {
    [key: string]: SVGElement;
  } {
    return {
      rect: createSvgEl("rect"),
    };
  }
}

class CustomCanvasPainter extends CanvasPainter {
  protected override performPaint(
    paintContext: CanvasPaintingContext,
    offset: Offset,
  ): void {
    const { canvas: ctx } = paintContext;
    ctx.save();
    ctx.fillStyle = "blue";
    ctx.fillRect(offset.x, offset.y, this.size.width, this.size.height);
    ctx.restore();
  }
}
```

그런 다음 RenderObject에서 `createSvgPainter`와 `createCanvasPainter` 메서드를 오버라이드합니다:

```typescript
class RenderCustomObject extends SingleChildRenderObject {
  // ...

  override createSvgPainter() {
    return new CustomSvgPainter(this);
  }

  override createCanvasPainter() {
    return new CustomCanvasPainter(this);
  }
}
```

## 예제: 커스텀 Wrap 위젯

커스텀 레이아웃 로직을 구현하는 커스텀 Wrap 위젯의 예제입니다:

```typescript
class Wrap extends MultiChildRenderObjectWidget {
  override createRenderObject(): RenderObject {
    return new RenderWrap();
  }

  override updateRenderObject(): void {
    // 필요한 경우 업데이트 로직
  }
}

class RenderWrap extends MultiChildRenderObject {
  constructor() {
    super({ isPainter: false });
  }

  protected override performLayout(): void {
    let currentX = 0;
    let currentY = 0;
    let maxHeightInRow = 0;
    let maxWidth = 0;

    this.children.forEach((child) => {
      child.layout(this.constraints);

      if (currentX + child.size.width > this.constraints.maxWidth) {
        currentX = 0;
        currentY += maxHeightInRow;
        maxHeightInRow = 0;
      }

      child.offset = new Offset({ x: currentX, y: currentY });
      currentX += child.size.width;
      maxHeightInRow = Math.max(maxHeightInRow, child.size.height);
      maxWidth = Math.max(maxWidth, currentX);
    });

    this.size = new Size({
      width: maxWidth,
      height: currentY + maxHeightInRow,
    });
  }
}
```

## 결론

Flitter에서 커스텀 RenderObject를 만들면 레이아웃과 페인팅에 대한 강력한 제어가 가능합니다. 커스텀 레이아웃 로직을 구현하고 SVG와 Canvas용 별도의 페인터를 만들어 매우 특화되고 효율적인 위젯을 만들 수 있습니다.

커스텀 RenderObject를 만들 때, 특히 자주 재구축되거나 페인트될 수 있는 구성 요소의 경우 성능 영향을 고려하는 것을 잊지 마세요. 애플리케이션에서 제대로 작동하는지 확인하기 위해 항상 커스텀 구현을 프로파일링하세요.
