# Flitter의 커스텀 페인팅

Flitter는 커스텀 페인팅을 위한 강력한 도구를 제공하여 복잡하고 효율적인 시각적 요소를 만들 수 있게 합니다. 이 가이드에서는 SVG와 Canvas 렌더링 모두에서 커스텀 그래픽을 만드는 과정을 단순화하는 CustomPaint 위젯과 Path 유틸리티를 소개합니다.

## CustomPaint 위젯

레이아웃을 변경하지 않고 페인팅 동작만 사용자 지정해야 하는 경우, CustomPaint 위젯이 완벽한 솔루션입니다. SVG와 Canvas 렌더러 모두에 대해 사용자 지정 페인팅 로직을 정의할 수 있습니다.

### CustomPaint 사용하기

CustomPaint를 사용하는 기본 예제입니다:

```typescript
import { CustomPaint, Size, Path } from "@meursyphus/flitter";

const MyCustomPaintWidget = CustomPaint({
  size: Size.infinite,
  painter: {
    svg: {
      createDefaultSvgEl(context) {
        return {
          path: context.createSvgEl("path"),
        };
      },
      paint({ path: pathEl }, size) {
        // SVG 페인팅 로직
        const path = new Path();
        // ... 경로 그리기 로직 ...
        pathEl.setAttribute("d", path.getD());
      },
    },
    canvas: {
      paint({ canvas }, size) {
        // Canvas 페인팅 로직
        const path = new Path();
        // ... 경로 그리기 로직 ...
        canvas.stroke(path.toCanvasPath());
      },
    },
  },
});
```

## Path 유틸리티

Flitter의 Path 유틸리티는 SVG와 Canvas 렌더링 모두에서 동일한 코드를 사용하여 복잡한 모양과 경로를 만들 수 있는 강력한 도구입니다. 이를 통해 다양한 렌더링 컨텍스트에서 작동하는 커스텀 그래픽을 만드는 과정이 크게 단순화됩니다.

### Path의 주요 기능

1. **통합 API**: SVG나 Canvas로 렌더링되는지에 관계없이 동일한 메서드를 사용하여 경로를 정의합니다.
2. **쉬운 변환**: 간단한 메서드 호출로 경로를 SVG 또는 Canvas 형식으로 변환합니다 (SVG용 `getD()`, Canvas용 `toCanvasPath()`).
3. **복잡한 모양 지원**: 풍부한 메서드 세트로 선, 곡선, 호 등을 만들 수 있습니다.

### 예제: 선형 차트 그리기

Path 유틸리티를 사용하여 선형 차트를 그리는 예제입니다:

```typescript
import { CustomPaint, Path, Size } from "@meursyphus/flitter";

function LineChart({ values, color, thickness = 2 }) {
  return CustomPaint({
    size: Size.infinite,
    painter: {
      svg: {
        createDefaultSvgEl(context) {
          return { path: context.createSvgEl("path") };
        },
        paint({ path: pathEl }, { width, height }) {
          const path = new Path();
          drawLineChart(path, values, width, height);
          pathEl.setAttribute("stroke", color);
          pathEl.setAttribute("fill", "none");
          pathEl.setAttribute("stroke-width", `${thickness}`);
          pathEl.setAttribute("d", path.getD()); // SVG 경로로 변환
        },
      },
      canvas: {
        paint({ canvas }, { width, height }) {
          const path = new Path();
          drawLineChart(path, values, width, height);
          canvas.strokeStyle = color;
          canvas.lineWidth = thickness;
          canvas.stroke(path.toCanvasPath()); // Canvas 경로로 변환
        },
      },
    },
  });
}

function drawLineChart(
  path: Path,
  values: number[],
  width: number,
  height: number,
) {
  // SVG와 Canvas 모두에서 동일한 그리기 로직 사용
  values.forEach((value, index) => {
    const x = (index / (values.length - 1)) * width;
    const y = height - (value / Math.max(...values)) * height;

    if (index === 0) {
      path.moveTo({ x, y });
    } else {
      path.lineTo({ x, y });
    }
  });
}
```

이 예제에서 `drawLineChart` 함수는 Path 유틸리티를 사용하여 선형 차트를 만듭니다. 동일한 경로가 SVG와 Canvas 렌더링 모두에 사용되며, 최종 변환 단계만 다릅니다 (SVG용 `getD()`, Canvas용 `toCanvasPath()`).

## 결론

Flitter의 CustomPaint 위젯과 Path 유틸리티는 커스텀 그래픽을 만드는 강력하고 유연한 방법을 제공합니다. 이러한 도구를 사용하면:

1. 페인팅 로직과 레이아웃 로직을 분리할 수 있습니다
2. 복잡한 모양과 경로를 쉽게 만들 수 있습니다
3. SVG와 Canvas 렌더링 모두에서 원활하게 작동하는 코드를 작성할 수 있습니다

이러한 접근 방식은 개발 과정을 단순화할 뿐만 아니라 다양한 렌더링 컨텍스트에서 일관성을 보장하여 Flitter를 정교한 데이터 시각화와 커스텀 UI 요소를 만드는 데 탁월한 선택으로 만듭니다.
