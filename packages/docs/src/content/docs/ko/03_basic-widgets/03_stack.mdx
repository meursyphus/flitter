# Flitter의 Stack 위젯

Flitter의 Stack 위젯은 여러 자식 위젯을 서로 겹쳐서 배치할 수 있게 해줍니다. 이는 이미지 위에 텍스트를 배치하거나 레이어드 UI를 만드는 것과 같이 요소들이 서로에 대해 상대적으로 배치되어야 하는 복잡한 레이아웃을 만들 때 특히 유용합니다.

## 개요

Stack은 자식을 상자의 가장자리에 대해 상대적으로 배치합니다. Stack 자체는 부모에 의해 제약되지 않는 한 자식을 수용할 수 있는 최대 크기로 확장됩니다.

## 주요 속성

- `children`: 쉽이에 배치할 자식 위젯의 목록입니다.
- `alignment`: 스택에서 위치가 지정되지 않은 또는 부분적으로 위치가 지정된 자식을 정렬하는 방법을 결정합니다.
- `fit`: 위치가 지정되지 않은 자식의 크기를 어떻게 조정할지 결정합니다.
- `clipBehavior`: 스택의 경계를 벗어나는 자식을 클립할지 여부를 결정합니다.

## 기본 사용법

Stack을 사용하는 간단한 예제입니다:

```typescript
import { Stack, Container, Positioned, Text } from "@meursyphus/flitter";

const myStack = Stack({
  children: [
    Container({ width: 300, height: 300, color: "lightblue" }),
    Positioned({
      top: 10,
      left: 10,
      child: Text("Top Left"),
    }),
    Positioned({
      bottom: 10,
      right: 10,
      child: Text("Bottom Right"),
    }),
  ],
});
```

이것은 왼쪽 상단과 오른쪽 하단에 텍스트가 배치된 연한 파란색 컨테이너를 만듭니다.

## 시각적 표현

```
┌────────────────────────────────┐
│ Top Left                       │
│                                │
│                                │
│                                │
│                                │
│                                │
│                                │
│                       Bottom Right
└────────────────────────────────┘
```

## 고급 사용법

### Positioned 위젯과 함께 사용하기

Positioned 위젯은 자식을 정확하게 배치하기 위해 Stack과 함께 자주 사용됩니다:

```typescript
import { Stack, Container, Positioned } from "@meursyphus/flitter";

const advancedStack = Stack({
  children: [
    Container({ width: 300, height: 300, color: "lightgrey" }),
    Positioned({
      left: 20,
      top: 20,
      child: Container({ width: 100, height: 100, color: "red" }),
    }),
    Positioned({
      right: 40,
      bottom: 40,
      child: Container({ width: 150, height: 150, color: "blue" }),
    }),
  ],
});
```

시각적 표현:

```
┌────────────────────────────────┐
│ ┌────────┐                     │
│ │        │                     │
│ │  Red   │                     │
│ │        │                     │
│ └────────┘                     │
│                                │
│                   ┌───────────┐│
│                   │           ││
│                   │   Blue    ││
│                   │           ││
│                   └───────────┘│
└────────────────────────────────┘
```

### Alignment 사용하기

`alignment` 속성을 사용하여 위치가 지정되지 않은 자식을 배치할 수 있습니다:

```typescript
import { Stack, Container, Alignment } from "@meursyphus/flitter";

const alignedStack = Stack({
  alignment: Alignment.center,
  children: [
    Container({ width: 300, height: 300, color: "lightgrey" }),
    Container({ width: 150, height: 150, color: "red" }),
  ],
});
```

이것은 연한 회색 컨테이너 내에서 빨간색 컨테이너를 중앙에 배치합니다.

## 모범 사례

1. **Positioned를 현명하게 사용**: Positioned는 정확한 제어를 제공하지만, 과도하게 사용하면 다양한 화면 크기에 잘 적응하지 않는 레이아웃이 될 수 있습니다.

2. **반응성 고려**: Stack은 다른 화면 크기에서 다르게 동작할 수 있다는 점을 기억하세요. 다양한 기기에서 레이아웃을 테스트하세요.

3. **순서 주의**: 자식은 children 목록에 나타나는 순서대로 그려집니다. 마지막 자식이 가장 위에 위치합니다.

4. **다른 위젯과 결합**: Stack은 다른 레이아웃 위젯과 잘 작동합니다. 예를 들어, Container 내부에 Stack을 사용하여 패딩이나 제약 조건을 추가할 수 있습니다.

## 결론

Stack 위젯은 Flitter에서 복잡하고 겹치는 레이아웃을 만드는 강력한 도구입니다. Stack을 효과적으로 사용하는 방법과 함께 Positioned 위젯을 이해함으로써 풍부하고 레이어드된 사용자 인터페이스를 만들 수 있습니다. 신중하게 사용하고 항상 레이아웃이 다양한 화면 크기와 방향에 어떻게 적응할지 고려하세요.
