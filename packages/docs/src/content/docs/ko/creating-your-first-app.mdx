# 첫 번째 Flitter 앱 만들기

이 가이드는 세 가지 다른 환경에서 간단한 Flitter 앱을 만드는 과정을 안내합니다: 순수 JavaScript, React (Vite 사용), Svelte (SvelteKit 사용). 텍스트가 있는 색상이 지정된 사각형을 표시하는 기본 앱을 만들 것입니다.

## 순수 JavaScript

1. 프로젝트 디렉토리에 `index.html` 파일을 생성합니다:

```html
<!doctype html>
<html lang="ko">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>나의 첫 번째 Flitter 앱</title>
  </head>
  <body>
    <div style="width: 500px; height: 500px" id="container">
      <!-- width와 height를 반드시 100%로 설정해야 합니다 -->
      <!-- canvas 대신 svg를 사용할 수도 있습니다 -->
      <canvas style="width: 100%; height: 100%;" id="view"></canvas>
    </div>
    <script type="module" src="./main.js"></script>
  </body>
</html>
```

2. 같은 디렉토리에 `main.js` 파일을 생성합니다:

```javascript
import {
  Widget,
  Container,
  Text,
  Center,
  AppRunner,
  TextStyle,
  Colors,
} from "@meursyphus/flitter";

const MyApp = () => {
  return Container({
    width: 300,
    height: 200,
    color: Colors.blue[500],
    child: Center({
      child: Text("안녕하세요, Flitter!", {
        style: new TextStyle({ color: Colors.white, fontSize: 24 }),
      }),
    }),
  });
};

const appElement = document.getElementById("view"); // canvas 또는 svg여야 합니다
const runner = new AppRunner({ view: appElement });
/**
 * canvas(또는 svg)의 크기를 계산하기 위해 resizeTarget을 설정해야 합니다
 */
app.onMount({
  resizeTarget: document.querySelector<HTMLDivElement>("#container")!,
});
runner.runApp(MyApp());
```

3. 로컬 서버를 사용하여 앱을 제공합니다 (예: `live-server` npm 패키지 사용).

## React (Vite 사용)

1. React 프로젝트 디렉토리에서 `src/App.tsx`를 열고 내용을 다음으로 교체합니다:

```tsx
import {
  Container,
  Text,
  Center,
  TextStyle,
  Colors,
} from "@meursyphus/flitter";
import Widget from "@meursyphus/flitter-react";

function App() {
  return (
    <Widget
      width="300px"
      height="200px"
      widget={Container({
        color: "blue",
        child: Center({
          child: Text("안녕하세요, Flitter!", {
            style: new TextStyle({ color: Colors.white, fontSize: 24 }),
          }),
        }),
      })}
    />
  );
}

export default App;
```

2. `npm run dev`로 앱을 실행합니다.

## Svelte (SvelteKit 사용)

1. SvelteKit 프로젝트에서 `src/routes/+page.svelte` 파일을 생성하고 다음 내용을 추가합니다:

```svelte
<script lang="ts">
  import {
    Container,
    Text,
    Center,
    TextStyle,
    Colors,
  } from "@meursyphus/flitter";
  import Widget from "@meursyphus/flitter-svelte";
</script>

<Widget
  width="300px"
  height="200px"
  widget={Container({
    color: "blue",
    child: Center({
      child: Text("안녕하세요, Flitter!", {
        style: new TextStyle({ color: Colors.white, fontSize: 24 }),
      }),
    }),
  })}
/>
```

2. `npm run dev`로 앱을 실행합니다.

## 다음 단계

축하합니다! 첫 번째 Flitter 앱을 만들었습니다. 이 간단한 예제는 Flitter 애플리케이션의 기본 구조와 Container, Center, Text와 같은 핵심 위젯을 사용하는 방법을 보여줍니다. 또한 TextStyle 클래스를 사용하여 텍스트를 적절하게 스타일링하는 방법도 보여줍니다.
