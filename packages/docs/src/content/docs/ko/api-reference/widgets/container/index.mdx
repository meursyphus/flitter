# Container

패딩, 마진, 장식, 크기 제약을 결합한 편의 위젯입니다.

## 클래스 정의

```typescript
Container({
  key?: any,
  alignment?: Alignment,
  padding?: EdgeInsets,
  color?: string,
  decoration?: BoxDecoration,
  foregroundDecoration?: BoxDecoration,
  width?: number,
  height?: number,
  constraints?: BoxConstraints,
  margin?: EdgeInsets,
  transform?: Matrix4,
  transformAlignment?: Alignment,
  child?: Widget,
  clipBehavior?: 'none' | 'hardEdge' | 'antiAlias' | 'antiAliasWithSaveLayer'
})
```

## 생성자

### Container

Container 위젯을 생성합니다.

#### 매개변수

| 이름 | 타입 | 설명 | 기본값 | 필수 |
|------|------|------|--------|------|
| `key` | `any` | 위젯의 고유 식별자 | `undefined` | ❌ |
| `alignment` | `Alignment` | 자식 위젯의 정렬 | `undefined` | ❌ |
| `padding` | `EdgeInsets` | 내부 여백 | `undefined` | ❌ |
| `color` | `string` | 배경색 (decoration이 없을 때만 사용) | `undefined` | ❌ |
| `decoration` | `BoxDecoration` | 배경 장식 | `undefined` | ❌ |
| `foregroundDecoration` | `BoxDecoration` | 전경 장식 | `undefined` | ❌ |
| `width` | `number` | 너비 | `undefined` | ❌ |
| `height` | `number` | 높이 | `undefined` | ❌ |
| `constraints` | `BoxConstraints` | 크기 제약 | `undefined` | ❌ |
| `margin` | `EdgeInsets` | 외부 여백 | `undefined` | ❌ |
| `transform` | `Matrix4` | 변환 행렬 | `undefined` | ❌ |
| `transformAlignment` | `Alignment` | 변환 기준점 | `undefined` | ❌ |
| `child` | `Widget` | 자식 위젯 | `undefined` | ❌ |
| `clipBehavior` | `ClipBehavior` | 클리핑 동작 | `'none'` | ❌ |

## 속성

### alignment
**타입**: `Alignment?`

Container 내에서 자식 위젯을 정렬합니다. null이면 자식이 Container를 채웁니다.

### padding
**타입**: `EdgeInsets?`

Container 내부의 빈 공간입니다. 자식이 있다면 자식 주위에 적용됩니다.

### color
**타입**: `string?`

Container의 배경색입니다. `decoration`이 제공된 경우 이 속성은 무시됩니다.

### decoration
**타입**: `BoxDecoration?`

Container 뒤에 그려지는 장식입니다.

### foregroundDecoration
**타입**: `BoxDecoration?`

Container 앞에 그려지는 장식입니다.

### width
**타입**: `number?`

Container의 너비입니다. null이면 자식 크기나 constraints에 따라 결정됩니다.

### height
**타입**: `number?`

Container의 높이입니다. null이면 자식 크기나 constraints에 따라 결정됩니다.

### constraints
**타입**: `BoxConstraints?`

Container에 적용할 추가 제약입니다.

### margin
**타입**: `EdgeInsets?`

Container 주위의 빈 공간입니다.

### transform
**타입**: `Matrix4?`

Container를 그리기 전에 적용할 변환 행렬입니다.

### transformAlignment
**타입**: `Alignment?`

변환의 원점입니다. 

### child
**타입**: `Widget?`

Container에 포함될 자식 위젯입니다.

### clipBehavior
**타입**: `ClipBehavior`

내용이 경계를 벗어날 때의 클리핑 동작입니다.

## 메서드

Container는 StatelessWidget이므로 공개 메서드가 없습니다.

## BoxDecoration

Container의 시각적 장식을 정의합니다.

```typescript
interface BoxDecoration {
  color?: string;
  image?: DecorationImage;
  border?: BoxBorder;
  borderRadius?: BorderRadius;
  boxShadow?: BoxShadow[];
  gradient?: Gradient;
  backgroundBlendMode?: BlendMode;
  shape?: BoxShape;
}
```

### 속성

| 속성 | 타입 | 설명 |
|------|------|------|
| `color` | `string?` | 배경색 |
| `image` | `DecorationImage?` | 배경 이미지 |
| `border` | `BoxBorder?` | 테두리 |
| `borderRadius` | `BorderRadius?` | 모서리 둥글기 |
| `boxShadow` | `BoxShadow[]?` | 그림자 효과 |
| `gradient` | `Gradient?` | 그라디언트 효과 |
| `backgroundBlendMode` | `BlendMode?` | 배경 블렌드 모드 |
| `shape` | `BoxShape?` | 박스 모양 (rectangle 또는 circle) |

</Widget>

## 주의사항

1. `color`와 `decoration`을 동시에 제공하면 오류가 발생합니다. 색상은 `decoration.color`를 사용하세요.
2. `constraints`와 `width`/`height`를 함께 사용하면, 더 제한적인 제약이 적용됩니다.
3. `transform`을 사용할 때는 `transformAlignment`도 고려하세요.
