# TextField

## 개요

TextField는 사용자로부터 텍스트 입력을 받을 수 있는 대화형 위젯입니다. 한 줄 또는 여러 줄의 텍스트 입력을 지원하며, 다양한 스타일링 옵션을 제공합니다.

## 사용 시기

다음과 같은 상황에서 TextField를 사용합니다:

- 사용자 이름, 이메일 등의 텍스트 입력이 필요할 때
- 검색 창을 구현할 때
- 댓글이나 메시지 입력 필드가 필요할 때
- 폼 데이터를 수집할 때

## 기본 사용법

```typescript
TextField('초기 텍스트', {
  onChanged: (text) => {
    console.log('텍스트 변경:', text);
  }
})
```

## 생성자 파라미터

| 파라미터 | 타입 | 설명 | 기본값 |
|---------|------|------|--------|
| text | `string` | 초기 텍스트 값 | 필수 |
| onChanged | `(text: string) => void` | 텍스트 변경 시 콜백 | undefined |
| onSubmitted | `(text: string) => void` | Enter 키 입력 시 콜백 | undefined |
| onFocused | `() => void` | 포커스 시 콜백 | undefined |
| onBlurred | `() => void` | 포커스 해제 시 콜백 | undefined |
| style | `TextStyle` | 텍스트 스타일 | TextStyle() |
| maxLines | `number` | 최대 줄 수 | 1 |
| textAlign | `TextAlign` | 텍스트 정렬 | start |
| textDirection | `TextDirection` | 텍스트 방향 | ltr |
| decoration | `BoxDecoration` | 필드 장식 | 기본 테두리 |
| padding | `EdgeInsets` | 내부 여백 | EdgeInsets.all(0) |
| width | `number` | 필드 너비 | Infinity |
| height | `number` | 필드 높이 | 20 |
| focusedBorder | `Border` | 포커스 시 테두리 | 파란색 테두리 |
| key | `any` | 위젯의 고유 키 | undefined |

### 이벤트 처리 예제

```typescript
class SearchField extends StatefulWidget {
  createState() {
    return new SearchFieldState();
  }
}

class SearchFieldState extends State<SearchField> {
  searchText = '';
  
  build() {
    return Column({
      children: [
        TextField(this.searchText, {
          width: 300,
          height: 35,
          placeholder: '검색어를 입력하세요',
          onChanged: (text) => {
            this.setState(() => {
              this.searchText = text;
            });
          },
          onSubmitted: (text) => {
            console.log('검색 실행:', text);
          },
          decoration: BoxDecoration({
            border: Border.all({ color: '#3498db', width: 1 }),
            borderRadius: { all: { radius: 20 } }
          }),
          padding: EdgeInsets.symmetric({ horizontal: 20, vertical: 8 })
        }),
        Text(`검색어: ${this.searchText}`, {
          style: TextStyle({ fontSize: 12, color: '#666' })
        })
      ]
    });
  }
}
```

## 주요 기능

### 텍스트 선택
- 마우스 드래그로 텍스트 선택 가능
- 선택된 텍스트는 하이라이트 표시

### 캐럿(커서)
- 깜빡이는 캐럿으로 현재 입력 위치 표시
- 타이핑 중에는 캐럿이 고정됨

### 포커스 상태
- 포커스 시 테두리 스타일 변경 가능
- 포커스/블러 이벤트 처리 가능

### 한글 입력
- IME(Input Method Editor) 지원
- 조합 중인 텍스트 표시

## 메서드

TextField의 State에서 사용 가능한 메서드:

- `focus(location?: number)` - 특정 위치에 포커스
- `blur()` - 포커스 해제

## 주의사항

- TextField는 StatefulWidget이므로 상태 관리가 필요합니다
- 브라우저의 네이티브 입력 기능을 활용합니다
- 큰 텍스트의 경우 성능에 영향을 줄 수 있습니다
- maxLines를 설정하면 스크롤이 자동으로 처리됩니다
