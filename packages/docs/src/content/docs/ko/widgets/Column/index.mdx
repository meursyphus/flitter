# Column

## 개요

Column은 자식 위젯들을 수직으로 배열하는 레이아웃 위젯입니다. Flex 위젯에 `direction: Axis.vertical`을 설정한 것과 동일하지만, 더 직관적이고 간편한 API를 제공합니다.

## 사용 시기

다음과 같은 상황에서 Column을 사용합니다:

- 여러 위젯을 위에서 아래로 배열하고 싶을 때
- 수직 목록이나 폼 레이아웃을 만들 때
- 카드나 대화상자의 내용을 구성할 때
- 메뉴 항목들을 수직으로 나열할 때

## 기본 사용법

```typescript
Column({
  children: [
    Text('첫 번째 항목'),
    Text('두 번째 항목'),
    Text('세 번째 항목')
  ]
})
```

## 생성자 파라미터

| 파라미터 | 타입 | 설명 | 기본값 |
|---------|------|------|--------|
| children | `Widget[]` | 수직으로 배열할 자식 위젯들 | 필수 |
| mainAxisAlignment | `MainAxisAlignment` | 주축(수직) 정렬 방식 | start |
| crossAxisAlignment | `CrossAxisAlignment` | 교차축(수평) 정렬 방식 | center |
| mainAxisSize | `MainAxisSize` | 주축 크기 설정 | max |
| verticalDirection | `VerticalDirection` | 수직 방향 (up/down) | down |
| key | `any` | 위젯의 고유 키 | undefined |

## 정렬 옵션

### MainAxisAlignment (수직 정렬)
- `start`: 위쪽 정렬
- `end`: 아래쪽 정렬
- `center`: 중앙 정렬
- `spaceBetween`: 양 끝 배치하고 균등 분배
- `spaceAround`: 균등한 여백으로 분배
- `spaceEvenly`: 모든 간격을 동일하게 분배

### CrossAxisAlignment (수평 정렬)
- `start`: 왼쪽 정렬
- `end`: 오른쪽 정렬
- `center`: 중앙 정렬
- `stretch`: 가로 전체로 늘리기

## 주의사항

- Column은 세로 방향으로 무한한 높이를 가정하므로, 스크롤이 필요한 경우 ScrollView로 감싸야 합니다
- 자식 위젯이 Column의 높이를 초과하면 오버플로우가 발생할 수 있습니다
- Expanded 위젯은 Column의 직접적인 자식이어야 합니다

## Flex와의 차이점

Column은 사실상 다음과 동일합니다:

```typescript
Flex({
  direction: Axis.vertical,
  children: [...]
})
```

Column을 사용하면 코드가 더 간결하고 의도가 명확해집니다.
