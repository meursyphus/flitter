# Flexible

## 개요

Flexible은 Row, Column 또는 Flex 위젯 내에서 자식 위젯이 사용 가능한 공간을 차지하도록 하는 위젯입니다. flex 값을 통해 다른 Flexible 위젯들과 비교하여 얼마나 많은 공간을 차지할지 결정할 수 있습니다.

## 사용 시기

다음과 같은 상황에서 Flexible을 사용합니다:

- Row나 Column 내에서 남은 공간을 채우고 싶을 때
- 여러 위젯 간에 공간을 비율적으로 분배하고 싶을 때
- 자식 위젯이 필요한 만큼만 공간을 차지하되, 더 많은 공간이 있으면 확장하도록 할 때
- 반응형 레이아웃을 구성할 때

## 기본 사용법

```typescript
Row({
  children: [
    Flexible({
      flex: 1,
      child: Container({
        color: 'blue',
        height: 100
      })
    }),
    Flexible({
      flex: 2,
      child: Container({
        color: 'red',
        height: 100
      })
    })
  ]
})
```

## 생성자 파라미터

| 파라미터 | 타입 | 설명 | 기본값 |
|---------|------|------|--------|
| flex | `number` | 다른 Flexible 위젯과 비교한 공간 비율 | 1 |
| fit | `'tight' \| 'loose'` | 자식 위젯의 크기 제약 방식 | 'loose' |
| child | `Widget` | Flexible이 적용될 자식 위젯 | undefined |
| key | `any` | 위젯의 고유 키 | undefined |

## FlexFit 옵션

- **loose**: 자식 위젯이 필요한 만큼만 공간을 차지하되, 최대 사용 가능한 공간까지 확장 가능
- **tight**: 자식 위젯이 사용 가능한 모든 공간을 차지하도록 강제 (Expanded와 동일)

## Flexible vs Expanded

Expanded는 Flexible의 특수한 경우입니다:

```typescript
// 이 두 코드는 동일합니다
Expanded({ child: myWidget })
Flexible({ fit: 'tight', child: myWidget })
```

- **Flexible**: 자식이 필요한 만큼만 공간을 차지할 수 있음 (fit: 'loose')
- **Expanded**: 자식이 사용 가능한 모든 공간을 차지하도록 강제

## 주의사항

1. Flexible은 반드시 Row, Column, 또는 Flex의 직접적인 자식이어야 합니다
2. flex 값은 0보다 커야 합니다
3. 여러 Flexible 위젯이 있을 때, 공간은 flex 비율에 따라 분배됩니다
4. 고정 크기 위젯과 함께 사용할 때, 고정 크기가 먼저 할당되고 남은 공간이 Flexible 위젯들에게 분배됩니다
