# Grid

## 개요

Grid는 자식 위젯들을 행과 열로 구성된 격자 형태로 배열하는 강력한 레이아웃 위젯입니다. CSS Grid와 유사한 개념으로, 복잡한 2차원 레이아웃을 쉽게 구성할 수 있습니다.

## 사용 시기

다음과 같은 상황에서 Grid를 사용합니다:

- 테이블 형태의 레이아웃이 필요할 때
- 이미지 갤러리나 카드 그리드를 만들 때
- 대시보드나 위젯 격자를 구성할 때
- 정확한 행과 열 크기 제어가 필요할 때

## 기본 사용법

```typescript
Grid({
  childrenByRow: [
    [widget1, widget2, widget3],  // 첫 번째 행
    [widget4, widget5, widget6],  // 두 번째 행
  ]
})
```

## 생성자 파라미터

| 파라미터 | 타입 | 설명 | 기본값 |
|---------|------|------|--------|
| childrenByRow | `Widget[][]` | 행별로 구성된 자식 위젯들 | 필수 |
| templateRows | `GridTemplate[]` | 행 크기 템플릿 | [] |
| templateColumns | `GridTemplate[]` | 열 크기 템플릿 | [] |
| autoRow | `GridTemplate` | 템플릿이 없는 행의 기본 크기 | Fr(1) |
| autoColumn | `GridTemplate` | 템플릿이 없는 열의 기본 크기 | Fr(1) |
| key | `any` | 위젯의 고유 키 | undefined |

## GridTemplate 옵션

Grid는 다양한 크기 단위를 지원합니다:

- `Grid.Fr(value)` - 비율 단위 (Fractional unit)
- `Grid.Px(value)` - 고정 픽셀 크기
- `Grid.Percent(value)` - 부모 크기의 백분율 (0-100)
- `Grid.ContentFit()` - 내용에 맞춤

## repeat 헬퍼 메서드

반복되는 템플릿을 쉽게 생성할 수 있습니다:

```typescript
Grid({
  templateColumns: Grid.Fr(1).repeat(4), // [Fr(1), Fr(1), Fr(1), Fr(1)]
  templateRows: Grid.Px(100).repeat(3),  // [Px(100), Px(100), Px(100)]
  childrenByRow: [...]
})
```

## 주의사항

- 각 행의 열 개수가 다를 수 있지만, templateColumns를 사용할 때는 일관성을 유지하는 것이 좋습니다
- Fr 단위는 고정 크기를 제외한 남은 공간을 비율로 나눕니다
- ContentFit은 자식의 내재 크기를 사용하므로 성능에 영향을 줄 수 있습니다
