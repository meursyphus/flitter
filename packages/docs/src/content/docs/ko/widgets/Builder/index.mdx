# Builder

## 개요

Builder는 BuildContext를 통해 위젯을 동적으로 생성할 수 있게 해주는 위젯입니다. 특정 컨텍스트의 정보나 상태에 접근해야 할 때 유용합니다.

## 사용 시기

다음과 같은 상황에서 Builder를 사용합니다:

- BuildContext에 접근해야 할 때
- Theme 데이터에 접근해야 할 때
- MediaQuery 정보가 필요할 때
- 위젯 트리의 특정 위치에서 컨텍스트가 필요할 때

## 기본 사용법

```typescript
Builder({
  builder: (context) => {
    // context를 사용하여 위젯 반환
    return Container({
      child: Text('Hello from Builder!')
    });
  }
})
```

## 생성자 파라미터

| 파라미터 | 타입 | 설명 | 기본값 |
|---------|------|------|--------|
| builder | `(context: BuildContext) => Widget` | 컨텍스트를 받아 위젯을 반환하는 함수 | 필수 |
| key | `any` | 위젯의 고유 키 | undefined |

## 예제

### 기본 예제

<Widget
  width="300px"
  height="200px"
  renderer="svg"
  widget={Container({
    alignment: Alignment.center,
    color: '#f0f0f0',
    child: Builder({
      builder: (context) => {
        return Container({
          padding: { all: 20 },
          decoration: {
            color: '#3498db',
            borderRadius: { all: { radius: 8 } }
          },
          child: Text('Builder로 생성된 위젯', {
            style: TextStyle({
              color: '#ffffff',
              fontSize: 16
            })
          })
        });
      }
    })
  })}
/>

      }
    })
  })}
/>

  width="300px"
  height="300px"
  renderer="svg"

    child: Builder({

        const items = ['아이템 1', '아이템 2', '아이템 3'];

              },

                style: TextStyle({ color: '#ffffff' })
              })
            })
          )
        });
      }
    })
  })}
/>

## 주의사항

- Builder의 builder 함수는 위젯이 빌드될 때마다 호출됩니다
- 무거운 계산은 builder 함수 밖에서 처리하는 것이 좋습니다
- context를 통해 상위 위젯의 정보에 접근할 수 있습니다
