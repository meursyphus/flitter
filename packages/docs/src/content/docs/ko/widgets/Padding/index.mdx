# Padding

## 개요

Padding은 자식 위젯 주위에 여백을 추가하는 위젯입니다. Container의 padding 속성과 동일한 기능을 제공하지만, 여백만 필요할 때 더 가벼운 선택지입니다.

## 사용 시기

다음과 같은 상황에서 Padding을 사용합니다:

- 위젯 주위에 여백만 추가하고 싶을 때
- Container의 다른 기능(색상, 테두리 등)이 필요 없을 때
- 성능을 최적화하고 싶을 때 (Container보다 가벼움)
- 명확하게 여백 추가 의도를 표현하고 싶을 때

## 기본 사용법

```typescript
Padding({
  padding: EdgeInsets.all(16),
  child: Text('Padded Text')
})
```

## 생성자 파라미터

| 파라미터 | 타입 | 설명 | 기본값 |
|---------|------|------|--------|
| padding | `EdgeInsets` | 여백 값 | EdgeInsets.all(0) |
| child | `Widget` | 여백이 적용될 자식 위젯 | undefined |
| key | `any` | 위젯의 고유 키 | undefined |

## EdgeInsets 사용법

EdgeInsets는 여백을 지정하는 여러 방법을 제공합니다:

- `EdgeInsets.all(value)` - 모든 방향에 동일한 여백
- `EdgeInsets.symmetric({ horizontal, vertical })` - 수평/수직 대칭 여백
- `EdgeInsets.only({ top, right, bottom, left })` - 각 방향 개별 지정
- `EdgeInsets.fromLTRB(left, top, right, bottom)` - 순서대로 지정

## 예제

### 기본 예제

<Widget
  width="300px"
  height="150px"
  renderer="svg"
  widget={Container({
    alignment: Alignment.center,
    color: '#f0f0f0',
    child: ColoredBox({
      color: '#e74c3c',
      child: Padding({
        padding: EdgeInsets.all(20),
        child: Text('20px 여백', {
          style: TextStyle({
            color: '#ffffff',
            fontSize: 16
          })
        })
      })
    })
  })}
/>

## 주의사항

- Padding은 Expanded 위젯을 직접 자식으로 가질 수 없습니다
- 여백이 음수일 수 없습니다
- 여백은 부모 위젯의 제약 조건 내에서 적용됩니다

## Container와의 차이점

| 특징 | Padding | Container (padding 속성 사용) |
|-----|---------|------------------------------|
| 여백 | ✓ | ✓ |
| 색상 | ✗ | ✓ |
| 테두리 | ✗ | ✓ |
| 크기 지정 | ✗ | ✓ |
| 변형(Transform) | ✗ | ✓ |
| 성능 | 더 가벼움 | 상대적으로 무거움 |
