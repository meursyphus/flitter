# Image

## 개요

Image는 웹에서 이미지를 표시하는 위젯입니다. 다양한 크기 조정 옵션과 위치 지정 옵션을 제공하여 이미지를 유연하게 표시할 수 있습니다.

## 사용 시기

다음과 같은 상황에서 Image를 사용합니다:

- 로고, 아이콘, 사진 등을 표시할 때
- 썸네일 이미지를 표시할 때
- 배경 이미지나 일러스트레이션을 표시할 때
- 반응형 이미지가 필요할 때

## 기본 사용법

```typescript
Image({
  src: 'https://example.com/image.jpg',
  width: 200,
  height: 150
})
```

## 생성자 파라미터

| 파라미터 | 타입 | 설명 | 기본값 |
|---------|------|------|--------|
| src | `string` | 이미지 URL 또는 경로 | 필수 |
| width | `number` | 이미지 너비 | undefined |
| height | `number` | 이미지 높이 | undefined |
| objectFit | `ObjectFit` | 이미지 크기 조정 방식 | undefined |
| objectPosition | `ObjectPosition` | 이미지 위치 정렬 | undefined |
| key | `any` | 위젯의 고유 키 | undefined |

## ObjectFit 옵션

이미지가 컨테이너에 맞춰지는 방식을 제어합니다:

- `fill` - 컨테이너를 완전히 채움 (비율 무시)
- `contain` - 비율을 유지하며 컨테이너 안에 맞춤
- `cover` - 비율을 유지하며 컨테이너를 가득 채움
- `none` - 원본 크기 유지
- `scale-down` - none과 contain 중 작은 것 선택

## ObjectPosition 옵션

이미지의 정렬 위치를 제어합니다:

- `center` - 중앙 정렬
- `top`, `bottom`, `left`, `right` - 각 방향 정렬
- `top left`, `top right`, `bottom left`, `bottom right` - 모서리 정렬

    src: '/logo.jpeg',

## 주의사항

- 이미지가 로드되기 전까지는 지정된 크기의 빈 공간이 표시됩니다
- 네트워크 이미지의 경우 CORS 정책을 확인해야 합니다
- 큰 이미지는 성능에 영향을 줄 수 있으므로 적절한 크기로 최적화하세요
- width나 height 중 하나만 지정하면 비율이 유지되지 않을 수 있습니다
