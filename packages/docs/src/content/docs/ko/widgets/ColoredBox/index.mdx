# ColoredBox

## 개요

ColoredBox는 지정된 색상으로 채워진 직사각형 박스를 생성하는 가장 간단한 위젯입니다. Container와 달리 색상만 지정할 수 있으며, 패딩이나 마진 등의 추가 속성은 없습니다.

## 사용 시기

다음과 같은 상황에서 ColoredBox를 사용합니다:

- 단순히 색상이 있는 배경이 필요할 때
- Container의 다른 기능이 필요 없을 때
- 성능을 최적화하고 싶을 때 (Container보다 가벼움)
- 색상 오버레이나 배경색만 필요할 때

## 기본 사용법

```typescript
ColoredBox({
  color: '#3498db',
  child: Text('Hello ColoredBox!')
})
```

## 생성자 파라미터

| 파라미터 | 타입 | 설명 | 기본값 |
|---------|------|------|--------|
| color | `string` | 박스의 배경색 (CSS 색상 값) | 필수 |
| child | `Widget` | 박스 안에 표시할 자식 위젯 | undefined |
| key | `any` | 위젯의 고유 키 | undefined |

## 예제

### 기본 예제

<Widget
  width="300px"
  height="150px"
  renderer="svg"
  widget={Container({
    alignment: Alignment.center,
    color: '#f0f0f0',
    child: ColoredBox({
      color: '#3498db',
      child: SizedBox({
        width: 200,
        height: 80,
        child: Container({
          alignment: Alignment.center,
          child: Text('ColoredBox', {
            style: TextStyle({
              color: '#ffffff',
              fontSize: 20,
              weight: 'bold'
            })
          })
        })
      })
    })
  })}
/>

## 주의사항

- ColoredBox는 크기를 지정하지 않으면 자식 위젯의 크기를 따릅니다
- 크기를 지정하려면 SizedBox나 Container로 감싸야 합니다
- 투명도가 있는 색상도 지원합니다 (예: 'rgba(255, 0, 0, 0.5)')

## Container와의 차이점

| 특징 | ColoredBox | Container |
|-----|------------|-----------|
| 색상 | ✓ | ✓ |
| 패딩/마진 | ✗ | ✓ |
| 테두리 | ✗ | ✓ |
| 크기 지정 | ✗ | ✓ |
| 변형(Transform) | ✗ | ✓ |
| 성능 | 더 가벼움 | 상대적으로 무거움 |
