## 概要

Spacerは、RowやColumnなどのFlexコンテナ内でウィジェット間の間隔を調整するために使用できる、調整可能な空のスペーサーを作成します。

Spacerウィジェットは利用可能なすべてのスペースを占めるため、Spacerを含むFlexコンテナのFlex.mainAxisAlignmentをMainAxisAlignment.spaceAround、MainAxisAlignment.spaceBetween、またはMainAxisAlignment.spaceEvenlyに設定しても、目に見える効果はありません：Spacerがすべての追加スペースを占めてしまうため、再配分するスペースが残っていないからです。

## 使用する場面

- RowやColumn内のウィジェット間に柔軟なスペースが必要な場合
- ウィジェットを反対端に押し出したい場合
- ウィジェットを均等に配置する必要がある場合
- 残りのスペースを特定の比率で割り当てたい場合
- 動的な間隔が必要なレスポンシブレイアウトを構築する場合

## Basic Usage

```typescript
// 基本的な使用：ウィジェットを反対端に押し出し
Row({
  children: [
    Text('左'),
    Spacer(),
    Text('右')
  ]
})

// 複数のスペーサーで均等配置
Row({
  children: [
    Spacer(),
    Text('最初'),
    Spacer(),
    Text('二番目'),
    Spacer(),
    Text('三番目'),
    Spacer()
  ]
})

// flex値を使用してスペース比率を調整
Row({
  children: [
    Text('開始'),
    Spacer({ flex: 1 }),
    Text('中央'),
    Spacer({ flex: 2 }),  // 最初のSpacerの2倍のスペースを取る
    Text('終了')
  ]
})
```

## プロパティ

### flex

**値: number** (デフォルト: **1**)

この子ウィジェットが他のFlexibleな子ウィジェットと比較してどの程度のスペースを占めるかを決定するフレックスファクター。

```typescript
// デフォルトflex値 (1)
Spacer()

// カスタムflex値
Spacer({ flex: 2 })  // flex: 1のウィジェットと比較して2倍のスペースを取る

// 比率の例
Row({
  children: [
    Container({ width: 50, height: 50, color: 'red' }),
    Spacer({ flex: 1 }),  // 1部分
    Container({ width: 50, height: 50, color: 'green' }),
    Spacer({ flex: 3 }),  // 3部分（最初の3倍）
    Container({ width: 50, height: 50, color: 'blue' })
  ]
})
```

### 例4: ステップインジケーター

```typescript
const StepIndicator = ({ currentStep, totalSteps, labels }) => {
  return Container({
    padding: EdgeInsets.all(24),
    child: Column({
      children: [
        // Step indicator bar
        Row({
          children: Array.from({ length: totalSteps }, (_, index) => {
            const isActive = index <= currentStep;
            const isLast = index === totalSteps - 1;
            
            return [
              // Step circle
              Container({
                width: 32,
                height: 32,
                decoration: BoxDecoration({
                  shape: BoxShape.circle,
                  color: isActive ? '#2196F3' : '#E0E0E0',
                  border: isActive ? null : Border.all({ 
                    color: '#BDBDBD', 
                    width: 2 
                  })
                }),
                child: Center({
                  child: Text((index + 1).toString(), {
                    style: TextStyle({
                      color: isActive ? 'white' : '#757575',
                      fontWeight: 'bold'
                    })
                  })
                })
              }),
              // 接続線（最後以外）
              if (!isLast) Expanded({
                child: Container({
                  height: 2,
                  margin: EdgeInsets.symmetric({ horizontal: 8 }),
                  color: isActive ? '#2196F3' : '#E0E0E0'
                })
              })
            ];
          }).flat()
        }),
        SizedBox({ height: 16 }),
        // Labels
        Row({
          mainAxisAlignment: MainAxisAlignment.spaceBetween,
          children: labels.map((label, index) => {
            if (index === 0) {
              return Text(label, {
                style: TextStyle({ fontSize: 12 })
              });
            } else if (index === labels.length - 1) {
              return Text(label, {
                style: TextStyle({ fontSize: 12 })
              });
            } else {
              return [
                Spacer(),
                Text(label, {
                  style: TextStyle({ fontSize: 12 })
                }),
                Spacer()
              ];
            }
          }).flat()
        })
      ]
    })
  });
};
```

## Spacer vs SizedBox

### どちらを使用するか？

```typescript
// ✅ Spacer: 柔軟なスペースが必要な場合
Row({
  children: [
    Text('左'),
    Spacer(),  // 残りのすべてのスペースを取る
    Text('右')
  ]
})

// ✅ SizedBox: 固定スペースが必要な場合
Row({
  children: [
    Text('最初'),
    SizedBox({ width: 16 }),  // 正確に16ピクセル
    Text('二番目')
  ]
})

// 比較例
Column({
  children: [
    // Spacerは残りのスペースを取る
    Container({
      height: 100,
      child: Row({
        children: [
          Container({ width: 50, color: 'red' }),
          Spacer(),  // 残りのスペース
          Container({ width: 50, color: 'blue' })
        ]
      })
    }),
    // SizedBoxは固定サイズ
    Row({
      children: [
        Container({ width: 50, color: 'red' }),
        SizedBox({ width: 30 }),  // 正確に30
        Container({ width: 50, color: 'blue' })
      ]
    })
  ]
})
```

## 重要な注意事項

- SpacerはFlexウィジェット（Row、Column、Flex）内でのみ使用できます
- Spacerが存在する場合、mainAxisAlignmentのスペース関連オプションは無視されます
- 複数のSpacerをflex値と共に使用して比率を制御できます
- Spacerは実際にはExpanded(child: SizedBox.shrink())の短縮形です
- 無制限のスペースでエラーを引き起こすため、慎重に使用してください

## 関連ウィジェット

- **Expanded**: Flex内で子ウィジェットを拡張するウィジェット
- **Flexible**: 子ウィジェットのフレックス動作を制御するウィジェット
- **SizedBox**: 固定サイズの空白スペースを作成するウィジェット
- **Padding**: 他のウィジェットの周りにスペースを追加するウィジェット
- **Container**: マージン、パディング、サイズを指定できるウィジェット
