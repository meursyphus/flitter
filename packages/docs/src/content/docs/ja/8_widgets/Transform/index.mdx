## 概要

`Transform`は、描画前に子ウィジェットに変換を適用するウィジェットです。FlutterのTransformにインスパイアされており、Matrix4を使用して回転、スケーリング、平移、歪みなどの様々な変換を適用します。

RotatedBoxとは異なり、Transformはレイアウト前ではなく描画の直前に変換を適用します。これはウィジェットのスペース消費を計算する際に変換が考慮されないことを意味します。これによりパフォーマンス上の利益が得られますが、レイアウトへの影響を慎重に考慮する必要があります。

## 使用する場面

- ウィジェットを回転させる必要がある場合
- ウィジェットをスケール（サイズ変更）する必要がある場合
- ウィジェットを平移（移動）させる必要がある場合
- 3D効果やパースペクティブを作成する場合
- アニメーション効果を作成する場合
- 視覚的効果や装飾を追加する場合

## Basic Usage

```typescript
import { Transform, Matrix4, Container } from 'flitter';

// 45度回転
const RotatedBox = Transform.rotate({
  angle: Math.PI / 4,  // ラジアン
  child: Container({
    width: 100,
    height: 100,
    color: '#3498db'
  })
});

// スケーリング
const ScaledBox = Transform.scale({
  scale: 1.5,  // 1.5倍スケール
  child: Container({
    width: 100,
    height: 100,
    color: '#e74c3c'
  })
});

// 平移
const TranslatedBox = Transform.translate({
  offset: new Offset({ x: 50, y: 30 }),
  child: Container({
    width: 100,
    height: 100,
    color: '#2ecc71'
  })
});
```

## プロパティ

### transform (必須)
**値: Matrix4**

適用する変換を表す4x4変換マトリックス。Matrix4クラスの様々な静的メソッドを使用して作成できます。

```typescript
// 平移変換
transform: Matrix4.translationValues(50, 30, 0)

// スケーリング変換
transform: Matrix4.diagonal3Values(2.0, 1.5, 1.0)  // X軸を2倍、Y軸を1.5倍

// 歪み変換
transform: Matrix4.skewX(0.5)  // X軸に沿って歪み
```

### origin (オプション)
**値: Offset**

変換の原点を指定します。指定しない場合は、alignmentによって決定されます。

```typescript
// 左上角を中心に回転
origin: new Offset({ x: 0, y: 0 })

// 右下角を中心に回転
origin: new Offset({ x: 100, y: 100 })
```

### alignment (オプション)
**値: Alignment** (デフォルト: **Alignment.center**)

変換の配置基準点を指定します。originが指定されていない場合に使用されます。

```typescript
// 中央基準（デフォルト）
alignment: Alignment.center

// 左上基準
alignment: Alignment.topLeft

// 右下基準
alignment: Alignment.bottomRight
```

### child (オプション)
**値: Widget**

変換が適用される子ウィジェット。

## 便利メソッド

Transformウィジェットは、一般的な変換のための静的メソッドを提供します：

### Transform.rotate()
```typescript
Transform.rotate({
  angle: number,          // 回転角度（ラジアン）
  origin?: Offset,        // 回転原点
  alignment?: Alignment,  // 配置基準
  child?: Widget
})
```

### Transform.scale()
```typescript
Transform.scale({
  scale?: number,         // 均等スケーリング
  scaleX?: number,        // X軸スケーリング
  scaleY?: number,        // Y軸スケーリング
  origin?: Offset,        // スケーリング原点
  alignment?: Alignment,  // 配置基準
  child?: Widget
})
```

### Transform.translate()
```typescript
Transform.translate({
  offset: Offset,         // 平移距離
  child?: Widget
})
```

const CombinedTransform = () => {

### 例5: Transformアニメーション

```typescript
import { Transform, AnimationController, Tween } from 'flitter';

class AnimatedTransform extends StatefulWidget {
  createState() {
    return new AnimatedTransformState();
  }
}

class AnimatedTransformState extends State {
  animationController!: AnimationController;
  rotationTween!: Tween<number>;
  scaleTween!: Tween<number>;
  
  initState() {
    this.animationController = new AnimationController({
      duration: 2000
    });
    
    this.rotationTween = new Tween({
      begin: 0,
      end: Math.PI * 2
    });
    
    this.scaleTween = new Tween({
      begin: 0.5,
      end: 1.5
    });
    
    this.animationController.addListener(() => this.setState());
    this.animationController.repeat({ reverse: true });
  }
  
  dispose() {
    this.animationController.dispose();
  }
  
  build() {
    const rotation = this.rotationTween.evaluate(this.animationController);
    const scale = this.scaleTween.evaluate(this.animationController);
    
    return Transform({
      transform: (() => {
        const matrix = Matrix4.identity();
        matrix.rotateZ(rotation);
        matrix.scale(scale, scale, 1.0);
        return matrix;
      })(),
      alignment: Alignment.center,
      child: Container({
        width: 100,
        height: 100,
        decoration: new BoxDecoration({
          color: '#3498db',
          borderRadius: BorderRadius.circular(12)
        }),
        child: Center({
          child: Text('アニメーション', {
            style: { color: 'white', fontWeight: 'bold' }
          })
        })
      })
    });
  }
}
```

### 例6: カードフリップ効果

```typescript
import { Transform, Matrix4, GestureDetector } from 'flitter';

class FlipCard extends StatefulWidget {
  createState() {
    return new FlipCardState();
  }
}

class FlipCardState extends State {
  isFlipped = false;
  
  toggleFlip = () => {
    this.setState(() => {
      this.isFlipped = !this.isFlipped;
    });
  };
  
  build() {
    return GestureDetector({
      onTap: this.toggleFlip,
      child: Transform({
        transform: (() => {
          const matrix = Matrix4.identity();
          matrix.rotateY(this.isFlipped ? Math.PI : 0);
          return matrix;
        })(),
        alignment: Alignment.center,
        child: Container({
          width: 200,
          height: 120,
          decoration: new BoxDecoration({
            color: this.isFlipped ? '#e74c3c' : '#3498db',
            borderRadius: BorderRadius.circular(12),
            boxShadow: [
              new BoxShadow({
                color: 'rgba(0, 0, 0, 0.2)',
                offset: new Offset({ x: 0, y: 4 }),
                blurRadius: 8
              })
            ]
          }),
          child: Center({
            child: Text(
              this.isFlipped ? '裏' : '表',
              { 
                style: { 
                  color: 'white', 
                  fontSize: 18,
                  fontWeight: 'bold'
                }
              }
            )
          })
        })
      })
    });
  }
}
```

## ベストプラクティス

- **レイアウトへの影響なし**: Transformはウィジェットのスペース消費に影響せず、他のウィジェットと重なる可能性があります
- **パフォーマンス**: 複雑な変換や多数のTransformウィジェットはパフォーマンスに影響する可能性があります
- **角度の単位**: 回転角度はラジアンを使用します（度数 * Math.PI / 180）
- **基準点の理解**: originとalignmentの違いを理解し、適切に使用してください
- **3D変換**: Z軸変換にはパースペクティブ設定が必要な場合があります
- **アニメーション**: スムーズな変換アニメーションにはAnimationControllerと併用してください

## 関連ウィジェット

- **AnimatedContainer**: 自動アニメーション変換が必要な場合
- **RotatedBox**: レイアウトに影響する回転が必要な場合
- **FractionalTranslation**: サイズ比率ベースの平移が必要な場合
- **AnimatedRotation**: 回転アニメーションが必要な場合
- **AnimatedScale**: スケールアニメーションが必要な場合
