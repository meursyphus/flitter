# Tooltip

このウィジェットはFlutterのTooltipにインスパイアされています。
ただし、ツールチップメッセージとして任意のウィジェットをレンダリングできます（Flutterのtooltipはメッセージのみレンダリング可能）

## プロパティ

### width

**child: Widget**

### tootip: Widget\*\*

**child: Widget**

### position

**Value: 'topLeft' | 'topCenter' | 'topRight' ...etc (default: 'bottomCenter') **
