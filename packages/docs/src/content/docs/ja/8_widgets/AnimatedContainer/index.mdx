## 概要

AnimatedContainerは、プロパティ値が変更された際に自動的にアニメーションを適用するContainerのアニメーション版です。

AnimatedContainerは、指定されたカーブと継続時間を使用して、プロパティが変更された際に古い値から新しい値へ自動的にアニメーションします。nullのプロパティはアニメーションされません。子ウィジェットとその子孫ウィジェットはアニメーションされません。このクラスは内部のAnimationControllerを使用してContainerの異なるパラメータ間のシンプルな暗黙的遷移を生成するのに便利です。

## いつ使うか？

- ウィジェットのサイズ、色、パディングなどをスムーズに遷移させたい場合
- ユーザーの操作に応じて視覚的なフィードバックを提供したい場合
- 状態変化をスムーズに表現したい場合
- 複雑なAnimationControllerを使わずにシンプルなアニメーションが必要な場合
- ホバー効果や選択状態を表現したい場合

## 基本的な使用方法

```typescript
// 状態管理のためのStatefulWidgetを作成
class AnimatedContainerExample extends StatefulWidget {
  createState() {
    return new AnimatedContainerExampleState();
  }
}

class AnimatedContainerExampleState extends State<AnimatedContainerExample> {
  isExpanded = false;

  build() {
    return GestureDetector({
      onTap: () => {
        this.setState(() => {
          this.isExpanded = !this.isExpanded;
        });
      },
      child: AnimatedContainer({
        duration: 300, // 300ミリ秒
        curve: Curves.easeInOut,
        width: this.isExpanded ? 200 : 100,
        height: this.isExpanded ? 200 : 100,
        color: this.isExpanded ? 'blue' : 'red',
        child: Center({
          child: Text('タップしてください')
        })
      })
    });
  }
}

// ファクトリー関数としてエクスポート
export default classToFunction(AnimatedContainerExample);
```

## プロパティ

### duration （必須）

**値: number**

このコンテナのパラメータをアニメーションする継続時間（ミリ秒）です。

```typescript
AnimatedContainer({
  duration: 500, // 0.5秒
  width: 100,
  height: 100
})
```

### curve

**値: Curve** （デフォルト: **Curves.linear**）

アニメーションの進行カーブを定義します。様々な組み込みカーブが利用可能です。

```typescript
AnimatedContainer({
  duration: 300,
  curve: Curves.easeInOut, // スムーズな開始と終了
  width: expanded ? 200 : 100
})
```

利用可能なカーブ:
- **Curves.linear**: 一定速度
- **Curves.easeIn**: ゆっくり開始
- **Curves.easeOut**: ゆっくり終了
- **Curves.easeInOut**: ゆっくり開始・終了
- **Curves.bounceIn**: 開始時にバウンス
- **Curves.bounceOut**: 終了時にバウンス
- **Curves.bounceInOut**: 開始・終了時にバウンス
- **Curves.anticipate**: 後方に下がってから前進
- **Curves.backIn**: 引き戻してから開始
- **Curves.backOut**: 目標を越えてから戻る

### width

**値: number | undefined**

コンテナの幅です。変更時にアニメーションします。

```typescript
AnimatedContainer({
  duration: 200,
  width: isSelected ? 150 : 100,
  height: 50
})
```

### height

**値: number | undefined**

コンテナの高さです。変更時にアニメーションします。

```typescript
AnimatedContainer({
  duration: 200,
  width: 100,
  height: isExpanded ? 200 : 100
})
```

### color

**値: string | undefined**

コンテナの背景色です。decorationと同時に使用できません。

```typescript
AnimatedContainer({
  duration: 300,
  color: isActive ? 'blue' : 'gray',
  child: Text('状態インジケータ')
})
```

### decoration

**値: Decoration | undefined**

子ウィジェットの背景に描画する装飾です。BoxDecorationのすべてのプロパティがアニメーションします。

```typescript
AnimatedContainer({
  duration: 400,
  decoration: BoxDecoration({
    color: isHovered ? 'lightblue' : 'white',
    borderRadius: BorderRadius.circular(isHovered ? 20 : 10),
    boxShadow: isHovered ? [
      BoxShadow({
        color: 'rgba(0, 0, 0, 0.2)',
        blurRadius: 10,
        offset: { x: 0, y: 5 }
      })
    ] : []
  })
})
```

### margin

**値: EdgeInsets | undefined**

コンテナを囲む空白スペースです。変更時にアニメーションします。

```typescript
AnimatedContainer({
  duration: 300,
  margin: EdgeInsets.all(isSelected ? 20 : 10),
  color: 'blue'
})
```

### padding

**値: EdgeInsets | undefined**

コンテナ内部に書き込む空白スペースです。変更時にアニメーションします。

```typescript
AnimatedContainer({
  duration: 300,
  padding: EdgeInsets.all(isExpanded ? 20 : 10),
  child: Text('コンテンツ')
})
```

### alignment

**値: Alignment | undefined**

コンテナ内で子ウィジェットを配置します。変更時にアニメーションします。

```typescript
AnimatedContainer({
  duration: 500,
  alignment: isLeft ? Alignment.centerLeft : Alignment.centerRight,
  child: Icon({ icon: Icons.star })
})
```

### constraints

**値: Constraints | undefined**

子ウィジェットに適用する追加の制約です。最小・最大サイズがアニメーションします。

```typescript
AnimatedContainer({
  duration: 300,
  constraints: Constraints({
    minWidth: 100,
    maxWidth: isExpanded ? 300 : 150,
    minHeight: 50,
    maxHeight: isExpanded ? 200 : 100
  })
})
```

### clipped

**値: boolean** （デフォルト: **false**）

子ウィジェットをコンテナの境界にクリップするかどうかです。

```typescript
AnimatedContainer({
  duration: 300,
  clipped: true,
  width: 100,
  height: 100,
  child: Image({ src: 'large-image.jpg' })
})
```

### transform

**値: Matrix4 | undefined**

適用する変換マトリックスです。回転、スケール、平移がアニメーションします。

```typescript
AnimatedContainer({
  duration: 600,
  transform: isRotated 
    ? Matrix4.rotationZ(Math.PI / 4) // 45度回転
    : Matrix4.identity(),
  child: Icon({ icon: Icons.refresh })
})
```

### transformAlignment

**値: Alignment | undefined**

変換の原点の配置です。transformと組み合わせて使用します。

```typescript
AnimatedContainer({
  duration: 500,
  transform: Matrix4.rotationZ(angle),
  transformAlignment: Alignment.center, // 中心を軸に回転
  child: Text('回転中')
})
```

### child

**値: Widget | undefined**

子ウィジェットです。これはアニメーションされません。

```typescript
AnimatedContainer({
  duration: 300,
  width: 100,
  height: 100,
  child: Icon({ icon: Icons.favorite })
})
```

### onEnd

**値: () => void | undefined**

アニメーションが完了した時に呼び出されるコールバックです。

```typescript
AnimatedContainer({
  duration: 500,
  width: expanded ? 200 : 100,
  onEnd: () => {
    console.log('アニメーション完了');
    // 次のアニメーションや状態変更をトリガー
  }
})
```

## 一般的な使用例

### 状態ベースのUI変更

AnimatedContainerは異なるUI状態間のスムーズな遷移に優れています：

```typescript
// テーマ切り替え
AnimatedContainer({
  duration: 300,
  decoration: BoxDecoration({
    color: isDarkMode ? '#212121' : '#FFFFFF',
    borderRadius: BorderRadius.circular(8)
  }),
  child: content
})

// 選択状態
AnimatedContainer({
  duration: 200,
  decoration: BoxDecoration({
    border: Border.all({
      color: isSelected ? 'blue' : 'transparent',
      width: isSelected ? 2 : 0
    })
  })
})

// ローディング状態
AnimatedContainer({
  duration: 400,
  height: isLoading ? 200 : 0,
  opacity: isLoading ? 1 : 0,
  child: LoadingIndicator()
})
```

### インタラクティブなコンポーネント

スムーズな遷移で魅力的なインタラクティブ要素を作成します：

```typescript
// 展開可能なカード
AnimatedContainer({
  duration: 300,
  height: isExpanded ? null : 100,
  child: content
})

// ホバー効果
AnimatedContainer({
  duration: 200,
  transform: Matrix4.identity()
    .scaled(isHovered ? 1.05 : 1.0),
  boxShadow: isHovered ? elevatedShadow : flatShadow
})

// プレスフィードバック
AnimatedContainer({
  duration: 100,
  transform: Matrix4.identity()
    .scaled(isPressed ? 0.95 : 1.0)
})
```

### Example 5: Loading Skeleton

```typescript
class LoadingSkeleton extends StatefulWidget {
  createState() {
    return new LoadingSkeletonState();
  }
}

class LoadingSkeletonState extends State<LoadingSkeleton> {
  animationPhase = 0;
  Timer? timer;

  initState() {
    super.initState();
    this.timer = Timer.periodic(Duration({ milliseconds: 800 }), () => {
      this.setState(() => {
        this.animationPhase = (this.animationPhase + 1) % 3;
      });
    });
  }

  dispose() {
    this.timer?.cancel();
    super.dispose();
  }

  build() {
    return AnimatedContainer({
      duration: 800,
      curve: Curves.easeInOut,
      width: 300,
      height: 100,
      decoration: BoxDecoration({
        gradient: LinearGradient({
          colors: ['#E0E0E0', '#F5F5F5', '#E0E0E0'],
          stops: [0, 0.5, 1],
          begin: Alignment.centerLeft.add(Alignment(-1 + this.animationPhase * 0.5, 0)),
          end: Alignment.centerRight.add(Alignment(-1 + this.animationPhase * 0.5, 0))
        }),
        borderRadius: BorderRadius.circular(8)
      })
    });
  }
}
```

      height: 600,

            duration: 600,

                duration: 400,

                  icon: step.icon,

                    children: [

                              duration: 300,
                              width: index === this.currentStep ? 24 : 8,
                              height: 8,

                                color: index === this.currentStep ? step.color : '#E0E0E0',

                              }),
                            }),
                          });
                        }),
                      }),
                      
                      SizedBox({ height: 24 }),
                      
                      // Navigation buttons

                        children: [

                            opacity: this.currentStep > 0 ? 1 : 0,

                                  this.setState(() => {
                                    this.currentStep--;
                                  });
                                }
                              },
                              child: Text('Previous'),
                            }),
                          }),

class ResponsiveGridItem extends StatefulWidget {
  item: { id: string; title: string; color: string; icon: any };
  
  constructor({ item }: { item: any }) {
    super();
    this.item = item;
  }
  
  createState() {
    return new ResponsiveGridItemState();
  }
}

class ResponsiveGridItemState extends State<ResponsiveGridItem> {
  isPressed = false;
  isHovered = false;
  
  build() {
    return GestureDetector({
      onTapDown: () => this.setState(() => { this.isPressed = true; }),
      onTapUp: () => this.setState(() => { this.isPressed = false; }),
      onTapCancel: () => this.setState(() => { this.isPressed = false; }),
      onMouseEnter: () => this.setState(() => { this.isHovered = true; }),
      onMouseLeave: () => this.setState(() => { this.isHovered = false; }),
      
      child: AnimatedContainer({
        duration: 200,
        curve: Curves.easeOut,
        margin: EdgeInsets.all(this.isPressed ? 12 : 8),
        transform: Matrix4.identity()
          .scaled(this.isPressed ? 0.95 : (this.isHovered ? 1.05 : 1.0)),
        transformAlignment: Alignment.center,
        decoration: BoxDecoration({
          color: this.widget.item.color,
          borderRadius: BorderRadius.circular(this.isHovered ? 20 : 12),
          boxShadow: [
            BoxShadow({
              color: this.isPressed 
                ? 'rgba(0,0,0,0.1)' 
                : (this.isHovered ? 'rgba(0,0,0,0.3)' : 'rgba(0,0,0,0.15)'),
              blurRadius: this.isPressed ? 5 : (this.isHovered ? 20 : 10),
              offset: Offset({ 
                x: 0, 
                y: this.isPressed ? 2 : (this.isHovered ? 8 : 4) 
              }),
            }),
          ],
        }),
        child: Stack({
          children: [
            // Background pattern
            Positioned({
              right: -20,
              bottom: -20,
              child: AnimatedContainer({
                duration: 400,
                curve: Curves.easeOut,
                width: 100,
                height: 100,
                transform: Matrix4.identity()
                  .rotateZ(this.isHovered ? Math.PI / 6 : 0),
                transformAlignment: Alignment.center,
                decoration: BoxDecoration({
                  color: 'rgba(255,255,255,0.1)',
                  borderRadius: BorderRadius.circular(20),
                }),
              }),
            }),
            
            // Content
            Padding({
              padding: EdgeInsets.all(20),
              child: Column({
                crossAxisAlignment: CrossAxisAlignment.start,
                children: [
                  AnimatedContainer({
                    duration: 300,
                    padding: EdgeInsets.all(this.isHovered ? 12 : 8),
                    decoration: BoxDecoration({
                      color: 'rgba(255,255,255,0.2)',
                      borderRadius: BorderRadius.circular(this.isHovered ? 16 : 12),
                    }),
                    child: Icon({
                      icon: this.widget.item.icon,
                      size: 32,
                      color: 'white',
                    }),
                  }),
                  
                  Spacer(),
                  
                  AnimatedContainer({
                    duration: 200,
                    transform: Matrix4.identity()
                      .translate(this.isHovered ? -4 : 0, 0),
                    child: Text(this.widget.item.title, {
                      style: TextStyle({
                        color: 'white',
                        fontSize: 18,
                        fontWeight: 'bold',
                      }),
                    }),
                  }),
                  
                  AnimatedContainer({
                    duration: 300,
                    height: this.isHovered ? 20 : 0,
                    child: this.isHovered ? Text('Learn more →', {
                      style: TextStyle({
                        color: 'rgba(255,255,255,0.8)',
                        fontSize: 14,
                      }),
                    }) : null,
                  }),
                ],
              }),
            }),
          ],
        }),
      }),
    });
  }
}

## Performance Best Practices

### 1. Optimize Animated Properties

Avoid animating too many properties simultaneously:

```typescript
// ❌ Bad: Animating many properties at once
AnimatedContainer({
  duration: 300,
  width: isExpanded ? 300 : 100,
  height: isExpanded ? 300 : 100,
  margin: EdgeInsets.all(isExpanded ? 20 : 10),
  padding: EdgeInsets.all(isExpanded ? 30 : 15),
  decoration: BoxDecoration({
    color: isExpanded ? 'blue' : 'red',
    borderRadius: BorderRadius.circular(isExpanded ? 20 : 10),
    boxShadow: isExpanded ? [...largeShadows] : [...smallShadows]
  }),
  transform: Matrix4.rotationZ(isExpanded ? Math.PI : 0)
})

// ✅ Good: Animate only necessary properties
AnimatedContainer({
  duration: 300,
  width: isExpanded ? 300 : 100,
  height: isExpanded ? 300 : 100,
  decoration: BoxDecoration({
    color: isExpanded ? 'blue' : 'red',
    borderRadius: BorderRadius.circular(10)
  })
})
```

### 2. Use Appropriate Curves

Choose curves that match your animation intent:

```typescript
// Quick interactions
AnimatedContainer({
  duration: 200,
  curve: Curves.easeOut,  // Fast start, smooth end
  ...
})

// Smooth transitions
AnimatedContainer({
  duration: 400,
  curve: Curves.easeInOut,  // Smooth start and end
  ...
})

// Playful animations
AnimatedContainer({
  duration: 600,
  curve: Curves.bounceOut,  // Bounce effect
  ...
})
```

### 3. Avoid Frequent State Changes

Debounce rapid state changes to prevent animation interruptions:

```typescript
class DebouncedAnimation extends StatefulWidget {
  createState() => new DebouncedAnimationState();
}

class DebouncedAnimationState extends State<DebouncedAnimation> {
  Timer? debounceTimer;
  bool isExpanded = false;

  handleChange(bool value) {
    this.debounceTimer?.cancel();
    this.debounceTimer = Timer(Duration({ milliseconds: 100 }), () => {
      this.setState(() => {
        this.isExpanded = value;
      });
    });
  }

  build() {
    return AnimatedContainer({
      duration: 300,
      width: this.isExpanded ? 200 : 100,
      height: 100,
      color: this.isExpanded ? 'blue' : 'gray'
    });
  }
}
```

### 4. Consider Using AnimatedBuilder for Complex Animations

For complex animations that require more control:

```typescript
class ComplexAnimation extends StatefulWidget {
  createState() => new ComplexAnimationState();
}

class ComplexAnimationState extends State<ComplexAnimation> 
    with SingleTickerProviderStateMixin {
  late AnimationController controller;
  late Animation<double> scaleAnimation;
  late Animation<double> rotationAnimation;

  initState() {
    super.initState();
    this.controller = AnimationController({
      duration: Duration({ seconds: 2 }),
      vsync: this
    });
    
    this.scaleAnimation = Tween<double>({
      begin: 1.0,
      end: 1.5
    }).animate(CurvedAnimation({
      parent: this.controller,
      curve: Curves.easeInOut
    }));
    
    this.rotationAnimation = Tween<double>({
      begin: 0,
      end: 2 * Math.PI
    }).animate(this.controller);
  }

  build() {
    return AnimatedBuilder({
      animation: this.controller,
      builder: (context, child) => {
        return Transform.scale({
          scale: this.scaleAnimation.value,
          child: Transform.rotate({
            angle: this.rotationAnimation.value,
            child: Container({
              width: 100,
              height: 100,
              color: 'blue'
            })
          })
        });
      }
    });
  }
}
```

## 重要な注意事項

- durationは必須プロパティです。アニメーション継続時間を指定する必要があります。
- colorとdecorationは同時に使用できません。
- 子ウィジェットはアニメーションされません。子ウィジェットをアニメーションするには別のAnimatedWidgetを使用してください。
- 同時に多くのプロパティをアニメーションするとパフォーマンスに影響する可能性があります。
- 状態が急速に変化する場合、現在のアニメーションが中断され、新しいアニメーションが開始されます。
- transformはレイアウトサイズを変更しません。スペースを占有する必要があるアニメーションにはwidth/heightを使用してください。
- 複雑なdecorationアニメーションはパフォーマンスに影響する可能性があるため、慎重に使用してください。

## トラブルシューティング

### アニメーションがスムーズでない場合

アニメーションがカクカクして見える場合：

```typescript
// ❌ 問題: 継続時間が短すぎる
AnimatedContainer({
  duration: 50,  // 速すぎる
  width: expanded ? 300 : 100
})

// ✅ 解決策: 適切な継続時間を使用
AnimatedContainer({
  duration: 300,  // スムーズな遷移
  width: expanded ? 300 : 100
})
```

### アニメーションがトリガーされない場合

状態変更が適切に管理されていることを確認してください：

```typescript
// ❌ 問題: 直接変更
class MyWidget extends StatefulWidget {
  createState() => new MyWidgetState();
}

class MyWidgetState extends State<MyWidget> {
  expanded = false;
  
  build() {
    // 間違い: setStateを使わない直接変更
    this.expanded = true;  // 再レンダーされない
  }
}

// ✅ 解決策: setStateを使用
class MyWidget extends StatefulWidget {
  createState() => new MyWidgetState();
}

class MyWidgetState extends State<MyWidget> {
  expanded = false;
  
  build() {
    return GestureDetector({
      onTap: () => {
        this.setState(() => {
          this.expanded = true;  // 再レンダーをトリガー
        });
      },
      child: AnimatedContainer({
        duration: 300,
        width: this.expanded ? 200 : 100,
        // ...
      })
    });
  }
}
```

### プロパティの競合

プロパティの競合に注意してください：

```typescript
// ❌ 問題: colorとdecorationの競合
AnimatedContainer({
  color: 'blue',
  decoration: BoxDecoration({ color: 'red' })  // エラー！
})

// ✅ 解決策: decorationのみ使用
AnimatedContainer({
  decoration: BoxDecoration({ color: 'blue' })
})
```
