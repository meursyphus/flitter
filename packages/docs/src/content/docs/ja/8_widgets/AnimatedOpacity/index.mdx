## 概要

AnimatedOpacityは、子ウィジェットの不透明度が変更された際に自動的にアニメーションし、スムーズな遷移を提供するウィジェットです。このウィジェットはFlutterのAnimatedOpacityウィジェットにインスパイアされています。

> 不透明度が変更された際に、指定された継続時間で子ウィジェットの不透明度を自動的に遷移させるOpacityのアニメーション版です。

## いつ使うか？

- フェードイン・フェードアウト効果でウィジェットを表示・非表示したい場合
- ユーザーの操作に基づいてウィジェットの可視性をスムーズに調整したい場合
- ローディング状態を示すためにコンテンツを暗くしたい場合
- ツールチップやヒントメッセージをスムーズに表示・非表示したい場合
- スクリーン遷移時に自然なフェード効果を提供したい場合

## 基本的な使用方法

```typescript
import { AnimatedOpacity, Container, StatefulWidget } from '@flitter/core';

class OpacityExample extends StatefulWidget {
  createState() {
    return new OpacityExampleState();
  }
}

class OpacityExampleState extends State<OpacityExample> {
  isVisible = true;

  build() {
    return Column({
      children: [
        ElevatedButton({
          onPressed: () => {
            this.setState(() => {
              this.isVisible = !this.isVisible;
            });
          },
          child: Text(this.isVisible ? "非表示" : "表示"),
        }),
        AnimatedOpacity({
          opacity: this.isVisible ? 1.0 : 0.0,
          duration: 500, // 0.5秒
          child: Container({
            width: 200,
            height: 200,
            color: "blue",
            child: Center({
              child: Text("フェード効果", { style: TextStyle({ color: "white" }) }),
            }),
          }),
        }),
      ],
    });
  }
}
```

## プロパティ

### opacity （必須）
**値: number**

ウィジェットの不透明度を設定します。
- 0.0 = 完全に透明（非表示）
- 1.0 = 完全に不透明（完全表示）
- 0.0と1.0の間の値で部分的な透明性

### duration （必須）
**値: number**

アニメーションの継続時間をミリ秒で指定します。

### curve （オプション）
**値: Curve** （デフォルト: **Curves.linear**）

アニメーションの進行カーブを指定します。利用可能なカーブ：
- `Curves.linear`: 一定速度
- `Curves.easeIn`: ゆっくり開始
- `Curves.easeOut`: ゆっくり終了
- `Curves.easeInOut`: ゆっくり開始・終了
- `Curves.circIn`: 円形加速開始
- `Curves.circOut`: 円形減速終了
- `Curves.circInOut`: 円形加速・減速
- `Curves.backIn`: 戻ってから開始
- `Curves.backOut`: 目標を越えてから戻る
- `Curves.backInOut`: backIn + backOut
- `Curves.anticipate`: 進む前の予備動作
- `Curves.bounceIn`: 開始時にバウンス
- `Curves.bounceOut`: 終了時にバウンス
- `Curves.bounceInOut`: 開始・終了時にバウンス

### child （オプション）
**値: Widget | undefined**

不透明度が調整される子ウィジェットです。

### key （オプション）
**値: any**

ウィジェットの一意な識別子です。

## 実用的な例

### 例1: ローディング状態表示

```typescript
import { AnimatedOpacity, CircularProgressIndicator, Container, Curves } from '@flitter/core';

class LoadingOverlay extends StatefulWidget {
  createState() {
    return new LoadingOverlayState();
  }
}

class LoadingOverlayState extends State<LoadingOverlay> {
  isLoading = false;

  async loadData() {
    this.setState(() => {
      this.isLoading = true;
    });

    // データ読み込みをシミュレート
    await new Promise(resolve => setTimeout(resolve, 3000));

    this.setState(() => {
      this.isLoading = false;
    });
  }

  build() {
    return Stack({
      children: [
        // メインコンテンツ
        Container({
          width: double.infinity,
          height: double.infinity,
          child: Center({
            child: ElevatedButton({
              onPressed: () => this.loadData(),
              child: Text("データ読み込み"),
            }),
          }),
        }),
        
        // ローディングオーバーレイ
        AnimatedOpacity({
          opacity: this.isLoading ? 1.0 : 0.0,
          duration: 300,
          curve: Curves.easeInOut,
          child: Container({
            width: double.infinity,
            height: double.infinity,
            color: "rgba(0, 0, 0, 0.7)",
            child: Center({
              child: Column({
                mainAxisAlignment: MainAxisAlignment.center,
                children: [
                  CircularProgressIndicator({
                    color: "white",
                  }),
                  SizedBox({ height: 16 }),
                  Text(
                    "読み込み中...",
                    { style: TextStyle({ color: "white", fontSize: 18 }) }
                  ),
                ],
              }),
            }),
          }),
        }),
      ],
    });
  }
}
```

### 例2: ツールチップメッセージ

```typescript
import { AnimatedOpacity, Container, Tooltip, Curves } from '@flitter/core';

class TooltipExample extends StatefulWidget {
  createState() {
    return new TooltipExampleState();
  }
}

class TooltipExampleState extends State<TooltipExample> {
  showTooltip = false;

  build() {
    return Container({
      padding: EdgeInsets.all(20),
      child: Column({
        children: [
          // ホバーエリア
          MouseRegion({
            onEnter: () => {
              this.setState(() => {
                this.showTooltip = true;
              });
            },
            onExit: () => {
              this.setState(() => {
                this.showTooltip = false;
              });
            },
            child: Container({
              padding: EdgeInsets.symmetric({ horizontal: 16, vertical: 8 }),
              decoration: BoxDecoration({
                color: "blue",
                borderRadius: BorderRadius.circular(8),
              }),
              child: Text(
                "ホバーしてください",
                { style: TextStyle({ color: "white" }) }
              ),
            }),
          }),
          
          SizedBox({ height: 8 }),
          
          // ツールチップメッセージ
          AnimatedOpacity({
            opacity: this.showTooltip ? 1.0 : 0.0,
            duration: 200,
            curve: Curves.easeOut,
            child: Container({
              padding: EdgeInsets.all(12),
              decoration: BoxDecoration({
                color: "rgba(0, 0, 0, 0.8)",
                borderRadius: BorderRadius.circular(4),
              }),
              child: Text(
                "これはツールチップメッセージです！",
                { style: TextStyle({ color: "white", fontSize: 14 }) }
              ),
            }),
          }),
        ],
      }),
    });
  }
}
```

### 例3: 連続フェードイン効果

```typescript
import { AnimatedOpacity, Container, Curves } from '@flitter/core';

class SequentialFadeIn extends StatefulWidget {
  createState() {
    return new SequentialFadeInState();
  }
}

class SequentialFadeInState extends State<SequentialFadeIn> {
  item1Visible = false;
  item2Visible = false;
  item3Visible = false;

  initState() {
    super.initState();
    
    // 連続フェードイン
    setTimeout(() => {
      this.setState(() => this.item1Visible = true);
    }, 500);
    
    setTimeout(() => {
      this.setState(() => this.item2Visible = true);
    }, 1000);
    
    setTimeout(() => {
      this.setState(() => this.item3Visible = true);
    }, 1500);
  }

  build() {
    return Container({
      padding: EdgeInsets.all(20),
      child: Column({
        mainAxisAlignment: MainAxisAlignment.center,
        children: [
          AnimatedOpacity({
            opacity: this.item1Visible ? 1.0 : 0.0,
            duration: 600,
            curve: Curves.easeOut,
            child: Container({
              width: 300,
              padding: EdgeInsets.all(16),
              margin: EdgeInsets.only({ bottom: 16 }),
              decoration: BoxDecoration({
                color: "#FF6B6B",
                borderRadius: BorderRadius.circular(8),
              }),
              child: Text(
                "最初のアイテム",
                { style: TextStyle({ color: "white", fontSize: 18 }) }
              ),
            }),
          }),
          
          AnimatedOpacity({
            opacity: this.item2Visible ? 1.0 : 0.0,
            duration: 600,
            curve: Curves.easeOut,
            child: Container({
              width: 300,
              padding: EdgeInsets.all(16),
              margin: EdgeInsets.only({ bottom: 16 }),
              decoration: BoxDecoration({
                color: "#4ECDC4",
                borderRadius: BorderRadius.circular(8),
              }),
              child: Text(
                "二番目のアイテム",
                { style: TextStyle({ color: "white", fontSize: 18 }) }
              ),
            }),
          }),
          
          AnimatedOpacity({
            opacity: this.item3Visible ? 1.0 : 0.0,
            duration: 600,
            curve: Curves.easeOut,
            child: Container({
              width: 300,
              padding: EdgeInsets.all(16),
              decoration: BoxDecoration({
                color: "#45B7D1",
                borderRadius: BorderRadius.circular(8),
              }),
              child: Text(
                "三番目のアイテム",
                { style: TextStyle({ color: "white", fontSize: 18 }) }
              ),
            }),
          }),
        ],
      }),
    });
  }
}
```

### 例4: クロスフェード遷移

```typescript
import { AnimatedOpacity, Container, Curves } from '@flitter/core';

class CrossFadeExample extends StatefulWidget {
  createState() {
    return new CrossFadeExampleState();
  }
}

class CrossFadeExampleState extends State<CrossFadeExample> {
  showFirst = true;

  build() {
    return GestureDetector({
      onTap: () => {
        this.setState(() => {
          this.showFirst = !this.showFirst;
        });
      },
      child: Container({
        width: 300,
        height: 300,
        child: Stack({
          children: [
            // 最初の画像
            AnimatedOpacity({
              opacity: this.showFirst ? 1.0 : 0.0,
              duration: 500,
              curve: Curves.easeInOut,
              child: Container({
                width: double.infinity,
                height: double.infinity,
                decoration: BoxDecoration({
                  gradient: LinearGradient({
                    colors: ["#667eea", "#764ba2"],
                    begin: Alignment.topLeft,
                    end: Alignment.bottomRight,
                  }),
                  borderRadius: BorderRadius.circular(16),
                }),
                child: Center({
                  child: Icon({
                    icon: Icons.sunny,
                    size: 80,
                    color: "white",
                  }),
                }),
              }),
            }),
            
            // 二番目の画像
            AnimatedOpacity({
              opacity: this.showFirst ? 0.0 : 1.0,
              duration: 500,
              curve: Curves.easeInOut,
              child: Container({
                width: double.infinity,
                height: double.infinity,
                decoration: BoxDecoration({
                  gradient: LinearGradient({
                    colors: ["#f093fb", "#f5576c"],
                    begin: Alignment.topLeft,
                    end: Alignment.bottomRight,
                  }),
                  borderRadius: BorderRadius.circular(16),
                }),
                child: Center({
                  child: Icon({
                    icon: Icons.nightlight,
                    size: 80,
                    color: "white",
                  }),
                }),
              }),
            }),
          ],
        }),
      }),
    });
  }
}
```

## 注意事項

- 不透明度の値は0.0と1.0の間である必要があります
- 不透明度が0.0であっても、ウィジェットはレイアウトスペースを占有したままです
- 完全に非表示にしてスペースを除去するには、条件付きレンダリングを使用してください
- パフォーマンスのため、同時に多くのウィジェットに不透明度アニメーションを適用することは避けてください
- アニメーション中に新しい不透明度値が設定された場合、現在の値から新しい値へスムーズに遷移します

## 関連ウィジェット

- **Opacity**: アニメーションなしで不透明度を設定する基本ウィジェット
- **AnimatedContainer**: 複数のプロパティを同時にアニメーション
- **FadeTransition**: 明示的なAnimationオブジェクトを使用したフェード効果
- **Visibility**: ウィジェットの可視性を制御し、レイアウトスペースを管理
