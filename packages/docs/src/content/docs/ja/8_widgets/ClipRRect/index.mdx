## 概要

ClipRRectは、角丸矩形を使用して子要素をクリップするウィジェットです。

デフォルトでは、ClipRRectは自身の境界をクリップの基準矩形として使用しますが、カスタムクリッパーを使用してクリップのサイズと位置をカスタマイズできます。borderRadiusプロパティにより、各角の丸みを個別に設定できます。

## 使用場面

- 画像やコンテナに角丸を適用したい場合
- スムーズな角丸効果を持つカードUIやボタンを作成する場合
- オーバーフローするコンテンツを角丸でクリップする必要がある場合
- 各角に異なる半径を設定したい場合
- プロフィール画像やサムネイルに角丸効果を適用する場合

## 基本的な使用方法

```typescript
// Same radius for all corners
ClipRRect({
  borderRadius: BorderRadius.circular(16),
  child: Image({
    src: 'https://example.com/image.jpg',
    width: 200,
    height: 200,
    objectFit: 'cover'
  })
})

// Rounded specific corners only
ClipRRect({
  borderRadius: BorderRadius.only({
    topLeft: Radius.circular(20),
    topRight: Radius.circular(20),
    bottomLeft: Radius.zero,
    bottomRight: Radius.zero
  }),
  child: Container({
    width: 300,
    height: 200,
    color: 'blue'
  })
})

// Elliptical corners
ClipRRect({
  borderRadius: BorderRadius.all(Radius.elliptical(40, 20)),
  child: Container({
    width: 150,
    height: 100,
    color: 'green'
  })
})
```

## プロパティの詳細

### borderRadius

**型: BorderRadius**（デフォルト: **BorderRadius.zero**）

各角の丸みを定義します。BorderRadiusクラスは様々なファクトリーメソッドを提供します：

- `BorderRadius.circular(radius)`: Apply the same circular radius to all corners
- `BorderRadius.all(Radius)`: Apply the same Radius to all corners
- `BorderRadius.only({topLeft?, topRight?, bottomLeft?, bottomRight?})`: Set each corner individually
- `BorderRadius.vertical({top?, bottom?})`: Set top and bottom corners
- `BorderRadius.horizontal({left?, right?})`: Set left and right corners

```typescript
// Circular radius
ClipRRect({
  borderRadius: BorderRadius.circular(20),
  child: child
})

// Elliptical radius
ClipRRect({
  borderRadius: BorderRadius.all(Radius.elliptical(30, 15)),
  child: child
})

// Individual corner settings
ClipRRect({
  borderRadius: BorderRadius.only({
    topLeft: Radius.circular(30),
    topRight: Radius.circular(10),
    bottomLeft: Radius.circular(5),
    bottomRight: Radius.circular(20)
  }),
  child: child
})
```

### clipper

**型: (size: Size) => RRect**（オプション）

カスタムクリッピング領域を定義するコールバック関数。ウィジェットのサイズを受け取り、RRect（角丸矩形）オブジェクトを返す必要があります。

```typescript
ClipRRect({
  clipper: (size) => {
    // Clip to a smaller rounded rectangle in the center
    return RRect.fromRectAndRadius({
      rect: Rect.fromCenter({
        center: { x: size.width / 2, y: size.height / 2 },
        width: size.width * 0.8,
        height: size.height * 0.8
      }),
      radius: Radius.circular(10)
    });
  },
  child: child
})
```

### clipped

**型: boolean**（デフォルト: **true**）

クリッピング効果を有効または無効にします。

- `true`: クリッピングを適用
- `false`: クリッピングを無効化（子ウィジェットは通常通り表示）

```typescript
ClipRRect({
  clipped: isClippingEnabled,
  borderRadius: BorderRadius.circular(16),
  child: content
})
```

### child

**型: Widget**

クリップされる子ウィジェット。

### 例5: 画像ギャラリーサムネイル

```typescript
const GalleryThumbnail = ({ images, title }) => {
  const gridSize = Math.ceil(Math.sqrt(images.length));
  
  return Column({
    children: [
      ClipRRect({
        borderRadius: BorderRadius.circular(12),
        child: Container({
          width: 200,
          height: 200,
          color: '#f0f0f0',

            ? Image({
                src: images[0],
                width: 200,
                height: 200,
                objectFit: 'cover'
              })
            : Grid({
                crossAxisCount: gridSize,
                gap: 2,
                children: images.slice(0, gridSize * gridSize).map((img, index) => 
                  ClipRRect({
                    borderRadius: BorderRadius.circular(
                      index === 0 ? 12 : 0
                    ),
                    child: Image({
                      src: img,
                      width: 200 / gridSize - 2,
                      height: 200 / gridSize - 2,
                      objectFit: 'cover'
                    })
                  })
                )
              })
        })
      }),
      SizedBox({ height: 8 }),
      Container({
        width: 200,
        child: Row({
          children: [
            Expanded({
              child: Text(title, {
                style: TextStyle({
                  fontSize: 14,
                  fontWeight: 'bold'
                }),
                overflow: TextOverflow.ellipsis
              })
            }),
            if (images.length > gridSize * gridSize)
              Container({
                padding: EdgeInsets.symmetric({ horizontal: 8, vertical: 2 }),
                decoration: BoxDecoration({
                  color: 'rgba(0,0,0,0.6)',
                  borderRadius: BorderRadius.circular(12)
                }),
                child: Text(`+${images.length - gridSize * gridSize}`, {
                  style: TextStyle({
                    color: 'white',
                    fontSize: 12
                  })
                })
              })
          ]
        })
      })
    ]
  });
};
```

## RRect APIの理解

### RRect作成メソッド

```typescript
// Basic constructors
RRect.fromLTRBR({
  left: 0,
  top: 0,
  right: 100,
  bottom: 100,
  radius: Radius.circular(10)
});

RRect.fromRectAndRadius({
  rect: Rect.fromLTWH({ left: 0, top: 0, width: 100, height: 100 }),
  radius: Radius.circular(10)
});

RRect.fromRectAndCorners({
  rect: rect,
  topLeft: Radius.circular(10),
  topRight: Radius.circular(20),
  bottomLeft: Radius.circular(5),
  bottomRight: Radius.circular(15)
});

// Inflate/Deflate
const inflatedRRect = rrect.inflate(10);  // Expand by 10 pixels
const deflatedRRect = rrect.deflate(5);   // Shrink by 5 pixels
```

## 重要な注意事項

- クリッピングはレンダリングパフォーマンスに影響する可能性があるため、必要な場合のみ使用してください
- borderRadius値がウィジェットサイズより大きい場合、予期しない結果が生じる可能性があります
- クリップされた領域外のタッチイベントは検出されません
- 複雑なレイアウトでContainerのdecorationとClipRRectを併用する際は注意してください
- 画像読み込み中はプレースホルダーを使用してレイアウトシフトを防いでください

## 関連ウィジェット

- **ClipRect**: 矩形でクリップ
- **ClipOval**: 楕円形でクリップ
- **ClipPath**: カスタムパスでクリップ
- **Container**: decorationプロパティで角丸を実装可能
- **Card**: デフォルトで角丸を持つマテリアルデザインカード
