## 概要

`RichText`は、複数の異なるスタイルを使用してテキストを表示するウィジェットです。FlutterのRichTextにインスパイアされており、TextSpanオブジェクトのツリーを使用してテキストを記述し、各スパンはそのサブツリーに関連付けられたスタイルを持っています。

RichTextのすべてのテキストは明示的にスタイルを設定する必要があります。Textウィジェットは単一スタイルのテキストにはよりシンプルですが、複雑なテキストフォーマット、ハイライト、リンク、または単一のテキストブロック内での混合スタイルが必要な場合にはRichTextが不可欠です。

## 使用する場面

- 単一のテキスト内で複数の異なるスタイルが必要な場合
- テキストの一部をハイライトや強調する必要がある場合
- リンクやクリック可能なテキスト領域を作成する場合
- 複雑なテキストフォーマット（太字、斜体、色）が必要な場合
- 段落内で様々なフォントやサイズを混合する必要がある場合

## Basic Usage

```typescript
import { RichText, TextSpan, TextStyle } from 'flitter';

// 基本的なリッチテキスト
const BasicRichText = RichText({
  text: new TextSpan({
    text: 'こんにちは、',
    style: new TextStyle({
      fontSize: 16,
      color: 'black'
    }),
    children: [
      new TextSpan({
        text: '太字テキスト',
        style: new TextStyle({
          fontWeight: 'bold',
          color: '#e74c3c'
        })
      }),
      new TextSpan({
        text: '！'
      })
    ]
  })
});
```

## プロパティ

### text (必須)
**値: InlineSpan**

表示するテキストを記述するInlineSpanオブジェクト（通常はTextSpan）。テキストコンテンツとスタイリングの両方を定義します。

```typescript
text: new TextSpan({
  text: 'メインテキスト',
  style: new TextStyle({ fontSize: 16 }),
  children: [
    new TextSpan({
      text: '子テキスト',
      style: new TextStyle({ fontWeight: 'bold' })
    })
  ]
})
```

### textAlign (オプション)
**値: TextAlign** (デフォルト: **TextAlign.start**)

テキストの配置方法を指定します。

- `TextAlign.start`: テキスト方向に基づく開始位置（デフォルト）
- `TextAlign.end`: テキスト方向に基づく終了位置
- `TextAlign.left`: 左寄せ
- `TextAlign.right`: 右寄せ
- `TextAlign.center`: 中央寄せ

### overflow (オプション)
**値: TextOverflow** (デフォルト: **TextOverflow.clip**)

コンテナからはみ出すテキストの処理方法。

- `TextOverflow.clip`: はみ出しテキストをクリップ
- `TextOverflow.ellipsis`: はみ出しに省略記号（…）を表示
- `TextOverflow.visible`: はみ出しテキストをコンテナ外に表示

### softWrap (オプション)
**値: boolean** (デフォルト: **true**)

スペースがなくなったときにテキストを自動的に折り返すかどうか。

- `true`: 自動的に新しい行に折り返す
- `false`: テキストを単一行に保つ

### maxLines (オプション)
**値: number**

テキストの最大行数を制限します。超過した場合は、オーバーフロー設定が処理を決定します。

### textWidthBasis (オプション)
**値: TextWidthBasis** (デフォルト: **TextWidthBasis.parent**)

テキスト幅の計算方法を決定します。

- `TextWidthBasis.parent`: 親ウィジェットの幅に基づいて計算
- `TextWidthBasis.longestLine`: 最長行の長さに基づいて計算

### textDirection (オプション)
**値: TextDirection**

テキストの方向を指定します。

- `TextDirection.ltr`: 左から右（デフォルト）
- `TextDirection.rtl`: 右から左

### textScaleFactor (オプション)
**値: number**

テキストサイズのスケールファクターを調整します。1.0がデフォルトサイズ、2.0が倍サイズです。

## 実世界の例

### 例1: マルチスタイルテキスト

```typescript
import { RichText, TextSpan, TextStyle } from 'flitter';

const StyledText = RichText({
  text: new TextSpan({
    text: 'This is ',
    style: new TextStyle({
      fontSize: 16,
      color: '#2c3e50'
    }),
    children: [
      new TextSpan({
        text: '赤い ',
        style: new TextStyle({
          color: '#e74c3c',
          fontWeight: 'bold'
        })
      }),
      new TextSpan({
        text: 'そして ',
        style: new TextStyle({
          fontSize: 14,
          fontStyle: 'italic'
        })
      }),
      new TextSpan({
        text: '青い ',
        style: new TextStyle({
          color: '#3498db',
          fontSize: 20
        })
      }),
      new TextSpan({
        text: 'テキスト。',
        style: new TextStyle({
          textDecoration: 'underline'
        })
      })
    ]
  })
});
```

### 例2: クリック可能なリンクテキスト

```typescript
import { RichText, TextSpan, TextStyle, GestureDetector } from 'flitter';

const LinkText = RichText({
  text: new TextSpan({
    text: '詳細情報については、',
    style: new TextStyle({
      fontSize: 16,
      color: 'black'
    }),
    children: [
      new TextSpan({
        text: 'こちらをクリック',

          textDecoration: 'underline',
          fontWeight: 'bold'
        }),
        recognizer: new TapGestureRecognizer({
          onTap: () => {
            console.log('リンクがクリックされました！');
            // リンクロジックを処理
          }
        })
      }),
      new TextSpan({
        text: 'してください。'
      })
    ]
  })
});
```

### 例4: 省略記号でのテキスト切り默め

```typescript
const TruncatedText = RichText({

```

### 例5: 多言語テキスト方向

```typescript
import { RichText, TextSpan, TextStyle } from 'flitter';

const MultiLanguageText = Column({

            style: new TextStyle({

```

### 例6: 動的スタイル変更

```typescript
import { RichText, TextSpan, TextStyle } from 'flitter';

class DynamicRichText extends StatefulWidget {
  createState() {
    return new DynamicRichTextState();
  }
}

class DynamicRichTextState extends State {
  isHighlighted = false;
  
  build() {
    return GestureDetector({
      onTap: () => this.setState(() => {
        this.isHighlighted = !this.isHighlighted;
      }),
      child: RichText({
        text: new TextSpan({
          text: 'クリックして ',
          style: new TextStyle({
            fontSize: 16
          }),
          children: [
            new TextSpan({
              text: 'この部分',
              style: new TextStyle({
                color: this.isHighlighted ? '#e74c3c' : '#3498db',
                fontWeight: this.isHighlighted ? 'bold' : 'normal',
                backgroundColor: this.isHighlighted ? '#f8f9fa' : 'transparent'
              })
            }),
            new TextSpan({
              text: ' を動的に変更します。'
            })
          ]
        })
      })
    });
  }
}
```

## ベストプラクティス

- **明示的スタイリング**: RichTextのすべてのテキストは明示的にスタイルを設定する必要があります
- **パフォーマンス**: 複雑なTextSpanツリーはレンダリングパフォーマンスに影響を与える可能性があります
- **スタイル継承**: 子TextSpanは親のスタイルを継承します（inherit: falseで無効化可能）
- **ジェスチャ認識**: TextSpanにレコグナイザーを追加してタッチイベントを処理します
- **アクセシビリティ**: スクリーンリーダーを考慮し、意味のあるテキスト構造を作成してください

## 関連ウィジェット

- **Text**: 単一スタイルのテキストが必要な場合
- **SelectableText**: 選択可能なテキストが必要な場合
- **TextField**: 編集可能なテキスト入力が必要な場合
- **Container**: テキストの背景やパディングが必要な場合
