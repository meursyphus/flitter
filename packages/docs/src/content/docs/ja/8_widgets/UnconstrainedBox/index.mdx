## 概要

UnconstrainedBoxは、子ウィジェットに制約を課さず、「自然な」サイズでレンダリングできるようにするウィジェットです。

これにより、子ウィジェットは制約のない無限キャンバス上に単独で置かれた場合と同じサイズでレンダリングできます。このコンテナは、独自の制約の範囲内で同じサイズを採用しようとします。異なるサイズになった場合は、alignmentに基づいて子ウィジェットを配置します。ボックスが子ウィジェット全体を収容するのに十分に拡張できない場合、子ウィジェットはクリップされます。

See: [https://api.flutter.dev/flutter/widgets/UnconstrainedBox-class.html](https://api.flutter.dev/flutter/widgets/UnconstrainedBox-class.html)

## 使用する場面

- 子ウィジェットが親の制約に影響されることなく、独自のサイズでレンダリングする必要がある場合
- 特定の軸（水平または垂直）のみ制約を取り除きたい場合
- オーバーフローのデバッグのために一時的に制約を取り除く場合
- 子ウィジェットの実際のサイズを確認する必要がある場合
- 親の厳しい制約を無視して、子ウィジェットに柔軟なサイズを持たせたい場合

## 基本的な使用方法

```typescript
// すべての制約を取り除く
UnconstrainedBox({
  child: Container({
    width: 200,
    height: 100,
    color: 'blue'
  })
})

// 垂直軸のみ制約を取り除く（水平は親に従う）
UnconstrainedBox({
  constrainedAxis: 'horizontal',
  child: Container({
    width: 200,  // 親の幅に従う
    height: 100, // 自由に100に設定
    color: 'green'
  })
})

// 配置と併用
UnconstrainedBox({
  alignment: Alignment.topLeft,
  child: Container({
    width: 50,
    height: 50,
    color: 'red'
  })
})
```

## プロパティ詳細

### constrainedAxis

**値: 'vertical' | 'horizontal' | undefined**

特定の軸のみ制約を維持したい場合に使用します。

- `undefined` (デフォルト): すべての軸の制約を取り除く
- `'vertical'`: 垂直制約を維持し、水平制約のみ取り除く
- `'horizontal'`: 水平制約を維持し、垂直制約のみ取り除く

```typescript
// 垂直制約を維持（水平は自由）
UnconstrainedBox({
  constrainedAxis: 'vertical',
  child: Container({
    width: 300,   // 自由に設定可能
    height: 100,  // 親の垂直制約に従う
    color: 'blue'
  })
})

// 水平制約を維持（垂直は自由）
UnconstrainedBox({
  constrainedAxis: 'horizontal',
  child: Container({
    width: 300,   // 親の水平制約に従う
    height: 100,  // 自由に設定可能
    color: 'green'
  })
})
```

### alignment

**値: Alignment** (デフォルト: **Alignment.center**)

子ウィジェットがUnconstrainedBoxより小さい場合の配置方法を指定します。

```typescript
UnconstrainedBox({
  alignment: Alignment.topRight,
  child: Container({
    width: 50,
    height: 50,
    color: 'purple'
  })
})

UnconstrainedBox({
  alignment: Alignment.bottomCenter,
  child: Text('Bottom Aligned Text')
})
```

### clipped

**値: boolean** (デフォルト: **false**)

子ウィジェットがUnconstrainedBoxの境界をオーバーフローした際にクリップするかどうかを決定します。

- `false`: オーバーフローを許可（デバッグに有用）
- `true`: 境界を超えた部分をクリップ

```typescript
// オーバーフローを許可
UnconstrainedBox({
  clipped: false,
  child: Container({
    width: 500,
    height: 500,
    color: 'red'
  })
})

// オーバーフローをクリップ
UnconstrainedBox({
  clipped: true,
  child: Container({
    width: 500,
    height: 500,
    color: 'blue'
  })
})
```

### child

**値: Widget | undefined**

制約が取り除かれる子ウィジェット。

## 重要な注意事項

- UnconstrainedBoxの過度な使用はレイアウトオーバーフローを引き起こす可能性があります
- プロダクション環境では、オーバーフローを防ぐために`clipped: true`を使用してください
- デバッグ目的の場合は、開発環境でのみ使用してください
- ネストしたUnconstrainedBoxは予期しないレイアウト問題を引き起こす可能性があります
- パフォーマンスが重要な領域では慎重に使用してください

## 関連ウィジェット

- **ConstrainedBox**: 子ウィジェットに追加の制約を課す場合
- **LimitedBox**: 制約がない場合のみサイズ制限を適用する場合
- **OverflowBox**: 親の制約を無視して異なる制約を課す場合
- **SizedBox**: 固定サイズを指定する場合
- **FittedBox**: 子ウィジェットを親に合わせてスケーリングする場合
