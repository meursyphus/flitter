## 概要

ColoredBoxは、単色でボックスを塗りつぶすウィジェットです。

ColoredBoxはContainerのcolorプロパティと同じ効果を提供しますが、より軽量で効率的です。色のみが必要で、Containerの他の機能（パディング、マージン、デコレーションなど）が不要な場合にパフォーマンスの利点を提供します。

## 使用場面

- シンプルな色背景のみが必要な場合
- Containerより軽量なウィジェットが必要な場合
- パフォーマンス最適化が重要な場合
- 色のオーバーレイを作成する場合
- リストアイテムの背景色を指定する場合

## 基本的な使用方法

```typescript
// Solid color background
ColoredBox({
  color: 'blue',
  child: Text('Blue background')
})

// Color with transparency
ColoredBox({
  color: 'rgba(255, 0, 0, 0.5)',
  child: Padding({
    padding: EdgeInsets.all(20),
    child: Text('Semi-transparent red background')
  })
})
```

## プロパティ

### color（必須）

**型: string**

ボックスの背景色。CSSカラー値を使用できます。

```typescript
ColoredBox({
  color: 'red',  // Color name
  child: Text('Red background')
})

ColoredBox({
  color: '#FF5733',  // HEX color
  child: Text('Orange background')
})

ColoredBox({
  color: 'rgba(0, 0, 255, 0.3)',  // RGBA
  child: Text('Semi-transparent blue background')
})
```

### child

**型: Widget | undefined**

色背景の上に表示される子ウィジェット。

```typescript
ColoredBox({
  color: 'lightgray',
  child: Center({
    child: Text('Centered text')
  })
})
```

## Containerとの違い

### ColoredBoxを使用
```typescript
// When only color is needed
ColoredBox({
  color: 'blue',
  child: Text('Text')
})
```

### Containerを使用
```typescript
// When color and other styling are needed
Container({
  color: 'blue',
  padding: EdgeInsets.all(16),
  margin: EdgeInsets.all(8),
  child: Text('Text')
})
```

## 実用的な例

### 例1: ステータスバッジ

```typescript
const StatusBadge = ({ status }) => {
  const getStatusColor = (status) => {
    switch (status) {
      case 'active': return '#4CAF50';
      case 'pending': return '#FF9800';
      case 'inactive': return '#F44336';
      default: return '#9E9E9E';
    }
  };

  return ColoredBox({
    color: getStatusColor(status),
    child: Padding({
      padding: EdgeInsets.symmetric({ horizontal: 12, vertical: 4 }),
      child: Text(status.toUpperCase(), {
        style: TextStyle({
          color: 'white',
          fontSize: 12,
          fontWeight: 'bold'
        })
      })
    })
  });
};
```

## パフォーマンスの考慮事項

ColoredBoxはContainerより軽量です：

1. **メモリ使用量**: Containerよりメモリ使用量が少ない
2. **レンダリングパフォーマンス**: シンプルなレンダリングロジックで高速処理
3. **リストでの有効性**: 多数のアイテムを持つリストで特に効果的

```typescript
// In performance-critical lists
ListView({
  children: items.map(item => 
    ColoredBox({
      color: item.isSelected ? '#E3F2FD' : 'white',
      child: ListTile({ title: item.name })
    })
  )
})
```

## 重要な注意事項

- ColoredBoxは色のみを指定できます。グラデーション、画像、ボーダーなどにはContainerまたはDecoratedBoxを使用してください
- ColoredBoxのサイズは子ウィジェットのサイズによって決まります
- 透明度を持つ色を使用する場合は背景とのブレンドを考慮してください
- SVGレンダリングモードでも正常に動作します

## 関連ウィジェット

- **Container**: より多くのスタイリングオプションが必要な場合
- **DecoratedBox**: 複雑なデコレーションが必要な場合
- **Opacity**: ウィジェット全体の透明度を調整する場合
- **AnimatedContainer**: 色の変化をアニメーションする場合
