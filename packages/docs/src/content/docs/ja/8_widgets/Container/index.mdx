## 概要

Containerは、子要素のために一般的な描画、配置、サイズ設定ウィジェットを結合した便利なウィジェットです。

Containerは、いくつかの基本ウィジェット（Padding、Align、ColoredBox、DecoratedBox、ConstrainedBox、Transformなど）を単一のウィジェットに結合し、一般的なレイアウトとスタイリングタスクを簡素化します。空のContainerは可能な限り多くのスペースを占めようとしますが、子要素を持つ場合は子要素に合わせてサイズを調整します。

## 使用場面

- ウィジェットに背景色、ボーダー、影などのスタイルを適用する場合
- ウィジェットの周りにマージンやパディングを追加する場合
- ウィジェットのサイズを制約または固定する場合
- 複数のレイアウトプロパティを一度に適用する場合
- カードUI、ボタン背景、セクション区切り線などを作成する場合

## 基本的な使用方法

```typescript
// Simplest example
const widget = Container({
  width: 200,
  height: 100,
  color: 'blue',
  child: Text('Hello Container!')
});

// Using padding and margin
const paddedContainer = Container({
  margin: EdgeInsets.all(10),
  padding: EdgeInsets.symmetric({ horizontal: 20, vertical: 10 }),
  color: 'lightgray',
  child: Text('Padded Text')
});
```

## プロパティ

### width

**型: number | undefined**

Containerの幅をピクセル単位で指定します。指定しない場合は、子要素のサイズまたは親の制約によって決まります。

```typescript
Container({ width: 300, color: 'red' })
```

### height

**型: number | undefined**

Containerの高さをピクセル単位で指定します。指定しない場合は、子要素のサイズまたは親の制約によって決まります。

```typescript
Container({ height: 150, color: 'green' })
```

### constraints

**型: Constraints | undefined**

Containerの最小/最大幅と高さを指定します。width/heightよりも柔軟なサイズ制御を提供します。

```typescript
Container({
  constraints: Constraints({
    minWidth: 100,
    maxWidth: 300,
    minHeight: 50,
    maxHeight: 200
  }),
  color: 'orange'
})
```

### padding

**型: EdgeInsets**（デフォルト: **なし**）

Containerの縁と子ウィジェットの間のスペーシング。

```typescript
// Same padding on all sides
Container({
  padding: EdgeInsets.all(16),
  color: 'lightblue',
  child: Text('Padded')
})

// Different padding per side
Container({
  padding: EdgeInsets.only({ top: 20, left: 10, right: 10, bottom: 5 }),
  color: 'pink'
})
```

### margin

**型: EdgeInsets**（デフォルト: **なし**）

Containerとその外側の他のウィジェットとの間のスペーシング。

```typescript
Container({
  margin: EdgeInsets.symmetric({ horizontal: 20, vertical: 10 }),
  color: 'yellow',
  child: Text('Margined')
})
```

### alignment

**型: Alignment | undefined**

Container内の子ウィジェットの配置位置を指定します。xとyの値は-1から1の範囲です。

```typescript
Container({
  width: 200,
  height: 200,
  color: 'gray',
  alignment: Alignment.center,
  child: Text('Centered')
})

// Available alignment constants
// Alignment.topLeft, Alignment.topCenter, Alignment.topRight
// Alignment.centerLeft, Alignment.center, Alignment.centerRight
// Alignment.bottomLeft, Alignment.bottomCenter, Alignment.bottomRight
```

### color

**型: string | undefined**

Containerの背景色を指定します。decorationと同時に使用できません。

⚠️ **警告**: decorationプロパティと一緒に使用するとエラーが発生します。

```typescript
Container({
  width: 100,
  height: 100,
  color: '#FF5733'
})
```

### decoration

**型: Decoration | undefined**

Containerの複雑なスタイリング（ボーダー、角丸、影など）を指定します。

⚠️ **警告**: colorプロパティと一緒に使用できません。代わりにdecoration内で色を指定してください。

```typescript
Container({
  width: 150,
  height: 150,
  decoration: BoxDecoration({
    color: 'white',
    border: Border.all({ color: 'black', width: 2 }),
    borderRadius: BorderRadius.circular(10),
    boxShadow: [
      BoxShadow({
        color: 'rgba(0, 0, 0, 0.3)',
        blurRadius: 10,
        offset: { x: 5, y: 5 }
      })
    ]
  }),
  child: Text('Decorated')
})
```

### clipped

**型: boolean | undefined**（デフォルト: **false**）

decorationの形状に従って子ウィジェットをクリップするかどうかを決定します。

⚠️ **警告**: clippedがtrueの場合、decorationが必要です。

```typescript
Container({
  width: 100,
  height: 100,
  clipped: true,
  decoration: BoxDecoration({
    shape: 'circle',
    color: 'blue'
  }),
  child: Image({ src: 'photo.jpg', fit: 'cover' })
})
```

### transform

**型: Matrix4 | undefined**

Containerに回転、スケール、歪みなどの変換を適用します。

```typescript
Container({
  color: 'purple',
  transform: Matrix4.rotationZ(Math.PI / 4), // 45 degree rotation
  child: Text('Rotated')
})
```

### transformAlignment

**型: Alignment | undefined**

変換の原点を指定します。デフォルトはContainerの中心です。

```typescript
Container({
  width: 100,
  height: 100,
  color: 'green',
  transform: Matrix4.rotationZ(Math.PI / 6),
  transformAlignment: Alignment.topLeft, // Rotate around top-left corner
  child: Text('Transform')
})
```

### child

**型: Widget | undefined**

Container内に表示する子ウィジェット。

```typescript
Container({
  padding: EdgeInsets.all(20),
  color: 'lightgray',
  child: Column({
    children: [
      Text('Title'),
      Text('Subtitle')
    ]
  })
})
```

## 実用的な例

### カードUIの作成

```typescript
const card = Container({
  margin: EdgeInsets.all(16),
  padding: EdgeInsets.all(16),
  decoration: BoxDecoration({
    color: 'white',
    borderRadius: BorderRadius.circular(12),
    boxShadow: [
      BoxShadow({
        color: 'rgba(0, 0, 0, 0.1)',
        blurRadius: 8,
        offset: { x: 0, y: 2 }
      })
    ]
  }),
  child: Column({
    crossAxisAlignment: 'start',
    children: [
      Text('Card Title', { style: TextStyle({ fontSize: 18, fontWeight: 'bold' }) }),
      SizedBox({ height: 8 }),
      Text('Card content goes here...')
    ]
  })
});
```

### 円形アバターの作成

```typescript
const avatar = Container({
  width: 80,
  height: 80,
  clipped: true,
  decoration: BoxDecoration({
    shape: 'circle',
    border: Border.all({ color: 'blue', width: 3 })
  }),
  child: Image({
    src: 'profile.jpg',
    fit: 'cover'
  })
});
```

### ボタンのスタイリング

```typescript
const customButton = GestureDetector({
  onTap: () => console.log('Button tapped'),
  child: Container({
    padding: EdgeInsets.symmetric({ horizontal: 24, vertical: 12 }),
    decoration: BoxDecoration({
      color: 'blue',
      borderRadius: BorderRadius.circular(8)
    }),
    child: Text('Click Me', {
      style: TextStyle({ color: 'white', fontSize: 16 })
    })
  })
});
```

## 重要な注意事項

- `color`と`decoration`を同時に使用することはできません。decorationを使用する場合は、その中で色を指定してください。
- `clipped`をtrueに設定する場合、`decoration`が必要です。
- 子要素を持たずサイズ制約もないContainerは、可能な限り多くのスペースを占めようとします。
- `transform`を使用する場合、変換されたContainerが他のウィジェットと重なる可能性があることに注意してください。
- decorationでボーダーを使用すると自動的にパディングが追加されます。

## 関連ウィジェット

- **DecoratedBox**: デコレーションのみが必要な場合に使用
- **ColoredBox**: 背景色のみが必要な場合に使用
- **Padding**: マージンやパディングのみが必要な場合に使用
- **SizedBox**: 固定サイズのみが必要な場合に使用
- **ConstrainedBox**: サイズ制約のみが必要な場合に使用
- **Align**: 配置のみが必要な場合に使用
