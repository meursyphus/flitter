## 概要

AspectRatioは、子要素を特定のアスペクト比（横幅と高さの比率）でサイズ調整するウィジェットです。子要素を可能な限り大きなサイズで表示しながら、幅と高さの一定の比率を維持します。

## 使用場面

- 画像や動画の元のアスペクト比を維持したい場合
- レスポンシブデザインで一定の比率を持つ要素を作成する場合
- カードやタイルの一貫した外観を維持する場合
- チャートやグラフのアスペクト比を固定する場合
- ロゴやアイコンの比例を保持する場合

## 基本的な使用方法

```typescript
// 16:9の比率
AspectRatio({
  aspectRatio: 16 / 9,
  child: Container({
    color: 'blue',
    child: Center({
      child: Text('16:9')
    })
  })
})

// 正方形（1:1の比率）
AspectRatio({
  aspectRatio: 1.0,
  child: Image({
    src: '/assets/profile.jpg',
    objectFit: 'cover'
  })
})

// 黄金比
AspectRatio({
  aspectRatio: 1.618,
  child: Card({
    child: Center({
      child: Text('Golden Ratio')
    })
  })
})
```

## プロパティ

### aspectRatio（必須）
**型: number**

横幅と高さの比率。0より大きく、有限である必要があります。

一般的なアスペクト比:
- `1.0`: 正方形（1:1）
- `16/9`（〜1.78）: ワイドスクリーン動画
- `4/3`（〜1.33）: 従来のテレビ/モニター
- `3/2`（1.5）: 35mmフィルム
- `1.618`: 黄金比
- `9/16`（〜0.56）: ポートレートモバイル画面

```typescript
// 様々なアスペクト比の例
AspectRatio({
  aspectRatio: 16 / 9,  // ワイドスクリーン
  child: VideoPlayer({ url: 'video.mp4' })
})

AspectRatio({
  aspectRatio: 1.0,  // 正方形
  child: ProfileImage({ src: 'avatar.jpg' })
})

AspectRatio({
  aspectRatio: 3 / 4,  // ポートレート
  child: ProductCard({ product })
})
```

### child（オプション）
**型: Widget | undefined**

アスペクト比が適用される子ウィジェット。子要素がなくても、AspectRatioは指定された比率でスペースを占有します。

## サイズ計算

AspectRatioは以下の順序でサイズを決定します：

1. 制約がタイトの場合、その寸法を使用
2. 最大幅が有限の場合、幅に基づいて高さを計算
3. 幅が無限の場合、最大高さに基づいて幅を計算
4. 計算されたサイズが制約を超える場合は調整
5. 最終的に最小/最大制約内で比率を維持

            })

      })
    })
  });

## 重要な注意事項

- aspectRatioは0より大きく、有限である必要があります
- 親の制約が不十分な場合、望ましい比率を維持できない可能性があります
- 無限制約での子のサイズに基づいてサイズが決定されます
- 固有サイズ計算時にパフォーマンスに影響を与える可能性があります
- Stack内で使用する場合は適切な制約を提供する必要があります

## 関連ウィジェット

- **FractionallySizedBox**: 親の寸法に基づいてサイズを決定
- **SizedBox**: 固定の寸法を指定
- **Container**: 制約で比率を制御可能
- **FittedBox**: 子を親に合わせてスケール
- **Align**: widthFactorとheightFactorを使用してサイズ調整
