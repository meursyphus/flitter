## 概要

ClipPathは、ユーザーが定義したカスタムパスを使用して子要素をクリップするウィジェットです。

Pathオブジェクトを返すクリッパーコールバック関数を受け取り、子ウィジェットを任意の形状にクリップできます。複雑な形状、曲線、多角形、その他様々なクリッピング形状が可能です。

## 使用場面

- 画像やコンテンツをカスタム形状にクリップしたい場合
- 特殊なデザイン効果（波、対角線、星形など）を作成する場合
- 複雑なマスキング効果が必要な場合
- アニメーションで動的なクリッピング効果を実装する場合
- 組み込みクリップウィジェット（ClipRect、ClipOval、ClipRRect）では不可能な形状が必要な場合

## 基本的な使用方法

```typescript
// 三角形クリッピング
ClipPath({
  clipper: (size) => {
    return new Path()
      .moveTo({ x: size.width / 2, y: 0 })
      .lineTo({ x: 0, y: size.height })
      .lineTo({ x: size.width, y: size.height })
      .close();
  },
  child: Container({
    width: 200,
    height: 200,
    color: 'blue'
  })
})

// 円形クリッピング
ClipPath({
  clipper: (size) => {
    const rect = Rect.fromLTWH({
      left: 0,
      top: 0,
      width: size.width,
      height: size.height
    });
    return new Path().addOval(rect);
  },
  child: Image({ src: 'profile.jpg' })
})
```

## プロパティの詳細

### clipper（必須）

**型: (size: Size) => Path**

クリッピングパスを定義するコールバック関数。ウィジェットのサイズをパラメータとして受け取り、Pathオブジェクトを返す必要があります。

```typescript
// Star shape clipping
ClipPath({
  clipper: (size) => {
    const path = new Path();
    const halfWidth = size.width / 2;
    const halfHeight = size.height / 2;
    
    // Draw a 5-pointed star
    for (let i = 0; i < 5; i++) {
      const angle = (i * 4 * Math.PI) / 5 - Math.PI / 2;
      const x = halfWidth + halfWidth * 0.8 * Math.cos(angle);
      const y = halfHeight + halfHeight * 0.8 * Math.sin(angle);
      
      if (i === 0) {
        path.moveTo({ x, y });
      } else {
        path.lineTo({ x, y });
      }
    }
    
    return path.close();
  },
  child: child
})
```

### clipped

**型: boolean**（デフォルト: **true**）

クリッピング効果を有効/無効にします。

- `true`: クリッピングを適用
- `false`: クリッピングを無効化（子ウィジェットは通常通り表示）

```typescript
ClipPath({
  clipped: isClippingEnabled,
  clipper: (size) => createCustomPath(size),
  child: content
})
```

### child

**型: Widget | undefined**

クリップされる子ウィジェット。

## Path API の理解

### 主要なPathメソッド

```typescript
const path = new Path();

// Movement
path.moveTo({ x: 10, y: 10 });           // Move to absolute position
path.relativeMoveTo({ x: 5, y: 5 });     // Move to relative position

// Lines
path.lineTo({ x: 50, y: 50 });           // Line to absolute position
path.relativeLineTo({ x: 20, y: 0 });    // Line to relative position

// Curves
path.quadraticBezierTo({                 // Quadratic Bezier curve
  controlPoint: { x: 25, y: 0 },
  endPoint: { x: 50, y: 25 }
});

path.cubicTo({                           // Cubic Bezier curve
  startControlPoint: { x: 20, y: 0 },
  endControlPoint: { x: 40, y: 50 },
  endPoint: { x: 60, y: 30 }
});

// Arcs
path.arcToPoint({
  endPoint: { x: 100, y: 100 },
  radius: { x: 50, y: 50 },
  rotation: 0,
  largeArc: false,
  clockwise: true
});

// Shapes
path.addRect(rect);                      // Add rectangle
path.addOval(rect);                      // Add oval
path.addRRect(roundedRect);              // Add rounded rectangle
path.addPolygons(points);                // Add polygon

// Close path
path.close();
```

### 例3: アニメーション変形効果

```typescript
const MorphingShape = ({ progress }) => {
  return ClipPath({
    clipper: (size) => {
      const path = new Path();
      const center = { x: size.width / 2, y: size.height / 2 };
      const radius = Math.min(size.width, size.height) / 2 - 20;
      
      // Morph from circle to star based on progress
      const sides = Math.floor(3 + progress * 3); // From triangle to hexagon
      
      for (let i = 0; i < sides; i++) {
        const angle = (i * 2 * Math.PI) / sides - Math.PI / 2;
        const innerRadius = radius * (0.5 + progress * 0.5);
        
        // Outer points of star
        const outerX = center.x + radius * Math.cos(angle);
        const outerY = center.y + radius * Math.sin(angle);
        
        // Inner points of star
        const innerAngle = angle + Math.PI / sides;
        const innerX = center.x + innerRadius * Math.cos(innerAngle);
        const innerY = center.y + innerRadius * Math.sin(innerAngle);
        
        if (i === 0) {
          path.moveTo({ x: outerX, y: outerY });
        } else {
          path.lineTo({ x: outerX, y: outerY });
        }
        
        if (progress > 0) {
          path.lineTo({ x: innerX, y: innerY });
        }
      }
      
      return path.close();
    },
    child: Container({
      width: 200,
      height: 200,
      decoration: BoxDecoration({
        gradient: RadialGradient({
          colors: ['#FF6B6B', '#4ECDC4'],
          center: Alignment.center
        })
      })
    })
  });
};
```

### 例4: メッセージバブル

```typescript
const MessageBubble = ({ message, isMe, time }) => {
  return ClipPath({
    clipper: (size) => {
      const path = new Path();
      const radius = 16;
      const tailSize = 10;
      
      // Rounded rectangle body
      const rect = RRect.fromLTRBR({
        left: isMe ? 0 : tailSize,
        top: 0,
        right: isMe ? size.width - tailSize : size.width,
        bottom: size.height,
        radius: Radius.circular(radius)
      });
      
      path.addRRect(rect);
      
      // Tail part
      if (isMe) {
        path.moveTo({ x: size.width - tailSize, y: size.height - 20 });
        path.lineTo({ x: size.width, y: size.height - 15 });
        path.lineTo({ x: size.width - tailSize, y: size.height - 10 });
      } else {
        path.moveTo({ x: tailSize, y: size.height - 20 });
        path.lineTo({ x: 0, y: size.height - 15 });
        path.lineTo({ x: tailSize, y: size.height - 10 });
      }
      
      return path;
    },
    child: Container({
      padding: EdgeInsets.all(12),
      constraints: BoxConstraints({ maxWidth: 250 }),
      decoration: BoxDecoration({
        color: isMe ? '#007AFF' : '#E5E5EA'
      }),
      child: Column({
        crossAxisAlignment: isMe ? CrossAxisAlignment.end : CrossAxisAlignment.start,
        children: [
          Text(message, {
            style: TextStyle({
              color: isMe ? 'white' : 'black',
              fontSize: 16
            })
          }),
          SizedBox({ height: 4 }),
          Text(time, {
            style: TextStyle({
              color: isMe ? 'rgba(255,255,255,0.7)' : 'rgba(0,0,0,0.5)',
              fontSize: 12
            })
          })
        ]
      })
    })
  });
};
```

```typescript
const HexagonalProfile = ({ profiles }) => {
```

## 重要な注意事項

- 複雑なパスはレンダリングパフォーマンスに影響する可能性があるため、慎重に使用してください
- クリッパー関数はウィジェットのサイズが変更されるたびに呼ばれるため、重い計算は避けてください
- クリップされた領域外のタッチイベントは検出されません
- アニメーションと組み合わせて使用する場合はパフォーマンスを考慮してください
- Pathオブジェクトは再利用できるため、必要に応じてキャッシュを検討してください

## 関連ウィジェット

- **ClipRect**: 矩形でクリップ
- **ClipOval**: 楕円でクリップ
- **ClipRRect**: 角丸矩形でクリップ
- **CustomPaint**: カスタム描画
- **ShaderMask**: シェーダーを使用したマスキング
