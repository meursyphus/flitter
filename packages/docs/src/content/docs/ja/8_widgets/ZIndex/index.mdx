## 概要

`ZIndex`は、子ウィジェットのレイヤー順序（z-index）を制御するウィジェットです。これはFlitter独自のウィジェット（Flutter自体には存在しない）で、CSSのz-indexと似たようにウィジェットの前後関係を決定できます。

特定のウィジェットを他のウィジェットの上に表示したり、複雑なレイヤー構造を作成する必要がある場合に使用します。Stackウィジェットと一緒に使用することで、より洗練されたレイアウトを実装できます。

## 使用する場面

- ウィジェットのレンダリング順序を明示的に制御する必要がある場合
- ポップアップやオーバーレイを他のウィジェットの上に表示する場合
- 複雑なレイヤー構造で特定のウィジェットを前面に持ってくる場合
- ドラッグアンドドロップ時に選択された要素を最前面に移動する場合
- 図表やゲームで要素の深度を管理する場合

## 基本的な使用方法

```typescript
import { ZIndex, Container, Stack } from 'flitter';

// 基本的なz-index適用
const LayeredWidget = Stack({
  children: [
    Container({
      width: 200,
      height: 200,
      color: '#e74c3c'
    }),
    ZIndex({
      zIndex: 10,
      child: Container({
        width: 100,
        height: 100,
        color: '#3498db'
      })
    })
  ]
});
```

## プロパティ

### zIndex (必須)
**値: number**

ウィジェットのレイヤー順序を表す数値。高い値ほど前面（上部）にレンダリングされます。

- **正の数値**: デフォルトレイヤーより前面に表示
- **0**: デフォルトレイヤー（ベースライン）
- **負の数値**: デフォルトレイヤーより背面に表示

```typescript
// 最前面に表示
zIndex: 9999

// デフォルトレイヤー
zIndex: 0

// 最背面に表示
zIndex: -1
```

### child (オプション)
**値: Widget**

z-indexが適用される子ウィジェット。子ウィジェットは1つだけ持つことができます。

## スタッキングコンテキスト

ZIndexはCSSのスタッキングコンテキストと似たシステムを使用します：

### 基本ルール
1. **高いz-indexは低いz-indexより前面に表示される**
2. **z-index値が同じ場合は、ドキュメント順序（作成順序）が優先される**
3. **ネストされたZIndexウィジェットは親のスタッキングコンテキストに制約される**

### コンテキストの分離
```typescript
// 親zIndexが1の場合、子のzIndex 9999は
// 他の兄弟要素のzIndex 2よりも背面に表示される可能性がある
ZIndex({
  zIndex: 1,
  child: ZIndex({
    zIndex: 9999,
    child: Container({ color: 'red' })
  })
})
```

## 実践的な例

### 例1: 基本レイヤリング

```typescript
import { ZIndex, Container, Stack, Positioned } from 'flitter';

const BasicLayering = Stack({
  children: [
    // 背景（z-indexなし、デフォルト0）
    Container({
      width: 300,
      height: 300,
      color: '#ecf0f1'
    }),
    
    // 中間レイヤー
    Positioned({
      top: 50,
      left: 50,
      child: ZIndex({
        zIndex: 1,
        child: Container({
          width: 200,
          height: 200,
          color: '#3498db',
          child: Center({
            child: Text('中間レイヤー', {
              style: { color: 'white', fontSize: 16 }
            })
          })
        })
      })
    }),
    
    // 上位レイヤー
    Positioned({
      top: 100,
      left: 100,
      child: ZIndex({
        zIndex: 10,
        child: Container({
          width: 100,
          height: 100,
          color: '#e74c3c',
          child: Center({
            child: Text('上', {
              style: { color: 'white', fontSize: 14 }
            })
          })
        })
      })
    }),
    
    // 背景の後ろ（負のz-index）
    Positioned({
      top: 25,
      left: 25,
      child: ZIndex({
        zIndex: -1,
        child: Container({
          width: 50,
          height: 50,
          color: '#95a5a6',
          child: Center({
            child: Text('後ろ', {
              style: { color: 'white', fontSize: 12 }
            })
          })
        })
      })
    })
  ]
});
```

### 例2: ドロップダウンメニュー

```typescript
import { ZIndex, Container, Column, GestureDetector } from 'flitter';

class DropdownMenu extends StatefulWidget {
  createState() {
    return new DropdownMenuState();
  }
}

class DropdownMenuState extends State {
  isOpen = false;
  
  toggleDropdown = () => {
    this.setState(() => {
      this.isOpen = !this.isOpen;
    });
  };
  
  build() {
    return Stack({
      children: [
        // メインボタン
        GestureDetector({
          onTap: this.toggleDropdown,
          child: Container({
            padding: EdgeInsets.symmetric({ horizontal: 16, vertical: 12 }),
            decoration: new BoxDecoration({
              color: '#3498db',
              borderRadius: BorderRadius.circular(4)
            }),
            child: Row({
              mainAxisSize: MainAxisSize.min,
              children: [
                Text('メニュー', { style: { color: 'white' } }),
                SizedBox({ width: 8 }),
                Icon(
                  this.isOpen ? Icons.arrow_drop_up : Icons.arrow_drop_down,
                  { color: 'white' }
                )
              ]
            })
          })
        }),
        
        // ドロップダウンメニュー（他の要素の上に表示するための高いz-index）
        if (this.isOpen)
          Positioned({
            top: 50,
            left: 0,
            child: ZIndex({
              zIndex: 1000,  // すべての要素の上に表示するための高いz-index
              child: Container({
                width: 150,
                decoration: new BoxDecoration({
                  color: 'white',
                  borderRadius: BorderRadius.circular(4),
                  boxShadow: [
                    new BoxShadow({
                      color: 'rgba(0, 0, 0, 0.1)',
                      offset: new Offset({ x: 0, y: 2 }),
                      blurRadius: 8
                    })
                  ]
                }),
                child: Column({
                  crossAxisAlignment: CrossAxisAlignment.stretch,
                  children: [
                    _buildMenuItem('オプション1'),
                    _buildMenuItem('オプション2'),
                    _buildMenuItem('オプション3')
                  ]
                })
              })
            })
          })
      ]
    });
  }
  
  _buildMenuItem(text: string) {
    return GestureDetector({
      onTap: () => {
        console.log(`${text} が選択されました`);
        this.toggleDropdown();
      },
      child: Container({
        padding: EdgeInsets.all(12),
        child: Text(text, { style: { fontSize: 14 } })
      })
    });
  }
}
```

### 例3: モーダルダイアログ

```typescript
import { ZIndex, Container, Stack, Positioned, GestureDetector } from 'flitter';

const Modal = ({ isVisible, onClose, children }) => {
  if (!isVisible) return null;
  
  return Stack({
    children: [
      // 背景オーバーレイ（中程度のz-index）
      Positioned.fill({
        child: ZIndex({
          zIndex: 100,
          child: GestureDetector({
            onTap: onClose,
            child: Container({
              color: 'rgba(0, 0, 0, 0.5)'
            })
          })
        })
      }),
      
      // モーダルコンテンツ（最高z-index）
      Center({
        child: ZIndex({
          zIndex: 200,
          child: Container({
            width: 300,
            padding: EdgeInsets.all(24),
            decoration: new BoxDecoration({
              color: 'white',
              borderRadius: BorderRadius.circular(12),
              boxShadow: [
                new BoxShadow({
                  color: 'rgba(0, 0, 0, 0.2)',
                  offset: new Offset({ x: 0, y: 4 }),
                  blurRadius: 16
                })
              ]
            }),
            child: children
          })
        })
      })
    ]
  });
};
```

### 例4: ドラッグ可能カードシステム

```typescript
import { ZIndex, Container, GestureDetector } from 'flitter';

class DraggableCard extends StatefulWidget {
  constructor(
    private color: string,
    private initialZIndex: number,
    private title: string
  ) {
    super();
  }
  
  createState() {
    return new DraggableCardState();
  }
}

class DraggableCardState extends State {
  isDragging = false;
  position = new Offset({ x: 0, y: 0 });
  
  get currentZIndex() {
    // ドラッグ中は最高z-indexを使用
    return this.isDragging ? 9999 : this.widget.initialZIndex;
  }
  
  build() {
    return Positioned({
      left: this.position.x,
      top: this.position.y,
      child: ZIndex({
        zIndex: this.currentZIndex,
        child: GestureDetector({
          onPanStart: (details) => {
            this.setState(() => {
              this.isDragging = true;
            });
          },
          
          onPanUpdate: (details) => {
            this.setState(() => {
              this.position = this.position.plus(details.delta);
            });
          },
          
          onPanEnd: (details) => {
            this.setState(() => {
              this.isDragging = false;
            });
          },
          
          child: Container({
            width: 120,
            height: 80,
            decoration: new BoxDecoration({
              color: this.widget.color,
              borderRadius: BorderRadius.circular(8),
              boxShadow: this.isDragging ? [
                new BoxShadow({
                  color: 'rgba(0, 0, 0, 0.3)',
                  offset: new Offset({ x: 0, y: 8 }),
                  blurRadius: 16
                })
              ] : [
                new BoxShadow({
                  color: 'rgba(0, 0, 0, 0.1)',
                  offset: new Offset({ x: 0, y: 2 }),
                  blurRadius: 4
                })
              ]
            }),
            child: Center({
              child: Text(this.widget.title, {
                style: { 
                  color: 'white', 
                  fontWeight: 'bold',
                  fontSize: 14
                }
              })
            })
          })
        })
      })
    });
  }
}

// 使用例
const DraggableCards = Stack({
  children: [
    DraggableCard('#e74c3c', 1, 'カード1'),
    DraggableCard('#3498db', 2, 'カード2'),
    DraggableCard('#2ecc71', 3, 'カード3')
  ]
});
```

### 例5: ツールチップシステム

```typescript
import { ZIndex, Container, Positioned, GestureDetector } from 'flitter';

class TooltipWidget extends StatefulWidget {
  constructor(
    private tooltip: string,
    private child: Widget
  ) {
    super();
  }
  
  createState() {
    return new TooltipWidgetState();
  }
}

class TooltipWidgetState extends State {
  showTooltip = false;
  
  build() {
    return Stack({
      children: [
        // ベースウィジェット
        GestureDetector({
          onLongPress: () => this.setState(() => {
            this.showTooltip = true;
          }),
          onTapDown: () => this.setState(() => {
            this.showTooltip = false;
          }),
          child: this.widget.child
        }),
        
        // ツールチップ（非常に高いz-index）
        if (this.showTooltip)
          Positioned({
            bottom: 0,
            left: 0,
            child: ZIndex({
              zIndex: 9999,
              child: Container({
                padding: EdgeInsets.symmetric({
                  horizontal: 8,
                  vertical: 4
                }),
                decoration: new BoxDecoration({
                  color: 'rgba(0, 0, 0, 0.8)',
                  borderRadius: BorderRadius.circular(4)
                }),
                child: Text(this.widget.tooltip, {
                  style: { 
                    color: 'white', 
                    fontSize: 12 
                  }
                })
              })
            })
          })
      ]
    });
  }
}
```

## ベストプラクティス

- **パフォーマンス**: ZIndexの過度な使用はレンダリングパフォーマンスに影響を与える可能性があります
- **複雑性**: ネストしたスタッキングコンテキストは予期しない結果を生み出す可能性があります
- **デバッグ**: z-indexが期待通りに動作しない場合は、スタッキングコンテキストの階層を確認してください
- **アクセシビリティ**: 視覚的順序とフォーカス順序が異なる可能性があるため、アクセシビリティを考慮してください
- **一貫性**: プロジェクト全体で一貫したz-index値システムを維持してください

## 関連ウィジェット

- **Stack**: ウィジェットの空間的配置を管理する場合
- **Positioned**: Stack内で絶対位置を指定する場合
- **Overlay**: アプリ全体のオーバーレイが必要な場合
- **Transform**: 3D変換で深度を表現する場合
