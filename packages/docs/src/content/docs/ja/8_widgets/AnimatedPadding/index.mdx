## 概要

AnimatedPaddingは、パディングが変更されたときに自動的にアニメーションを行い、スムーズな遷移を提供するウィジェットです。このウィジェットはFlutterのAnimatedPaddingウィジェットにインスパイアされています。

> 指定されたインデントが変更されるたびに、指定された期間にわたってインデントを自動的に遷移するPaddingのアニメーション版。

## いつ使うか？

- ユーザーインタラクションに基づいてウィジェット間隔を動的に調整する場合
- カードやコンテナの展開/折りたたみ時に内部マージンをスムーズに変更する場合
- メイソンリーリストでアイテム間隔を動的に調整する場合
- レスポンシブデザインで画面サイズに基づいて間隔を調整する場合
- 折りたたみ可能なコンテンツでアニメーション付きのパディング遷移を行う場合

## 基本的な使用法

```typescript
import { AnimatedPadding, Container, EdgeInsets, StatefulWidget } from '@flitter/core';

class PaddingExample extends StatefulWidget {
  createState() {
    return new PaddingExampleState();
  }
}

class PaddingExampleState extends State<PaddingExample> {
  isExpanded = false;

  build() {
    return Column({
      children: [
        ElevatedButton({
          onPressed: () => {
            this.setState(() => {
              this.isExpanded = !this.isExpanded;
            });
          },
          child: Text(this.isExpanded ? "折りたたむ" : "展開する"),
        }),
        Container({
          width: 300,
          height: 300,
          color: "lightgray",
          child: AnimatedPadding({
            padding: this.isExpanded 
              ? EdgeInsets.all(50) 
              : EdgeInsets.all(10),
            duration: 500, // 0.5秒
            child: Container({
              color: "blue",
              child: Center({
                child: Text("アニメーションパディング", {
                  style: TextStyle({ color: "white" })
                }),
              }),
            }),
          }),
        }),
      ],
    });
  }
}
```

## プロパティ

### duration（必須）
**値: number**

アニメーション期間をミリ秒で指定します。

### padding（オプション）
**値: EdgeInsetsGeometry**（デフォルト: **EdgeInsets.all(0)**）

ウィジェットの内部間隔を設定します。利用可能なメソッド：

#### EdgeInsetsメソッド
- `EdgeInsets.all(value)`: 全方向に同じ間隔
- `EdgeInsets.symmetric({ horizontal, vertical })`: 水平/垂直対称の間隔
- `EdgeInsets.only({ top, bottom, left, right })`: 各方向の間隔を個別指定

```typescript
// 様々なパディングタイプ
AnimatedPadding({
  padding: EdgeInsets.all(20),           // 全方向20
  padding: EdgeInsets.symmetric({        // 水平10、垂直20
    horizontal: 10, 
    vertical: 20 
  }),
  padding: EdgeInsets.only({             // 個別指定
    top: 10, 
    bottom: 15, 
    left: 5, 
    right: 25 
  }),
  duration: 300,
  child: Container({ /* ... */ })
})
```

### child（オプション）
**値: Widget**

パディングが適用される子ウィジェット。

### curve（オプション）
**値: Curve**（デフォルト: **Curves.linear**）

アニメーションカーブを指定します。利用可能なカーブ：

```typescript
// カーブの例
AnimatedPadding({
  padding: EdgeInsets.all(padding),
  duration: 500,
  curve: Curves.easeInOut,    // 滑らかな開始と終了
  curve: Curves.bounceIn,     // バウンス効果
  curve: Curves.elasticOut,   // 弾性効果
  child: myWidget
})
```

### onEnd（オプション）
**値: () => void**

アニメーション完了時に呼び出されるコールバック関数。

```typescript
AnimatedPadding({
  padding: EdgeInsets.all(padding),
  duration: 300,
  onEnd: () => {
    console.log('パディングアニメーション完了');
  },
  child: myWidget
})
```

## 実践例

### 例1: カード展開効果

```typescript
class ExpandableCard extends StatefulWidget {
  title: string;
  content: string;

  constructor({ title, content }) {
    super();
    this.title = title;
    this.content = content;
  }

  createState() {
    return new ExpandableCardState();
  }
}

class ExpandableCardState extends State<ExpandableCard> {
  isExpanded = false;

  build() {
    return Container({
      margin: EdgeInsets.all(8),
      decoration: BoxDecoration({
        color: 'white',
        borderRadius: BorderRadius.circular(12),
        boxShadow: [
          BoxShadow({
            color: 'rgba(0, 0, 0, 0.1)',
            blurRadius: 8,
            offset: { x: 0, y: 2 }
          })
        ]
      }),
      child: Column({
        children: [
          GestureDetector({
            onTap: () => {
              this.setState(() => {
                this.isExpanded = !this.isExpanded;
              });
            },
            child: Container({
              padding: EdgeInsets.all(16),
              child: Row({
                mainAxisAlignment: MainAxisAlignment.spaceBetween,
                children: [
                  Text(this.widget.title, {
                    style: TextStyle({
                      fontSize: 18,
                      fontWeight: 'bold'
                    })
                  }),
                  Icon(this.isExpanded ? Icons.expand_less : Icons.expand_more)
                ]
              })
            })
          }),
          AnimatedPadding({
            padding: this.isExpanded 
              ? EdgeInsets.fromLTRB(16, 0, 16, 16)
              : EdgeInsets.zero,
            duration: 300,
            curve: Curves.easeInOut,
            child: this.isExpanded 
              ? Text(this.widget.content, {
                  style: TextStyle({ fontSize: 14, color: '#666' })
                })
              : SizedBox.shrink()
          })
        ]
      })
    });
  }
}
```

### 例2: レスポンシブマージン

```typescript
class ResponsiveContainer extends StatefulWidget {
  child: Widget;

  constructor({ child }) {
    super();
    this.child = child;
  }

  createState() {
    return new ResponsiveContainerState();
  }
}

class ResponsiveContainerState extends State<ResponsiveContainer> {
  screenWidth = 1200; // 仮の画面幅

  get responsivePadding() {
    if (this.screenWidth < 600) {
      return EdgeInsets.all(8);
    } else if (this.screenWidth < 1200) {
      return EdgeInsets.all(16);
    } else {
      return EdgeInsets.all(24);
    }
  }

  build() {
    return AnimatedPadding({
      padding: this.responsivePadding,
      duration: 250,
      curve: Curves.easeOut,
      child: Container({
        color: '#F5F5F5',
        child: this.widget.child
      })
    });
  }
}
```

### 例3: インタラクティブボタンパディング

```typescript
class InteractiveButton extends StatefulWidget {
  text: string;
  onPressed: () => void;

  constructor({ text, onPressed }) {
    super();
    this.text = text;
    this.onPressed = onPressed;
  }

  createState() {
    return new InteractiveButtonState();
  }
}

class InteractiveButtonState extends State<InteractiveButton> {
  isPressed = false;
  isHovered = false;

  get buttonPadding() {
    if (this.isPressed) {
      return EdgeInsets.symmetric({ horizontal: 12, vertical: 6 });
    } else if (this.isHovered) {
      return EdgeInsets.symmetric({ horizontal: 20, vertical: 12 });
    } else {
      return EdgeInsets.symmetric({ horizontal: 16, vertical: 8 });
    }
  }

  build() {
    return GestureDetector({
      onTapDown: () => {
        this.setState(() => {
          this.isPressed = true;
        });
      },
      onTapUp: () => {
        this.setState(() => {
          this.isPressed = false;
        });
        this.widget.onPressed();
      },
      onMouseEnter: () => {
        this.setState(() => {
          this.isHovered = true;
        });
      },
      onMouseLeave: () => {
        this.setState(() => {
          this.isHovered = false;
          this.isPressed = false;
        });
      },
      child: Container({
        decoration: BoxDecoration({
          color: this.isPressed ? '#1976D2' : '#2196F3',
          borderRadius: BorderRadius.circular(8)
        }),
        child: AnimatedPadding({
          padding: this.buttonPadding,
          duration: 150,
          curve: Curves.easeInOut,
          child: Center({
            child: Text(this.widget.text, {
              style: TextStyle({
                color: 'white',
                fontWeight: 'bold'
              })
            })
          })
        })
      })
    });
  }
}
```

### 例4: ギャラリーアイテム間隔調整

```typescript
class GalleryView extends StatefulWidget {
  items: string[];

  constructor({ items }) {
    super();
    this.items = items;
  }

  createState() {
    return new GalleryViewState();
  }
}

class GalleryViewState extends State<GalleryView> {
  viewMode = 'grid'; // 'grid' または 'list'

  get itemPadding() {
    return this.viewMode === 'grid' 
      ? EdgeInsets.all(4)
      : EdgeInsets.symmetric({ horizontal: 16, vertical: 8 });
  }

  build() {
    return Column({
      children: [
        Row({
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            ElevatedButton({
              onPressed: () => {
                this.setState(() => {
                  this.viewMode = 'grid';
                });
              },
              child: Text('グリッド表示')
            }),
            SizedBox({ width: 8 }),
            ElevatedButton({
              onPressed: () => {
                this.setState(() => {
                  this.viewMode = 'list';
                });
              },
              child: Text('リスト表示')
            })
          ]
        }),
        SizedBox({ height: 16 }),
        Expanded({
          child: this.viewMode === 'grid'
            ? GridView.count({
                crossAxisCount: 3,
                children: this.widget.items.map(item => 
                  AnimatedPadding({
                    padding: this.itemPadding,
                    duration: 300,
                    curve: Curves.easeInOut,
                    child: Container({
                      decoration: BoxDecoration({
                        color: '#E3F2FD',
                        borderRadius: BorderRadius.circular(8)
                      }),
                      child: Center({
                        child: Text(item)
                      })
                    })
                  })
                )
              })
            : ListView({
                children: this.widget.items.map(item => 
                  AnimatedPadding({
                    padding: this.itemPadding,
                    duration: 300,
                    curve: Curves.easeInOut,
                    child: Container({
                      height: 60,
                      decoration: BoxDecoration({
                        color: '#E8F5E8',
                        borderRadius: BorderRadius.circular(8)
                      }),
                      child: Center({
                        child: Text(item, {
                          style: TextStyle({ fontSize: 16 })
                        })
                      })
                    })
                  })
                )
              })
        })
      ]
    });
  }
}
```

## 重要な注意事項

1. **パフォーマンス**: 頻繁なパディング変更はパフォーマンスに影響する可能性があります
2. **レイアウト再計算**: パディング変更時に親ウィジェットのレイアウトが再計算されます
3. **アニメーション期間**: 適切な期間（200-500ms）を選択してユーザビリティを向上させます
4. **カーブ選択**: コンテキストに適したアニメーションカーブを使用します

## よくある間違い

```typescript
// ❌ 間違い - 状態を直接変更
this.padding = EdgeInsets.all(20); // UIは更新されません

// ✅ 正しい - setStateを使用
this.setState(() => {
  this.padding = EdgeInsets.all(20);
});

// ❌ 間違い - 極端に短いアニメーション期間
AnimatedPadding({
  duration: 50, // 短すぎる
  // ...
})

// ✅ 正しい - 適切なアニメーション期間
AnimatedPadding({
  duration: 250, // 適切
  // ...
})
```
