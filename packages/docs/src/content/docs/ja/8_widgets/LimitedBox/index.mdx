## 概要

LimitedBoxは、無制限の制約を受け取ったときのみ、その子ウィジェットにサイズ制限を適用するウィジェットです。

このウィジェットは主に、ListView、Row、Columnなどのスクロール可能なウィジェットや無限のスペースを提供する他のウィジェット内で子ウィジェットが無限に成長するのを防ぐために使用されます。親ウィジェットが既に有限の制約を提供している場合、LimitedBoxは何もしません。

## 使用する場面

- ListView、Column、Rowなどでの無限拡張を防ぐ場合
- スクロール可能なコンテナ内で子ウィジェットのサイズを制限する必要がある場合
- 無制限の制約環境でのみ選択的にサイズ制限を適用したい場合
- 柔軟性を維持しながらコンテナが大きくなりすぎるのを防ぐ場合
- レスポンシブレイアウトで安全な最大サイズを設定する場合

## Basic Usage

```typescript
// 垂直スクロールリスト内での幅制限
ListView({
  children: [
    LimitedBox({
      maxWidth: 300,
      child: Container({
        color: 'blue',
        child: Text('幅が300に制限されています')
      })
    })
  ]
})

// 水平スクロールリスト内での高さ制限
SingleChildScrollView({
  scrollDirection: Axis.horizontal,
  child: Row({
    children: [
      LimitedBox({
        maxHeight: 200,
        child: Container({
          color: 'red',
          child: Text('高さが200に制限されています')
        })
      })
    ]
  })
})

// 両方向の制限
Column({
  children: [
    LimitedBox({
      maxWidth: 400,
      maxHeight: 300,
      child: Container({
        color: 'green',
        child: Text('幅400、高さ300に制限')
      })
    })
  ]
})
```

## プロパティ

### maxWidth

**値: number** (デフォルト: **Infinity**)

幅制約が無制限のときに適用する最大幅。

親ウィジェットが既に有限の幅制約を提供している場合、この値は無視されます。

```typescript
LimitedBox({
  maxWidth: 300,    // 無制限幅制約で最大300
  child: child
})

LimitedBox({
  maxWidth: Infinity,  // 幅制限なし（デフォルト）
  child: child
})
```

### maxHeight

**値: number** (デフォルト: **Infinity**)

高さ制約が無制限のときに適用する最大高さ。

親ウィジェットが既に有限の高さ制約を提供している場合、この値は無視されます。

```typescript
LimitedBox({
  maxHeight: 200,   // 無制限高さ制約で最大200
  child: child
})

LimitedBox({
  maxHeight: Infinity,  // 高さ制限なし（デフォルト）
  child: child
})
```

### child

**値: Widget | undefined**

サイズ制限が適用される子ウィジェット。

## 制約の動作理解

### 有限制約 vs 無限制約

```typescript
// 有限制約環境（LimitedBoxは効果なし）
Container({
  width: 400,    // 明確な幅制約
  height: 300,   // 明確な高さ制約
  child: LimitedBox({
    maxWidth: 200,   // この値は無視される（親に既に有限制約あり）
    maxHeight: 150,  // この値は無視される（親に既に有限制約あり）
    child: Container({ color: 'blue' })
  })
})

// 無限制約環境（LimitedBoxは効果あり）
Column({  // Columnは無限の垂直スペースを提供
  children: [
    LimitedBox({
      maxHeight: 200,  // この値が適用される
      child: Container({ color: 'red' })
    })
  ]
})
```

### いつ効果を発揮するか？

```typescript
// ✅ 効果があるケース
ListView({  // 無限の垂直スペース
  children: [
    LimitedBox({ maxHeight: 300, child: child })
  ]
})

Row({  // 無限の水平スペース
  children: [
    LimitedBox({ maxWidth: 200, child: child })
  ]
})

SingleChildScrollView({  // スクロール方向の無限スペース
  child: LimitedBox({ maxHeight: 400, child: child })
})

// ❌ 効果がないケース
Container({
  width: 300,  // 既に有限制約
  child: LimitedBox({ maxWidth: 200, child: child })  // 無視される
})

SizedBox({
  height: 200,  // 既に有限制約
  child: LimitedBox({ maxHeight: 100, child: child })  // 無視される
})
```

## 重要な注意事項

- LimitedBoxは無限制約でのみ動作します
- 親ウィジェットが既に有限制約を提供している場合は効果がありません
- ConstrainedBoxとは異なり、条件付きで動作します
- 負の値は許可されません
- Infinity値を使用すると制限が解除されます

## 関連ウィジェット

- **ConstrainedBox**: 常に制約を適用するウィジェット
- **SizedBox**: 固定サイズを指定するウィジェット
- **UnconstrainedBox**: 制約を完全に除去するウィジェット
- **OverflowBox**: 親のサイズを無視して子のサイズを許可するウィジェット
- **FractionallySizedBox**: 子のサイズを親のサイズの比率で設定するウィジェット
