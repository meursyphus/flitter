## 概要

Alignは子ウィジェットを自身の中で配置し、オプションで子のサイズに基づいて自身のサイズを調整するウィジェットです。正規化された座標系を使用して、子を柔軟に配置します。

## いつ使うか？

- 親の中で子ウィジェットを特定の位置に配置する必要がある場合
- 子ウィジェットの周りに特定の比率のマージンを作成する場合
- ダイアログやポップアップでコンテンツを中央揃えする場合
- ボタンやアイコンを特定の位置に配置する場合
- 子ウィジェットのサイズに比例して親のサイズを調整する場合

## 基本的な使用法

```typescript
// 中央揃え（デフォルト）
Align({
  child: Text('中央揃えテキスト')
})

// 右上揃え
Align({
  alignment: Alignment.topRight,
  child: Icon(Icons.close)
})

// サイズ係数を使用
Align({
  widthFactor: 2.0,
  heightFactor: 1.5,
  child: Container({
    width: 100,
    height: 100,
    color: 'blue'
  })
})
```

## プロパティ

### child（オプション）
**型: Widget | undefined**

配置する子ウィジェット。

### alignment（オプション）
**型: Alignment**（デフォルト: **Alignment.center**）

子ウィジェットの配置位置を指定します。Alignmentはxとyの値で構成され、それぞれ-1.0から1.0の範囲です。

主要な配置定数：
- `Alignment.topLeft`: (-1.0, -1.0)
- `Alignment.topCenter`: (0.0, -1.0)
- `Alignment.topRight`: (1.0, -1.0)
- `Alignment.centerLeft`: (-1.0, 0.0)
- `Alignment.center`: (0.0, 0.0)
- `Alignment.centerRight`: (1.0, 0.0)
- `Alignment.bottomLeft`: (-1.0, 1.0)
- `Alignment.bottomCenter`: (0.0, 1.0)
- `Alignment.bottomRight`: (1.0, 1.0)

```typescript
// カスタム配置
Align({
  alignment: Alignment.of({ x: 0.5, y: -0.5 }), // 右上寄り
  child: Text('カスタム配置')
})
```

### widthFactor（オプション）
**型: number | undefined**

このウィジェットの幅を子ウィジェットの幅の倍数として設定します。nullの場合、利用可能な幅まで拡張します。

```typescript
Align({
  widthFactor: 1.5, // 子の幅の1.5倍
  child: Container({
    width: 100,
    height: 50,
    color: 'red'
  })
})
// Alignの幅は150になります
```

### heightFactor（オプション）
**型: number | undefined**

このウィジェットの高さを子ウィジェットの高さの倍数として設定します。nullの場合、利用可能な高さまで拡張します。

```typescript
Align({
  heightFactor: 2.0, // 子の高さの2倍
  child: Container({
    width: 100,
    height: 50,
    color: 'green'
  })
})
// Alignの高さは100になります
```

## レイアウト動作

### サイズ制約の処理

1. **制約がある場合**:
   - widthFactorとheightFactorがnullの場合、利用可能なサイズまで拡張
   - 緩和された制約で子をレイアウト
   - 配置に従って子を配置

2. **無制約の場合**:
   - widthFactorとheightFactorがnullの場合、子のサイズまで収縮
   - 係数が指定されている場合、子のサイズ × 係数でサイズが決定

3. **サイズ係数を使用する場合**:
   - 常に子のサイズ × 係数でサイズ決定
   - 親の制約に関係なく動作

### 例4: ツールチップの配置

```typescript
class TooltipWidget extends StatefulWidget {
  message: string;
  child: Widget;
  alignment: Alignment;

  constructor({ message, child, alignment = Alignment.topCenter }) {
    super();
    this.message = message;
    this.child = child;
    this.alignment = alignment;
  }

  createState(): State<TooltipWidget> {
    return new TooltipWidgetState();
  }
}

class TooltipWidgetState extends State<TooltipWidget> {
  isVisible = false;

  build(): Widget {
    return Stack({
      clipBehavior: Clip.none,
      children: [
        GestureDetector({
          onMouseEnter: () => {
            this.setState(() => {
              this.isVisible = true;
            });
          },
          onMouseLeave: () => {
            this.setState(() => {
              this.isVisible = false;
            });
          },
          child: this.widget.child
        }),
        if (this.isVisible) Align({
          alignment: this.widget.alignment,
          widthFactor: 1.0,
          child: Transform.translate({
            offset: { x: 0, y: this.widget.alignment.y < 0 ? -30 : 30 },
            child: Container({
              padding: EdgeInsets.symmetric({ horizontal: 12, vertical: 6 }),
              decoration: BoxDecoration({
                color: 'rgba(0, 0, 0, 0.8)',
                borderRadius: BorderRadius.circular(4)
              }),
              child: Text(this.widget.message, {
                style: TextStyle({
                  color: 'white',
                  fontSize: 14
                })
              })
            })
          })
        })
      ]
    });
  }
}
```

## 重要な注意事項

- widthFactorとheightFactorは0より大きくなければなりません
- alignmentのxとy値は-1.0から1.0の間でなければなりません
- 子がなく、widthFactorまたはheightFactorがnullの場合、サイズが0になる可能性があります
- Stack内で使用する際は、AlignとPositionedの違いを理解してください
- サイズ係数の使用はレイアウトパフォーマンスに影響する可能性があります
- 子が希望するサイズを持てるよう制約を緩和します

## 関連ウィジェット

- **Center**: Alignの特別なケース、常にコンテンツを中央揃え
- **Positioned**: Stack内での絶対位置指定
- **Container**: alignmentプロパティを使用して子を配置可能
- **FractionallySizedBox**: 親の寸法比率に基づいてサイズ決定
- **AnimatedAlign**: 配置間のアニメーション遷移
