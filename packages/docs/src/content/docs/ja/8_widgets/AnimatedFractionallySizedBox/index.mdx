## 概要

AnimatedFractionallySizedBoxは、親ウィジェットのサイズに対して相対的に子ウィジェットのサイズを設定し、widthFactorやheightFactorが変更された際に自動的にアニメーションするウィジェットです。また、alignmentが変更された際には位置変更もアニメーションします。このウィジェットはFlutterのAnimatedFractionallySizedBoxウィジェットにインスパイアされています。

> widthFactorやheightFactorが変更された際に子ウィジェットのサイズを、またalignmentが変更された際に位置を、指定された継続時間で自動的に遷移させるFractionallySizedBoxのアニメーション版です。

Flutter reference: https://api.flutter.dev/flutter/widgets/AnimatedFractionallySizedBox-class.html

## いつ使うか？

- 親サイズに対して相対的にウィジェットサイズを動的に調整したい場合
- レスポンシブレイアウトでサイズをスムーズに遷移させたい場合
- スクリーンサイズに基づいてコンテンツサイズをアニメーションしたい場合
- スムーズな展開・折りたたみ効果を実装したい場合
- モーダルやダイアログのサイズを段階的に遷移させたい場合

## 基本的な使用方法

```typescript
import { AnimatedFractionallySizedBox, Container, StatefulWidget } from '@flitter/core';

class SizeAnimationExample extends StatefulWidget {
  createState() {
    return new SizeAnimationExampleState();
  }
}

class SizeAnimationExampleState extends State<SizeAnimationExample> {
  isExpanded = false;

  build() {
    return Container({
      width: 300,
      height: 300,
      color: "lightgray",
      child: GestureDetector({
        onTap: () => {
          this.setState(() => {
            this.isExpanded = !this.isExpanded;
          });
        },
        child: AnimatedFractionallySizedBox({
          widthFactor: this.isExpanded ? 0.8 : 0.4,
          heightFactor: this.isExpanded ? 0.8 : 0.4,
          duration: 1000, // 1秒
          child: Container({
            color: "blue",
          }),
        }),
      }),
    });
  }
}
```

## プロパティ

### duration （必須）
**値: number**

アニメーションの継続時間をミリ秒で指定します。

### widthFactor （オプション）
**値: number | undefined**

親ウィジェットの幅に対する比率で子ウィジェットの幅を設定します。
- 0.5 = 親の幅の50%
- 1.0 = 親の幅の100%
- 指定されない場合は子ウィジェットの固有幅を使用

### heightFactor （オプション）
**値: number | undefined**

親ウィジェットの高さに対する比率で子ウィジェットの高さを設定します。
- 0.5 = 親の高さの50%
- 1.0 = 親の高さの100%
- 指定されない場合は子ウィジェットの固有高を使用

### alignment （オプション）
**値: Alignment** （デフォルト: **Alignment.center**）

子ウィジェットの配置位置を指定します。定義済みの値：
- `Alignment.topLeft`: 左上
- `Alignment.topCenter`: 上中央
- `Alignment.topRight`: 右上
- `Alignment.centerLeft`: 左中央
- `Alignment.center`: 中央
- `Alignment.centerRight`: 右中央
- `Alignment.bottomLeft`: 左下
- `Alignment.bottomCenter`: 下中央
- `Alignment.bottomRight`: 右下

### curve （オプション）
**値: Curve** （デフォルト: **Curves.linear**）

アニメーションの進行カーブを指定します。利用可能なカーブ：
- `Curves.linear`: 一定速度
- `Curves.easeIn`: ゆっくり開始
- `Curves.easeOut`: ゆっくり終了
- `Curves.easeInOut`: ゆっくり開始・終了
- `Curves.circIn`: 円形加速開始
- `Curves.circOut`: 円形減速終了
- `Curves.circInOut`: 円形加速・減速
- `Curves.backIn`: 戻ってから開始
- `Curves.backOut`: 目標を越えてから戻る
- `Curves.backInOut`: backIn + backOut
- `Curves.anticipate`: 進む前の予備動作
- `Curves.bounceIn`: 開始時にバウンス
- `Curves.bounceOut`: 終了時にバウンス
- `Curves.bounceInOut`: 開始・終了時にバウンス

### child （オプション）
**値: Widget | undefined**

サイズが調整される子ウィジェットです。

### key （オプション）
**値: any**

ウィジェットの一意な識別子です。

## 実用的な例

### 例1: レスポンシブカードの展開・折りたたみ

```typescript
import { AnimatedFractionallySizedBox, Container, Card, Curves } from '@flitter/core';

class ResponsiveCard extends StatefulWidget {
  createState() {
    return new ResponsiveCardState();
  }
}

class ResponsiveCardState extends State<ResponsiveCard> {
  isExpanded = false;

  build() {
    return Container({
      width: 400,
      height: 600,
      color: "#f0f0f0",
      child: Center({
        child: GestureDetector({
          onTap: () => {
            this.setState(() => {
              this.isExpanded = !this.isExpanded;
            });
          },
          child: AnimatedFractionallySizedBox({
            widthFactor: this.isExpanded ? 0.9 : 0.6,
            heightFactor: this.isExpanded ? 0.7 : 0.4,
            duration: 600,
            curve: Curves.easeInOut,
            alignment: Alignment.center,
            child: Card({
              elevation: 4,
              child: Container({
                decoration: BoxDecoration({
                  gradient: LinearGradient({
                    colors: ["#4A90E2", "#7B68EE"],
                    begin: Alignment.topLeft,
                    end: Alignment.bottomRight,
                  }),
                }),
                child: Center({
                  child: Column({
                    mainAxisAlignment: MainAxisAlignment.center,
                    children: [
                      Icon({
                        icon: this.isExpanded ? Icons.unfold_less : Icons.unfold_more,
                        size: 48,
                        color: "white",
                      }),
                      SizedBox({ height: 16 }),
                      Text(
                        this.isExpanded ? "クリックで折りたたむ" : "クリックで展開",
                        { style: TextStyle({ color: "white", fontSize: 18 }) }
                      ),
                    ],
                  }),
                }),
              }),
            }),
          }),
        }),
      }),
    });
  }
}
```

### 例2: 多段階サイズ遷移

```typescript
import { AnimatedFractionallySizedBox, Container, Row, Curves } from '@flitter/core';

class MultiSizeTransition extends StatefulWidget {
  createState() {
    return new MultiSizeTransitionState();
  }
}

class MultiSizeTransitionState extends State<MultiSizeTransition> {
  sizeLevel = 0; // 0: 小, 1: 中, 2: 大
  sizes = [
    { width: 0.3, height: 0.3 },
    { width: 0.6, height: 0.5 },
    { width: 0.9, height: 0.8 },
  ];

  build() {
    const currentSize = this.sizes[this.sizeLevel];
    
    return Column({
      children: [
        // コントロールボタン
        Row({
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            ElevatedButton({
              onPressed: () => this.changeSize(0),
              child: Text("小"),
              style: ButtonStyle({
                backgroundColor: this.sizeLevel === 0 ? "blue" : "gray",
              }),
            }),
            SizedBox({ width: 8 }),
            ElevatedButton({
              onPressed: () => this.changeSize(1),
              child: Text("中"),
              style: ButtonStyle({
                backgroundColor: this.sizeLevel === 1 ? "blue" : "gray",
              }),
            }),
            SizedBox({ width: 8 }),
            ElevatedButton({
              onPressed: () => this.changeSize(2),
              child: Text("大"),
              style: ButtonStyle({
                backgroundColor: this.sizeLevel === 2 ? "blue" : "gray",
              }),
            }),
          ],
        }),
        SizedBox({ height: 20 }),
        
        // アニメーションエリア
        Expanded({
          child: Container({
            color: "#e0e0e0",
            child: AnimatedFractionallySizedBox({
              widthFactor: currentSize.width,
              heightFactor: currentSize.height,
              duration: 800,
              curve: Curves.anticipate,
              child: Container({
                decoration: BoxDecoration({
                  color: "deepPurple",
                  borderRadius: BorderRadius.circular(16),
                  boxShadow: [
                    BoxShadow({
                      color: "rgba(0,0,0,0.3)",
                      blurRadius: 10,
                      offset: Offset({ x: 0, y: 5 }),
                    }),
                  ],
                }),
                child: Center({
                  child: Text(
                    `${Math.round(currentSize.width * 100)}% x ${Math.round(currentSize.height * 100)}%`,
                    { style: TextStyle({ color: "white", fontSize: 24, fontWeight: "bold" }) }
                  ),
                }),
              }),
            }),
          }),
        }),
      ],
    });
  }

  changeSize(level: number) {
    this.setState(() => {
      this.sizeLevel = level;
    });
  }
}
```

### 例3: 配置とサイズアニメーションの組み合わせ

```typescript
import { AnimatedFractionallySizedBox, Container, Alignment, Curves } from '@flitter/core';

class AlignmentAndSizeAnimation extends StatefulWidget {
  createState() {
    return new AlignmentAndSizeAnimationState();
  }
}

class AlignmentAndSizeAnimationState extends State<AlignmentAndSizeAnimation> {
  currentIndex = 0;
  configs = [
    { alignment: Alignment.topLeft, widthFactor: 0.3, heightFactor: 0.3 },
    { alignment: Alignment.topRight, widthFactor: 0.5, heightFactor: 0.2 },
    { alignment: Alignment.center, widthFactor: 0.8, heightFactor: 0.8 },
    { alignment: Alignment.bottomLeft, widthFactor: 0.4, heightFactor: 0.6 },
    { alignment: Alignment.bottomRight, widthFactor: 0.6, heightFactor: 0.4 },
  ];

  build() {
    const config = this.configs[this.currentIndex];
    
    return GestureDetector({
      onTap: () => this.nextConfiguration(),
      child: Container({
        width: double.infinity,
        height: double.infinity,
        color: "lightblue",
        child: AnimatedFractionallySizedBox({
          alignment: config.alignment,
          widthFactor: config.widthFactor,
          heightFactor: config.heightFactor,
          duration: 1000,
          curve: Curves.easeInOut,
          child: Container({
            decoration: BoxDecoration({
              color: "orange",
              borderRadius: BorderRadius.circular(20),
              border: Border.all({ color: "darkorange", width: 3 }),
            }),
            child: Center({
              child: Column({
                mainAxisAlignment: MainAxisAlignment.center,
                children: [
                  Text(
                    `位置 ${this.currentIndex + 1}/5`,
                    { style: TextStyle({ fontSize: 20, fontWeight: "bold" }) }
                  ),
                  SizedBox({ height: 8 }),
                  Text(
                    "タップで次へ",
                    { style: TextStyle({ fontSize: 16 }) }
                  ),
                ],
              }),
            }),
          }),
        }),
      }),
    });
  }

  nextConfiguration() {
    this.setState(() => {
      this.currentIndex = (this.currentIndex + 1) % this.configs.length;
    });
  }
}
```

### 例4: アスペクト比保持画像コンテナ

```typescript
import { AnimatedFractionallySizedBox, Container, Image, Curves } from '@flitter/core';

class AspectRatioImageContainer extends StatefulWidget {
  createState() {
    return new AspectRatioImageContainerState();
  }
}

class AspectRatioImageContainerState extends State<AspectRatioImageContainer> {
  isFullscreen = false;

  build() {
    return Container({
      width: double.infinity,
      height: double.infinity,
      color: "black",
      child: GestureDetector({
        onTap: () => {
          this.setState(() => {
            this.isFullscreen = !this.isFullscreen;
          });
        },
        child: AnimatedFractionallySizedBox({
          widthFactor: this.isFullscreen ? 1.0 : 0.7,
          heightFactor: this.isFullscreen ? 1.0 : 0.5,
          duration: 500,
          curve: Curves.easeOut,
          alignment: Alignment.center,
          child: Container({
            decoration: BoxDecoration({
              boxShadow: this.isFullscreen ? [] : [
                BoxShadow({
                  color: "rgba(0,0,0,0.5)",
                  blurRadius: 20,
                  spreadRadius: 5,
                }),
              ],
            }),
            child: ClipRRect({
              borderRadius: BorderRadius.circular(this.isFullscreen ? 0 : 16),
              child: Image({
                src: "https://example.com/landscape.jpg",
                fit: "cover",
              }),
            }),
          }),
        }),
      }),
    });
  }
}
```

## 注意事項

- widthFactorとheightFactorは0以上である必要があります
- widthFactorとheightFactorの両方がundefinedの場合、子ウィジェットの固有サイズが使用されます
- 親ウィジェットのサイズが変更されると、AnimatedFractionallySizedBoxの実際のサイズも自動的に調整されます
- alignmentとfactor値が同時に変更される場合、すべてが一緒にアニメーションします
- パフォーマンスを考慮して、頻繁なサイズ変更は避けてください

## 関連ウィジェット

- **FractionallySizedBox**: アニメーションなしで親に比例してサイズを設定する基本ウィジェット
- **AnimatedContainer**: 複数のプロパティを同時にアニメーション
- **AnimatedAlign**: 配置の遷移のみアニメーション
- **SizedBox**: 固定サイズを設定するウィジェット
