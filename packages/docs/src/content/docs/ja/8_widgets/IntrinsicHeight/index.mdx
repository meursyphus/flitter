## 概要

IntrinsicHeightは、子ウィジェットを固有の高さにサイズ調整するウィジェットです。

IntrinsicHeightは子ウィジェットに固有の高さを強制します。これは、Rowの複数の子ウィジェットが同じ高さになるようにしたい場合や、子ウィジェットのコンテンツに基づいて高さを動的に調整する必要がある場合に便利です。ただし、このウィジェットは高いパフォーマンスコストがあるため、慎重に使用する必要があります。

## 使用する場面

- Rowの子ウィジェットが同じ高さを持つ必要がある場合
- 高さが子ウィジェットのコンテンツによって決定される必要がある場合
- 様々なコンテンツを持つウィジェットの高さを一致させる必要がある場合
- DividerやVerticalDividerが適切な高さを必要とする場合
- CrossAxisAlignment.stretchが期待通りに動作しない場合

## Basic Usage

```typescript
IntrinsicHeight({
  child: Row({
    crossAxisAlignment: CrossAxisAlignment.stretch,
    children: [
      Container({
        color: 'blue',
        width: 100,
        child: Text('短いテキスト')
      }),
      Container({
        color: 'red',
        width: 100,
        child: Text('これはより長いテキストで、複数行にまたがります')
      })
    ]
  })
})
```

## プロパティ

### child

**値: Widget | undefined**

サイズが固有の高さに調整される子ウィジェット。

```typescript
IntrinsicHeight({
  child: Container({
    color: 'blue',
    child: Text('高さがコンテンツに調整されます')
  })
})
```

## 動作原理

IntrinsicHeightは以下のように動作します：

1. 子ウィジェットに「指定された幅での最小高さは何ですか？」と尋ねます
2. 子ウィジェットが回答した高さを使用して制約を作成します
3. これらの制約で子ウィジェットをレイアウトします

このプロセスには追加のレイアウトパスが必要で、パフォーマンスコストが発生します。

## 実用的な例

### 例1: 等しい高さのカード

```typescript
const EqualHeightCards = () => {
  return IntrinsicHeight({
    child: Row({
      crossAxisAlignment: CrossAxisAlignment.stretch,
      children: [
        Expanded({
          child: Card({
            child: Padding({
              padding: EdgeInsets.all(16),
              child: Column({
                children: [
                  Text('カード1', {
                    style: TextStyle({ fontSize: 18, fontWeight: 'bold' })
                  }),
                  SizedBox({ height: 8 }),
                  Text('短いコンテンツ')
                ]
              })
            })
          })
        }),
        SizedBox({ width: 16 }),
        Expanded({
          child: Card({
            child: Padding({
              padding: EdgeInsets.all(16),
              child: Column({
                children: [
                  Text('カード2', {
                    style: TextStyle({ fontSize: 18, fontWeight: 'bold' })
                  }),
                  SizedBox({ height: 8 }),
                  Text('このカードはより多くのコンテンツを持っているため、自然により高くなります。IntrinsicHeightのおかげで、カード1は同じ高さになります。')
                ]
              })
            })
          })
        })
      ]
    })
  });
};
```

## パフォーマンスに関する考慮事項

IntrinsicHeightは追加のレイアウトパスが必要なため、パフォーマンスコストが発生します：

1. **O(N²)の複雑性**: 深くネストされたIntrinsicHeightウィジェットは指数関数的に遅くなります
2. **代替案を検討**: 可能な場合はまず他のアプローチを試してください
3. **スクロールビューでの注意**: ListViewやスクロール可能な領域では特に注意が必要です

## 代替案

パフォーマンスが重要な場合は、これらの代替案を検討してください：

1. **固定高さ**: 可能な場合は明示的な高さを指定
2. **AspectRatio**: アスペクト比が一定の場合
3. **Tableウィジェット**: テーブル形式のレイアウトの場合
4. **カスタムRenderObject**: 複雑なレイアウトロジックの場合

## 重要な注意事項

- IntrinsicHeightは高いパフォーマンスコストがあるため、必要な場合のみ使用してください
- 深くネストされたIntrinsicHeightウィジェットは避けてください
- 無限の高さ制約では動作しません
- 子ウィジェットの固有の高さが未定義の場合、予期しない結果が発生する可能性があります

## 関連ウィジェット

- **IntrinsicWidth**: 子ウィジェットの固有の幅にサイズ調整
- **AspectRatio**: アスペクト比を維持
- **Table**: テーブルレイアウト
- **CustomMultiChildLayout**: 複雑なカスタムレイアウト
