## 概要

AnimatedAlignは、子ウィジェットの配置が変更された際に自動的にアニメーション遷移を行うウィジェットです。位置変更をスムーズに表現します。このウィジェットはFlutterのAnimatedAlignウィジェットにインスパイアされています。

> Alignのアニメーション版で、配置が変更された際に指定された期間で子ウィジェットの位置を自動的に遷移させます。

Flutter リファレンス: https://api.flutter.dev/flutter/widgets/AnimatedAlign-class.html

## いつ使うか？

- ウィジェットの位置をスムーズに移動させたい場合
- ユーザーの操作に基づいてウィジェットの配置を動的に変更する場合
- レイアウト変更時に視覚的な連続性を提供したい場合
- フローティングボタンやポップアップの位置をアニメーション付きで切り替える場合

## 基本的な使用方法

```typescript
import { AnimatedAlign, Alignment, Container, StatefulWidget } from '@flitter/core';

class AlignmentExample extends StatefulWidget {
  createState() {
    return new AlignmentExampleState();
  }
}

class AlignmentExampleState extends State<AlignmentExample> {
  alignment = Alignment.topLeft;

  build() {
    return GestureDetector({
      onTap: () => {
        this.setState(() => {
          // タップで配置位置を変更
          this.alignment = this.alignment === Alignment.topLeft 
            ? Alignment.bottomRight 
            : Alignment.topLeft;
        });
      },
      child: AnimatedAlign({
        alignment: this.alignment,
        duration: 1000, // 1秒
        child: Container({
          width: 50,
          height: 50,
          color: "blue",
        }),
      }),
    });
  }
}
```

## プロパティ

### alignment （必須）
**値: Alignment**

子ウィジェットの配置位置を指定します。定義済みの値：
- `Alignment.topLeft`: 左上 (-1, -1)
- `Alignment.topCenter`: 上中央 (0, -1)
- `Alignment.topRight`: 右上 (1, -1)
- `Alignment.centerLeft`: 左中央 (-1, 0)
- `Alignment.center`: 中央 (0, 0)
- `Alignment.centerRight`: 右中央 (1, 0)
- `Alignment.bottomLeft`: 左下 (-1, 1)
- `Alignment.bottomCenter`: 下中央 (0, 1)
- `Alignment.bottomRight`: 右下 (1, 1)

カスタム配置も可能です：
```typescript
Alignment.of({ x: 0.5, y: -0.5 }) // x: -1~1, y: -1~1
```

### duration （必須）
**値: number**

アニメーションの継続時間をミリ秒で指定します。

### curve （オプション）
**値: Curve** （デフォルト: **Curves.linear**）

アニメーションの進行カーブを指定します。利用可能なカーブ：
- `Curves.linear`: 一定速度
- `Curves.easeIn`: ゆっくり開始
- `Curves.easeOut`: ゆっくり終了
- `Curves.easeInOut`: ゆっくり開始・終了
- `Curves.circIn`: 円形加速開始
- `Curves.circOut`: 円形減速終了
- `Curves.circInOut`: 円形加速・減速
- `Curves.backIn`: 戻ってから開始
- `Curves.backOut`: 目標を越えてから戻る
- `Curves.backInOut`: backIn + backOut
- `Curves.anticipate`: 進む前の予備動作
- `Curves.bounceIn`: 開始時にバウンス
- `Curves.bounceOut`: 終了時にバウンス
- `Curves.bounceInOut`: 開始・終了時にバウンス

### widthFactor （オプション）
**値: number | undefined**

子ウィジェットの幅の倍率です。指定されない場合は親の全幅を使用します。

### heightFactor （オプション）
**値: number | undefined**

子ウィジェットの高さの倍率です。指定されない場合は親の全高を使用します。

### child （オプション）
**値: Widget | undefined**

配置される子ウィジェットです。

### key （オプション）
**値: any**

ウィジェットの一意な識別子です。

## 実用的な例

### 例1: インタラクティブなフローティングボタン

```typescript
import { AnimatedAlign, Alignment, Container, FloatingActionButton, Curves } from '@flitter/core';

class InteractiveFloatingButton extends StatefulWidget {
  createState() {
    return new InteractiveFloatingButtonState();
  }
}

class InteractiveFloatingButtonState extends State<InteractiveFloatingButton> {
  isExpanded = false;

  build() {
    return Stack({
      children: [
        // メインコンテンツ
        Container({
          color: "lightgray",
        }),
        
        // アニメーション付きフローティングボタン
        AnimatedAlign({
          alignment: this.isExpanded 
            ? Alignment.center 
            : Alignment.bottomRight,
          duration: 500,
          curve: Curves.easeInOut,
          child: Padding({
            padding: EdgeInsets.all(16),
            child: FloatingActionButton({
              onPressed: () => {
                this.setState(() => {
                  this.isExpanded = !this.isExpanded;
                });
              },
              child: Icon(this.isExpanded ? Icons.close : Icons.add),
            }),
          }),
        }),
      ],
    });
  }
}
```

### 例2: 複数位置のトランジションアニメーション

```typescript
import { AnimatedAlign, Alignment, Container, Row, Column, Curves } from '@flitter/core';

class MultiPositionAnimation extends StatefulWidget {
  createState() {
    return new MultiPositionAnimationState();
  }
}

class MultiPositionAnimationState extends State<MultiPositionAnimation> {
  currentPosition = 0;
  positions = [
    Alignment.topLeft,
    Alignment.topRight,
    Alignment.bottomRight,
    Alignment.bottomLeft,
    Alignment.center,
  ];

  build() {
    return Column({
      children: [
        // コントロールボタン
        Row({
          mainAxisAlignment: MainAxisAlignment.spaceEvenly,
          children: [
            ElevatedButton({
              onPressed: () => this.moveToNext(),
              child: Text("次の位置"),
            }),
            ElevatedButton({
              onPressed: () => this.moveToCenter(),
              child: Text("中央へ"),
            }),
          ],
        }),
        
        // アニメーションエリア
        Expanded({
          child: Container({
            color: "#f0f0f0",
            child: AnimatedAlign({
              alignment: this.positions[this.currentPosition],
              duration: 800,
              curve: Curves.anticipate,
              child: Container({
                width: 80,
                height: 80,
                decoration: BoxDecoration({
                  color: "purple",
                  borderRadius: BorderRadius.circular(40),
                }),
                child: Center({
                  child: Text(
                    (this.currentPosition + 1).toString(),
                    style: TextStyle({ color: "white", fontSize: 24 }),
                  ),
                }),
              }),
            }),
          }),
        }),
      ],
    });
  }

  moveToNext() {
    this.setState(() => {
      this.currentPosition = (this.currentPosition + 1) % this.positions.length;
    });
  }

  moveToCenter() {
    this.setState(() => {
      this.currentPosition = 4; // 中央位置
    });
  }
}
```

### 例3: widthFactorとheightFactorの使用

```typescript
import { AnimatedAlign, Alignment, Container, Curves } from '@flitter/core';

class FactorAnimation extends StatefulWidget {
  createState() {
    return new FactorAnimationState();
  }
}

class FactorAnimationState extends State<FactorAnimation> {
  isCompact = false;

  build() {
    return GestureDetector({
      onTap: () => {
        this.setState(() => {
          this.isCompact = !this.isCompact;
        });
      },
      child: Container({
        width: 300,
        height: 300,
        color: "lightblue",
        child: AnimatedAlign({
          alignment: Alignment.center,
          widthFactor: this.isCompact ? 0.5 : 1.0,
          heightFactor: this.isCompact ? 0.5 : 1.0,
          duration: 600,
          curve: Curves.bounceOut,
          child: Container({
            width: 100,
            height: 100,
            color: "red",
            child: Center({
              child: Text(
                this.isCompact ? "収縮" : "拡張",
                style: TextStyle({ color: "white" }),
              ),
            }),
          }),
        }),
      }),
    });
  }
}
```

## 注意事項

- アニメーションは配置値が変更された時のみ発生します
- widthFactorとheightFactorは子ウィジェットのサイズに影響し、親ウィジェットのサイズ制約にも影響します
- アニメーション中に新しい配置値が設定された場合、現在位置から新しい目標位置へスムーズに遷移します
- durationが0の場合、ウィジェットはアニメーションなしで即座に移動します

## 関連ウィジェット

- **Align**: アニメーションなしで子ウィジェットを配置する基本ウィジェット
- **AnimatedPositioned**: Stack内での位置遷移をアニメーション化
- **AnimatedContainer**: 複数のプロパティを同時にアニメーション化
- **AnimatedPadding**: パディングの遷移をアニメーション化
