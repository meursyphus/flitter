## 概要

IntrinsicWidthは、子ウィジェットを固有の幅にサイズ調整するウィジェットです。

IntrinsicWidthは子ウィジェットに固有の幅を強制します。これは、Columnの複数の子ウィジェットが同じ幅を持つようにしたい場合や、子ウィジェットのコンテンツに基づいて幅を動的に調整する必要がある場合に便利です。IntrinsicHeightと同様に、このウィジェットは高いパフォーマンスコストがあり、慎重に使用する必要があります。

## 使用する場面

- Columnの子ウィジェットが同じ幅を持つ必要がある場合
- 幅が子ウィジェットのコンテンツによって決定される必要がある場合
- 様々なコンテンツを持つウィジェットの幅を一致させる必要がある場合
- ボタンやチップの幅をコンテンツに合わせる必要がある場合
- CrossAxisAlignment.stretchが期待通りに動作しない場合

## Basic Usage

```typescript
IntrinsicWidth({
  child: Column({
    crossAxisAlignment: CrossAxisAlignment.stretch,
    children: [
      Container({
        color: 'blue',
        height: 50,
        child: Text('短い')
      }),
      Container({
        color: 'red',
        height: 50,
        child: Text('これはより長いテキスト')
      })
    ]
  })
})
```

## プロパティ

### child

**値: Widget | undefined**

サイズが固有の幅に調整される子ウィジェット。

```typescript
IntrinsicWidth({
  child: Container({
    color: 'blue',
    child: Text('幅がコンテンツに調整されます')
  })
})
```

## 動作原理

IntrinsicWidthは以下のように動作します：

1. 子ウィジェットに「指定された高さでの最小幅は何ですか？」と尋ねます
2. 子ウィジェットが回答した幅を使用して制約を作成します
3. これらの制約で子ウィジェットをレイアウトします

このプロセスには追加のレイアウトパスが必要で、パフォーマンスコストが発生します。

```typescript
const UniformWidthButtons = () => {
  return IntrinsicWidth({
    child: Column({
      crossAxisAlignment: CrossAxisAlignment.stretch,
      children: [
        ElevatedButton({

          child: Text('保存')

    })
  });
```

## パフォーマンスに関する考慮事項

IntrinsicWidthはIntrinsicHeightと同じパフォーマンス特性を持っています：

1. **O(N²)の複雑性**: 深くネストされたIntrinsicWidthウィジェットは指数関数的に遅くなります
2. **レイアウトパス**: 追加の測定ステップが必要です
3. **スクロールビューでの注意**: 多くのアイテムを持つリストでは避けてください

## 代替案

パフォーマンスが重要な場合は、これらの代替案を検討してください：

1. **固定幅**: 可能な場合は明示的な幅を指定
2. **ConstrainedBox**: 最小/最大幅の制約のみが必要な場合
3. **Wrapウィジェット**: 動的レイアウトの場合
4. **LayoutBuilder**: 親のサイズに基づいた調整が必要な場合

## 重要な注意事項

- IntrinsicWidthは高いパフォーマンスコストがあるため、必要な場合のみ使用してください
- 深くネストされたIntrinsicWidthウィジェットは避けてください
- 無限の幅制約では動作しません
- Row内でExpandedと一緒に使用する場合は注意が必要です

## 関連ウィジェット

- **IntrinsicHeight**: 子ウィジェットの固有の高さにサイズ調整
- **Wrap**: 自動折り返しを行う柔軟なレイアウト
- **FittedBox**: 子ウィジェットを利用可能なスペースにフィット
- **ConstrainedBox**: サイズ制約を適用
