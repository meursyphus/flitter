## 概要

Centerは、子要素を自身の中央に配置するウィジェットです。`alignment: Alignment.center`が設定されたAlignウィジェットの便利版で、コンテンツを簡単に中央配置する方法を提供します。

参考: [https://api.flutter.dev/flutter/widgets/Center-class.html](https://api.flutter.dev/flutter/widgets/Center-class.html)

## 使用場面

- コンテナ内のコンテンツを中央配置したい場合
- 画面の中央にローディングインジケーターを表示する場合
- 空の状態メッセージを中央に配置する場合
- ダイアログやモーダルのコンテンツを中央揃えする場合
- アイコンやロゴを中央配置する場合

## 基本的な使用方法

```typescript
// シンプルな中央配置
Center({
  child: Text('Centered text')
})

// サイズファクターを使用
Center({
  widthFactor: 1.5,
  heightFactor: 2.0,
  child: Icon(Icons.star, { size: 48 })
})

// 全画面中央配置
Scaffold({
  body: Center({
    child: CircularProgressIndicator()
  })
})
```

## プロパティ

### child（オプション）
**型: Widget | undefined**

中央配置される子ウィジェット。

### widthFactor（オプション）
**型: number | undefined**

子ウィジェットの幅の倍数として、このウィジェットの幅を設定します。nullの場合、利用可能な幅まで拡張します。

```typescript
Center({
  widthFactor: 2.0,  // 2 times the child's width
  child: Container({
    width: 100,
    height: 100,
    color: 'blue'
  })
})
// Centerの幅は200になります
```

### heightFactor（オプション）
**型: number | undefined**

子ウィジェットの高さの倍数として、このウィジェットの高さを設定します。nullの場合、利用可能な高さまで拡張します。

```typescript
Center({
  heightFactor: 1.5,  // 1.5 times the child's height
  child: Container({
    width: 100,
    height: 100,
    color: 'green'
  })
})
// Centerの高さは150になります
```

## Center vs Align

CenterはAlignの特殊ケースです：

```typescript
// これらの二つは同等です
Center({
  child: Text('Hello')
})

Align({
  alignment: Alignment.center,
  child: Text('Hello')
})
```

## レイアウト動作

Centerウィジェットがサイズを決定する方法：

1. **タイトな制約の場合**: 制約のサイズを使用
2. **ルースな制約とnullファクターの場合**: 可能な限り拡張
3. **無限制約とnullファクターの場合**: 子のサイズを使用
4. **指定されたファクターの場合**: 子のサイズ × ファクター

```typescript
// 様々なシナリオ
Container({
  width: 200,
  height: 200,
  color: 'lightgray',
  child: Center({
    // Centerは200x200まで拡張
    child: Container({
      width: 50,
      height: 50,
      color: 'blue'
    })
  })
})

Center({
  widthFactor: 2.0,
  heightFactor: 2.0,
  // Centerは100x100（子の2倍）
  child: Container({
    width: 50,
    height: 50,
    color: 'red'
  })
})
```


## 重要な注意事項

- Centerはデフォルトで可能な限り拡張するため、Stackや無限サイズコンテナでは注意が必要です
- widthFactorとheightFactorは0より大きい必要があります
- 複数のCenterをネストすることは一般的に不要です
- 複雑な配置ニーズには、Alignウィジェットを直接使用してください
- 子要素がなくファクターがnullの場合、サイズが0になる可能性があります

## 関連ウィジェット

- **Align**: より多くの配置オプションを提供する親ウィジェット
- **Container**: alignmentプロパティで中央配置可能
- **Positioned**: Stack内での位置指定
- **Padding**: マージンを含めた中央配置が必要な場合
- **Column/Row**: mainAxisAlignmentとcrossAxisAlignmentで配置
