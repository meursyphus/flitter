# 状態管理

## 概要

FlitterのProviderは、ReactのContext APIに似た概念で、ウィジェットツリー全体で効率的な状態管理と共有を可能にします。ProviderはInheritedWidgetをベースにしており、ウィジェットツリーのどこからでも状態にアクセスできます。

```
┌─────────────────────────────────────────────┐
│              Provider Pattern                │
│                                             │
│   ┌─────────────────────────────────┐       │
│   │     ChangeNotifierProvider      │       │
│   │   (React's Context.Provider)    │       │
│   └──────────────┬──────────────────┘       │
│                  │                           │
│                  ▼                           │
│   ┌─────────────────────────────────┐       │
│   │         Widget Tree             │       │
│   │  ┌─────────────────────────┐   │       │
│   │  │    Provider.of(context)  │   │       │
│   │  │  (React's useContext)    │   │       │
│   │  └─────────────────────────┘   │       │
│   └─────────────────────────────────┘       │
└─────────────────────────────────────────────┘
```

## なぜProviderが必要なのか？

複雑なアプリケーションでは、以下のような状況がよく発生します：

- **深いウィジェットツリー**: データを複数のレベルを通して渡す必要があるProp drillingの問題
- **状態の共有**: 複数のウィジェットが同じ状態を使用し、更新する必要がある場合
- **グローバル状態**: ユーザー認証情報やテーマ設定など、アプリ全体で使用されるデータ
- **パフォーマンス最適化**: 状態が変更されたときに必要なウィジェットのみを再構築してパフォーマンスを向上

## コアコンセプト

### 1. Providerキーの定義

Providerを識別するためのユニークなキーを定義します：

```typescript
const COUNTER_KEY = Symbol('CounterProvider');
```

### 2. Providerで値を提供

`Provider`を使用してウィジェットツリーに値を提供します：

```typescript
// シンプルな値の提供
Provider({
  value: { count: 0 },
  providerKey: COUNTER_KEY,
  child: MyApp({})
})

// Provider関数でラップ
function CounterProvider({ child }: { child: Widget }) {
  return Provider({
    value: { count: 0, increment: () => {} },
    providerKey: COUNTER_KEY,
    child
  });
}
```

### 3. Provider.ofで値を取得

`Provider.of`を使用してProviderの値にアクセスします：

```typescript
// Provider.ofの使用
const counter = Provider.of(COUNTER_KEY, context);

// ウィジェット内での使用
class MyWidget extends StatelessWidget {
  build(context: BuildContext): Widget {
    const counter = Provider.of(COUNTER_KEY, context) as CounterData;
    
    return Text(`Count: ${counter.count}`);
  }
}

// Provider関数にofメソッドを追加（便利機能）
function CounterProvider({ child }: { child: Widget }) {
  return Provider({
    value: { count: 0 },
    providerKey: COUNTER_KEY,
    child
  });
}

CounterProvider.of = (context: BuildContext) => {
  return Provider.of(COUNTER_KEY, context) as CounterData;
};
```

### 複数のProviderの使用

複数のProviderをネストできます：

```typescript
const THEME_KEY = Symbol('ThemeProvider');
const USER_KEY = Symbol('UserProvider');
const CART_KEY = Symbol('CartProvider');

function AppProviders({ child }: { child: Widget }) {
  return Provider({
    value: new ThemeController(),
    providerKey: THEME_KEY,
    child: Provider({
      value: new UserController(),
      providerKey: USER_KEY,
      child: Provider({
        value: new CartController(),
        providerKey: CART_KEY,
        child
      })
    })
  });
}

// 使用例
AppProviders({
  child: MyApp({})
})
```

## 実践例

### 1. シンプルなカウンターの例

```typescript
const COUNTER_KEY = Symbol('CounterProvider');

interface CounterData {
  count: number;
}

// StatefulWidgetでの状態管理
class CounterApp extends StatefulWidget {
  createState() {
    return new CounterAppState();
  }
}

class CounterAppState extends State<CounterApp> {
  count = 0;
  
  increment() {
    this.setState(() => {
      this.count++;
    });
  }
  
  build(context: BuildContext): Widget {
    return Provider({
      value: { count: this.count },
      providerKey: COUNTER_KEY,
      child: Column({
        mainAxisAlignment: MainAxisAlignment.center,
        children: [
          CounterDisplay({}),
          SizedBox({ height: 20 }),
          GestureDetector({
            onClick: () => this.increment(),
            child: Container({
              padding: EdgeInsets.all(12),
              decoration: new BoxDecoration({
                color: '#3b82f6',
                borderRadius: BorderRadius.circular(8)
              }),
              child: Text("増加", {
                style: new TextStyle({
                  color: '#ffffff'
                })
              })
            })
          })
        ]
      })
    });
  }
}

// Providerから値を読み取る別のウィジェット
class CounterDisplay extends StatelessWidget {
  build(context: BuildContext): Widget {
    const data = Provider.of(COUNTER_KEY, context) as CounterData;
    
    return Text(`Count: ${data.count}`, {
      style: new TextStyle({
        fontSize: 24,
        color: '#ffffff'
      })
    });
  }
}
```

### 2. Provider関数パターン

```typescript
const THEME_KEY = Symbol('ThemeProvider');

interface ThemeData {
  isDarkMode: boolean;
  primaryColor: string;
}

// Provider関数の定義
function ThemeProvider({ child }: { child: Widget }) {
  return Provider({
    value: {
      isDarkMode: true,
      primaryColor: '#3b82f6'
    },
    providerKey: THEME_KEY,
    child
  });
}

// ofメソッドの追加
ThemeProvider.of = (context: BuildContext) => {
  return Provider.of(THEME_KEY, context) as ThemeData;
};

// 使用例
class ThemedApp extends StatelessWidget {
  build(context: BuildContext): Widget {
    return ThemeProvider({
      child: MainContent({})
    });
  }
}

class MainContent extends StatelessWidget {
  build(context: BuildContext): Widget {
    const theme = ThemeProvider.of(context);
    
    return Container({
      color: theme.isDarkMode ? '#1a1a1a' : '#ffffff',
      child: Text("テーマアプリケーションの例", {
        style: new TextStyle({
          color: theme.primaryColor,
          fontSize: 24
        })
      })
    });
  }
}
```

### 3. 複雑な状態管理の例

```typescript
const APP_STATE_KEY = Symbol('AppStateProvider');

class AppController {
  user: User | null = null;
  isDarkMode = false;
  items: Item[] = [];
  
  constructor() {
    // 初期化ロジック
  }
  
  login(email: string, password: string) {
    // ログインロジック
    this.user = new User("1", "User", email);
  }
  
  logout() {
    this.user = null;
  }
  
  toggleTheme() {
    this.isDarkMode = !this.isDarkMode;
  }
  
  addItem(item: Item) {
    this.items.push(item);
  }
}

// Provider関数
function AppStateProvider({ child }: { child: Widget }) {
  return Provider({
    value: new AppController(),
    providerKey: APP_STATE_KEY,
    child
  });
}

AppStateProvider.of = (context: BuildContext) => {
  return Provider.of(APP_STATE_KEY, context) as AppController;
};

// StatefulWidgetでの使用
class MyApp extends StatefulWidget {
  createState() {
    return new MyAppState();
  }
}

class MyAppState extends State<MyApp> {
  controller = new AppController();
  
  build(context: BuildContext): Widget {
    return Provider({
      value: this.controller,
      providerKey: APP_STATE_KEY,
      child: AppContent({
        onLogin: (email: string, password: string) => {
          this.setState(() => {
            this.controller.login(email, password);
          });
        },
        onThemeToggle: () => {
          this.setState(() => {
            this.controller.toggleTheme();
          });
        }
      })
    });
  }
}
```

## 重要な注意事項

### 1. Providerのスコープとアクセシビリティ

Providerはウィジェットツリーで提供された位置より下からのみアクセス可能です：

```typescript
// ❌ 悪い例: Providerが提供される前にアクセスしようとしている
class BadExample extends StatelessWidget {
  build(context: BuildContext): Widget {
    const data = Provider.of(MY_KEY, context); // エラー！
    
    return Provider({
      value: { count: 0 },
      providerKey: MY_KEY,
      child: Text(`Count: ${data.count}`)
    });
  }
}

// ✅ 良い例: Providerの下からアクセス
class GoodExample extends StatelessWidget {
  build(context: BuildContext): Widget {
    return Provider({
      value: { count: 0 },
      providerKey: MY_KEY,
      child: ChildWidget({})  // ここからアクセス可能
    });
  }
}

class ChildWidget extends StatelessWidget {
  build(context: BuildContext): Widget {
    const data = Provider.of(MY_KEY, context);
    return Text(`Count: ${data.count}`);
  }
}
```

### 2. 型安全性の維持

Providerを使用する際は、型キャストを明示的に行う必要があります：

```typescript
// 型定義
interface UserData {
  id: string;
  name: string;
  email: string;
}

const USER_KEY = Symbol('UserProvider');

// Provider関数でジェネリクスを使用
function UserProvider({ child }: { child: Widget }) {
  const userData: UserData = {
    id: '1',
    name: 'ユーザー',
    email: 'user@example.com'
  };
  
  return Provider({
    value: userData,
    providerKey: USER_KEY,
    child
  });
}

// 型安全なofメソッド
UserProvider.of = (context: BuildContext): UserData => {
  return Provider.of(USER_KEY, context) as UserData;
};

// 使用
const user = UserProvider.of(context);
console.log(user.name); // 型安全！
```

### 3. Providerの値の動的更新

Providerの値を更新するには、StatefulWidgetと一緒に使用する必要があります：

```typescript
const SETTINGS_KEY = Symbol('SettingsProvider');

interface Settings {
  fontSize: number;
  isDarkMode: boolean;
}

class SettingsWidget extends StatefulWidget {
  createState() {
    return new SettingsWidgetState();
  }
}

class SettingsWidgetState extends State<SettingsWidget> {
  settings: Settings = {
    fontSize: 16,
    isDarkMode: false
  };
  
  updateFontSize(size: number) {
    this.setState(() => {
      this.settings = { ...this.settings, fontSize: size };
    });
  }
  
  toggleDarkMode() {
    this.setState(() => {
      this.settings = { 
        ...this.settings, 
        isDarkMode: !this.settings.isDarkMode 
      };
    });
  }
  
  build(context: BuildContext): Widget {
    return Provider({
      value: this.settings,
      providerKey: SETTINGS_KEY,
      child: SettingsContent({
        onFontSizeChange: (size) => this.updateFontSize(size),
        onThemeToggle: () => this.toggleDarkMode()
      })
    });
  }
}
```
