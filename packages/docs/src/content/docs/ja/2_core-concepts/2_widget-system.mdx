# ウィジェットシステム

## 概要

FlitterのWidgetはUIを構成する基本単位です。Flutterと同様に、画面に表示されるすべての要素はウィジェットで構成されています。ボタン、テキスト、レイアウト、さらにはアプリ自体もすべてウィジェットです。

## なぜ重要なのか？

ウィジェットシステムを理解することで以下が可能になります：

- **再利用可能なコンポーネント**: 一度作成したウィジェットをどこでも再利用
- **コンポーザブルな構造**: 小さなウィジェットを組み合わせて複雑なUIを構築
- **明確な状態管理**: StatelessWidgetとStatefulWidgetで状態管理パターンを区別
- **予測可能な動作**: ウィジェットライフサイクルによる体系的な開発

## コアコンセプト

### ウィジェットタイプ

Flitterには3つの主要なウィジェットタイプがあります：

1. **StatelessWidget**: 状態を持たない静的なウィジェット
2. **StatefulWidget**: 状態を持つ動的なウィジェット
3. **RenderObjectWidget**: 直接的なレンダリングを担当する低レベルウィジェット

### StatelessWidget

一度作成されると変更されない、状態を持たないウィジェット：

```typescript
import { StatelessWidget, Text, Container, EdgeInsets, Colors, type BuildContext, type Widget } from '@meursyphus/flitter';

class Greeting extends StatelessWidget {
  constructor(private props: { name: string }) {
    super();
  }

  build(context: BuildContext): Widget {
    return Container({
      padding: EdgeInsets.all(16),
      color: Colors.blue.shade100,
      child: Text(`Hello, ${this.props.name}!`)
    });
  }
}

// ファクトリー関数としてエクスポート
export default function GreetingWidget(props: { name: string }): Widget {
  return new Greeting(props);
}
```

### StatefulWidget

状態を持ち、状態が変更されると自動的にUIが更新されるウィジェット：

```typescript
import { 
  StatefulWidget, 
  State, 
  Container, 
  Column, 
  Text, 
  GestureDetector,
  EdgeInsets,
  Colors,
  TextStyle,
  type BuildContext,
  type Widget 
} from '@meursyphus/flitter';

class Counter extends StatefulWidget {
  createState(): State<Counter> {
    return new CounterState();
  }
}

class CounterState extends State<Counter> {
  count = 0;

  build(context: BuildContext): Widget {
    return Column({
      children: [
        Text(`Count: ${this.count}`, {
          style: TextStyle({ fontSize: 24 })
        }),
        GestureDetector({
          onClick: () => {
            this.setState(() => {
              this.count++;
            });
          },
          child: Container({
            margin: EdgeInsets.only({ top: 16 }),
            padding: EdgeInsets.symmetric({ horizontal: 24, vertical: 12 }),
            color: Colors.blue,
            child: Text("増加", {
              style: TextStyle({ color: Colors.white })
            })
          })
        })
      ]
    });
  }
}

// ファクトリー関数としてエクスポート
export default function CounterWidget(): Widget {
  return new Counter();
}
```

### ウィジェットライフサイクル

#### StatefulWidgetライフサイクル

```typescript
class MyWidgetState extends State<MyWidget> {
  // 1. ステートオブジェクトが作成されるときに一度だけ呼ばれる
  initState(): void {
    super.initState();
    console.log("ウィジェットが初期化されました");
    // アニメーションコントローラーやストリームサブスクリプションなどを初期化
  }

  // 2. 親ウィジェットが変更され、このウィジェットを更新する必要があるとき
  didUpdateWidget(oldWidget: MyWidget): void {
    super.didUpdateWidget(oldWidget);
    console.log("ウィジェット設定が変更されました");
    // プロパティの変更に基づいて状態を更新
  }

  // 3. setStateが呼ばれるたびに実行される
  build(context: BuildContext): Widget {
    console.log("UIをレンダリング中");
    return Container({ /* ... */ });
  }

  // 4. ステートオブジェクトが削除されるとき
  dispose(): void {
    console.log("ウィジェットが破棄されました");
    // アニメーションコントローラーやストリームサブスクリプションなどをクリーンアップ
    super.dispose();
  }
}
```

### 2. 複雑な状態を持つStatefulWidget

```typescript
class TodoApp extends StatefulWidget {
  createState(): State<TodoApp> {
    return new TodoAppState();
  }
}

class TodoAppState extends State<TodoApp> {
  todos: Array<{ id: number; text: string; done: boolean }> = [];
  nextId = 1;
  inputText = "";

  addTodo(text: string): void {
    if (text.trim() === "") return;
    
    this.setState(() => {
      this.todos.push({
        id: this.nextId++,
        text: text,
        done: false
      });
      this.inputText = "";
    });
  }

  toggleTodo(id: number): void {
    this.setState(() => {
      const todo = this.todos.find(t => t.id === id);
      if (todo) {
        todo.done = !todo.done;
      }
    });
  }

  deleteTodo(id: number): void {
    this.setState(() => {
      this.todos = this.todos.filter(t => t.id !== id);
    });
  }

  build(context: BuildContext): Widget {
    return Container({
      padding: EdgeInsets.all(16),
      child: Column({
        children: [
          Text("Todoリスト", {
            style: TextStyle({ 
              fontSize: 24, 
              fontWeight: FontWeight.bold,
              color: Colors.white 
            })
          }),
          SizedBox({ height: 16 }),
          
          // 入力フィールド（実際にはTextFieldウィジェットを使用）
          Container({
            padding: EdgeInsets.all(12),
            color: Colors.grey.shade800,
            child: Text(this.inputText || "新しいTodoを入力...", {
              style: TextStyle({ color: Colors.grey.shade400 })
            })
          }),
          
          SizedBox({ height: 16 }),
          
          // Todoリスト
          ...this.todos.map(todo => 
            Container({
              margin: EdgeInsets.only({ bottom: 8 }),
              padding: EdgeInsets.all(12),
              color: todo.done ? Colors.grey.shade800 : Colors.grey.shade700,
              child: Row({
                children: [
                  GestureDetector({
                    onClick: () => this.toggleTodo(todo.id),
                    child: Icon(
                      todo.done ? Icons.check_box : Icons.check_box_outline_blank,
                      { color: Colors.white }
                    )
                  }),
                  SizedBox({ width: 12 }),
                  Expanded({
                    child: Text(todo.text, {
                      style: TextStyle({
                        color: Colors.white,
                        decoration: todo.done ? TextDecoration.lineThrough : TextDecoration.none
                      })
                    })
                  }),
                  GestureDetector({
                    onClick: () => this.deleteTodo(todo.id),
                    child: Icon(Icons.delete, { color: Colors.red.shade400 })
                  })
                ]
              })
            })
          )
        ]
      })
    });
  }
}

export default function TodoAppWidget(): Widget {
  return new TodoApp();
}
```

### 3. ライフサイクル使用例

```typescript
class TimerWidget extends StatefulWidget {
  constructor(private props: { duration: number }) {
    super();
  }

  createState(): State<TimerWidget> {
    return new TimerWidgetState();
  }
}

class TimerWidgetState extends State<TimerWidget> {
  timeLeft = 0;
  timer?: NodeJS.Timeout;

  initState(): void {
    super.initState();
    this.timeLeft = this.widget.props.duration;
    this.startTimer();
  }

  startTimer(): void {
    this.timer = setInterval(() => {
      this.setState(() => {
        if (this.timeLeft > 0) {
          this.timeLeft--;
        } else {
          this.stopTimer();
        }
      });
    }, 1000);
  }

  stopTimer(): void {
    if (this.timer) {
      clearInterval(this.timer);
      this.timer = undefined;
    }
  }

  didUpdateWidget(oldWidget: TimerWidget): void {
    super.didUpdateWidget(oldWidget);
    if (oldWidget.props.duration !== this.widget.props.duration) {
      this.stopTimer();
      this.timeLeft = this.widget.props.duration;
      this.startTimer();
    }
  }

  dispose(): void {
    this.stopTimer();
    super.dispose();
  }

  build(context: BuildContext): Widget {
    const minutes = Math.floor(this.timeLeft / 60);
    const seconds = this.timeLeft % 60;
    
    return Container({
      padding: EdgeInsets.all(24),
      color: this.timeLeft === 0 ? Colors.red.shade900 : Colors.grey.shade900,
      child: Column({
        children: [
          Text("タイマー", {
            style: TextStyle({ 
              fontSize: 20, 
              color: Colors.white 
            })
          }),
          SizedBox({ height: 16 }),
          Text(
            `${minutes.toString().padStart(2, '0')}:${seconds.toString().padStart(2, '0')}`,
            {
              style: TextStyle({ 
                fontSize: 48, 
                fontWeight: FontWeight.bold,
                color: this.timeLeft === 0 ? Colors.red : Colors.white 
              })
            }
          ),
          if (this.timeLeft === 0)
            Text("時間切れ！", {
              style: TextStyle({ 
                fontSize: 24, 
                color: Colors.red.shade400 
              })
            })
        ]
      })
    });
  }
}

export default function TimerWidgetExample(props: { duration: number }): Widget {
  return new TimerWidget(props);
}
```

## 重要な注意事項

### 1. 状態管理のルール

```typescript
// ❌ 間違い - setStateなしでの状態変更
this.count++;  // UIは更新されません！

// ✅ 正しい - setStateを使用
this.setState(() => {
  this.count++;
});

// ❌ 間違い - setState外での状態変更
this.items.push(newItem);
this.setState(() => {});  // 空のsetState

// ✅ 正しい - すべての変更をsetState内で
this.setState(() => {
  this.items.push(newItem);
});
```

### 2. ウィジェットの再利用

```typescript
// ❌ 間違い - buildメソッド内でウィジェットを作成
build(context: BuildContext): Widget {
  // 毎回新しいウィジェットインスタンスを作成（非効率）
  const button = new MyButton();
  return Container({ child: button });
}

// ✅ 正しい - ウィジェットを適切に分離
build(context: BuildContext): Widget {
  return Container({
    child: MyButton({ onClick: this.handleClick })
  });
}
```

### 3. プロパティ vs 状態

- **プロパティ**: 親から渡される不変のデータ
- **状態**: ウィジェット内で管理される可変のデータ

```typescript
class MyWidget extends StatefulWidget {
  constructor(private props: { initialCount: number }) {
    super();
  }

  createState(): State<MyWidget> {
    return new MyWidgetState();
  }
}

class MyWidgetState extends State<MyWidget> {
  // プロパティは初期値としてのみ使用
  count = this.widget.props.initialCount;

  build(context: BuildContext): Widget {
    // プロパティは直接読み取ることができる
    return Text(`初期値: ${this.widget.props.initialCount}, 現在値: ${this.count}`);
  }
}
```
