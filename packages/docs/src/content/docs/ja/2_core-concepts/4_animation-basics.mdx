# アニメーションの基礎

## 概要

FlitterはFlutterと同じ強力なアニメーションシステムを提供します。AnimationController、Tween、Curveを組み合わせることで、スムーズで自然なアニメーションを簡単に実装できます。

## なぜアニメーションが重要なのか？

よくデザインされたアニメーションはユーザーエクスペリエンスを大幅に向上させます：

- **視覚的フィードバック**: ユーザーアクションに即座に応答を提供
- **状態の遷移**: 画面や要素の変化をスムーズに表現
- **注意の誘導**: 重要な情報や変化にユーザーの焦点を引きつける
- **ブランドアイデンティティ**: ユニークなアニメーションでアプリの個性を表現
- **認知的連続性**: 要素の移動や変形を自然に示す

## コアコンセプト

### 1. AnimationController

アニメーションの再生、停止、繰り返しなどを制御するコアクラス：

```typescript
class MyWidgetState extends State<MyWidget> {
  controller!: AnimationController;
  
  initState(context: BuildContext) {
    super.initState(context);
    // durationはミリ秒で指定
    this.controller = new AnimationController({
      duration: 1000  // 1秒
    });
  }
  
  dispose() {
    this.controller.dispose();
    super.dispose();
  }
}
```

### 2. Tween

開始値と終了値の間の補間を定義：

```typescript
// 数値のTween
const sizeTween = new Tween({
  begin: 50,
  end: 200
});

// 色のTween
const colorTween = new ColorTween({
  begin: '#3b82f6',
  end: '#ef4444'
});

// Offset Tween（位置の移動）
const positionTween = new Tween({
  begin: new Offset(0, 0),
  end: new Offset(100, 100)
});
```

### 3. Animation

TweenとAnimationControllerを接続して実際のアニメーション値を生成：

```typescript
const animation = sizeTween.animated(this.controller);

// CurvedAnimationでイージング効果を適用
const curvedAnimation = new CurvedAnimation({
  parent: this.controller,
  curve: Curves.easeInOut
});

const animation = sizeTween.animated(curvedAnimation);
```

### 4. アニメーションリスナー

アニメーション値が変化するたびにウィジェットを再構築するリスナーを追加：

```typescript
class MyWidgetState extends State<MyWidget> {
  controller!: AnimationController;
  animation!: Animation<number>;
  
  initState(context: BuildContext) {
    super.initState(context);
    this.controller = new AnimationController({ duration: 1000 });
    this.animation = new Tween({ begin: 0, end: 100 }).animated(this.controller);
    
    // リスナーを追加 - アニメーション値が変化するたびにsetStateを呼び出す
    this.controller.addListener(() => {
      this.setState();
    });
  }
  
  build(context: BuildContext): Widget {
    return Container({
      width: this.animation.value,
      height: this.animation.value,
      color: '#3b82f6'
    });
  }
}
```

### アニメーションコントロール

```typescript
// アニメーションを開始
this.controller.forward();

// アニメーションを逆再生
this.controller.reverse();

// アニメーションを繰り返し
this.controller.repeat();

// 特定の値にアニメーション
this.controller.animateTo(0.5);

// アニメーションを停止
this.controller.stop();

// アニメーションをリセット
this.controller.reset();
```

## 実践例

### 1. パルスアニメーション

```typescript
class PulseAnimation extends StatefulWidget {
  createState() {
    return new PulseAnimationState();
  }
}

class PulseAnimationState extends State<PulseAnimation> {
  controller!: AnimationController;
  animation!: Animation<number>;
  
  initState(context: BuildContext) {
    super.initState(context);
    
    this.controller = new AnimationController({
      duration: 1000  // 1秒
    });
    
    this.animation = new Tween({
      begin: 1.0,
      end: 1.2
    }).animated(new CurvedAnimation({
      parent: this.controller,
      curve: Curves.easeInOut
    }));
    
    this.controller.repeat({ reverse: true });
  }
  
  dispose() {
    this.controller.dispose();
    super.dispose();
  }
  
  build(context: BuildContext): Widget {
    return Transform.scale({
      scale: this.animation.value,
      child: Container({
        width: 100,
        height: 100,
        decoration: new BoxDecoration({
          color: '#3b82f6',
          shape: 'circle'
        })
      })
    });
  }
}
```

### 2. シーケンシャルアニメーション

```typescript
class SequentialAnimation extends StatefulWidget {
  createState() {
    return new SequentialAnimationState();
  }
}

class SequentialAnimationState extends State<SequentialAnimation> {
  controller!: AnimationController;
  slideAnimation!: Animation<Offset>;
  fadeAnimation!: Animation<number>;
  
  initState(context: BuildContext) {
    super.initState(context);
    
    this.controller = new AnimationController({
      duration: 2000  // 2秒
    });
    
    // スライドアニメーション
    this.slideAnimation = new Tween({
      begin: new Offset(-1, 0),
      end: new Offset(0, 0)
    }).animated(new CurvedAnimation({
      parent: this.controller,
      curve: Curves.easeOut
    }));
    
    // フェードアニメーション
    this.fadeAnimation = new Tween({
      begin: 0.0,
      end: 1.0
    }).animated(new CurvedAnimation({
      parent: this.controller,
      curve: Curves.easeIn
    }));
    
    // アニメーションリスナーを追加
    this.controller.addListener(() => {
      this.setState();
    });
    
    this.controller.forward();
  }
  
  dispose() {
    this.controller.dispose();
    super.dispose();
  }
  
  build(context: BuildContext): Widget {
    return Transform.translate({
      offset: new Offset(
        this.slideAnimation.value.dx * 200,  // x軸の移動
        this.slideAnimation.value.dy * 0     // y軸の移動
      ),
      child: Opacity({
        opacity: this.fadeAnimation.value,
        child: Container({
          width: 200,
          height: 100,
          color: '#10b981',
          child: Center({
            child: Text("シーケンシャルアニメーション", {
              style: new TextStyle({
                color: '#ffffff',
                fontSize: 18
              })
            })
          })
        })
      })
    });
  }
}
```

### 3. カスタムカーブアニメーション

```typescript
class CustomCurveAnimation extends StatefulWidget {
  createState() {
    return new CustomCurveAnimationState();
  }
}

class CustomCurveAnimationState extends State<CustomCurveAnimation> {
  controller!: AnimationController;
  bounceAnimation!: Animation<number>;
  
  initState(context: BuildContext) {
    super.initState(context);
    
    this.controller = new AnimationController({
      duration: 1500  // 1.5秒
    });
    
    // バウンス効果のためのカスタムカーブ
    this.bounceAnimation = new Tween({
      begin: 0,
      end: 300
    }).animated(new CurvedAnimation({
      parent: this.controller,
      curve: Curves.bounceOut
    }));
    
    // アニメーションリスナーを追加
    this.controller.addListener(() => {
      this.setState();
    });
    
    this.controller.forward();
  }
  
  dispose() {
    this.controller.dispose();
    super.dispose();
  }
  
  build(context: BuildContext): Widget {
    return Transform.translate({
      offset: new Offset(this.bounceAnimation.value, 0),
      child: Container({
        width: 50,
        height: 50,
        decoration: new BoxDecoration({
          color: '#10b981',
          shape: 'circle'
        })
      })
    });
  }
}
```

## 重要な注意事項

### 1. パフォーマンス最適化

アニメーションはパフォーマンスに影響を与える可能性があるため、最適化が重要です：

```typescript
// ❌ 悪い例: ウィジェットツリー全体を再構築
class MyWidgetState extends State<MyWidget> {
  build(context: BuildContext): Widget {
    return Column({
      children: [
        ComplexWidget({}),  // 毎回再作成される
        Container({
          width: this.animation.value,
          height: 100
        })
      ]
    });
  }
}

// ✅ 良い例: アニメーションに影響を受ける部分のみを分離
class MyWidgetState extends State<MyWidget> {
  complexWidget = ComplexWidget({});  // 一度だけ作成
  
  build(context: BuildContext): Widget {
    return Column({
      children: [
        this.complexWidget,  // 再利用
        Container({
          width: this.animation.value,
          height: 100
        })
      ]
    });
  }
}
```

### 2. メモリ管理

AnimationControllerは必ずdisposeする必要があります：

```typescript
dispose() {
  this.controller.dispose();  // 必須！
  super.dispose();
}
```

### 3. vsyncの設定

SingleTickerProviderStateMixinまたはTickerProviderStateMixinを使用する必要があります：

```typescript
// Flitterはmixinを使用しません
// AnimationControllerを直接作成して管理します
class MyState extends State<MyWidget> {
  controller!: AnimationController;
  
  initState(context: BuildContext) {
    super.initState(context);
    this.controller = new AnimationController({
      duration: 1000
    });
  }
  
  dispose() {
    this.controller.dispose();
    super.dispose();
  }
}
```

## 組み込みアニメーションウィジェット

Flitterはよく使用されるアニメーション用の組み込みウィジェットを提供しています：

- **AnimatedContainer**: プロパティが変更されたときの自動アニメーション
- **AnimatedOpacity**: 不透明度のアニメーション
- **AnimatedPositioned**: Stack内での位置アニメーション
- **AnimatedScale**: サイズアニメーション
- **AnimatedRotation**: 回転アニメーション
- **AnimatedSlide**: スライドアニメーション

これらのウィジェットはAnimationControllerなしでシンプルなアニメーションを可能にします。
