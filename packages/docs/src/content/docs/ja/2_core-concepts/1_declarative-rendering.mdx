# 宣言的レンダリング

## 概要

FlitterはFlutterと同様に**宣言的**レンダリングアプローチを採用しています。これは「画面がどのように見えるべきか」を宣言すると、Flitterが自動的にレンダリングを処理することを意味します。これは従来の命令的手法とは根本的に異なるアプローチです。

## なぜ重要なのか？

宣言的プログラミングは以下の利点を提供します：

- **コードの可読性向上**：UIがどのように表示されるかを直感的に理解できる
- **バグの削減**：状態管理が簡素化され、予測可能な動作を実現
- **メンテナンスの容易さ**：複雑なDOM操作なしにUIを更新
- **生産性の向上**：より少ないコードで複雑なUIを実装

## コアコンセプト

### 命令的 vs 宣言的

#### 命令的アプローチ（D3.jsの例）
命令的アプローチでは、各ステップで何をすべきかを指定します：

```javascript
// D3.jsでテキストを中央揃えにする
const svg = d3.select("svg");
const width = 400;
const height = 200;

// 1. テキスト要素を作成
const text = svg.append("text")
  .text("Hello, World!");

// 2. テキストサイズを測定
const bbox = text.node().getBBox();

// 3. 中心位置を計算
const x = (width - bbox.width) / 2;
const y = (height + bbox.height) / 2;

// 4. 位置を設定
text.attr("x", x)
    .attr("y", y);

// 状態が変更されたときは、すべての計算をやり直す必要がある
function updateText(newText) {
  text.text(newText);
  const newBbox = text.node().getBBox();
  const newX = (width - newBbox.width) / 2;
  const newY = (height + newBbox.height) / 2;
  text.attr("x", newX).attr("y", newY);
}
```

#### 宣言的アプローチ（Flitterの例）
宣言的アプローチでは、望む結果だけを宣言します：

```typescript
// Flitterでテキストを中央揃えにする
Center({
  child: Text("Hello, World!")
})

// 状態が変更されたときは、宣言を変更するだけ
Center({
  child: Text(isJapanese ? "こんにちは！" : "Hello, World!")
})
```

### 宣言的レンダリングの仕組み

1. **状態を定義**：アプリケーションの現在の状態を定義
2. **UIを宣言**：状態に基づいてUIがどのように見えるべきかを宣言
3. **自動更新**：状態が変更されると、FlitterがUIを自動的に更新

```typescript
class _CounterWidget extends StatefulWidget {
  createState() {
    return new CounterWidgetState();
  }
}

class CounterWidgetState extends State<_CounterWidget> {
  count = 0;  // 状態定義

  build(context: BuildContext): Widget {
    // UI宣言 - UIはcount状態によって決定される
    return Column({
      children: [
        Text(`現在のカウント: ${this.count}`),
        GestureDetector({
          onClick: () => {
            this.setState(() => {
              this.count++;  // 状態変更時に自動再レンダリング
            });
          },
          child: Container({
            padding: EdgeInsets.all(8),
            color: Colors.blue,
            child: Text("増加", { style: TextStyle({ color: Colors.white }) })
          })
        })
      ]
    });
  }
}

// ファクトリー関数としてエクスポート
export default function CounterWidget(): Widget {
  return new _CounterWidget();
}
```

## 実践例

### 1. 条件付きレンダリング

宣言的アプローチでは、条件文を使用して異なるUIを簡単に表示できます：

```typescript
class ConditionalExample extends StatefulWidget {
  createState() {
    return new ConditionalExampleState();
  }
}

class ConditionalExampleState extends State<ConditionalExample> {
  isLoggedIn = false;

  build(context: BuildContext): Widget {
    return Center({
      child: this.isLoggedIn 
        ? Column({
            children: [
              Text("ようこそ！"),
              GestureDetector({
                onClick: () => {
                  this.setState(() => {
                    this.isLoggedIn = false;
                  });
                },
                child: Text("ログアウト", { 
                  style: TextStyle({ color: Colors.red }) 
                })
              })
            ]
          })
        : GestureDetector({
            onClick: () => {
              this.setState(() => {
                this.isLoggedIn = true;
              });
            },
            child: Container({
              padding: EdgeInsets.all(12),
              color: Colors.blue,
              child: Text("ログイン", { 
                style: TextStyle({ color: Colors.white }) 
              })
            })
          })
    });
  }
}
```

### 2. リストレンダリング

配列データをUIに変換することも非常に直感的です：

```typescript
class TodoList extends StatefulWidget {
  createState() {
    return new TodoListState();
  }
}

class TodoListState extends State<TodoList> {
  todos = ["Flitterを学ぶ", "宣言的UIを理解する", "アプリを構築する"];

  build(context: BuildContext): Widget {
    return Column({
      children: [
        Text("Todoリスト", { 
          style: TextStyle({ fontSize: 20, fontWeight: FontWeight.bold }) 
        }),
        SizedBox({ height: 10 }),
        ...this.todos.map((todo, index) => 
          Container({
            padding: EdgeInsets.all(8),
            margin: EdgeInsets.only({ bottom: 4 }),
            color: Colors.grey.shade200,
            child: Row({
              children: [
                Text(`${index + 1}. ${todo}`),
                Spacer(),
                GestureDetector({
                  onClick: () => {
                    this.setState(() => {
                      this.todos.splice(index, 1);
                    });
                  },
                  child: Icon(Icons.delete, { color: Colors.red })
                })
              ]
            })
          })
        )
      ]
    });
  }
}
```

### 3. 複雑な状態管理

複数の状態が相互に関連している場合でも、宣言的に簡単に処理できます：

```typescript
class ShoppingCart extends StatefulWidget {
  createState() {
    return new ShoppingCartState();
  }
}

class ShoppingCartState extends State<ShoppingCart> {
  items = [
    { name: "リンゴ", price: 100, quantity: 0 },
    { name: "バナナ", price: 150, quantity: 0 },
    { name: "オレンジ", price: 200, quantity: 0 }
  ];

  get totalPrice() {
    return this.items.reduce((sum, item) => 
      sum + (item.price * item.quantity), 0
    );
  }

  build(context: BuildContext): Widget {
    return Column({
      children: [
        Text("ショッピングカート", { 
          style: TextStyle({ fontSize: 24, fontWeight: FontWeight.bold }) 
        }),
        SizedBox({ height: 20 }),
        ...this.items.map(item => 
          Row({
            children: [
              Text(item.name),
              Spacer(),
              Text(`¥${item.price}`),
              SizedBox({ width: 20 }),
              Row({
                children: [
                  GestureDetector({
                    onClick: () => {
                      this.setState(() => {
                        if (item.quantity > 0) item.quantity--;
                      });
                    },
                    child: Icon(Icons.remove_circle)
                  }),
                  Padding({
                    padding: EdgeInsets.symmetric({ horizontal: 10 }),
                    child: Text(`${item.quantity}`)
                  }),
                  GestureDetector({
                    onClick: () => {
                      this.setState(() => {
                        item.quantity++;
                      });
                    },
                    child: Icon(Icons.add_circle)
                  })
                ]
              })
            ]
          })
        ),
        Divider(),
        Text(`合計: ¥${this.totalPrice}`, {
          style: TextStyle({ fontSize: 18, fontWeight: FontWeight.bold })
        })
      ]
    });
  }
}
```

## 重要な注意事項

1. **不変性を保つ**：状態を直接変更せず、常に`setState`を使用する
2. **純粋関数**：`build`メソッドは副作用のない純粋関数であるべき
3. **パフォーマンスの考慮**：不要な再レンダリングを避けるため、ウィジェットを適切に分離する

```typescript
// ❌ 間違い - 状態の直接変更
this.count++;  // UIは更新されません

// ✅ 正しい - setStateを使用
this.setState(() => {
  this.count++;
});

// ❌ 間違い - buildメソッド内での副作用
build(context: BuildContext): Widget {
  // API呼び出しなどの副作用はinitStateで行うべき
  fetch('/api/data');  // 間違い！
  return Text("...");
}

// ✅ 正しい - initStateで副作用を処理
initState() {
  super.initState();
  fetch('/api/data').then(data => {
    this.setState(() => {
      this.data = data;
    });
  });
}
```
