## headless-chartとは？

`@meursyphus/headless-chart`はUIを持たないチャートライブラリです。データとロジックのみを提供し、実際のUIは開発者がFlitterウィジェットを使用して直接実装します。これにより、完全にカスタマイズ可能なチャートを作成できます。

- **GitHub**: [https://github.com/meursyphus/headless-chart](https://github.com/meursyphus/headless-chart)
- **インストール**: `npm install @meursyphus/headless-chart`

## コアコンセプト

headless-chartのコアは**データ構造**と**カスタムレンダリング関数**で構成されています：

- **データ構造**: ラベルとデータセットで構成
- **カスタム関数**: チャートの各部分（軸、目盛り、バー、ラインなど）をFlitterウィジェットとしてレンダリング

### 主要なカスタマイズポイント

1. **レイアウトのカスタマイズ**
   - `custom.layout`関数でチャート全体の構造を定義
   - StackとPositionedで自由な要素配置

2. **軸ラベルのスタイリング**
   - `custom.xAxisLabel`と`custom.yAxisLabel`でテキストスタイルを適用
   - フォント、サイズ、色を自由に設定

3. **バーのデザイン**
   - `custom.bar`関数でContainerとBoxDecorationを活用
   - 色、角丸、シャドウなどを自由にデザイン

4. **凡例のカスタマイズ**
   - チャート内にフローティングボックスとして凡例を配置
   - BoxShadowで深みを追加

### バーチャート実装コード例

```javascript
const Bar = (...[{ legend, value }, { data }]) => {
  const index = data.datasets.findIndex((d) => d.legend === legend);
  const backgroundColor = backgroundColors[index];
  
  return Container({
    width: Infinity,
    height: 14,
    alignment: Alignment.centerRight,
    decoration: new BoxDecoration({
      color: backgroundColor,
      borderRadius: BorderRadius.only({
        topRight: Radius.circular(7),
        bottomRight: Radius.circular(7),
      }),
    }),
    child: FractionalTranslation({
      translation: { x: 1, y: 0 },
      child: Padding({
        padding: EdgeInsets.only({ left: 6 }),
        child: Text(value.toLocaleString("ko-KR").replace(",", " "), {
          style: new TextStyle({
            fontFamily: "Noto Sans JP",
            fontSize: 12,
            fontWeight: "bold",
            color: "#111827",
          }),
        }),
      }),
    }),
  });
};
```

このコードでは：
- FlitterのContainerとBoxDecorationを使用してバーを描画
- FractionalTranslationでバーの末端に値テキストを配置
- 各データセットに異なる色を適用

### ラインチャートのカスタマイズ

1. **CustomPaintでラインを描画**
   ```javascript
   custom.line: (...[{ values, index }, { scale }]) => {
     return CustomPaint({
       painter: {
         svg: {
           paint({ line, point }, { height, width }) {
             const linePath = new Path();
             const pointPath = new Path();
             
             // データポイントを計算
             const points = values.map((value, index) => {
               const y = height - (height * (value - scale.min)) / (scale.max - scale.min);
               const x = (index * width) / (values.length - 1);
               return { x, y };
             });
             
             // ラインを描画
             linePath.moveTo(points[0]);
             points.slice(1).forEach((point) => {
               linePath.lineTo(point);
             });
             
             // ポイントを描画
             points.forEach((point) => {
               pointPath.addOval(
                 Rect.fromCircle({ center: new Offset(point), radius: 5 })
               );
             });
             
             // SVG属性を設定
             line.setAttribute("fill", "none");
             line.setAttribute("stroke", colors[index]);
             line.setAttribute("stroke-width", "2");
             line.setAttribute("d", linePath.getD());
             
             point.setAttribute("fill", "#1f2937");
             point.setAttribute("stroke", colors[index]);
             point.setAttribute("stroke-width", "1");
             point.setAttribute("d", pointPath.getD());
           }
         }
       }
     });
   }
   ```

2. **カラーパレットの使用**
   - 各データセットに異なる色を適用
   - ラインとポイントの色を調和

3. **レイアウトの柔軟性**
   - Rowでチャートと凡例を並べて配置
   - Flexibleでレスポンシブレイアウトを実装

## headless-chartの利点

1. **完全なカスタマイズ**: Flitterウィジェットですべての視覚要素を制御
2. **一貫した開発体験**: Flitterのウィジェットシステムをそのまま使用
3. **パフォーマンス最適化**: 必要な部分のみレンダリング
4. **再利用性**: カスタムコンポーネントを簡単に再利用

## headless-chartの使い方

### 1. インストール
```bash
npm install @meursyphus/headless-chart
```

### 2. 基本的な使用法
```javascript
import { BarChart, LineChart } from "@meursyphus/headless-chart";

// データを定義
const data = {
  labels: ["A", "B", "C", "D"],
  datasets: [
    {
      legend: "Dataset 1",
      values: [10, 20, 30, 40],
    },
  ],
};

// チャートを作成
const chart = BarChart({
  data,
  custom: {
    // Flitterウィジェットで各要素をカスタマイズ
    bar: (...args) => Container({ /* ... */ }),
    xAxisLabel: (...args) => Text(/* ... */),
    // ... その他のカスタマイズ
  },
});
```

### 3. サポートされているチャートタイプ
- **BarChart**: バーチャート（縦/横）
- **LineChart**: ラインチャート
- **PieChart**: 円グラフ
- **ScatterChart**: 散布図
