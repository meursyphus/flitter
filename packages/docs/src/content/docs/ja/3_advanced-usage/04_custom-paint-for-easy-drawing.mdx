## CustomPaintウィジェットの背景

以前学んだRenderObjectWidgetは強力ですが複雑です。単に何かを描画したいだけでも、RenderObjectを継承し、createRenderObjectを実装し、paintメソッドをオーバーライドする必要があります。

CustomPaintはこの複雑さを解決します。ペイント動作を関数として渡すだけで完了です！

### CustomPaintの利点

1. **シンプルAPI**: painter関数を渡すだけ
2. **高速プロトタイピング**: 複雑なクラス構造が不要
3. **再利用性**: painter関数を簡単に差し替え可能
4. **パフォーマンス**: 内部で最適化されたRenderObjectを使用

### 基本的な使用法

```typescript
// SVGレンダラー用
CustomPaint({
  size: new Size(300, 200),
  painter: {
    svg: {
      createDefaultSvgEl(context) {
        return {
          circle: context.createSvgEl('circle')
        };
      },
      paint(els, size) {
        els.circle.setAttribute('cx', `${size.width / 2}`);
        els.circle.setAttribute('cy', `${size.height / 2}`);
        els.circle.setAttribute('r', '50');
        els.circle.setAttribute('fill', '#3B82F6');
      }
    }
  }
})

// Canvasレンダラー用
CustomPaint({
  size: new Size(300, 200),
  painter: {
    canvas: {
      paint(context, size) {
        const ctx = context.canvas;
        ctx.fillStyle = '#3B82F6';
        ctx.beginPath();
        ctx.arc(size.width / 2, size.height / 2, 50, 0, Math.PI * 2);
        ctx.fill();
      }
    }
  }
})
```

### shouldRepaint最適化

パフォーマンスのために再描画のタイミングを制御できます：

```typescript
CustomPaint({
  painter: {
    dependencies: myData, // 依存データ
    shouldRepaint: (oldPainter) => {
      // trueを返すと再描画
      // falseを返すと以前の描画を保持
      return oldPainter.dependencies !== myData;
    },
    svg: {
      // SVG実装
    },
    canvas: {
      // Canvas実装
    }
  }
})
```

## SVG vs Canvasレンダリング

FlitterのCustomPaintは2つのレンダリング方法をサポートしています：

### SVGレンダリング
- **スケーリング時の品質を維持**
- **ベクターグラフィックスに適している**
- **createDefaultSvgEl()でSVG要素を作成**
- **paint()内でsetAttributeで属性を設定**

```typescript
svg: {
  createDefaultSvgEl(context) {
    return {
      line: context.createSvgEl('path'),
      point: context.createSvgEl('circle')
    };
  },
  paint(els, size) {
    els.line.setAttribute('d', pathData);
    els.line.setAttribute('stroke', '#3B82F6');
    els.point.setAttribute('cx', '50');
    els.point.setAttribute('cy', '50');
  }
}
```

### Canvasレンダリング
- **複雑なピクセル操作に適している**
- **高パフォーマンスアニメーションに有利**
- **Web Canvas APIと同じアプローチ**

```typescript
canvas: {
  paint(context, size) {
    const ctx = context.canvas;
    ctx.fillStyle = '#3B82F6';
    ctx.fillRect(0, 0, size.width, size.height);
    ctx.strokeStyle = '#FF0000';
    ctx.lineWidth = 2;
    ctx.beginPath();
    ctx.moveTo(0, 0);
    ctx.lineTo(100, 100);
    ctx.stroke();
  }
}
```

## ソースコードの場所

CustomPaintの実装を調べるには：

- `packages/flitter/src/component/CustomPaint.ts`: CustomPaintウィジェット
- `packages/flitter/src/engine/canvas/`: Canvas実装
- `packages/flitter/src/engine/paint.ts`: Paintクラス

## 主要なまとめ

1. **CustomPaintはRenderObjectの複雑さを隠蔽**
2. **painterオブジェクト内でsvg/canvasの別々の実装を提供**
3. **dependenciesとshouldRepaintでパフォーマンスを最適化可能**
4. **SVGとCanvasの両レンダリング方法をサポート**
5. **使用するレンダラーの実装のみ提供すればよい**
6. **アニメーションと簡単に組み合わせ可能**
