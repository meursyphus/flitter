## RenderObjectWidgetハンズオン

これまで学んだRenderObjectとConstraintsシステムを使って、実際にウィジェットを作成してみましょう。Flitterの内部動作を理解するために、Columnの簡略化されたバージョンを実装します。

## RenderObjectWidgetの種類

**SingleChildRenderObjectWidget**
- 単一の子要素を持つウィジェット（Container、Paddingなど）
- `createRenderObject()`: RenderObjectを作成
- `updateRenderObject()`: プロパティを更新

**MultiChildRenderObjectWidget**
- 複数の子要素を持つウィジェット（Row、Column、Stackなど）
- 子要素のリストを管理
- 各子要素のレイアウトを調整

### いつ使うか？

- 既存のウィジェットで実装できないカスタムレイアウトが必要な場合
- パフォーマンスクリティカルな複雑なレンダリングロジックが必要な場合
- 特殊なペイント動作が必要な場合

## SimpleColumnの実装

### ウィジェットクラスの定義

```typescript
class SimpleColumn extends MultiChildRenderObjectWidget {
  constructor(props: { children: Widget[] }) {
    super(props);
  }
  
  createRenderObject(): RenderObject {
    return new RenderSimpleColumn();
  }
  
  updateRenderObject(renderObject: RenderSimpleColumn) {
    // プロパティが変更されたときにRenderObjectを更新
    // この例では特別なプロパティがないため空のまま
  }
}

export default function SimpleColumn(props: { children: Widget[] }): Widget {
  return new _SimpleColumn(props);
}
```

### RenderObjectクラスの実装

```typescript
class RenderSimpleColumn extends RenderBox {
  performLayout() {
    let height = 0;
    let maxWidth = 0;
    
    // 各子要素のレイアウトを実行
    for (const child of this.children) {
      // 子要素に制約を渡す（高さの制約を緩める）
      child.layout(constraints.loosen({ height: true }));
      
      // 子要素の位置を設定（順番に縦に並べる）
      child.offset = new Offset(0, height);
      
      // 次の子要素の位置を計算
      height += child.size.height;
      maxWidth = Math.max(maxWidth, child.size.width);
    }
    
    // 自身のサイズを決定
    this.size = constraints.constrain(new Size(maxWidth, height));
  }
  
  // 子要素のヒットテスト（クリックイベントなど）
  hitTestChildren(result: HitTestResult, position: Offset): boolean {
    return this.defaultHitTestChildren(result, position);
  }
  
  // 子要素のペイント
  paint(context: PaintingContext, offset: Offset) {
    this.defaultPaint(context, offset);
  }
}
```

### レイアウトプロセスの詳細分析

1. **制約の渡し方**:
   ```typescript
   // 親からの制約を高さの制約のみ緩めて渡す
   child.layout(constraints.loosen({ height: true }));
   ```

2. **位置の計算**:
   ```typescript
   // 以前の子要素の高さを累積してY位置を決定
   child.offset = new Offset(0, height);
   height += child.size.height;
   ```

3. **サイズの決定**:
   ```typescript
   // 最も幅の広い子要素の幅と、すべての子要素の高さの合計
   this.size = constraints.constrain(new Size(maxWidth, height));
   ```

## 実際のColumnとの違い

実際のColumnはより複雑な機能を提供しています：

### MainAxisAlignment
```typescript
enum MainAxisAlignment {
  start,    // 開始位置に配置
  center,   // 中央に配置  
  end,      // 終了位置に配置
  spaceBetween,  // 均等分割
  spaceAround,   // 周囲の空間を含む
  spaceEvenly    // 完全な均等分割
}
```

### CrossAxisAlignment
```typescript
enum CrossAxisAlignment {
  start,    // クロス軸の開始位置
  center,   // クロス軸の中央
  end,      // クロス軸の終了位置
  stretch   // クロス軸全体を埋める
}
```

### Flex子要素の処理
- **Expanded**: 残りの空間を占有
- **Flexible**: 必要な分だけ取る

### オーバーフローの処理
- 子要素の合計サイズが親を超える場合の処理
- クリッピングまたはスクロールの提供

## ペインティングウィジェットの作成

RenderObjectで直接描画操作を実行することもできます。FlitterはDecoratedBoxのようなクラスベースのPainterパターンを使用しています：

```typescript
class RenderCustomShape extends RenderBox {
  constructor() {
    super({ isPainter: true }); // これがpainterであることを示す
  }
  
  performLayout() {
    this.size = constraints.biggest;
  }
  
  // SVG painterを作成
  protected override createSvgPainter() {
    return new CustomShapeSvgPainter(this);
  }
  
  // Canvas painterを作成
  protected override createCanvasPainter() {
    return new CustomShapeCanvasPainter(this);
  }
}
```

### SVG Painterの実装

```typescript
class CustomShapeSvgPainter extends SvgPainter {
  protected override createDefaultSvgEl({ createSvgEl }: SvgPaintContext) {
    return {
      shape: createSvgEl("path"),
      border: createSvgEl("path"),
    };
  }
  
  protected override performPaint(svgEls: { shape: SVGPathElement; border: SVGPathElement }) {
    const { shape, border } = svgEls;
    
    // SVGパスデータを生成
    const pathData = `M 10,10 L ${this.size.width-10},10 L ${this.size.width-10},${this.size.height-10} L 10,${this.size.height-10} Z`;
    
    shape.setAttribute('d', pathData);
    shape.setAttribute('fill', '#3b82f6');
    
    border.setAttribute('d', pathData);
    border.setAttribute('fill', 'none');
    border.setAttribute('stroke', '#1e40af');
    border.setAttribute('stroke-width', '2');
  }
}
```

### Canvas Painterの実装

```typescript
class CustomShapeCanvasPainter extends CanvasPainter {
  override performPaint(context: CanvasPaintingContext, offset: Offset) {
    const ctx = context.canvas;
    
    ctx.save();
    ctx.translate(offset.x, offset.y);
    
    // 矩形を描画
    ctx.fillStyle = '#3b82f6';
    ctx.fillRect(10, 10, this.size.width - 20, this.size.height - 20);
    
    // ボーダーを描画
    ctx.strokeStyle = '#1e40af';
    ctx.lineWidth = 2;
    ctx.strokeRect(10, 10, this.size.width - 20, this.size.height - 20);
    
    ctx.restore();
  }
}
```

### シンプルなペインティングが必要？

複雑なRenderObject実装の代わりに、[CustomPaintウィジェット](/docs/widgets/CustomPaint)を使う方が簡単です：

```typescript
CustomPaint({
  painter: {
    svg: {
      createDefaultSvgEl: (context) => ({
        shape: context.createSvgEl('rect')
      }),
      paint: (els, size) => {
        els.shape.setAttribute('width', `${size.width}`);
        els.shape.setAttribute('height', `${size.height}`);
        els.shape.setAttribute('fill', '#3b82f6');
      }
    },
    canvas: {
      paint: (context, size) => {
        context.canvas.fillStyle = '#3b82f6';
        context.canvas.fillRect(0, 0, size.width, size.height);
      }
    }
  }
})
```

## 主要なまとめ

1. **RenderObjectWidgetはWidgetとRenderObjectをつなぐ**
2. **performLayout()で子要素のサイズと位置を決定**
3. **paint()で実際の描画操作を実行**
4. **SVGとCanvasの両レンダラーをサポートする必要がある**
5. **必要な機能のみ実装すればよい**
