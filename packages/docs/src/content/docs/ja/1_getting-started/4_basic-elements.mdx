# 基本要素 - 図形、レイアウト、テキスト

FlitterはFlutterに似たウィジェットシステムを提供し、複雑なUIを簡単に構築できます。
このドキュメントでは、最も基本的な要素である図形、レイアウト、テキストの扱い方について説明します。

## 基本的な図形の描画

Flitterでは、`Container`ウィジェットと`BoxDecoration`を使用して図形を作成します。

### Containerウィジェット

`Container`はFlitterで最も基本的でありながら強力なウィジェットです：

- **サイズ設定**：widthとheightプロパティでサイズを指定
- **色**：colorまたはdecoration.colorで背景色を設定
- **間隔**：paddingとmarginで内部/外部の余白を設定
- **装飾**：BoxDecorationで境界線、角丸、シャドウなどを追加

### BoxDecorationの使用

```typescript
Container({
  decoration: new BoxDecoration({
    color: '#3B82F6',
    border: new Border({
      top: new BorderSide({ color: '#1E40AF', width: 2 }),
      // right、bottom、leftも同様に設定可能
    }),
    borderRadius: BorderRadius.circular(8),
    // または個別の角を設定
    borderRadius: BorderRadius.only({
      topLeft: Radius.circular(16),
      topRight: Radius.circular(16),
      bottomLeft: Radius.circular(0),
      bottomRight: Radius.circular(0)
    })
  })
})
```

### RowとColumn

**Row**は子ウィジェットを水平に配置し、**Column**は垂直に配置します：

```typescript
// 水平配置
Row({
  mainAxisAlignment: MainAxisAlignment.spaceBetween, // 主軸の配置
  crossAxisAlignment: CrossAxisAlignment.center,     // 交差軸の配置
  children: [/* ウィジェット */]
})

// 垂直配置
Column({
  mainAxisAlignment: MainAxisAlignment.start,
  crossAxisAlignment: CrossAxisAlignment.stretch,
  children: [/* ウィジェット */]
})
```

### StackとPositioned

**Stack**はウィジェットを重ねて配置するために使用されます：

```typescript
Stack({
  children: [
    Container({ /* 背景 */ }),
    Positioned({
      top: 10,
      left: 10,
      child: Container({ /* 絶対位置指定 */ })
    })
  ]
})
```

### ExpandedとFlexible

残りのスペースを埋めたり、比例的にスペースを配分するために使用されます：

```typescript
Row({
  children: [
    Container({ width: 100 }), // 固定幅
    Expanded({
      flex: 2, // 2倍のスペースを占有
      child: Container({ /* 残りのスペースを埋める */ })
    }),
    Expanded({
      flex: 1, // 1倍のスペースを占有
      child: Container({ /* 残りのスペースを埋める */ })
    })
  ]
})
```

## テキストの扱い

FlitterのTextウィジェットは様々なスタイリングとレイアウトオプションを提供します。

### TextStyleプロパティ

```typescript
Text('スタイル付きテキスト', {
  style: new TextStyle({
    fontSize: 18,          // フォントサイズ
    fontWeight: 'bold',    // 太さ：'normal'、'bold'
    fontStyle: 'italic',   // スタイル：'normal'、'italic'
    fontFamily: 'Arial',   // フォントファミリー
    color: '#3B82F6',      // 色
    letterSpacing: 1.5,    // 文字間隔
    wordSpacing: 2.0,      // 単語間隔
    height: 1.5,           // 行の高さ
    decoration: 'underline' // 'none'、'underline'、'overline'、'lineThrough'
  })
})
```

### テキストの配置とオーバーフロー

```typescript
Container({
  width: 200,
  child: Text('長いテキストがここに入ります...', {
    textAlign: TextAlign.center,    // 配置：left、right、center、justify
    maxLines: 2,                     // 最大行数
    overflow: TextOverflow.ellipsis, // オーバーフロー処理：clip、fade、ellipsis
  })
})
```

## 実践例：カードコンポーネントの作成

これまでに学んだ内容を使用してカードコンポーネントを作成してみましょう：

```typescript
Container({
  width: 300,
  padding: EdgeInsets.all(16),
  decoration: new BoxDecoration({
    color: '#FFFFFF',
    borderRadius: BorderRadius.circular(12),
    border: new Border({
      top: new BorderSide({ color: '#E5E7EB', width: 1 }),
      right: new BorderSide({ color: '#E5E7EB', width: 1 }),
      bottom: new BorderSide({ color: '#E5E7EB', width: 1 }),
      left: new BorderSide({ color: '#E5E7EB', width: 1 })
    })
  }),
  child: Column({
    crossAxisAlignment: CrossAxisAlignment.start,
    children: [
      Text('カードタイトル', {
        style: new TextStyle({
          fontSize: 20,
          fontWeight: 'bold',
          color: '#1F2937'
        })
      }),
      SizedBox({ height: 8 }),
      Text('カードのコンテンツがここに入ります。複数行のテキストを含めることができます。', {
        style: new TextStyle({
          fontSize: 14,
          color: '#6B7280'
        })
      }),
      SizedBox({ height: 16 }),
      Row({
        mainAxisAlignment: MainAxisAlignment.end,
        children: [
          Container({
            padding: EdgeInsets.symmetric({ horizontal: 12, vertical: 6 }),
            decoration: new BoxDecoration({
              color: '#3B82F6',
              borderRadius: BorderRadius.circular(6)
            }),
            child: Text('アクション', {
              style: new TextStyle({
                fontSize: 14,
                color: '#FFFFFF',
                fontWeight: 'bold'
              })
            })
          })
        ]
      })
    ]
  })
})
```

## まとめ

- **Container**：サイズ、色、間隔、装飾を持つ基本コンテナ
- **BoxDecoration**：境界線や角丸などの視覚的装飾
- **Row/Column**：水平/垂直方向のレイアウト
- **Stack**：ウィジェットの重ね合わせ
- **Text**：様々なスタイルと配置オプションを持つテキスト
- **Expanded**：残りのスペースを埋める
