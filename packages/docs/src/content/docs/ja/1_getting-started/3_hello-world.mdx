# Hello World - テキストの中央揃え

ウェブでグラフィックスを扱う際の最も基本的なタスクの1つは、画面上でテキストを中央揃えにすることです。
この一見単純なタスクでさえ、従来のアプローチではかなり複雑なコードが必要です。

## なぜこれが問題なのか？

SVGやCanvasで要素を中央揃えにするには：
1. コンテナのサイズを知る必要があります
2. 要素のサイズを計算する必要があります
3. 中心座標を手動で計算する必要があります
4. サイズが変わるたびに再計算する必要があります

これらの繰り返しで複雑なタスクはエラーが発生しやすく、コードを読みにくくします。

## 主要概念の理解

### 1. Centerウィジェット
Flitterの`Center`ウィジェットは、子要素を自動的に中央揃えにします：

```typescript
Center({
  child: Text("これは中央揃えになります！")
})
```

### 2. 自動サイジング
Flitterは親コンテナのサイズが変更されると、レイアウトを自動的に再計算します。
別途リサイズイベントハンドラを書く必要はありません。

### 3. 宣言的スタイリング
`TextStyle`を使用してテキストの外観を宣言的に定義します：

```typescript
Text("スタイル付きテキスト", {
  style: TextStyle({
    fontSize: 24,
    fontWeight: 'bold',
    color: '#3B82F6'
  })
})
```

## 実践：様々な配置方法

### Alignウィジェットの使用
`Center`は実際には`Align`ウィジェットの特殊なケースです。より正確な制御のために：

```typescript
// 右上に配置
Align({
  alignment: Alignment.topRight,
  child: Text("右上")
})

// カスタム位置（中央より少し上）
Align({
  alignment: new Alignment(0, -0.5),
  child: Text("中央の上")
})
```

### Containerと一緒に使用
実際のアプリケーションでは、通常`Container`と一緒に使用されます：

```typescript
Container({
  width: 300,
  height: 200,
  color: '#EFF6FF',
  child: Center({
    child: Text("コンテナ内のテキスト", {
      style: TextStyle({
        fontSize: 20,
        color: '#1E40AF'
      })
    })
  })
})
```

## なぜこれが重要なのか？

1. **生産性**：複雑な計算なしに望むレイアウトを直接実装
2. **可読性**：コードが意図を明確に表現
3. **保守性**：レイアウトロジックがカプセル化され、修正が簡単
4. **スケーラビリティ**：ウィジェットを組み合わせることで複雑なレイアウトを簡単に実装
