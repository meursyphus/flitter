# Hello World - Centering Text

One of the most basic tasks when working with graphics on the web is centering text on the screen.
Even this seemingly simple task requires quite complex code with traditional approaches.

## Why is this a problem?

To center elements in SVG or Canvas:
1. You need to know the container size
2. You need to calculate the element's size
3. You need to manually calculate the center coordinates
4. You need to recalculate whenever the size changes

These repetitive and complex tasks are error-prone and make code difficult to read.

## Understanding Key Concepts

### 1. Center Widget
Flitter's `Center` widget automatically centers its child element:

```typescript
Center({
  child: Text("This will be centered!")
})
```

### 2. Automatic Sizing
Flitter automatically recalculates the layout when the parent container size changes.
There's no need to write separate resize event handlers.

### 3. Declarative Styling
Use `TextStyle` to declaratively define the appearance of text:

```typescript
Text("Styled text", {
  style: TextStyle({
    fontSize: 24,
    fontWeight: 'bold',
    color: '#3B82F6'
  })
})
```

## Practice: Various Alignment Methods

### Using the Align Widget
`Center` is actually a special case of the `Align` widget. For more precise control:

```typescript
// Position at top right
Align({
  alignment: Alignment.topRight,
  child: Text("Top Right")
})

// Custom position (slightly above center)
Align({
  alignment: new Alignment(0, -0.5),
  child: Text("Above Center")
})
```

### Using with Container
In real applications, it's usually used together with `Container`:

```typescript
Container({
  width: 300,
  height: 200,
  color: '#EFF6FF',
  child: Center({
    child: Text("Text in Container", {
      style: TextStyle({
        fontSize: 20,
        color: '#1E40AF'
      })
    })
  })
})
```

## Why is this important?

1. **Productivity**: Implement desired layouts directly without complex calculations
2. **Readability**: Code clearly expresses intent
3. **Maintainability**: Layout logic is encapsulated, making modifications easy
4. **Scalability**: Complex layouts can be easily implemented by combining widgets
