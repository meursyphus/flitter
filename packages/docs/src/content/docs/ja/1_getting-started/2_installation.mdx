# Flitterのインストールとセットアップ

Flitterはnpmでインストールしてすぐに使用できるライブラリです。

## サポートされているフレームワーク

Flitterは以下の環境を公式にサポートしています：

- **Vanilla JavaScript** - フレームワークなしの純粋なJavaScriptで使用
- **React** - Reactコンポーネントとして簡単に統合
- **Svelte** - Svelteコンポーネントとして自然に使用
- **Vue** - Vue 3 Composition APIで使用
- **SolidJS** - リアクティブシステムとの完璧な統合
- **Qwik** - 最適化されたローディングで使用

## レンダラーの選択

Flitterは2種類のレンダラーをサポートしています：

### Canvasレンダラー
- **利点**：高パフォーマンス、ピクセルレベルの制御、複雑なアニメーションに適している
- **欠点**：テキスト選択不可、SEOに不向き
- **使用例**：ゲーム、複雑な視覚化、アニメーション重視のアプリケーション

### SVGレンダラー
- **利点**：ベクターグラフィックス、テキスト選択可能、SEOフレンドリー、CSSスタイリング可能
- **欠点**：複雑なアニメーションでパフォーマンス低下の可能性
- **使用例**：チャート、ダイアグラム、静的な視覚化

### サーバーサイドレンダリング

```typescript
// サーバーサイドモードを使用する場合：
// 1. 最初にサーバーでSVGとしてレンダリング
// 2. クライアントで指定されたレンダラーでハイドレート
<Widget 
  renderer="canvas"     // クライアントレンダラー
  ssr={{                 // SSRを有効にしてサイズを指定
    size: {
      width: 800,      // サーバーでレンダリングする幅
      height: 600      // サーバーでレンダリングする高さ
    }
  }}
  widget={...} 
/>
```

## TypeScriptサポート

FlitterはTypeScriptで書かれており、完全な型サポートを提供しています。

```typescript
import { Container, ContainerProps, EdgeInsets, Text } from '@meursyphus/flitter';

const props: ContainerProps = {
  color: 'lightblue',
  padding: EdgeInsets.all(20),
  child: Text('こんにちは、TypeScript!')
};

const container = Container(props);
```
