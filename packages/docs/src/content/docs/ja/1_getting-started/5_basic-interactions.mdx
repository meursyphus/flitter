# 基本的なインタラクション - GestureDetector

ユーザーインタラクションはウェブアプリケーションに不可欠です。Flitterは`GestureDetector`ウィジェットを通じて様々なユーザー入力を簡単に処理できます。

## GestureDetectorとは？

`GestureDetector`は、子ウィジェット上の様々なジェスチャーを検出するウィジェットです。
クリック、ダブルクリック、ホバー、ドラッグなど、様々なユーザー入力を処理できます。

### 基本的な使い方

```typescript
GestureDetector({
  onClick: () => {
    console.log('クリックされました！');
  },
  child: Container({
    width: 100,
    height: 100,
    color: '#3B82F6',
    child: Center({
      child: Text('クリックしてください')
    })
  })
})
```

## StatefulWidgetとの使用

ほとんどのインタラクションは状態変更を伴うため、`StatefulWidget`と一緒に使用されます：

```typescript
class InteractiveButton extends StatefulWidget {
  createState() {
    return new InteractiveButtonState();
  }
}

class InteractiveButtonState extends State<InteractiveButton> {
  isPressed = false;
  isHovered = false;

  build(context: BuildContext) {
    return GestureDetector({
      onClick: () => {
        console.log('ボタンがクリックされました！');
      },
      onMouseEnter: () => {
        this.setState(() => {
          this.isHovered = true;
        });
      },
      onMouseLeave: () => {
        this.setState(() => {
          this.isHovered = false;
        });
      },
      onPanStart: () => {
        this.setState(() => {
          this.isPressed = true;
        });
      },
      onPanEnd: () => {
        this.setState(() => {
          this.isPressed = false;
        });
      },
      child: Container({
        padding: EdgeInsets.symmetric({ horizontal: 24, vertical: 12 }),
        decoration: new BoxDecoration({
          color: this.isPressed 
            ? '#1E40AF' 
            : this.isHovered 
              ? '#2563EB' 
              : '#3B82F6',
          borderRadius: BorderRadius.circular(8)
        }),
        child: Text('インタラクティブボタン', {
          style: new TextStyle({
            color: '#FFFFFF',
            fontWeight: 'bold'
          })
        })
      })
    });
  }
}
```

## 詳細なイベントタイプ

### クリック関連イベント

- **onClick**: クリック時にトリガー
- **onDoubleClick**: ダブルクリック時にトリガー
- **onLongPress**: ロングプレス時にトリガー

### マウス関連イベント

- **onMouseEnter**: マウスがウィジェット領域に入ったとき
- **onMouseLeave**: マウスがウィジェット領域から出たとき
- **onMouseMove**: マウスがウィジェット上で移動したとき

### ドラッグ関連イベント

- **onPanStart**: ドラッグ開始時
- **onPanUpdate**: ドラッグ中（デルタ値を提供）
- **onPanEnd**: ドラッグ終了時

## 実用的な使用例

### 1. トグルスイッチ

```typescript
class ToggleSwitch extends StatefulWidget {
  createState() {
    return new ToggleSwitchState();
  }
}

class ToggleSwitchState extends State<ToggleSwitch> {
  isOn = false;

  build(context: BuildContext) {
    return GestureDetector({
      onClick: () => {
        this.setState(() => {
          this.isOn = !this.isOn;
        });
      },
      child: Container({
        width: 60,
        height: 30,
        decoration: new BoxDecoration({
          color: this.isOn ? '#10B981' : '#6B7280',
          borderRadius: BorderRadius.circular(15)
        }),
        child: Stack({
          children: [
            AnimatedPositioned({
              duration: 200,
              left: this.isOn ? 30 : 0,
              child: Container({
                width: 30,
                height: 30,
                decoration: new BoxDecoration({
                  color: '#FFFFFF',
                  borderRadius: BorderRadius.circular(15)
                })
              })
            })
          ]
        })
      })
    });
  }
}
```

### 2. ドロップダウンメニュー

```typescript
class DropdownMenu extends StatefulWidget {
  createState() {
    return new DropdownMenuState();
  }
}

class DropdownMenuState extends State<DropdownMenu> {
  isOpen = false;

  build(context: BuildContext) {
    return Column({
      children: [
        GestureDetector({
          onClick: () => {
            this.setState(() => {
              this.isOpen = !this.isOpen;
            });
          },
          child: Container({
            padding: EdgeInsets.all(12),
            decoration: new BoxDecoration({
              color: '#374151',
              borderRadius: BorderRadius.circular(6)
            }),
            child: Row({
              mainAxisAlignment: MainAxisAlignment.spaceBetween,
              children: [
                Text('メニューを選択', {
                  style: new TextStyle({ color: '#E5E7EB' })
                }),
                Icon(this.isOpen ? 'arrow_up' : 'arrow_down')
              ]
            })
          })
        }),
        if (this.isOpen) Container({
          margin: EdgeInsets.only({ top: 4 }),
          decoration: new BoxDecoration({
            color: '#374151',
            borderRadius: BorderRadius.circular(6)
          }),
          child: Column({
            children: ['オプション1', 'オプション2', 'オプション3'].map(option => 
              GestureDetector({
                onClick: () => {
                  console.log(`選択: ${option}`);
                  this.setState(() => {
                    this.isOpen = false;
                  });
                },
                child: Container({
                  padding: EdgeInsets.all(12),
                  child: Text(option, {
                    style: new TextStyle({ color: '#E5E7EB' })
                  })
                })
              })
            )
          })
        })
      ]
    });
  }
}
```

## パフォーマンス最適化のヒント

1. **適切なレンダラーを選択**: 複雑なインタラクションにはCanvasレンダラーを使用
2. **イベントのデバウンシング**: 頻繁なイベント（例：onMouseMove）にはデバウンシングを検討
3. **状態更新の最適化**: 不要なsetState呼び出しを削減

## アクセシビリティの考慮事項

GestureDetectorを使用する際は、アクセシビリティを考慮すべきです：

1. **キーボードサポート**: 重要なインタラクションはキーボードでもアクセス可能に
2. **フォーカス表示**: フォーカスされた要素を視覚的に区別
3. **十分なタッチエリア**: モバイルでは最小44x44pxのサイズを確保
