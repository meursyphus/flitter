# API Reference

Complete reference for all Flitter classes, functions, and properties.

## Widget Categories

### Layout Widgets
Widgets for basic layout composition.

- [Container](/en/api-reference/widgets/container) - A box with decoration, padding, and constraints
- [Row](/en/api-reference/widgets/row) - Horizontal layout
- [Column](/en/api-reference/widgets/column) - Vertical layout
- [Stack](/en/api-reference/widgets/stack) - Overlapping layout
- [Flex](/en/api-reference/widgets/flex) - Flexible layout
- [Expanded](/en/api-reference/widgets/expanded) - Expands within Flex
- [Flexible](/en/api-reference/widgets/flexible) - Flexible sizing within Flex
- [Spacer](/en/api-reference/widgets/spacer) - Fill empty space

### Positioning Widgets
Widgets that control the position of their children.

- [Align](/en/api-reference/widgets/align) - Alignment
- [Center](/en/api-reference/widgets/center) - Center alignment
- [Padding](/en/api-reference/widgets/padding) - Add padding
- [Transform](/en/api-reference/widgets/transform) - Apply transformations
- [FractionalTranslation](/en/api-reference/widgets/fractional-translation) - Fractional unit translation

### Sizing Widgets
Widgets that control widget dimensions.

- [SizedBox](/en/api-reference/widgets/sized-box) - Fixed size box
- [ConstrainedBox](/en/api-reference/widgets/constrained-box) - Constrained box
- [UnconstrainedBox](/en/api-reference/widgets/unconstrained-box) - Unconstrained box
- [FractionallySizedBox](/en/api-reference/widgets/fractionally-sized-box) - Fractional size box
- [AspectRatio](/en/api-reference/widgets/aspect-ratio) - Maintain aspect ratio
- [IntrinsicHeight](/en/api-reference/widgets/intrinsic-height) - Intrinsic height
- [IntrinsicWidth](/en/api-reference/widgets/intrinsic-width) - Intrinsic width
- [LimitedBox](/en/api-reference/widgets/limited-box) - Limited box
- [OverflowBox](/en/api-reference/widgets/overflow-box) - Overflow box

### Decoration Widgets
Widgets that add visual effects.

- [ColoredBox](/en/api-reference/widgets/colored-box) - Colored box
- [DecoratedBox](/en/api-reference/widgets/decorated-box) - Decorated box
- [Opacity](/en/api-reference/widgets/opacity) - Opacity
- [ClipRect](/en/api-reference/widgets/clip-rect) - Rectangle clipping
- [ClipRRect](/en/api-reference/widgets/clip-rrect) - Rounded rectangle clipping
- [ClipOval](/en/api-reference/widgets/clip-oval) - Oval clipping
- [ClipPath](/en/api-reference/widgets/clip-path) - Path clipping

### Interaction Widgets
Widgets that handle user input.

- [GestureDetector](/en/api-reference/widgets/gesture-detector) - Gesture detection
- [Draggable](/en/api-reference/widgets/draggable) - Draggable widget
- [TextField](/en/api-reference/widgets/text-field) - Text input
- [Tooltip](/en/api-reference/widgets/tooltip) - Tooltip

### Animation Widgets
Widgets that provide animation effects.

- [AnimatedContainer](/en/api-reference/widgets/animated-container) - Animated container
- [AnimatedAlign](/en/api-reference/widgets/animated-align) - Animated alignment
- [AnimatedOpacity](/en/api-reference/widgets/animated-opacity) - Animated opacity
- [AnimatedPadding](/en/api-reference/widgets/animated-padding) - Animated padding
- [AnimatedPositioned](/en/api-reference/widgets/animated-positioned) - Animated position
- [AnimatedRotation](/en/api-reference/widgets/animated-rotation) - Animated rotation
- [AnimatedScale](/en/api-reference/widgets/animated-scale) - Animated scale
- [AnimatedSlide](/en/api-reference/widgets/animated-slide) - Animated slide
- [AnimatedFractionallySizedBox](/en/api-reference/widgets/animated-fractionally-sized-box) - Animated fractional size box
