# Flexible

## Overview

Flexible is a widget that controls how a child of a Row, Column, or Flex widget flexes. Using the flex property, you can determine how much space this widget should take relative to other Flexible widgets.

## When to Use

Use Flexible in these situations:

- When you want to fill remaining space in a Row or Column
- When you need to distribute space proportionally between multiple widgets
- When a child widget should take only necessary space but expand if more space is available
- When building responsive layouts

## Basic Usage

```typescript
Row({
  children: [
    Flexible({
      flex: 1,
      child: Container({
        color: 'blue',
        height: 100
      })
    }),
    Flexible({
      flex: 2,
      child: Container({
        color: 'red',
        height: 100
      })
    })
  ]
})
```

## Constructor Parameters

| Parameter | Type | Description | Default |
|-----------|------|-------------|---------|
| flex | `number` | The flex factor to use for this child | 1 |
| fit | `'tight' \| 'loose'` | How the child should be sized | 'loose' |
| child | `Widget` | The widget to be made flexible | undefined |
| key | `any` | Unique key for the widget | undefined |

## FlexFit Options

- **loose**: The child can be at most as large as the available space (but can be smaller)
- **tight**: The child is forced to fill the available space (same as Expanded)

## Flexible vs Expanded

Expanded is a special case of Flexible:

```typescript
// These two are equivalent
Expanded({ child: myWidget })
Flexible({ fit: 'tight', child: myWidget })
```

- **Flexible**: Allows child to take only necessary space (fit: 'loose')
- **Expanded**: Forces child to take all available space

## Important Notes

1. Flexible must be a direct child of Row, Column, or Flex
2. The flex value must be greater than 0
3. When multiple Flexible widgets are present, space is distributed according to flex ratios
4. When used with fixed-size widgets, fixed sizes are allocated first, then remaining space is distributed to Flexible widgets
