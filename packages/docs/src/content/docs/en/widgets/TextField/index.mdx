# TextField

## Overview

TextField is an interactive widget that can receive text input from users. It supports single-line or multi-line text input and provides various styling options.

## When to Use

Use TextField in the following situations:

- When text input like username or email is needed
- When implementing a search bar
- When comment or message input fields are needed
- When collecting form data

## Basic Usage

```typescript
TextField('Initial text', {
  onChanged: (text) => {
    console.log('Text changed:', text);
  }
})
```

## Constructor Parameters

| Parameter | Type | Description | Default |
|-----------|------|-------------|---------|
| text | `string` | Initial text value | Required |
| onChanged | `(text: string) => void` | Callback on text change | undefined |
| onSubmitted | `(text: string) => void` | Callback on Enter key | undefined |
| onFocused | `() => void` | Callback on focus | undefined |
| onBlurred | `() => void` | Callback on blur | undefined |
| style | `TextStyle` | Text style | TextStyle() |
| maxLines | `number` | Maximum number of lines | 1 |
| textAlign | `TextAlign` | Text alignment | start |
| textDirection | `TextDirection` | Text direction | ltr |
| decoration | `BoxDecoration` | Field decoration | Default border |
| padding | `EdgeInsets` | Inner padding | EdgeInsets.all(0) |
| width | `number` | Field width | Infinity |
| height | `number` | Field height | 20 |
| focusedBorder | `Border` | Border when focused | Blue border |
| key | `any` | Unique key for the widget | undefined |

### Event Handling Example

```typescript
class SearchField extends StatefulWidget {
  createState() {
    return new SearchFieldState();
  }
}

class SearchFieldState extends State<SearchField> {
  searchText = '';
  
  build() {
    return Column({
      children: [
        TextField(this.searchText, {
          width: 300,
          height: 35,
          placeholder: 'Enter search term',
          onChanged: (text) => {
            this.setState(() => {
              this.searchText = text;
            });
          },
          onSubmitted: (text) => {
            console.log('Search for:', text);
          },
          decoration: BoxDecoration({
            border: Border.all({ color: '#3498db', width: 1 }),
            borderRadius: { all: { radius: 20 } }
          }),
          padding: EdgeInsets.symmetric({ horizontal: 20, vertical: 8 })
        }),
        Text(`Search: ${this.searchText}`, {
          style: TextStyle({ fontSize: 12, color: '#666' })
        })
      ]
    });
  }
}
```

## Key Features

### Text Selection
- Select text with mouse drag
- Selected text is highlighted

### Caret (Cursor)
- Blinking caret shows current input position
- Caret is fixed while typing

### Focus State
- Border style can change on focus
- Focus/blur events can be handled

### International Input
- IME (Input Method Editor) support
- Composing text display

## Methods

Methods available in TextField's State:

- `focus(location?: number)` - Focus at specific position
- `blur()` - Remove focus

## Notes

- TextField is a StatefulWidget, so state management is required
- Utilizes browser's native input capabilities
- Large texts may affect performance
- Scrolling is automatically handled when maxLines is set
