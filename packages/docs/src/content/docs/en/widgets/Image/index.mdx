# Image

## Overview

Image is a widget that displays images on the web. It provides various sizing and positioning options to display images flexibly.

## When to Use

Use Image in the following situations:

- When displaying logos, icons, or photos
- When showing thumbnail images
- When displaying background images or illustrations
- When responsive images are needed

## Basic Usage

```typescript
Image({
  src: 'https://example.com/image.jpg',
  width: 200,
  height: 150
})
```

## Constructor Parameters

| Parameter | Type | Description | Default |
|-----------|------|-------------|---------|
| src | `string` | Image URL or path | Required |
| width | `number` | Image width | undefined |
| height | `number` | Image height | undefined |
| objectFit | `ObjectFit` | Image sizing mode | undefined |
| objectPosition | `ObjectPosition` | Image alignment position | undefined |
| key | `any` | Unique key for the widget | undefined |

## ObjectFit Options

Controls how the image fits within its container:

- `fill` - Fills the container completely (ignores aspect ratio)
- `contain` - Fits within container while maintaining aspect ratio
- `cover` - Fills container while maintaining aspect ratio
- `none` - Maintains original size
- `scale-down` - Chooses smaller of none or contain

## ObjectPosition Options

Controls the alignment position of the image:

- `center` - Center alignment
- `top`, `bottom`, `left`, `right` - Directional alignment
- `top left`, `top right`, `bottom left`, `bottom right` - Corner alignment

## Notes

- Empty space of specified size is displayed until image loads
- Check CORS policy for network images
- Large images can affect performance, so optimize to appropriate size
- Specifying only width or height may not maintain aspect ratio
