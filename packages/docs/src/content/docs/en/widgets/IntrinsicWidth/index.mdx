# IntrinsicWidth

## Overview

IntrinsicWidth is a widget that sizes its child to the child's minimum intrinsic width. It's useful when a child widget receives unbounded width constraints and helps calculate an appropriate width based on the child's content.

## When to Use

Use IntrinsicWidth in these situations:

- When you want to make multiple widgets in a Column have the same width
- When you need to give an appropriate width to widgets with unbounded width constraints
- When you want to ensure a minimum width based on child widget's content
- When specific widgets in a Row should only take up as much space as needed

## Basic Usage

```typescript
IntrinsicWidth({
  child: Column({
    children: [
      Container({
        color: 'blue',
        height: 50,
        child: Text('Short text')
      }),
      Container({
        color: 'red', 
        height: 50,
        child: Text('This is a much longer text')
      })
    ]
  })
})
```

## Constructor Parameters

| Parameter | Type | Description | Default |
|-----------|------|-------------|---------|
| child | `Widget` | The widget to apply intrinsic width to | undefined |
| key | `any` | Unique key for the widget | undefined |

## Performance Considerations

IntrinsicWidth calculates layout twice, which can impact performance:

1. First pass calculates the child's intrinsic width
2. Second pass performs the actual layout

Therefore, consider the following:

- Avoid using in deeply nested structures
- Not recommended for animated widgets
- Consider alternatives (like fixed widths) if available
- Can have significant performance impact in lists or grids
