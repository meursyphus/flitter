# Grid

## Overview

Grid is a powerful layout widget that arranges child widgets in a grid pattern of rows and columns. Similar to CSS Grid, it makes it easy to create complex two-dimensional layouts.

## When to Use

Use Grid in the following situations:

- When you need table-like layouts
- When creating image galleries or card grids
- When building dashboards or widget grids
- When precise row and column size control is needed

## Basic Usage

```typescript
Grid({
  childrenByRow: [
    [widget1, widget2, widget3],  // First row
    [widget4, widget5, widget6],  // Second row
  ]
})
```

## Constructor Parameters

| Parameter | Type | Description | Default |
|-----------|------|-------------|---------|
| childrenByRow | `Widget[][]` | Child widgets organized by rows | Required |
| templateRows | `GridTemplate[]` | Row size templates | [] |
| templateColumns | `GridTemplate[]` | Column size templates | [] |
| autoRow | `GridTemplate` | Default size for rows without template | Fr(1) |
| autoColumn | `GridTemplate` | Default size for columns without template | Fr(1) |
| key | `any` | Unique key for the widget | undefined |

## GridTemplate Options

Grid supports various sizing units:

- `Grid.Fr(value)` - Fractional unit (ratio)
- `Grid.Px(value)` - Fixed pixel size
- `Grid.Percent(value)` - Percentage of parent size (0-100)
- `Grid.ContentFit()` - Fit to content

## repeat Helper Method

You can easily create repeating templates:

```typescript
Grid({
  templateColumns: Grid.Fr(1).repeat(4), // [Fr(1), Fr(1), Fr(1), Fr(1)]
  templateRows: Grid.Px(100).repeat(3),  // [Px(100), Px(100), Px(100)]
  childrenByRow: [...]
})
```

## Notes

- Each row can have a different number of columns, but it's better to maintain consistency when using templateColumns
- Fr units divide the remaining space proportionally after fixed sizes
- ContentFit uses the intrinsic size of children, which may impact performance
