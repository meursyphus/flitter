# ColoredBox

## Overview

ColoredBox is the simplest widget for creating a rectangular box filled with a specified color. Unlike Container, it only allows you to specify color without additional properties like padding or margin.

## When to Use

Use ColoredBox in the following situations:

- When you simply need a colored background
- When you don't need other Container features
- When you want to optimize performance (lighter than Container)
- When you only need color overlays or background colors

## Basic Usage

```typescript
ColoredBox({
  color: '#3498db',
  child: Text('Hello ColoredBox!')
})
```

## Constructor Parameters

| Parameter | Type | Description | Default |
|-----------|------|-------------|---------|
| color | `string` | Background color of the box (CSS color value) | Required |
| child | `Widget` | Child widget to display inside the box | undefined |
| key | `any` | Unique key for the widget | undefined |

  height="150px"
  renderer="svg"

    alignment: Alignment.center,

      color: '#3498db',

        height: 80,

          child: Text('ColoredBox', {
            style: TextStyle({
              color: '#ffffff',

              weight: 'bold'
            })

        })
      })
    })
  })}
/>

## Notes

- ColoredBox follows the size of its child widget if no size is specified
- To specify size, wrap it with SizedBox or Container
- Supports colors with transparency (e.g., 'rgba(255, 0, 0, 0.5)')

## Differences from Container

| Feature | ColoredBox | Container |
|---------|------------|-----------|
| Color | ✓ | ✓ |
| Padding/Margin | ✗ | ✓ |
| Border | ✗ | ✓ |
| Size specification | ✗ | ✓ |
| Transform | ✗ | ✓ |
| Performance | Lighter | Relatively heavier |
