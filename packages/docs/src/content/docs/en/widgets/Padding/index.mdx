# Padding

## Overview

Padding is a widget that adds spacing around its child widget. It provides the same functionality as Container's padding property but is a lighter choice when you only need padding.

## When to Use

Use Padding in the following situations:

- When you only want to add spacing around a widget
- When you don't need other Container features (color, border, etc.)
- When you want to optimize performance (lighter than Container)
- When you want to clearly express the intent of adding padding

## Basic Usage

```typescript
Padding({
  padding: EdgeInsets.all(16),
  child: Text('Padded Text')
})
```

## Constructor Parameters

| Parameter | Type | Description | Default |
|-----------|------|-------------|---------|
| padding | `EdgeInsets` | Padding values | EdgeInsets.all(0) |
| child | `Widget` | Child widget to apply padding to | undefined |
| key | `any` | Unique key for the widget | undefined |

## EdgeInsets Usage

EdgeInsets provides several ways to specify padding:

- `EdgeInsets.all(value)` - Same padding in all directions
- `EdgeInsets.symmetric({ horizontal, vertical })` - Symmetric horizontal/vertical padding
- `EdgeInsets.only({ top, right, bottom, left })` - Individual padding for each direction
- `EdgeInsets.fromLTRB(left, top, right, bottom)` - Specify in order

## Examples

### Basic Example

<Widget
  width="300px"
  height="150px"
  renderer="svg"
  widget={Container({
    alignment: Alignment.center,
    color: '#f0f0f0',
    child: ColoredBox({
      color: '#e74c3c',
      child: Padding({
        padding: EdgeInsets.all(20),
        child: Text('20px padding', {
          style: TextStyle({
            color: '#ffffff',
            fontSize: 16
          })
        })
      })
    })
  })}
/>

### Symmetric Padding Example

<Widget
  width="300px"
  height="200px"
  renderer="svg"
  widget={Container({
    alignment: Alignment.center,
    color: '#f0f0f0',
    child: Column({
      mainAxisSize: 'min',
      children: [
        ColoredBox({
          color: '#3498db',
          child: Padding({
            padding: EdgeInsets.symmetric({ horizontal: 40, vertical: 10 }),
            child: Text('H: 40px, V: 10px', {
              style: TextStyle({
                color: '#ffffff',
                fontSize: 14
              })
            })
          })
        }),
        Container({ height: 10 }),
        ColoredBox({
          color: '#9b59b6',
          child: Padding({
            padding: EdgeInsets.symmetric({ horizontal: 10, vertical: 30 }),
            child: Text('H: 10px, V: 30px', {
              style: TextStyle({
                color: '#ffffff',
                fontSize: 14
              })
            })
          })
        })
      ]
    })
  })}
/>

## Notes

- Padding cannot have an Expanded widget as a direct child
- Padding values cannot be negative
- Padding is applied within the parent widget's constraints

## Differences from Container

| Feature | Padding | Container (with padding) |
|---------|---------|-------------------------|
| Padding | ✓ | ✓ |
| Color | ✗ | ✓ |
| Border | ✗ | ✓ |
| Size specification | ✗ | ✓ |
| Transform | ✗ | ✓ |
| Performance | Lighter | Relatively heavier |
