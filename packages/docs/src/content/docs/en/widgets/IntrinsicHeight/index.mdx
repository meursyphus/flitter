# IntrinsicHeight

## Overview

IntrinsicHeight is a widget that sizes its child to the child's minimum intrinsic height. It's useful when a child widget receives unbounded height constraints and helps calculate an appropriate height based on the child's content.

## When to Use

Use IntrinsicHeight in these situations:

- When you want to make multiple widgets in a Row have the same height
- When you need to give an appropriate height to widgets with unbounded height constraints
- When you want to ensure a minimum height based on child widget's content
- When specific widgets in a Column should only take up as much space as needed

## Basic Usage

```typescript
IntrinsicHeight({
  child: Row({
    children: [
      Container({
        color: 'blue',
        width: 100,
        child: Text('Short')
      }),
      Container({
        color: 'red', 
        width: 100,
        child: Text('This is a much longer text that wraps')
      })
    ]
  })
})
```

## Constructor Parameters

| Parameter | Type | Description | Default |
|-----------|------|-------------|---------|
| child | `Widget` | The widget to apply intrinsic height to | undefined |
| key | `any` | Unique key for the widget | undefined |

## Performance Considerations

IntrinsicHeight calculates layout twice, which can impact performance:

1. First pass calculates the child's intrinsic height
2. Second pass performs the actual layout

Therefore, consider the following:

- Avoid using in deeply nested structures
- Not recommended for animated widgets
- Consider alternatives (like fixed heights) if available
