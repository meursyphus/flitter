# Column

## Overview

Column is a layout widget that arranges its children vertically. It's equivalent to a Flex widget with `direction: Axis.vertical`, but provides a more intuitive and convenient API.

## When to Use

Use Column in the following situations:

- When you want to arrange multiple widgets from top to bottom
- When creating vertical lists or form layouts
- When composing content for cards or dialogs
- When listing menu items vertically

## Basic Usage

```typescript
Column({
  children: [
    Text('First item'),
    Text('Second item'),
    Text('Third item')
  ]
})
```

## Constructor Parameters

| Parameter | Type | Description | Default |
|-----------|------|-------------|---------|
| children | `Widget[]` | Child widgets to arrange vertically | Required |
| mainAxisAlignment | `MainAxisAlignment` | Main axis (vertical) alignment | start |
| crossAxisAlignment | `CrossAxisAlignment` | Cross axis (horizontal) alignment | center |
| mainAxisSize | `MainAxisSize` | Main axis size setting | max |
| verticalDirection | `VerticalDirection` | Vertical direction (up/down) | down |
| key | `any` | Unique key for the widget | undefined |

## Alignment Options

### MainAxisAlignment (Vertical Alignment)
- `start`: Align to top
- `end`: Align to bottom
- `center`: Center alignment
- `spaceBetween`: Place at ends and distribute evenly
- `spaceAround`: Distribute with equal padding
- `spaceEvenly`: Distribute all spacing equally

### CrossAxisAlignment (Horizontal Alignment)
- `start`: Align to left
- `end`: Align to right
- `center`: Center alignment
- `stretch`: Stretch to full width

## Notes

- Column assumes infinite height vertically, so wrap with ScrollView if scrolling is needed
- Overflow may occur if child widgets exceed Column's height
- Expanded widgets must be direct children of Column

## Difference from Flex

Column is essentially equivalent to:

```typescript
Flex({
  direction: Axis.vertical,
  children: [...]
})
```

Using Column makes the code more concise and the intent clearer.
