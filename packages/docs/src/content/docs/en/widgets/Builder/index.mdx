# Builder

## Overview

Builder is a widget that allows you to build widgets dynamically through BuildContext. It's useful when you need to access information or state from a specific context.

## When to Use

Use Builder in the following situations:

- When you need access to BuildContext
- When you need to access Theme data
- When MediaQuery information is required
- When context is needed at a specific position in the widget tree

## Basic Usage

```typescript
Builder({
  builder: (context) => {
    // Use context to return a widget
    return Container({
      child: Text('Hello from Builder!')
    });
  }
})
```

## Constructor Parameters

| Parameter | Type | Description | Default |
|-----------|------|-------------|---------|
| builder | `(context: BuildContext) => Widget` | Function that receives context and returns a widget | Required |
| key | `any` | Unique key for the widget | undefined |

## Examples

### Basic Example

<Widget
  width="300px"
  height="200px"
  renderer="svg"
  widget={Container({
    alignment: Alignment.center,
    color: '#f0f0f0',
    child: Builder({
      builder: (context) => {
        return Container({
          padding: { all: 20 },
          decoration: {
            color: '#3498db',
            borderRadius: { all: { radius: 8 } }
          },
          child: Text('Widget created by Builder', {
            style: TextStyle({
              color: '#ffffff',
              fontSize: 16
            })
          })
        });
      }
    })
  })}
/>

### Conditional Rendering Example

<Widget
  width="300px"
  height="200px"
  renderer="svg"
  widget={Container({
    alignment: Alignment.center,
    color: '#f0f0f0',
    child: Builder({
      builder: (context) => {
        const isLargeScreen = true; // In practice, determine with MediaQuery etc.
        
        if (isLargeScreen) {
          return Container({
            width: 200,
            height: 100,
            color: '#2ecc71',
            alignment: Alignment.center,
            child: Text('Large Screen', {
              style: TextStyle({ color: '#ffffff' })
            })
          });
        } else {
          return Container({
            width: 100,
            height: 50,
            color: '#e74c3c',
            alignment: Alignment.center,
            child: Text('Small Screen', {
              style: TextStyle({ color: '#ffffff' })
            })
          });
        }
      }
    })
  })}
/>

### Dynamic List Creation Example

<Widget
  width="300px"
  height="300px"
  renderer="svg"
  widget={Container({
    alignment: Alignment.topCenter,
    color: '#f0f0f0',
    padding: { all: 20 },
    child: Builder({
      builder: (context) => {
        const items = ['Item 1', 'Item 2', 'Item 3'];
        
        return Column({
          mainAxisSize: 'min',
          children: items.map(item => 
            Container({
              margin: { bottom: 10 },
              padding: { all: 10 },
              decoration: {
                color: '#9b59b6',
                borderRadius: { all: { radius: 4 } }
              },
              child: Text(item, {
                style: TextStyle({ color: '#ffffff' })
              })
            })
          )
        });
      }
    })
  })}
/>

## Notes

- The builder function is called every time the widget is built
- Heavy computations should be done outside the builder function
- You can access parent widget information through context
