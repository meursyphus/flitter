## Overview

ConstraintsTransformBox is a container widget that applies an arbitrary transform to its constraints and sizes its child using the resulting BoxConstraints.

This container sizes its child using a BoxConstraints created by applying constraintsTransform to its own constraints. This container will then attempt to adopt the same size, within the limits of its own constraints. If it ends up with a different size, it will align the child based on alignment. If the container cannot expand enough to accommodate the entire child, the child will be clipped if clipped is true.

See: [https://api.flutter.dev/flutter/widgets/ConstraintsTransformBox-class.html](https://api.flutter.dev/flutter/widgets/ConstraintsTransformBox-class.html)

## When to use it?

- When you want to provide unlimited size or special constraints to child widgets
- When you want children to ignore parent constraints and have their natural size
- When you need to remove constraints in specific directions only
- When creating layouts where children can be larger than their parents
- In complex layouts where flexible constraint manipulation is needed

## Basic Usage

```typescript
// No constraints - child has natural size
ConstraintsTransformBox({
  constraintsTransform: ConstraintsTransformBox.unconstrained,
  child: Container({
    width: 300,
    height: 300,
    color: 'blue'
  })
})

// Remove only height constraints
ConstraintsTransformBox({
  constraintsTransform: ConstraintsTransformBox.heightUnconstrained,
  clipped: true,
  child: Column({
    children: [
      Container({ height: 100, color: 'red' }),
      Container({ height: 100, color: 'green' }),
      Container({ height: 100, color: 'blue' })
    ]
  })
})

// Custom constraint transformation
ConstraintsTransformBox({
  constraintsTransform: (constraints) => constraints.copyWith({
    maxWidth: constraints.maxWidth * 2,
    maxHeight: constraints.maxHeight * 0.5
  }),
  child: Container({
    color: 'purple',
    child: Text('Transformed constraints')
  })
})
```

## Props

### constraintsTransform (required)

**Value: (constraints: Constraints) => Constraints**

A function that transforms input constraints. Several static methods are provided:

```typescript
// Built-in transformation functions
ConstraintsTransformBox.unmodified        // Keep constraints unchanged
ConstraintsTransformBox.unconstrained     // Remove all constraints
ConstraintsTransformBox.widthUnconstrained    // Remove width constraints only
ConstraintsTransformBox.heightUnconstrained   // Remove height constraints only
ConstraintsTransformBox.maxWidthUnconstrained  // Unlimited max width only
ConstraintsTransformBox.maxHeightUnconstrained // Unlimited max height only
ConstraintsTransformBox.maxUnconstrained      // Unlimited max width/height

// Custom transformation function
(constraints) => constraints.copyWith({
  minWidth: 100,
  maxWidth: 500,
  minHeight: 50,
  maxHeight: 200
})
```

### alignment

**Value: Alignment** (default: **Alignment.center**)

How to align the child when it has a different size than the container.

```typescript
ConstraintsTransformBox({
  constraintsTransform: ConstraintsTransformBox.unconstrained,
  alignment: Alignment.topLeft,
  child: child
})
```

### clipped

**Value: boolean** (default: **false**)

Whether to clip the child when it exceeds the container area.

```typescript
ConstraintsTransformBox({
  constraintsTransform: ConstraintsTransformBox.unconstrained,
  clipped: true,  // Clip on overflow
  child: child
})
```

### child

**Value: Widget | undefined**

The child widget to which the transformed constraints will be applied.

## Practical Examples

### Example 1: Long List Without Scrolling

```typescript
const UnconstrainedList = ({ items }) => {
  return Container({
    height: 200,
    decoration: BoxDecoration({
      border: Border.all({ color: '#E0E0E0' }),
      borderRadius: BorderRadius.circular(8)
    }),
    child: ConstraintsTransformBox({
      constraintsTransform: ConstraintsTransformBox.heightUnconstrained,
      clipped: true,
      alignment: Alignment.topCenter,
      child: Column({
        children: items.map(item => 
          Container({
            height: 50,
            padding: EdgeInsets.all(16),
            decoration: BoxDecoration({
              border: Border(bottom: BorderSide({ color: '#F0F0F0' }))
            }),
            child: Text(item.title)
          })
        )
      })
    })
  });
};
```

### Example 2: Responsive Card Grid

```typescript
const ResponsiveCardGrid = ({ cards, maxCardWidth = 300 }) => {
  return ConstraintsTransformBox({
    constraintsTransform: (constraints) => {
      const availableWidth = constraints.maxWidth;
      const cardsPerRow = Math.floor(availableWidth / maxCardWidth);
      const actualCardWidth = availableWidth / cardsPerRow;
      
      return constraints.copyWith({
        minWidth: actualCardWidth,
        maxWidth: actualCardWidth
      });
    },
    child: Wrap({
      children: cards.map(card => 
        Container({
          height: 200,
          margin: EdgeInsets.all(8),
          decoration: BoxDecoration({
            color: 'white',
            borderRadius: BorderRadius.circular(12),
            boxShadow: [
              BoxShadow({
                color: 'rgba(0,0,0,0.1)',
                blurRadius: 8,
                offset: { x: 0, y: 2 }
              })
            ]
          }),
          child: Center({
            child: Text(card.title)
          })
        })
      )
    })
  });
};
```

### Example 3: Overflow Allowed Text

```typescript
const OverflowText = ({ text, maxLines = 1 }) => {
  return Container({

```

### Example 4: Flexible Image Gallery

```typescript
const FlexibleImageGallery = ({ images }) => {
  return ConstraintsTransformBox({
    constraintsTransform: (constraints) => {
      // Allow image gallery to have as much height as needed
      return constraints.copyWith({
        maxHeight: double.infinity
      });
    },
    clipped: false,
    child: Column({
      children: images.map(image => 
        Container({
          margin: EdgeInsets.only({ bottom: 16 }),
          child: AspectRatio({
            aspectRatio: 16/9,
            child: Image({
              src: image.url,
              objectFit: 'cover'
            })
          })
        })
      )
    })
  });
};
```

### Example 5: Dynamic Form Field

```typescript
const DynamicFormField = ({ 
  label, 
  value, 
  multiline = false,
  maxWidth = 400 
}) => {
  return ConstraintsTransformBox({
    constraintsTransform: (constraints) => {
      if (multiline) {
        // Multiline field has no height constraint
        return constraints.copyWith({
          maxWidth: Math.min(maxWidth, constraints.maxWidth),
          maxHeight: double.infinity
        });
      }
      // Single line field only limits max width
      return constraints.copyWith({
        maxWidth: Math.min(maxWidth, constraints.maxWidth)
      });
    },
    alignment: Alignment.topLeft,
    child: Column({
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Text(label, {
          style: TextStyle({
            fontSize: 14,
            fontWeight: 'bold',
            color: '#333'
          })
        }),
        SizedBox({ height: 8 }),
        Container({
          padding: EdgeInsets.all(12),
          decoration: BoxDecoration({
            border: Border.all({ color: '#E0E0E0' }),
            borderRadius: BorderRadius.circular(6)
          }),
          child: TextField({
            value: value,
            multiline: multiline,
            decoration: InputDecoration.none
          })
        })
      ]
    })
  });
};
```

## Understanding Transform Functions

Behavior of each static method:

```typescript
// 1. unmodified: No constraint changes
(constraints) => constraints

// 2. unconstrained: Remove all constraints
(constraints) => new Constraints()

// 3. widthUnconstrained: Remove width constraints only
(constraints) => constraints.heightConstraints()

// 4. heightUnconstrained: Remove height constraints only
(constraints) => constraints.widthConstraints()

// 5. maxWidthUnconstrained: Unlimited max width only
(constraints) => constraints.copyWith({ maxWidth: Infinity })

// 6. maxHeightUnconstrained: Unlimited max height only
(constraints) => constraints.copyWith({ maxHeight: Infinity })

// 7. maxUnconstrained: Unlimited max width/height
(constraints) => constraints.copyWith({ 
  maxWidth: Infinity, 
  maxHeight: Infinity 
})
```

## Important Notes

- Children with removed constraints can be larger than parents, so consider the clipped option
- Unconstrained transforms can impact performance, so use carefully
- Children might request infinite size, so appropriate limits are needed
- Special care is needed when using within Stack
- Layout overflow can occur, so testing is important
