## 熟悉的挫折感

听起来很熟悉吗？

在 Web 上处理复杂图形一直是开发人员的噩梦。HTML/CSS 有明显的局限性，使用 D3.js 或 Canvas API 感觉就像回到了 1990 年代，你必须手动计算一切。

让我们看一个简单的例子：在框中居中文本并使其自动换行。

### 使用 D3.js，是这样复杂的：

```javascript
// 从坐标计算开始...
const svg = d3.select("svg");
const boxWidth = 200;
const boxHeight = 100;

// 创建文本元素并设置位置
const text = svg.append("text")
  .attr("x", boxWidth / 2)
  .attr("y", boxHeight / 2)
  .attr("text-anchor", "middle");

// 实现复杂的换行函数
function wrapText(text, width) {
  const words = text.text().split(/\s+/);
  const lineHeight = 1.2;
  let line = [];
  let lineNumber = 0;
  let tspan = text.text(null).append("tspan");
  
  words.forEach(word => {
    line.push(word);
    tspan.text(line.join(" "));
    if (tspan.node().getComputedTextLength() > width) {
      line.pop();
      tspan.text(line.join(" "));
      line = [word];
      tspan = text.append("tspan")
        .attr("x", boxWidth / 2)
        .attr("dy", lineHeight + "em")
        .text(word);
    }
  });
  
  // 垂直居中的额外计算...
  const totalHeight = lineNumber * lineHeight * 16;
  text.attr("transform", `translate(0, ${-totalHeight/2})`);
}

// 还有调整大小事件处理...
```

超过 50 行代码，复杂的计算，结果仍然不完美。您能相信这是 2024 年的 Web 开发吗？

## 什么是 Flitter？

```
┌─────────────────────────────────────────────────┐
│                   您的应用                       │
├─────────────────────────────────────────────────┤
│                Widget 层                         │
│         (Container, Text, Column...)             │
├─────────────────────────────────────────────────┤
│              RenderObject 树                     │
│         (布局、绘制、命中测试)                  │
├─────────────────────────────────────────────────┤
│            Flitter 引擎核心                      │
├─────────────┬───────────────────────────────────┤
│  SVG 渲染器   │         Canvas 渲染器            │
└───────────────┴─────────────────────────────────┘
```

Flitter 是一个**在 Web 上工作的声明式 UI 渲染引擎**。它在 JavaScript 中实现了 Flutter 强大的 widget 系统。

### 核心特性

#### 🎯 双渲染器系统
- **SVG**：SEO 友好、可选择文本、CSS 动画
- **Canvas**：高性能、像素级控制、复杂动画

![svg-canvas](/svg-canvas.gif)

#### 🚀 业界首创的 SSR + Canvas Hydration
```typescript
// 在服务器上使用 SVG 渲染 → 在客户端切换到 Canvas
<Widget 
  renderer="canvas"
  ssr={{
    size: { width: 800, height: 600 }  // 服务器渲染尺寸
  }}
  widget={...} 
/>
```

使用 SVG 快速初始加载，使用 Canvas 流畅交互。**只有 Flitter 能做到这一点。**

## 与其他图形库的比较

### 😫 现有库的局限性

| 库 | 问题 |
|---------|----------|
| **D3.js** | 手动计算一切。坐标、尺寸、动画... |
| **Konva.js** | 面向对象但仍然是命令式的。复杂布局是噩梦 |
| **Fabric.js** | 适合画布操作，但不适合 UI 组合 |
| **Paper.js** | 在矢量图形方面很强，但对于一般 UI 很困难 |
| **Three.js** | 非常适合 3D，但是...用 Three.js 做 2D UI？ |

### ✨ Flitter 的解决方案

```typescript
// 其他库：数百行样板代码
// Flitter：只需要您需要的

Column({
  children: [
    Text("标题", { style: headerStyle }),
    Container({
      padding: EdgeInsets.all(20),
      decoration: new BoxDecoration({
        color: '#F3F4F6',
        borderRadius: BorderRadius.circular(8)
      }),
      child: Row({
        mainAxisAlignment: MainAxisAlignment.spaceBetween,
        children: [/* 复杂布局变得简单 */]
      })
    })
  ]
})
```

## 为什么现在选择 Flitter？

### 📈 市场需求
- SaaS 产品的复杂性不断增加
- 仪表板、工作流编辑器、图表工具的需求爆炸性增长
- 像"做得像 Notion 一样"或"像 Figma 一样"的需求

### 🚀 技术优势
- **开发速度**：与 D3.js 相比，开发速度快 5-10 倍
- **维护**：声明式代码易于理解
- **性能**：仅重新绘制必要部分的高效渲染
- **可扩展性**：基于 widget 架构无限可扩展
