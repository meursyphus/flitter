# Hello World - 居中文本

在 Web 上处理图形时，最基本的任务之一是在屏幕上居中文本。
即使是这个看似简单的任务，使用传统方法也需要相当复杂的代码。

## 为什么这是个问题？

要在 SVG 或 Canvas 中居中元素：
1. 您需要知道容器大小
2. 您需要计算元素的大小
3. 您需要手动计算中心坐标
4. 每当大小改变时，您需要重新计算

这些重复且复杂的任务容易出错，并使代码难以阅读。

## 理解关键概念

### 1. Center 组件
Flitter 的 `Center` 组件自动将其子元素居中：

```typescript
Center({
  child: Text("这将被居中！")
})
```

### 2. 自动调整大小
当父容器大小改变时，Flitter 会自动重新计算布局。
无需编写单独的调整大小事件处理程序。

### 3. 声明式样式
使用 `TextStyle` 声明式地定义文本的外观：

```typescript
Text("样式化文本", {
  style: TextStyle({
    fontSize: 24,
    fontWeight: 'bold',
    color: '#3B82F6'
  })
})
```

## 练习：各种对齐方法

### 使用 Align 组件
`Center` 实际上是 `Align` 组件的特例。要进行更精确的控制：

```typescript
// 定位在右上角
Align({
  alignment: Alignment.topRight,
  child: Text("右上角")
})

// 自定义位置（稍微在中心上方）
Align({
  alignment: new Alignment(0, -0.5),
  child: Text("中心上方")
})
```

### 与 Container 一起使用
在实际应用中，通常与 `Container` 一起使用：

```typescript
Container({
  width: 300,
  height: 200,
  color: '#EFF6FF',
  child: Center({
    child: Text("Container 中的文本", {
      style: TextStyle({
        fontSize: 20,
        color: '#1E40AF'
      })
    })
  })
})
```

## 为什么这很重要？

1. **生产力**：无需复杂计算即可直接实现所需布局
2. **可读性**：代码清楚地表达意图
3. **可维护性**：布局逻辑被封装，易于修改
4. **可扩展性**：通过组合组件可以轻松实现复杂布局
