# Flitter 安装和设置

Flitter 是一个可以通过 npm 安装并立即使用的库。

## 支持的框架

Flitter 官方支持以下环境：

- **Vanilla JavaScript** - 无需框架即可使用纯 JavaScript
- **React** - 轻松集成为 React 组件
- **Svelte** - 自然地用作 Svelte 组件
- **Vue** - 与 Vue 3 Composition API 一起使用
- **SolidJS** - 与响应式系统完美集成
- **Qwik** - 以优化的加载方式使用

## 选择渲染器

Flitter 支持两种类型的渲染器：

### Canvas 渲染器
- **优点**：高性能、像素级控制、适合复杂动画
- **缺点**：无法选择文本、对 SEO 不友好
- **用例**：游戏、复杂可视化、动画密集型应用

### SVG 渲染器
- **优点**：矢量图形、可选择文本、SEO 友好、可使用 CSS 样式
- **缺点**：复杂动画可能导致性能下降
- **用例**：图表、图表、静态可视化

### 服务器端渲染

```typescript
// 使用服务器端模式时：
// 1. 首先在服务器上渲染为 SVG
// 2. 在客户端使用指定的渲染器进行水合
<Widget 
  renderer="canvas"     // 客户端渲染器
  ssr={{                 // 启用 SSR 并指定尺寸
    size: {
      width: 800,      // 在服务器上渲染的宽度
      height: 600      // 在服务器上渲染的高度
    }
  }}
  widget={...} 
/>
```

## TypeScript 支持

Flitter 使用 TypeScript 编写，提供完整的类型支持。

```typescript
import { Container, ContainerProps, EdgeInsets, Text } from '@meursyphus/flitter';

const props: ContainerProps = {
  color: 'lightblue',
  padding: EdgeInsets.all(20),
  child: Text('你好，TypeScript！')
};

const container = Container(props);
```
