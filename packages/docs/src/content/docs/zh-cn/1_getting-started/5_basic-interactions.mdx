# 基本交互 - GestureDetector

用户交互在 Web 应用程序中是必不可少的。Flitter 通过 `GestureDetector` 组件支持简单处理各种用户输入。

## 什么是 GestureDetector？

`GestureDetector` 是一个检测其子组件上各种手势的组件。
它可以处理各种用户输入，如点击、双击、悬停、拖动等。

### 基本用法

```typescript
GestureDetector({
  onClick: () => {
    console.log('点击了！');
  },
  child: Container({
    width: 100,
    height: 100,
    color: '#3B82F6',
    child: Center({
      child: Text('点击我')
    })
  })
})
```

## 与 StatefulWidget 一起使用

大多数交互涉及状态更改，因此它们与 `StatefulWidget` 一起使用：

```typescript
class InteractiveButton extends StatefulWidget {
  createState() {
    return new InteractiveButtonState();
  }
}

class InteractiveButtonState extends State<InteractiveButton> {
  isPressed = false;
  isHovered = false;

  build(context: BuildContext) {
    return GestureDetector({
      onClick: () => {
        console.log('按钮被点击！');
      },
      onMouseEnter: () => {
        this.setState(() => {
          this.isHovered = true;
        });
      },
      onMouseLeave: () => {
        this.setState(() => {
          this.isHovered = false;
        });
      },
      onPanStart: () => {
        this.setState(() => {
          this.isPressed = true;
        });
      },
      onPanEnd: () => {
        this.setState(() => {
          this.isPressed = false;
        });
      },
      child: Container({
        padding: EdgeInsets.symmetric({ horizontal: 24, vertical: 12 }),
        decoration: new BoxDecoration({
          color: this.isPressed 
            ? '#1E40AF' 
            : this.isHovered 
              ? '#2563EB' 
              : '#3B82F6',
          borderRadius: BorderRadius.circular(8)
        }),
        child: Text('交互式按钮', {
          style: new TextStyle({
            color: '#FFFFFF',
            fontWeight: 'bold'
          })
        })
      })
    });
  }
}
```

## 详细的事件类型

### 点击相关事件

- **onClick**：点击时触发
- **onDoubleClick**：双击时触发
- **onLongPress**：长按时触发

### 鼠标相关事件

- **onMouseEnter**：鼠标进入组件区域时
- **onMouseLeave**：鼠标离开组件区域时
- **onMouseMove**：鼠标在组件上移动时

### 拖动相关事件

- **onPanStart**：拖动开始时
- **onPanUpdate**：拖动过程中（提供增量值）
- **onPanEnd**：拖动结束时

## 实际使用示例

### 1. 切换开关

```typescript
class ToggleSwitch extends StatefulWidget {
  createState() {
    return new ToggleSwitchState();
  }
}

class ToggleSwitchState extends State<ToggleSwitch> {
  isOn = false;

  build(context: BuildContext) {
    return GestureDetector({
      onClick: () => {
        this.setState(() => {
          this.isOn = !this.isOn;
        });
      },
      child: Container({
        width: 60,
        height: 30,
        decoration: new BoxDecoration({
          color: this.isOn ? '#10B981' : '#6B7280',
          borderRadius: BorderRadius.circular(15)
        }),
        child: Stack({
          children: [
            AnimatedPositioned({
              duration: 200,
              left: this.isOn ? 30 : 0,
              child: Container({
                width: 30,
                height: 30,
                decoration: new BoxDecoration({
                  color: '#FFFFFF',
                  borderRadius: BorderRadius.circular(15)
                })
              })
            })
          ]
        })
      })
    });
  }
}
```

### 2. 下拉菜单

```typescript
class DropdownMenu extends StatefulWidget {
  createState() {
    return new DropdownMenuState();
  }
}

class DropdownMenuState extends State<DropdownMenu> {
  isOpen = false;

  build(context: BuildContext) {
    return Column({
      children: [
        GestureDetector({
          onClick: () => {
            this.setState(() => {
              this.isOpen = !this.isOpen;
            });
          },
          child: Container({
            padding: EdgeInsets.all(12),
            decoration: new BoxDecoration({
              color: '#374151',
              borderRadius: BorderRadius.circular(6)
            }),
            child: Row({
              mainAxisAlignment: MainAxisAlignment.spaceBetween,
              children: [
                Text('选择菜单', {
                  style: new TextStyle({ color: '#E5E7EB' })
                }),
                Icon(this.isOpen ? 'arrow_up' : 'arrow_down')
              ]
            })
          })
        }),
        if (this.isOpen) Container({
          margin: EdgeInsets.only({ top: 4 }),
          decoration: new BoxDecoration({
            color: '#374151',
            borderRadius: BorderRadius.circular(6)
          }),
          child: Column({
            children: ['选项 1', '选项 2', '选项 3'].map(option => 
              GestureDetector({
                onClick: () => {
                  console.log(`已选择：${option}`);
                  this.setState(() => {
                    this.isOpen = false;
                  });
                },
                child: Container({
                  padding: EdgeInsets.all(12),
                  child: Text(option, {
                    style: new TextStyle({ color: '#E5E7EB' })
                  })
                })
              })
            )
          })
        })
      ]
    });
  }
}
```

## 性能优化技巧

1. **选择适当的渲染器**：对于复杂交互使用 Canvas 渲染器
2. **事件去抖**：对于频繁的事件（例如 onMouseMove）考虑去抖
3. **优化状态更新**：减少不必要的 setState 调用

## 可访问性考虑

使用 GestureDetector 时，应考虑可访问性：

1. **键盘支持**：使重要的交互可通过键盘访问
2. **焦点指示**：视觉上区分聚焦的元素
3. **足够的触摸区域**：确保移动设备上最小 44x44px 的大小
