# 基本元素 - 形状、布局、文本

Flitter 提供了类似于 Flutter 的组件系统，使构建复杂 UI 变得容易。
本文档介绍如何使用最基本的元素：形状、布局和文本。

## 绘制基本形状

在 Flitter 中，形状是使用 `Container` 组件和 `BoxDecoration` 创建的。

### Container 组件

`Container` 是 Flitter 中最基本但功能强大的组件：

- **尺寸设置**：使用 width 和 height 属性指定尺寸
- **颜色**：使用 color 或 decoration.color 设置背景颜色
- **间距**：使用 padding 和 margin 设置内部/外部边距
- **装饰**：使用 BoxDecoration 添加边框、圆角、阴影等

### 使用 BoxDecoration

```typescript
Container({
  decoration: new BoxDecoration({
    color: '#3B82F6',
    border: new Border({
      top: new BorderSide({ color: '#1E40AF', width: 2 }),
      // right、bottom、left 可以以相同方式设置
    }),
    borderRadius: BorderRadius.circular(8),
    // 或设置单个角
    borderRadius: BorderRadius.only({
      topLeft: Radius.circular(16),
      topRight: Radius.circular(16),
      bottomLeft: Radius.circular(0),
      bottomRight: Radius.circular(0)
    })
  })
})
```

### Row 和 Column

**Row** 水平排列子组件，而 **Column** 垂直排列子组件：

```typescript
// 水平排列
Row({
  mainAxisAlignment: MainAxisAlignment.spaceBetween, // 主轴对齐
  crossAxisAlignment: CrossAxisAlignment.center,     // 交叉轴对齐
  children: [/* 组件 */]
})

// 垂直排列
Column({
  mainAxisAlignment: MainAxisAlignment.start,
  crossAxisAlignment: CrossAxisAlignment.stretch,
  children: [/* 组件 */]
})
```

### Stack 和 Positioned

**Stack** 用于将组件叠加在一起：

```typescript
Stack({
  children: [
    Container({ /* 背景 */ }),
    Positioned({
      top: 10,
      left: 10,
      child: Container({ /* 绝对定位 */ })
    })
  ]
})
```

### Expanded 和 Flexible

用于填充剩余空间或按比例分配空间：

```typescript
Row({
  children: [
    Container({ width: 100 }), // 固定宽度
    Expanded({
      flex: 2, // 占用 2 倍空间
      child: Container({ /* 填充剩余空间 */ })
    }),
    Expanded({
      flex: 1, // 占用 1 倍空间
      child: Container({ /* 填充剩余空间 */ })
    })
  ]
})
```

Flitter 的 Text 组件提供各种样式和布局选项。

### TextStyle 属性

```typescript
Text('样式化文本', {
  style: new TextStyle({
    fontSize: 18,          // 字体大小
    fontWeight: 'bold',    // 粗细：'normal'、'bold'
    fontStyle: 'italic',   // 样式：'normal'、'italic'
    fontFamily: 'Arial',   // 字体系列
    color: '#3B82F6',      // 颜色
    letterSpacing: 1.5,    // 字母间距
    wordSpacing: 2.0,      // 单词间距
    height: 1.5,           // 行高
    decoration: 'underline' // 'none'、'underline'、'overline'、'lineThrough'
  })
})
```

### 文本对齐和溢出

```typescript
Container({
  width: 200,
  child: Text('长文本在这里...', {
    textAlign: TextAlign.center,    // 对齐：left、right、center、justify
    maxLines: 2,                     // 最大行数
    overflow: TextOverflow.ellipsis, // 溢出处理：clip、fade、ellipsis
  })
})
```

## 实际示例：创建卡片组件

让我们使用目前学到的内容创建一个卡片组件：

```typescript
Container({
  width: 300,
  padding: EdgeInsets.all(16),
  decoration: new BoxDecoration({
    color: '#FFFFFF',
    borderRadius: BorderRadius.circular(12),
    border: new Border({
      top: new BorderSide({ color: '#E5E7EB', width: 1 }),
      right: new BorderSide({ color: '#E5E7EB', width: 1 }),
      bottom: new BorderSide({ color: '#E5E7EB', width: 1 }),
      left: new BorderSide({ color: '#E5E7EB', width: 1 })
    })
  }),
  child: Column({
    crossAxisAlignment: CrossAxisAlignment.start,
    children: [
      Text('卡片标题', {
        style: new TextStyle({
          fontSize: 20,
          fontWeight: 'bold',
          color: '#1F2937'
        })
      }),
      SizedBox({ height: 8 }),
      Text('卡片内容在这里。它可以包含多行文本。', {
        style: new TextStyle({
          fontSize: 14,
          color: '#6B7280'
        })
      }),
      SizedBox({ height: 16 }),
      Row({
        mainAxisAlignment: MainAxisAlignment.end,
        children: [
          Container({
            padding: EdgeInsets.symmetric({ horizontal: 12, vertical: 6 }),
            decoration: new BoxDecoration({
              color: '#3B82F6',
              borderRadius: BorderRadius.circular(6)
            }),
            child: Text('操作', {
              style: new TextStyle({
                fontSize: 14,
                color: '#FFFFFF',
                fontWeight: 'bold'
              })
            })
          })
        ]
      })
    ]
  })
})
```

## 总结

- **Container**：具有尺寸、颜色、间距和装饰的基本容器
- **BoxDecoration**：边框和圆角等视觉装饰
- **Row/Column**：水平/垂直方向布局
- **Stack**：组件叠加
- **Text**：具有各种样式和对齐选项的文本
- **Expanded**：填充剩余空间
