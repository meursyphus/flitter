## 概述

ClipRRect 是一个使用圆角矩形裁剪其子组件的组件。

默认情况下，ClipRRect 使用自己的边界作为裁剪的基础矩形，但可以使用自定义裁剪器来定制裁剪的大小和位置。borderRadius 属性允许您单独设置每个角的圆度。

## 何时使用？

- 当您想为图像或容器应用圆角时
- 当创建具有平滑角效果的卡片 UI 或按钮时
- 当您需要用圆角裁剪溢出内容时
- 当您想为每个角设置不同半径时
- 当为头像或缩略图应用圆角效果时

## 基本用法

```typescript
// 所有角使用相同半径
ClipRRect({
  borderRadius: BorderRadius.circular(16),
  child: Image({
    src: 'https://example.com/image.jpg',
    width: 200,
    height: 200,
    objectFit: 'cover'
  })
})

// 仅特定角圆角
ClipRRect({
  borderRadius: BorderRadius.only({
    topLeft: Radius.circular(20),
    topRight: Radius.circular(20),
    bottomLeft: Radius.zero,
    bottomRight: Radius.zero
  }),
  child: Container({
    width: 300,
    height: 200,
    color: 'blue'
  })
})

// 椭圆角
ClipRRect({
  borderRadius: BorderRadius.all(Radius.elliptical(40, 20)),
  child: Container({
    width: 150,
    height: 100,
    color: 'green'
  })
})
```

## 属性详情

### borderRadius

**类型: BorderRadius**（默认值: **BorderRadius.zero**）

定义每个角的圆度。BorderRadius 类提供了各种工厂方法：

- `BorderRadius.circular(radius)`: 对所有角应用相同的圆形半径
- `BorderRadius.all(Radius)`: 对所有角应用相同的半径
- `BorderRadius.only({topLeft?, topRight?, bottomLeft?, bottomRight?})`: 单独设置每个角
- `BorderRadius.vertical({top?, bottom?})`: 设置上下角
- `BorderRadius.horizontal({left?, right?})`: 设置左右角

```typescript
// 圆形半径
ClipRRect({
  borderRadius: BorderRadius.circular(20),
  child: child
})

// 椭圆半径
ClipRRect({
  borderRadius: BorderRadius.all(Radius.elliptical(30, 15)),
  child: child
})

// 单独角设置
ClipRRect({
  borderRadius: BorderRadius.only({
    topLeft: Radius.circular(30),
    topRight: Radius.circular(10),
    bottomLeft: Radius.circular(5),
    bottomRight: Radius.circular(20)
  }),
  child: child
})
```

### clipper

**类型: (size: Size) => RRect**（可选）

定义自定义裁剪区域的回调函数。它接收组件的尺寸并必须返回一个 RRect（圆角矩形）对象。

```typescript
ClipRRect({
  clipper: (size) => {
    // 裁剪到中心的较小圆角矩形
    return RRect.fromRectAndRadius({
      rect: Rect.fromCenter({
        center: { x: size.width / 2, y: size.height / 2 },
        width: size.width * 0.8,
        height: size.height * 0.8
      }),
      radius: Radius.circular(10)
    });
  },
  child: child
})
```

### clipped

**类型: boolean**（默认值: **true**）

启用或禁用裁剪效果。

- `true`: 应用裁剪
- `false`: 禁用裁剪（子组件正常显示）

```typescript
ClipRRect({
  clipped: isClippingEnabled,
  borderRadius: BorderRadius.circular(16),
  child: content
})
```

### child

**类型: Widget**

要裁剪的子组件。

const GalleryThumbnail = ({ images, title }) => {

                  fontWeight: 'bold'
                }),
                overflow: TextOverflow.ellipsis
              })
            }),

                    color: 'white',
                    fontSize: 12
                  })
                })
              })
          ]
        })
      })
    ]
  });

## 理解 RRect API

### RRect 创建方法

```typescript
// 基本构造函数
RRect.fromLTRBR({
  left: 0,
  top: 0,
  right: 100,
  bottom: 100,
  radius: Radius.circular(10)
});

RRect.fromRectAndRadius({
  rect: Rect.fromLTWH({ left: 0, top: 0, width: 100, height: 100 }),
  radius: Radius.circular(10)
});

RRect.fromRectAndCorners({
  rect: rect,
  topLeft: Radius.circular(10),
  topRight: Radius.circular(20),
  bottomLeft: Radius.circular(5),
  bottomRight: Radius.circular(15)
});

// 膨胀/收缩
const inflatedRRect = rrect.inflate(10);  // 扩展 10 像素
const deflatedRRect = rrect.deflate(5);   // 收缩 5 像素
```

## 重要说明

- 裁剪可能影响渲染性能，所以仅在必要时使用
- 如果 borderRadius 值大于组件尺寸，可能会出现意外结果
- 裁剪区域外的触摸事件不会被检测到
- 在复杂布局中使用 Container 的 decoration 与 ClipRRect 时要小心
- 在图像加载期间使用占位符以防止布局移位
