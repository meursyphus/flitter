## 概述

`CustomPaint` 是一个允许您使用 Canvas API 或 SVG 绘制自定义图形的组件。受 Flutter 的 CustomPaint 启发，当您需要绘制复杂图形、图表、图表或任何自定义视觉元素时使用。

Flitter 的 CustomPaint 的独特之处在于它同时支持 SVG 和 Canvas 渲染。虽然由于 SVG 支持，接口与 Flutter 略有不同，但布局规则保持不变。

## 何时使用？

- 当需要绘制复杂图形或形状时
- 当实现自定义图表或图形时
- 当创建带有动画的自定义 UI 时
- 当开发游戏或可视化工具时
- 当现有组件无法表达您的特定 UI 需求时

## 基本用法

```typescript
import { CustomPaint, Size } from 'flitter';

// Canvas 渲染示例
const MyCanvasPaint = CustomPaint({
  size: new Size(200, 200),
  painter: {
    canvas: {
      paint: (context, size) => {
        const ctx = context.canvas;
        ctx.fillStyle = 'blue';
        ctx.fillRect(0, 0, size.width, size.height);
      }
    }
  }
});

// SVG 渲染示例
const MySvgPaint = CustomPaint({
  size: new Size(200, 200),
  painter: {
    svg: {
      createDefaultSvgEl: ({ createSvgEl }) => {
        return {
          rect: createSvgEl('rect')
        };
      },
      paint: ({ rect }, size) => {
        rect.setAttribute('fill', 'red');
        rect.setAttribute('width', `${size.width}`);
        rect.setAttribute('height', `${size.height}`);
      }
    }
  }
});
```

## 属性

### size（可选）
**值: Size**（默认值: **Size.zero**）

指定 CustomPaint 区域的尺寸。当为 `Size.zero` 时，它遵循子组件的尺寸。使用 `Size.infinite` 扩展到最大可用尺寸。

```typescript
// 固定尺寸
size: new Size(300, 200)

// 扩展到最大尺寸
size: Size.infinite

// 遵循子组件尺寸（默认）
size: Size.zero
```

### painter（必需）
**值: Painter**

包含图形绘制逻辑的 Painter 对象。您可以实现 SVG、Canvas 或两者。

#### Painter 类型定义：
```typescript
type Painter<SVGEls, D> = {
  dependencies?: D;  // 依赖数据
  shouldRepaint?: (oldPainter: Painter<SVGEls, D>) => boolean;  // 确定是否重绘
  svg?: CustomSvgPainter<SVGEls>;    // SVG 渲染实现
  canvas?: CustomCanvasPainter;       // Canvas 渲染实现
};
```

#### Canvas Painter：
```typescript
type CustomCanvasPainter = {
  paint: (context: CanvasPaintingContext, size: Size) => void;
};
```

#### SVG Painter：
```typescript
type CustomSvgPainter<T> = {
  createDefaultSvgEl: (context: SvgPaintContext) => T;  // 创建 SVG 元素
  paint: (els: T, size: Size) => void;                  // 更新 SVG 元素
};
```

### child（可选）
**值: Widget**

要在 CustomPaint 上方绘制的子组件。当存在子组件时，CustomPaint 在其后面绘制。

## 实际示例

### 示例 1：绘制简单形状

```typescript
import { CustomPaint, Size } from 'flitter';

const SimpleShapes = CustomPaint({
  size: new Size(300, 300),
  painter: {
    canvas: {
      paint: (context, size) => {
        const ctx = context.canvas;
        
        // 背景
        ctx.fillStyle = '#f0f0f0';
        ctx.fillRect(0, 0, size.width, size.height);
        
        // 绘制圆形
        ctx.fillStyle = '#3498db';
        ctx.beginPath();
        ctx.arc(150, 100, 50, 0, Math.PI * 2);
        ctx.fill();
        
        // 绘制矩形
        ctx.fillStyle = '#e74c3c';
        ctx.fillRect(100, 160, 100, 80);
        
        // 绘制三角形
        ctx.fillStyle = '#2ecc71';
        ctx.beginPath();
        ctx.moveTo(150, 250);
        ctx.lineTo(100, 320);
        ctx.lineTo(200, 320);
        ctx.closePath();
        ctx.fill();
      }
    }
  }
});
```

### 示例 2：动画图表

```typescript
import { CustomPaint, Size, StatefulWidget, State } from 'flitter';

class AnimatedChart extends StatefulWidget {
  createState() {
    return new AnimatedChartState();
  }
}

class AnimatedChartState extends State<AnimatedChart> {
  values = [30, 50, 80, 40, 60];
  
  build() {
    return CustomPaint({
      size: new Size(400, 300),
      painter: {
        dependencies: this.values,  // 添加依赖
        shouldRepaint: (oldPainter) => {
          // 仅在值变化时重绘
          return oldPainter.dependencies !== this.values;
        },
        canvas: {
          paint: (context, size) => {
            const ctx = context.canvas;
            const barWidth = size.width / this.values.length;
            const maxValue = Math.max(...this.values);
            
            // 背景
            ctx.fillStyle = '#f8f9fa';
            ctx.fillRect(0, 0, size.width, size.height);
            
            // 柱状图
            this.values.forEach((value, index) => {
              const barHeight = (value / maxValue) * size.height * 0.8;
              const x = index * barWidth + barWidth * 0.1;
              const y = size.height - barHeight;
              const width = barWidth * 0.8;
              
              // 柱子
              ctx.fillStyle = '#3498db';
              ctx.fillRect(x, y, width, barHeight);
              
              // 值标签
              ctx.fillStyle = '#2c3e50';
              ctx.font = '14px Arial';
              ctx.textAlign = 'center';
              ctx.fillText(value.toString(), x + width / 2, y - 10);
            });
          }
        }
      }
    });
  }
}
```

### 示例 3：使用 SVG 的复杂路径

```typescript
import { CustomPaint, Size } from 'flitter';

const SvgPathExample = CustomPaint({
  size: new Size(300, 300),
  painter: {
    svg: {
      createDefaultSvgEl: ({ createSvgEl }) => {
        return {
          background: createSvgEl('rect'),
          path: createSvgEl('path'),
          circle: createSvgEl('circle')
        };
      },
      paint: (els, size) => {
        // 背景
        els.background.setAttribute('fill', '#f0f0f0');
        els.background.setAttribute('width', `${size.width}`);
        els.background.setAttribute('height', `${size.height}`);
        
        // 复杂路径
        const pathData = `
          M ${size.width * 0.2} ${size.height * 0.5}
          Q ${size.width * 0.5} ${size.height * 0.2}
            ${size.width * 0.8} ${size.height * 0.5}
          T ${size.width * 0.5} ${size.height * 0.8}
          Z
        `;
        els.path.setAttribute('d', pathData);
        els.path.setAttribute('fill', 'none');
        els.path.setAttribute('stroke', '#3498db');
        els.path.setAttribute('stroke-width', '3');
        
        // 中心点
        els.circle.setAttribute('cx', `${size.width * 0.5}`);
        els.circle.setAttribute('cy', `${size.height * 0.5}`);
        els.circle.setAttribute('r', '5');
        els.circle.setAttribute('fill', '#e74c3c');
      }
    }
  }
});
```

### 示例 4：与子组件一起使用

```typescript
import { CustomPaint, Size, Container, Text } from 'flitter';

const BackgroundPattern = CustomPaint({
  painter: {
    canvas: {
      paint: (context, size) => {
        const ctx = context.canvas;
        
        // 绘制图案
        for (let x = 0; x < size.width; x += 20) {
          for (let y = 0; y < size.height; y += 20) {
            ctx.fillStyle = (x + y) % 40 === 0 ? '#e0e0e0' : '#f5f5f5';
            ctx.fillRect(x, y, 20, 20);
          }
        }
      }
    }
  },
  child: Container({
    alignment: Alignment.center,
    padding: EdgeInsets.all(20),
    child: Text('CustomPaint 背景上的文本', {
      style: {
        fontSize: 18,
        fontWeight: 'bold',
        color: '#2c3e50'
      }
    })
  })
});
```

## 最佳实践

- 正确实现 `shouldRepaint` 方法以避免不必要的重绘
- 使用 Canvas API 时，预先计算复杂计算以获得更好的性能
- 为您的用例选择适当的渲染器（SVG 在缩放时保持质量，Canvas 更适合复杂动画）
- 不要忘记清理动画以防止内存泄漏
- 使用 `dependencies` 有效管理绘制器状态变化
