## 概述

AnimatedAlign 是一个在子组件对齐方式改变时自动动画化过渡的组件。它为位置变化提供平滑的过渡效果。这个组件受 Flutter 的 AnimatedAlign 组件启发。

> Align 的动画版本，当给定的对齐方式发生变化时，会在给定的持续时间内自动过渡子组件的位置。

Flutter 参考：https://api.flutter.dev/flutter/widgets/AnimatedAlign-class.html

## 何时使用？

- 当您想要平滑地移动组件位置时
- 当根据用户交互动态更改组件对齐方式时
- 当您想要在布局变化期间提供视觉连续性时
- 当使用动画过渡浮动按钮或弹出窗口的位置时

## 基本用法

```typescript
import { AnimatedAlign, Alignment, Container, StatefulWidget } from '@flitter/core';

class AlignmentExample extends StatefulWidget {
  createState() {
    return new AlignmentExampleState();
  }
}

class AlignmentExampleState extends State<AlignmentExample> {
  alignment = Alignment.topLeft;

  build() {
    return GestureDetector({
      onTap: () => {
        this.setState(() => {
          // 点击时更改对齐位置
          this.alignment = this.alignment === Alignment.topLeft 
            ? Alignment.bottomRight 
            : Alignment.topLeft;
        });
      },
      child: AnimatedAlign({
        alignment: this.alignment,
        duration: 1000, // 1 秒
        child: Container({
          width: 50,
          height: 50,
          color: "blue",
        }),
      }),
    });
  }
}
```

## 属性

### alignment（必需）
**值：Alignment**

指定子组件的对齐位置。预定义值：
- `Alignment.topLeft`：左上角 (-1, -1)
- `Alignment.topCenter`：顶部中心 (0, -1)
- `Alignment.topRight`：右上角 (1, -1)
- `Alignment.centerLeft`：左侧中心 (-1, 0)
- `Alignment.center`：中心 (0, 0)
- `Alignment.centerRight`：右侧中心 (1, 0)
- `Alignment.bottomLeft`：左下角 (-1, 1)
- `Alignment.bottomCenter`：底部中心 (0, 1)
- `Alignment.bottomRight`：右下角 (1, 1)

也可以自定义对齐：
```typescript
Alignment.of({ x: 0.5, y: -0.5 }) // x: -1~1, y: -1~1
```

### duration（必需）
**值：number**

指定动画持续时间（毫秒）。

### curve（可选）
**值：Curve**（默认值：**Curves.linear**）

指定动画进程曲线。可用曲线：
- `Curves.linear`：匀速
- `Curves.easeIn`：缓慢开始
- `Curves.easeOut`：缓慢结束
- `Curves.easeInOut`：缓慢开始和结束
- `Curves.circIn`：圆形加速开始
- `Curves.circOut`：圆形减速结束
- `Curves.circInOut`：圆形加速/减速
- `Curves.backIn`：先后退然后开始
- `Curves.backOut`：超过目标然后返回
- `Curves.backInOut`：backIn + backOut
- `Curves.anticipate`：在继续之前的预期运动
- `Curves.bounceIn`：开始时弹跳
- `Curves.bounceOut`：结束时弹跳
- `Curves.bounceInOut`：开始/结束时弹跳

### widthFactor（可选）
**值：number | undefined**

子组件宽度的乘数。如果未指定，则使用父组件的全宽。

### heightFactor（可选）
**值：number | undefined**

子组件高度的乘数。如果未指定，则使用父组件的全高。

### child（可选）
**值：Widget | undefined**

要对齐的子组件。

### key（可选）
**值：any**

组件的唯一标识符。

## 实际示例

### 示例 1：交互式浮动按钮

```typescript
import { AnimatedAlign, Alignment, Container, FloatingActionButton, Curves } from '@flitter/core';

class InteractiveFloatingButton extends StatefulWidget {
  createState() {
    return new InteractiveFloatingButtonState();
  }
}

class InteractiveFloatingButtonState extends State<InteractiveFloatingButton> {
  isExpanded = false;

  build() {
    return Stack({
      children: [
        // 主内容
        Container({
          color: "lightgray",
        }),
        
        // 动画浮动按钮
        AnimatedAlign({
          alignment: this.isExpanded 
            ? Alignment.center 
            : Alignment.bottomRight,
          duration: 500,
          curve: Curves.easeInOut,
          child: Padding({
            padding: EdgeInsets.all(16),
            child: FloatingActionButton({
              onPressed: () => {
                this.setState(() => {
                  this.isExpanded = !this.isExpanded;
                });
              },
              child: Icon(this.isExpanded ? Icons.close : Icons.add),
            }),
          }),
        }),
      ],
    });
  }
}
```

### 示例 2：多位置过渡动画

```typescript
import { AnimatedAlign, Alignment, Container, Row, Column, Curves } from '@flitter/core';

class MultiPositionAnimation extends StatefulWidget {
  createState() {
    return new MultiPositionAnimationState();
  }
}

class MultiPositionAnimationState extends State<MultiPositionAnimation> {
  currentPosition = 0;
  positions = [
    Alignment.topLeft,
    Alignment.topRight,
    Alignment.bottomRight,
    Alignment.bottomLeft,
    Alignment.center,
  ];

  build() {
    return Column({
      children: [
        // 控制按钮
        Row({
          mainAxisAlignment: MainAxisAlignment.spaceEvenly,
          children: [
            ElevatedButton({
              onPressed: () => this.moveToNext(),
              child: Text("下一个位置"),
            }),
            ElevatedButton({
              onPressed: () => this.moveToCenter(),
              child: Text("到中心"),
            }),
          ],
        }),
        
        // 动画区域
        Expanded({
          child: Container({
            color: "#f0f0f0",
            child: AnimatedAlign({
              alignment: this.positions[this.currentPosition],
              duration: 800,
              curve: Curves.anticipate,
              child: Container({
                width: 80,
                height: 80,
                decoration: BoxDecoration({
                  color: "purple",
                  borderRadius: BorderRadius.circular(40),
                }),
                child: Center({
                  child: Text(
                    (this.currentPosition + 1).toString(),
                    style: TextStyle({ color: "white", fontSize: 24 }),
                  ),
                }),
              }),
            }),
          }),
        }),
      ],
    });
  }

  moveToNext() {
    this.setState(() => {
      this.currentPosition = (this.currentPosition + 1) % this.positions.length;
    });
  }

  moveToCenter() {
    this.setState(() => {
      this.currentPosition = 4; // 中心位置
    });
  }
}
```

### 示例 3：使用 widthFactor 和 heightFactor

```typescript
import { AnimatedAlign, Alignment, Container, Curves } from '@flitter/core';

class FactorAnimation extends StatefulWidget {
  createState() {
    return new FactorAnimationState();
  }
}

class FactorAnimationState extends State<FactorAnimation> {
  isCompact = false;

  build() {
    return GestureDetector({
      onTap: () => {
        this.setState(() => {
          this.isCompact = !this.isCompact;
        });
      },
      child: Container({
        width: 300,
        height: 300,
        color: "lightblue",
        child: AnimatedAlign({
          alignment: Alignment.center,
          widthFactor: this.isCompact ? 0.5 : 1.0,
          heightFactor: this.isCompact ? 0.5 : 1.0,
          duration: 600,
          curve: Curves.bounceOut,
          child: Container({
            width: 100,
            height: 100,
            color: "red",
            child: Center({
              child: Text(
                this.isCompact ? "收缩" : "展开",
                style: TextStyle({ color: "white" }),
              ),
            }),
          }),
        }),
      }),
    });
  }
}
```

## 注意事项

- 动画仅在 alignment 值发生变化时触发
- widthFactor 和 heightFactor 会影响子组件的尺寸，同时也会影响父组件的尺寸约束
- 如果在动画过程中设置新的 alignment 值，它会从当前位置平滑过渡到新的目标位置
- 如果 duration 为 0，组件会立即移动而没有动画

## 相关组件

- **Align**：基本的对齐子组件的组件，没有动画
- **AnimatedPositioned**：在 Stack 内动画化位置过渡
- **AnimatedContainer**：同时动画化多个属性
- **AnimatedPadding**：动画化填充过渡
