## 概述

AnimatedPadding 是一个在内边距发生变化时自动进行动画的组件，提供平滑的过渡效果。这个组件受 Flutter 的 AnimatedPadding 组件启发。

> Padding 的动画版本，当给定的内边距发生变化时，会在给定的持续时间内自动过渡缩进。

## 何时使用？

- 当需要根据用户交互动态调整组件间距时
- 当在卡片或容器展开/收起期间平滑改变内部边距时
- 当在石工列表中动态调整项目间距时
- 当在响应式设计中根据屏幕大小调整间距时
- 当在可折叠内容中使用动画过渡内边距时

## 基本用法

```typescript
import { AnimatedPadding, Container, EdgeInsets, StatefulWidget } from '@flitter/core';

class PaddingExample extends StatefulWidget {
  createState() {
    return new PaddingExampleState();
  }
}

class PaddingExampleState extends State<PaddingExample> {
  isExpanded = false;

  build() {
    return Column({
      children: [
        ElevatedButton({
          onPressed: () => {
            this.setState(() => {
              this.isExpanded = !this.isExpanded;
            });
          },
          child: Text(this.isExpanded ? "收起" : "展开"),
        }),
        Container({
          width: 300,
          height: 300,
          color: "lightgray",
          child: AnimatedPadding({
            padding: this.isExpanded 
              ? EdgeInsets.all(50) 
              : EdgeInsets.all(10),
            duration: 500, // 0.5 seconds
            child: Container({
              color: "blue",
              child: Center({
                child: Text("动画内边距", {
                  style: TextStyle({ color: "white" })
                }),
              }),
            }),
          }),
        }),
      ],
    });
  }
}
```

## 属性

### duration（必需）
**值：number**

指定动画持续时间（毫秒）。

### padding（可选）
**值：EdgeInsetsGeometry**（默认值：**EdgeInsets.all(0)**）

设置组件的内部间距。可用方法：

#### EdgeInsets 方法
- `EdgeInsets.all(value)`：所有方向相同间距
- `EdgeInsets.symmetric({ horizontal, vertical })`：水平/垂直对称间距
- `EdgeInsets.only({ top, bottom, left, right })`：指定每个方向的间距
- `EdgeInsets.fromLTRB({ left, top, right, bottom })`：按左/上/右/下顺序指定

#### 使用示例
```typescript
// 所有方向 20 间距
EdgeInsets.all(20)

// 水平 16，垂直 8 间距
EdgeInsets.symmetric({ horizontal: 16, vertical: 8 })

// 每个方向不同间距
EdgeInsets.only({ top: 10, left: 20, right: 20, bottom: 30 })

// 按 LTRB 顺序指定
EdgeInsets.fromLTRB({ left: 10, top: 20, right: 10, bottom: 20 })
```

### curve（可选）
**值：Curve**（默认值：**Curves.linear**）

指定动画进程曲线。可用曲线：
- `Curves.linear`：匀速
- `Curves.easeIn`：缓慢开始
- `Curves.easeOut`：缓慢结束
- `Curves.easeInOut`：缓慢开始和结束
- `Curves.circIn`：圆形加速开始
- `Curves.circOut`：圆形减速结束
- `Curves.circInOut`：圆形加速/减速
- `Curves.backIn`：先后退然后开始
- `Curves.backOut`：超过目标然后返回
- `Curves.backInOut`：backIn + backOut
- `Curves.anticipate`：在继续之前的预期运动
- `Curves.bounceIn`：开始时弹跳
- `Curves.bounceOut`：结束时弹跳
- `Curves.bounceInOut`：开始/结束时弹跳

### child（可选）
**值：Widget | undefined**

将应用内边距的子组件。

### key（可选）
**值：any**

组件的唯一标识符。

## 实际示例

### 示例 1：可折叠卡片

```typescript
import { AnimatedPadding, Container, Card, EdgeInsets, Curves } from '@flitter/core';

class FoldableCard extends StatefulWidget {
  createState() {
    return new FoldableCardState();
  }
}

class FoldableCardState extends State<FoldableCard> {
  isExpanded = false;

  build() {
    return Card({
      child: Column({
        children: [
          // Header
          ListTile({
            title: Text("可折叠卡片"),
            trailing: Icon(
              this.isExpanded ? Icons.expand_less : Icons.expand_more
            ),
            onTap: () => {
              this.setState(() => {
                this.isExpanded = !this.isExpanded;
              });
            },
          }),
          
          // Expandable content
          AnimatedPadding({
            padding: this.isExpanded 
              ? EdgeInsets.fromLTRB({ left: 16, top: 0, right: 16, bottom: 16 })
              : EdgeInsets.all(0),
            duration: 300,
            curve: Curves.easeOut,
            child: this.isExpanded ? Column({
              crossAxisAlignment: CrossAxisAlignment.start,
              children: [
                Text(
                  "详细内容",
                  { style: TextStyle({ fontWeight: "bold", fontSize: 16 }) }
                ),
                SizedBox({ height: 8 }),
                Text(
                  "点击时此卡片会展开，内部内容的内边距会平滑动画，看起来很自然。"
                ),
                SizedBox({ height: 12 }),
                Row({
                  children: [
                    ElevatedButton({
                      onPressed: () => {},
                      child: Text("操作 1"),
                    }),
                    SizedBox({ width: 8 }),
                    OutlinedButton({
                      onPressed: () => {},
                      child: Text("操作 2"),
                    }),
                  ],
                }),
              ],
            }) : SizedBox.shrink(),
          }),
        ],
      }),
    });
  }
}
```

### 示例 2：响应式边距

```typescript
import { AnimatedPadding, Container, EdgeInsets, Curves } from '@flitter/core';

class ResponsiveMargin extends StatefulWidget {
  createState() {
    return new ResponsiveMarginState();
  }
}

class ResponsiveMarginState extends State<ResponsiveMargin> {
  screenSize = "mobile"; // mobile, tablet, desktop

  get currentPadding() {
    switch (this.screenSize) {
      case "mobile":
        return EdgeInsets.all(8);
      case "tablet":
        return EdgeInsets.all(16);
      case "desktop":
        return EdgeInsets.all(32);
      default:
        return EdgeInsets.all(8);
    }
  }

  build() {
    return Column({
      children: [
        // Screen size selection
        Row({
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            ElevatedButton({
              onPressed: () => this.changeScreenSize("mobile"),
              child: Text("手机"),
              style: ButtonStyle({
                backgroundColor: this.screenSize === "mobile" ? "blue" : "gray",
              }),
            }),
            SizedBox({ width: 8 }),
            ElevatedButton({
              onPressed: () => this.changeScreenSize("tablet"),
              child: Text("平板"),
              style: ButtonStyle({
                backgroundColor: this.screenSize === "tablet" ? "blue" : "gray",
              }),
            }),
            SizedBox({ width: 8 }),
            ElevatedButton({
              onPressed: () => this.changeScreenSize("desktop"),
              child: Text("桌面"),
              style: ButtonStyle({
                backgroundColor: this.screenSize === "desktop" ? "blue" : "gray",
              }),
            }),
          ],
        }),
        SizedBox({ height: 20 }),
        
        // Responsive container
        Container({
          width: 400,
          height: 300,
          color: "#f0f0f0",
          child: AnimatedPadding({
            padding: this.currentPadding,
            duration: 400,
            curve: Curves.easeInOut,
            child: Container({
              decoration: BoxDecoration({
                color: "white",
                borderRadius: BorderRadius.circular(8),
                boxShadow: [
                  BoxShadow({
                    color: "rgba(0,0,0,0.1)",
                    blurRadius: 4,
                    offset: Offset({ x: 0, y: 2 }),
                  }),
                ],
              }),
              child: Center({
                child: Column({
                  mainAxisAlignment: MainAxisAlignment.center,
                  children: [
                    Text(
                      `当前模式: ${this.screenSize}`,
                      { style: TextStyle({ fontSize: 18, fontWeight: "bold" }) }
                    ),
                    SizedBox({ height: 8 }),
                    Text(
                      `内边距: ${this.currentPadding.top}px`,
                      { style: TextStyle({ color: "gray" }) }
                    ),
                  ],
                }),
              }),
            }),
          }),
        }),
      ],
    });
  }

  changeScreenSize(size: string) {
    this.setState(() => {
      this.screenSize = size;
    });
  }
}
```

### 示例 3：动态列表项目间距

```typescript
import { AnimatedPadding, Container, ListView, EdgeInsets, Curves } from '@flitter/core';

class DynamicListSpacing extends StatefulWidget {
  createState() {
    return new DynamicListSpacingState();
  }
}

class DynamicListSpacingState extends State<DynamicListSpacing> {
  isCompact = false;
  items = [
    { title: "第一项", color: "#FF6B6B" },
    { title: "第二项", color: "#4ECDC4" },
    { title: "第三项", color: "#45B7D1" },
    { title: "第四项", color: "#96CEB4" },
    { title: "第五项", color: "#FFEAA7" },
  ];

  build() {
    return Column({
      children: [
        // Density control
        Padding({
          padding: EdgeInsets.all(16),
          child: Row({
            mainAxisAlignment: MainAxisAlignment.spaceBetween,
            children: [
              Text(
                "列表密度",
                { style: TextStyle({ fontSize: 18, fontWeight: "bold" }) }
              ),
              Switch({
                value: this.isCompact,
                onChanged: (value) => {
                  this.setState(() => {
                    this.isCompact = value;
                  });
                },
              }),
            ],
          }),
        }),
        
        // List
        Expanded({
          child: ListView({
            children: this.items.map((item, index) => {
              return AnimatedPadding({
                key: ValueKey(index),
                padding: this.isCompact 
                  ? EdgeInsets.symmetric({ horizontal: 16, vertical: 4 })
                  : EdgeInsets.symmetric({ horizontal: 16, vertical: 8 }),
                duration: 200,
                curve: Curves.easeOut,
                child: Container({
                  height: this.isCompact ? 60 : 80,
                  decoration: BoxDecoration({
                    color: item.color,
                    borderRadius: BorderRadius.circular(8),
                  }),
                  child: Center({
                    child: Text(
                      item.title,
                      { style: TextStyle({ color: "white", fontSize: 16 }) }
                    ),
                  }),
                }),
              });
            }),
          }),
        }),
      ],
    });
  }
}
```

### 示例 4：非对称内边距动画

```typescript
import { AnimatedPadding, Container, EdgeInsets, Curves } from '@flitter/core';

class AsymmetricPadding extends StatefulWidget {
  createState() {
    return new AsymmetricPaddingState();
  }
}

class AsymmetricPaddingState extends State<AsymmetricPadding> {
  paddingIndex = 0;
  paddingConfigs = [
    EdgeInsets.all(20),
    EdgeInsets.only({ left: 50, right: 10, top: 20, bottom: 20 }),
    EdgeInsets.only({ left: 10, right: 50, top: 40, bottom: 10 }),
    EdgeInsets.symmetric({ horizontal: 30, vertical: 10 }),
    EdgeInsets.fromLTRB({ left: 60, top: 10, right: 20, bottom: 40 }),
  ];

  build() {
    const currentPadding = this.paddingConfigs[this.paddingIndex];
    
    return GestureDetector({
      onTap: () => this.nextPadding(),
      child: Container({
        width: 350,
        height: 250,
        color: "#2C3E50",
        child: AnimatedPadding({
          padding: currentPadding,
          duration: 800,
          curve: Curves.backOut,
          child: Container({
            decoration: BoxDecoration({
              gradient: LinearGradient({
                colors: ["#74b9ff", "#0984e3"],
                begin: Alignment.topLeft,
                end: Alignment.bottomRight,
              }),
              borderRadius: BorderRadius.circular(12),
            }),
            child: Center({
              child: Column({
                mainAxisAlignment: MainAxisAlignment.center,
                children: [
                  Text(
                    "非对称内边距",
                    { style: TextStyle({ color: "white", fontSize: 20, fontWeight: "bold" }) }
                  ),
                  SizedBox({ height: 8 }),
                  Text(
                    `L:${currentPadding.left} T:${currentPadding.top} R:${currentPadding.right} B:${currentPadding.bottom}`,
                    { style: TextStyle({ color: "white", fontSize: 14 }) }
                  ),
                  SizedBox({ height: 16 }),
                  Text(
                    "点击切换内边距",
                    { style: TextStyle({ color: "white", fontSize: 12, opacity: 0.8 }) }
                  ),
                ],
              }),
            }),
          }),
        }),
      }),
    });
  }

  nextPadding() {
    this.setState(() => {
      this.paddingIndex = (this.paddingIndex + 1) % this.paddingConfigs.length;
    });
  }
}
```

## 注意事项

- 内边距值不能为负数
- EdgeInsetsGeometry 的所有属性同时动画
- 过大的内边距值可能影响性能
- 如果在动画期间设置新的内边距值，它会从当前值平滑过渡到新值
- 即使没有子组件，内边距空间仍然会保持

## 相关组件

- **Padding**：用于设置内边距的基本组件，无动画
- **AnimatedContainer**：同时动画化多个属性
- **AnimatedAlign**：动画化对齐过渡
- **Container**：可同时设置内边距和外边距的多功能组件
