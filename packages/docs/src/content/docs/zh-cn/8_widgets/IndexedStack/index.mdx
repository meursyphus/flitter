# IndexedStack

`IndexedStack` 是一个堆叠组件，基于特定索引从多个子组件中仅显示一个子组件。它对于选项卡界面和页面切换非常有用。

## 概述

IndexedStack 渲染所有子组件，但只在屏幕上显示指定索引处的组件。其他组件被隐藏但保持其状态。

## 何时使用

- **选项卡界面**：当一次只显示一个选项卡时
- **页面切换器**：当在页面之间转换同时保持状态时
- **条件显示**：当根据状态显示不同组件时
- **向导 UI**：当在逐步进行过程中保持之前步骤的状态时
- **卡牌堆**：当从卡牌堆中只显示特定卡牌时

## 基本用法

```typescript
import { IndexedStack, Container, Text } from '@meursyphus/flitter';

IndexedStack({
  index: 1, // 显示第二个子组件
  children: [
    Container({
      color: 'red',
      child: Text('第一页')
    }),
    Container({
      color: 'blue', 
      child: Text('第二页')
    }),
    Container({
      color: 'green',
      child: Text('第三页')
    })
  ]
})
```

## 属性

| 属性 | 类型 | 默认值 | 描述 |
|----------|------|---------|-------------|
| `index` | `number` | `0` | 要显示的子组件索引 |
| `children` | `Widget[]` | - | 包含在堆叠中的子组件 |
| `alignment` | `Alignment?` | `Alignment.topLeft` | 子组件的对齐方式 |
| `sizing` | `StackFit?` | `StackFit.loose` | 堆叠尺寸行为 |
| `clipped` | `boolean?` | `true` | 子组件溢出时是否裁剪 |

### StackFit 值

- `StackFit.loose`：使用子组件的自然尺寸
- `StackFit.expand`：扩展到最大可用尺寸
- `StackFit.passthrough`：直接传递父约束

## 实际示例

### 1. 基本 IndexedStack



```typescript
import { StatefulWidget, State, IndexedStack, Container, Text, Column, Button } from '@meursyphus/flitter';

class BasicIndexedStack extends StatefulWidget {
  createState() {
    return new BasicIndexedStackState();
  }
}

class BasicIndexedStackState extends State<BasicIndexedStack> {
  currentIndex = 0;

  switchPage = (index: number) => {
    this.setState(() => {
      this.currentIndex = index;
    });
  }

  build() {
    return Column({
      children: [
        // 页面按钮
        Row({
          children: [
            Button({
              onPressed: () => this.switchPage(0),
              child: Text('页面 1')
            }),
            Button({
              onPressed: () => this.switchPage(1),
              child: Text('页面 2')
            }),
            Button({
              onPressed: () => this.switchPage(2),
              child: Text('页面 3')
            })
          ]
        }),
        
        // 索引堆叠
        IndexedStack({
          index: this.currentIndex,
          children: [
            Container({
              width: 300,
              height: 200,
              color: '#ff6b6b',
              child: Text('第一页', {
                style: { color: 'white', fontSize: 24 }
              })
            }),
            Container({
              width: 300,
              height: 200,
              color: '#4ecdc4',
              child: Text('第二页', {
                style: { color: 'white', fontSize: 24 }
              })
            }),
            Container({
              width: 300,
              height: 200,
              color: '#45b7d1',
              child: Text('第三页', {
                style: { color: 'white', fontSize: 24 }
              })
            })
          ]
        })
      ]
    });
  }
}
```



### 2. 有状态的选项卡界面



```typescript
import { StatefulWidget, State, IndexedStack, Column, TextField, Text } from '@meursyphus/flitter';

class TabWithState extends StatefulWidget {
  createState() {
    return new TabWithStateState();
  }
}

class TabWithStateState extends State<TabWithState> {
  activeTab = 0;

  build() {
    return Column({
      children: [
        // 选项卡头部
        Row({
          children: [
            Button({
              onPressed: () => this.setState(() => { this.activeTab = 0; }),
              child: Text('个人资料')
            }),
            Button({
              onPressed: () => this.setState(() => { this.activeTab = 1; }),
              child: Text('设置')
            }),
            Button({
              onPressed: () => this.setState(() => { this.activeTab = 2; }),
              child: Text('帮助')
            })
          ]
        }),
        
        // 选项卡内容（状态被保持）
        IndexedStack({
          index: this.activeTab,
          children: [
            // 个人资料选项卡
            ProfileTab(),
            
            // 设置选项卡
            SettingsTab(),
            
            // 帮助选项卡
            HelpTab()
          ]
        })
      ]
    });
  }
}

class ProfileTab extends StatefulWidget {
  createState() {
    return new ProfileTabState();
  }
}

class ProfileTabState extends State<ProfileTab> {
  name = '';
  email = '';

  build() {
    return Column({
      children: [
        TextField({
          placeholder: '姓名',
          value: this.name,
          onChanged: (value) => {
            this.setState(() => {
              this.name = value;
            });
          }
        }),
        TextField({
          placeholder: '邮箱',
          value: this.email,
          onChanged: (value) => {
            this.setState(() => {
              this.email = value;
            });
          }
        }),
        Text(`输入的信息: ${this.name}, ${this.email}`)
      ]
    });
  }
}
```

### 5. 动画集成



```typescript
import { StatefulWidget, State, IndexedStack, AnimatedContainer, Text } from '@meursyphus/flitter';

class AnimatedIndexedStack extends StatefulWidget {
  createState() {
    return new AnimatedIndexedStackState();
  }
}

class AnimatedIndexedStackState extends State<AnimatedIndexedStack> {
  currentPage = 0;
  
  nextPage = () => {
    this.setState(() => {
      this.currentPage = (this.currentPage + 1) % 3;
    });
  }

  build() {
    return Column({
      children: [
        Button({
          onPressed: this.nextPage,
          child: Text('下一页')
        }),
        
        IndexedStack({
          index: this.currentPage,
          children: [
            AnimatedContainer({
              duration: 300,
              width: this.currentPage === 0 ? 200 : 150,
              height: this.currentPage === 0 ? 200 : 150,
              color: '#e74c3c',
              child: Text('页面 1')
            }),
            AnimatedContainer({
              duration: 300,
              width: this.currentPage === 1 ? 200 : 150,
              height: this.currentPage === 1 ? 200 : 150,
              color: '#3498db',
              child: Text('页面 2')
            }),
            AnimatedContainer({
              duration: 300,
              width: this.currentPage === 2 ? 200 : 150,
              height: this.currentPage === 2 ? 200 : 150,
              color: '#2ecc71',
              child: Text('页面 3')
            })
          ]
        })
      ]
    });
  }
}
```



### 6. 向导风格界面



```typescript
import { StatefulWidget, State, IndexedStack, Column, Text, Button, Row } from '@meursyphus/flitter';

class WizardInterface extends StatefulWidget {
  createState() {
    return new WizardInterfaceState();
  }
}

class WizardInterfaceState extends State<WizardInterface> {
  currentStep = 0;
  totalSteps = 3;

  nextStep = () => {
    if (this.currentStep < this.totalSteps - 1) {
      this.setState(() => {
        this.currentStep++;
      });
    }
  }

  prevStep = () => {
    if (this.currentStep > 0) {
      this.setState(() => {
        this.currentStep--;
      });
    }
  }

  build() {
    return Column({
      children: [
        // 进度指示器
        Text(`步骤 ${this.currentStep + 1} / ${this.totalSteps}`),
        
        // 主内容
        IndexedStack({
          index: this.currentStep,
          children: [
            // 步骤 1
            Container({
              padding: EdgeInsets.all(20),
              child: Column({
                children: [
                  Text('步骤 1：基本信息', { style: { fontSize: 18, fontWeight: 'bold' } }),
                  TextField({ placeholder: '输入您的姓名' }),
                  TextField({ placeholder: '输入您的邮箱' })
                ]
              })
            }),
            
            // 步骤 2
            Container({
              padding: EdgeInsets.all(20),
              child: Column({
                children: [
                  Text('步骤 2：附加信息', { style: { fontSize: 18, fontWeight: 'bold' } }),
                  TextField({ placeholder: '输入您的电话' }),
                  TextField({ placeholder: '输入您的地址' })
                ]
              })
            }),
            
            // 步骤 3
            Container({
              padding: EdgeInsets.all(20),
              child: Column({
                children: [
                  Text('步骤 3：完成', { style: { fontSize: 18, fontWeight: 'bold' } }),
                  Text('所有信息已输入。'),
                  Text('您希望完成注册吗？')
                ]
              })
            })
          ]
        }),
        
        // 导航按钮
        Row({
          children: [
            Button({
              onPressed: this.currentStep > 0 ? this.prevStep : null,
              child: Text('上一步')
            }),
            Button({
              onPressed: this.currentStep < this.totalSteps - 1 ? this.nextStep : null,
              child: Text(this.currentStep === this.totalSteps - 1 ? '完成' : '下一步')
            })
          ]
        })
      ]
    });
  }
}
```



## 重要说明

1. **内存使用**：所有子组件都保存在内存中，所以对于多个组件要谨慎。

2. **索引范围**：如果索引超出 children 数组范围，将不会显示任何内容。

3. **状态保持**：隐藏的组件保持其状态，消耗内存。

4. **性能考虑**：处理多个复杂组件时考虑懒加载。

5. **裁剪**：设置 `clipped: false` 允许子组件溢出边界。
