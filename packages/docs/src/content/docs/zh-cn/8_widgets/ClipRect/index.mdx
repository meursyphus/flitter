## 概述

ClipRect 是一个使用矩形区域裁剪其子组件的组件。

这个组件接受一个返回 Rect 对象的裁剪器回调函数，允许您将子组件裁剪到任何所需的矩形区域。在内部，它使用 ClipPath 来执行裁剪。

参考: [https://api.flutter.dev/flutter/widgets/ClipRect-class.html](https://api.flutter.dev/flutter/widgets/ClipRect-class.html)

## 何时使用？

- 当您只想显示组件的一部分时
- 当您需要隐藏溢出内容时
- 当为可滚动区域定义边界时
- 当仅显示图像或视频的特定区域时
- 当实现自定义裁剪功能时

## 基本用法

```typescript
// 全区域裁剪（默认）
ClipRect({
  clipper: (size) => Rect.fromLTWH({
    left: 0,
    top: 0,
    width: size.width,
    height: size.height
  }),
  child: Image({
    src: 'https://example.com/large-image.jpg',
    width: 400,
    height: 400
  })
})

// 仅裁剪中心部分
ClipRect({
  clipper: (size) => Rect.fromCenter({
    center: { x: size.width / 2, y: size.height / 2 },
    width: size.width * 0.5,
    height: size.height * 0.5
  }),
  child: Container({
    width: 200,
    height: 200,
    color: 'blue'
  })
})

// 仅显示上半部分
ClipRect({
  clipper: (size) => Rect.fromLTRB({
    left: 0,
    top: 0,
    right: size.width,
    bottom: size.height / 2
  }),
  child: child
})
```

## 属性详情

### clipper（必需）

**值：(size: Size) => Rect**

定义裁剪区域的回调函数。它接收组件的尺寸作为参数，并必须返回一个 Rect 对象。

```typescript
// 各种裁剪模式示例
ClipRect({
  // 仅左上象限
clipRect({
  clipper: (size) => Rect.fromLTWH({
    left: 0,
    top: 0,
    width: size.width / 2,
    height: size.height / 2
  }),
  child: child
})

// 水平中央条带
ClipRect({
  clipper: (size) => Rect.fromLTRB({
    left: 0,
    top: size.height * 0.25,
    right: size.width,
    bottom: size.height * 0.75
  }),
  child: child
})

// 带边距的裁剪
ClipRect({
  clipper: (size) => Rect.fromLTWH({
    left: 20,
    top: 20,
    width: size.width - 40,
    height: size.height - 40
  }),
  child: child
})
```

### clipped

**值：boolean**（默认值：**true**）

启用/禁用裁剪效果。

- `true`：应用裁剪
- `false`：禁用裁剪（子组件正常显示）

```typescript
ClipRect({
  clipped: isClippingEnabled,
  clipper: (size) => Rect.fromLTWH({ 
    left: 0, 
    top: 0, 
    width: size.width, 
    height: size.height 
  }),
  child: content
})
```

### child

**值：Widget**

要裁剪的子组件。

## 理解 Rect API

### Rect 创建方法

```typescript
// 从左、上、宽、高创建
Rect.fromLTWH({
  left: 10,
  top: 10,
  width: 100,
  height: 100
});

// 从左、上、右、下坐标创建
Rect.fromLTRB({
  left: 10,
  top: 10,
  right: 110,
  bottom: 110
});

// 从中心点和尺寸创建
Rect.fromCenter({
  center: { x: 60, y: 60 },
  width: 100,
  height: 100
});

// 包围圆形的矩形
Rect.fromCircle({
  center: { x: 50, y: 50 },
  radius: 50
});

// 从两个点创建
Rect.fromPoints(
  { x: 10, y: 10 },  // 第一个点
  { x: 110, y: 110 } // 第二个点
);
```

### 示例 1：图像裁剪工具

```typescript
class ImageCropper extends StatefulWidget {
  imageUrl: string;
  
  constructor({ imageUrl }: { imageUrl: string }) {
    super();
    this.imageUrl = imageUrl;
  }
  
  createState(): State<ImageCropper> {
    return new ImageCropperState();
  }
}

class ImageCropperState extends State<ImageCropper> {
  cropRect = {
    x: 0,
    y: 0,
    width: 200,
    height: 200
  };
  
  build(): Widget {
    return Container({
      width: 400,
      height: 400,
      child: Stack({
        children: [
          // 原始图像（变暗）
          Opacity({
            opacity: 0.3,
            child: Image({
              src: this.widget.imageUrl,
              width: 400,
              height: 400,
              objectFit: 'cover'
            })
          }),
          // 裁剪区域
          Positioned({
            left: this.cropRect.x,
            top: this.cropRect.y,
            child: ClipRect({
              clipper: (size) => Rect.fromLTWH({
                left: 0,
                top: 0,
                width: this.cropRect.width,
                height: this.cropRect.height
              }),
              child: Transform.translate({
                offset: { x: -this.cropRect.x, y: -this.cropRect.y },
                child: Image({
                  src: this.widget.imageUrl,
                  width: 400,
                  height: 400,
                  objectFit: 'cover'
                })
              })
            })
          }),
          // 裁剪区域边框
          Positioned({
            left: this.cropRect.x,
            top: this.cropRect.y,
            child: Container({
              width: this.cropRect.width,
              height: this.cropRect.height,
              decoration: BoxDecoration({
                border: Border.all({
                  color: 'white',
                  width: 2
                })
              })
            })
          })
        ]
      })
    });
  }
}
```

### 示例 5：图像对比滑块

```typescript
class ImageComparisonSlider extends StatefulWidget {
  beforeImage: string;
  afterImage: string;
  
  constructor({ beforeImage, afterImage }: { beforeImage: string; afterImage: string }) {
    super();
    this.beforeImage = beforeImage;
    this.afterImage = afterImage;
  }
  
  createState(): State<ImageComparisonSlider> {
    return new ImageComparisonSliderState();
  }
}

class ImageComparisonSliderState extends State<ImageComparisonSlider> {
  sliderPosition = 0.5;
  
  build(): Widget {
    return GestureDetector({
      onHorizontalDragUpdate: (details) => {
        const newPosition = Math.max(0, Math.min(1, 
          details.localPosition.x / 400
        ));
        this.setState(() => {
          this.sliderPosition = newPosition;
        });
      },
      child: Container({
        width: 400,
        height: 300,
        child: Stack({
          children: [
            // 后图像（完整）
            Image({
              src: this.widget.afterImage,
              width: 400,
              height: 300,
              objectFit: 'cover'
            }),
            // 前图像（裁剪）
            ClipRect({
              clipper: (size) => Rect.fromLTWH({
                left: 0,
                top: 0,
                width: size.width * this.sliderPosition,
                height: size.height
              }),
              child: Image({
                src: this.widget.beforeImage,
                width: 400,
                height: 300,
                objectFit: 'cover'
              })
            }),
            // 滑块线
            Positioned({
              left: 400 * this.sliderPosition - 2,
              top: 0,
              bottom: 0,
              child: Container({
                width: 4,
                color: 'white',
                child: Center({
                  child: Container({
                    width: 40,
                    height: 40,
                    decoration: BoxDecoration({
                      color: 'white',
                      borderRadius: BorderRadius.circular(20),
                      boxShadow: [
                        BoxShadow({
                          color: 'rgba(0,0,0,0.3)',
                          blurRadius: 4,
                          offset: { x: 0, y: 2 }
                        })
                      ]
                    }),
                    child: Center({
                      child: Icon({
                        icon: Icons.dragHandle,
                        color: '#666'
                      })
                    })
                  })
                })
              })
            })
          ]
        })
      })
    });
  }
}
```

## 重要说明

- ClipRect 可能影响渲染性能，所以仅在必要时使用
- 裁剪区域外的触摸事件不会被检测到
- 当组件尺寸变化时会调用 clipper 函数，所以要避免复杂计算
- 与动画一起使用时要考虑性能优化
- 嵌套裁剪可能导致性能问题，请谨慎使用
