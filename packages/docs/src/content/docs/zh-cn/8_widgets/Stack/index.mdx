## 概述

Stack 是一个允许您叠放多个子组件的布局组件。

Stack 让您在 z 轴方向上将组件一个叠一个放置。子组件按顺序绘制，所以数组中的最后一个元素显示在顶部。与 Positioned 组件一起使用时，您可以为 Stack 内的组件指定精确位置。

## 何时使用？

- 当在背景图像上放置文本或按钮时
- 当在特定屏幕位置创建浮动操作按钮时
- 当在图标上叠放徽章或通知时
- 当在卡片上显示标签或标签时
- 当创建自定义覆盖效果时

## 基本用法

```typescript
// 简单 Stack 示例
const stack = Stack({
  children: [
    Container({ width: 200, height: 200, color: 'blue' }),
    Container({ width: 150, height: 150, color: 'red' }),
    Container({ width: 100, height: 100, color: 'green' })
  ]
});

// 与 Positioned 一起使用
const positionedStack = Stack({
  children: [
    Container({ color: 'lightgray' }), // 背景
    Positioned({
      top: 20,
      left: 20,
      child: Text('左上')
    }),
    Positioned({
      bottom: 20,
      right: 20,
      child: Text('右下')
    })
  ]
});
```

## 属性

### children（必需）

**值: Widget[]**

要在 Stack 中显示的子组件数组。它们按数组顺序从底部到顶部堆叠。

```typescript
Stack({
  children: [
    Image({ src: 'background.jpg' }), // 底层
    Container({ color: 'rgba(0,0,0,0.5)' }), // 中间层（半透明覆盖）
    Text('覆盖文本') // 顶层
  ]
})
```

### alignment

**值: Alignment**（默认值: **Alignment.topLeft**）

定义非定位子组件在 Stack 内的对齐方式。

- **Alignment.topLeft**: 左上对齐（默认）
- **Alignment.center**: 居中对齐
- **Alignment.bottomRight**: 右下对齐
- 所有其他 Alignment 值都可用

```typescript
Stack({
  alignment: Alignment.center,
  children: [
    Container({ width: 200, height: 200, color: 'blue' }),
    Container({ width: 100, height: 100, color: 'red' }) // 居中
  ]
})
```

### fit

**值: StackFit**（默认值: **StackFit.loose**）

定义非定位子组件在 Stack 内应如何调整尺寸。

- **StackFit.loose**: 子组件仅使用它们需要的空间（默认）
- **StackFit.expand**: 子组件扩展以填满 Stack
- **StackFit.passthrough**: Stack 约束原样传递给子组件

```typescript
Stack({
  fit: StackFit.expand,
  children: [
    Container({ color: 'blue' }), // 扩展到完整 Stack 尺寸
    Center({
      child: Text('居中文本')
    })
  ]
})
```

### clipped

**值: boolean**（默认值: **false**）

确定是否裁剪超出 Stack 边界的子组件。

```typescript
Stack({
  clipped: true,
  children: [
    Container({ width: 100, height: 100, color: 'blue' }),
    Positioned({
      top: -10, // 超出 Stack 边界
      left: -10,
      child: Container({ width: 50, height: 50, color: 'red' })
    })
  ]
})
```

## Positioned 组件

一个控制 Stack 子组件位置的组件。

### Positioned 属性

- **top**: 从顶部的距离
- **bottom**: 从底部的距离
- **left**: 从左侧的距离
- **right**: 从右侧的距离
- **width**: 明确的宽度
- **height**: 明确的高度
- **child**: 要定位的组件

```typescript
Positioned({
  top: 10,
  left: 10,
  width: 100,
  height: 50,
  child: Container({ color: 'red' })
})
```

### Positioned.fill()

创建一个填满整个 Stack 的 Positioned 组件。

```typescript
Stack({
  children: [
    Image({ src: 'background.jpg' }),
    Positioned.fill({
      child: Container({ 
        color: 'rgba(0, 0, 0, 0.5)' // 半透明覆盖
      })
    })
  ]
})
```

## 实际示例

### 示例 1：带徽章的个人资料卡

```typescript
const profileCard = Container({
  width: 120,
  height: 120,
  child: Stack({
    children: [
      // 头像图像
      Container({
        decoration: BoxDecoration({
          shape: 'circle',
          color: 'gray'
        }),
        child: Icon({ 
          icon: Icons.person, 
          size: 80,
          color: 'white' 
        })
      }),

      Positioned({
        bottom: 0,
        right: 0,
        child: Container({
          width: 30,
          height: 30,

            shape: 'circle',
            color: 'green',
            border: Border.all({ color: 'white', width: 3 })
          })
        })
      })
    ]
  })
});
```

### 示例 2：带覆盖的图库

```typescript
const galleryItem = Container({
  width: 300,
  height: 200,
  child: Stack({
    fit: StackFit.expand,
    children: [
      // 背景图像
      Image({
        src: 'gallery-image.jpg',
        fit: 'cover'
      }),
      // 渐变覆盖
      Positioned.fill({
        child: Container({
          decoration: BoxDecoration({
            gradient: LinearGradient({
              begin: Alignment.topCenter,
              end: Alignment.bottomCenter,
              colors: ['transparent', 'rgba(0,0,0,0.7)']
            })
          })
        })
      }),
      // 文本信息
      Positioned({
        bottom: 20,
        left: 20,
        right: 20,
        child: Column({
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Text('图像标题', {
              style: TextStyle({ 
                color: 'white', 
                fontSize: 20, 
                fontWeight: 'bold' 
              })
            }),
            Text('摄影师名字', {
              style: TextStyle({ 
                color: 'rgba(255,255,255,0.8)', 
                fontSize: 14 
              })
            })
          ]
        })
      })
    ]
  })
});
```

### 示例 3：浮动操作按钮

```typescript
const screenWithFAB = Stack({

            })
          ]
        }),
        child: Icon({ 
          icon: Icons.add, 
          color: 'white' 
        })
      })
    })
  ]
})
```

## 重要说明

- Stack 的尺寸由最大的非定位子组件决定。
- Positioned 组件必须是 Stack 的直接子组件。
- 当同时指定 `top` 和 `bottom` 时，`height` 被忽略。
- 当同时指定 `left` 和 `right` 时，`width` 被忽略。
- 在 Stack 内使用无边界组件（如 ListView）时，您必须提供明确的尺寸约束。

## 相关组件

- **Positioned**: 控制 Stack 内子组件的位置
- **Align**: 对齐单个子组件的简单方法
- **IndexedStack**: 从多个子组件中仅显示一个
- **CustomMultiChildLayout**: 用于更复杂的布局
- **Overlay**: 用于在整个应用上显示组件
