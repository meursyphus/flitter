## 概述

Column 是一个将其子组件垂直排列的布局组件。

Column 是 Flex 组件的便利包装器，方向固定为垂直。它用于将多个组件上下放置，并提供各种对齐选项。默认情况下，Column 占用所有可用的垂直空间，但您可以调整 `mainAxisSize` 以仅占用所需的空间。

## 何时使用？

- 当垂直排列表单字段时
- 当在列表项中结构化内容时
- 当为卡片或对话框创建垂直布局时
- 当垂直排列菜单项时
- 当按顺序显示标题、子标题和正文时

## 基本用法

```typescript
// 简单示例
const column = Column({
  children: [
    Text('标题'),
    Text('子标题'),
    Text('正文')
  ]
});

// 使用对齐选项
const alignedColumn = Column({
  mainAxisAlignment: MainAxisAlignment.center,
  crossAxisAlignment: CrossAxisAlignment.start,
  children: [
    Text('左对齐'),
    Text('垂直居中'),
    Text('文本组件')
  ]
});
```

## 属性

### children（必需）

**值: Widget[]**

要在 Column 中显示的子组件数组。它们按数组顺序从上到下排列。

```typescript
Column({
  children: [
    Container({ width: 100, height: 50, color: 'red' }),
    Container({ width: 100, height: 50, color: 'green' }),
    Container({ width: 100, height: 50, color: 'blue' })
  ]
})
```

### mainAxisAlignment

**值: MainAxisAlignment**（默认值: **MainAxisAlignment.start**）

定义子组件的垂直对齐。

- **start**: 顶部对齐（默认）
- **end**: 底部对齐
- **center**: 居中对齐
- **spaceBetween**: 将第一个和最后一个组件放在边缘，平均分配剩余空间
- **spaceAround**: 在每个组件周围分配相等空间
- **spaceEvenly**: 在所有组件和边缘之间分配相等空间

```typescript
// 居中对齐
Column({
  mainAxisAlignment: MainAxisAlignment.center,
  children: [
    Text('A'),
    Text('B'),
    Text('C')
  ]
})

// 等距分布
Column({
  mainAxisAlignment: MainAxisAlignment.spaceEvenly,
  children: [
    Icon({ icon: Icons.home }),
    Icon({ icon: Icons.search }),
    Icon({ icon: Icons.settings })
  ]
})
```

### crossAxisAlignment

**值: CrossAxisAlignment**（默认值: **CrossAxisAlignment.center**）

定义子组件的水平对齐。

- **start**: 左对齐
- **end**: 右对齐
- **center**: 水平居中对齐（默认）
- **stretch**: 拉伸以填满可用的水平空间

```typescript
Column({
  crossAxisAlignment: CrossAxisAlignment.start,
  children: [
    Container({ width: 100, height: 50, color: 'red' }),
    Container({ width: 150, height: 50, color: 'green' }),
    Container({ width: 75, height: 50, color: 'blue' })
  ]
})
```

### mainAxisSize

**值: MainAxisSize**（默认值: **MainAxisSize.max**）

控制 Column 占用的垂直空间量。

- **max**: 占用所有可用的垂直空间（默认）
- **min**: 仅占用子组件所需的最小空间

```typescript
// 仅占用必要空间
Container({
  color: 'lightgray',
  child: Column({
    mainAxisSize: MainAxisSize.min,
    children: [
      Text('紧凑'),
      Text('列')
    ]
  })
})
```

### verticalDirection

**值: VerticalDirection**（默认值: **VerticalDirection.down**）

定义子组件的垂直布局顺序。

- **down**: 从上到下（默认）
- **up**: 从下到上

```typescript
Column({
  verticalDirection: VerticalDirection.up,
  children: [
    Text('第1个'), // 在底部显示
    Text('第2个'), // 在中间显示
    Text('第3个')  // 在顶部显示
  ]
})
```

## 高级用法

### 与 Expanded 一起使用

```typescript
Column({
  children: [
    Container({ width: 100, height: 50, color: 'red' }),
    Expanded({
      child: Container({ width: 100, color: 'green' })
    }),
    Container({ width: 100, height: 50, color: 'blue' })
  ]
})
// 绿色 Container 占用所有剩余的垂直空间
```

### 按比例分配空间

```typescript
Column({
  children: [
    Flexible({
      flex: 1,
      child: Container({ color: 'red' })
    }),
    Flexible({
      flex: 2,
      child: Container({ color: 'green' })
    }),
    Flexible({
      flex: 1,
      child: Container({ color: 'blue' })
    })
  ]
})
// 红色占 25%，绿色占 50%，蓝色占 25% 的高度
```

## 实际示例

### 示例 1：登录表单

```typescript
const loginForm = Container({
  padding: EdgeInsets.all(20),
  child: Column({
    mainAxisAlignment: MainAxisAlignment.center,
    crossAxisAlignment: CrossAxisAlignment.stretch,
    children: [
      Text('登录', {
        style: TextStyle({ fontSize: 24, fontWeight: 'bold' })
      }),
      SizedBox({ height: 30 }),
      TextField({
        decoration: InputDecoration({
          labelText: '邮箱',
          border: OutlineInputBorder()
        })
      }),
      SizedBox({ height: 16 }),
      TextField({
        obscureText: true,
        decoration: InputDecoration({
          labelText: '密码',
          border: OutlineInputBorder()
        })
      }),
      SizedBox({ height: 24 }),
      ElevatedButton({
        onPressed: () => console.log('Login'),
        child: Text('登录')
      }),
      SizedBox({ height: 16 }),
      TextButton({
        onPressed: () => console.log('Sign up'),
        child: Text('没有账户？注册')
      })
    ]
  })
});
```

## 重要说明

- 如果子组件超出垂直空间，会发生溢出错误。在这种情况下使用 `SingleChildScrollView` 或 `Flexible`/`Expanded`。
- 使用 `crossAxisAlignment.stretch` 时，如果子组件的宽度没有约束，它们可能会无限扩展。
- Column 不支持滚动。如果需要滚动，请使用 `SingleChildScrollView` 或 `ListView`。
- 使用 `Row` 组件进行水平布局。

## 相关组件

- **Row**: 水平排列子组件
- **Flex**: Column 和 Row 基于的更灵活的布局组件
- **ListView**: 可滚动的垂直列表
- **Stack**: 将子组件叠放在一起
- **Expanded**: 在 Column 内占用剩余空间
- **Flexible**: 允许在 Column 内灵活调整尺寸
