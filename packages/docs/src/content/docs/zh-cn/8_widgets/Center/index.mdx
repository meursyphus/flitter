## 概述

Center 是一个将其子组件在内部居中的组件。它是 Align 组件的便利版本，设置了 `alignment: Alignment.center`，提供了一种简单的内容居中方式。

参考: [https://api.flutter.dev/flutter/widgets/Center-class.html](https://api.flutter.dev/flutter/widgets/Center-class.html)

## 何时使用？

- 当在容器内居中内容时
- 当在屏幕中央显示加载指示器时
- 当在中心放置空状态消息时
- 当居中对齐对话框或模态内容时
- 当居中图标或徽标时

## 基本用法

```typescript
// 简单居中对齐
Center({
  child: Text('居中文本')
})

// 使用尺寸因子
Center({
  widthFactor: 1.5,
  heightFactor: 2.0,
  child: Icon(Icons.star, { size: 48 })
})

// 全屏居中
Scaffold({
  body: Center({
    child: CircularProgressIndicator()
  })
})
```

## 属性

### child（可选）
**类型: Widget | undefined**

要居中的子组件。

### widthFactor（可选）
**类型: number | undefined**

将此组件的宽度设置为子组件宽度的倍数。如果为 null，则扩展到可用宽度。

```typescript
Center({
  widthFactor: 2.0,  // 子组件宽度的 2 倍
  child: Container({
    width: 100,
    height: 100,
    color: 'blue'
  })
})
// Center 的宽度将为 200
```

### heightFactor（可选）
**类型: number | undefined**

将此组件的高度设置为子组件高度的倍数。如果为 null，则扩展到可用高度。

```typescript
Center({
  heightFactor: 1.5,  // 子组件高度的 1.5 倍
  child: Container({
    width: 100,
    height: 100,
    color: 'green'
  })
})
// Center 的高度将为 150
```

## Center vs Align

Center 是 Align 的特殊情况：

```typescript
// 这两者是等价的
Center({
  child: Text('你好')
})

Align({
  alignment: Alignment.center,
  child: Text('你好')
})
```

## 布局行为

Center 组件如何确定其尺寸：

1. **严格约束**：使用约束的尺寸
2. **宽松约束且因子为 null**：尽可能扩展
3. **无限约束且因子为 null**：使用子组件的尺寸
4. **指定因子**：子组件尺寸 × 因子

```typescript
// 各种场景
Container({
  width: 200,
  height: 200,
  color: 'lightgray',
  child: Center({
    // Center 扩展到 200x200
    child: Container({
      width: 50,
      height: 50,
      color: 'blue'
    })
  })
})

Center({
  widthFactor: 2.0,
  heightFactor: 2.0,
  // Center 为 100x100（子组件的 2 倍）
  child: Container({
    width: 50,
    height: 50,
    color: 'red'
  })
})
```


## 重要说明

- Center 默认尽可能扩展，所以在 Stack 或无限尺寸容器中要小心
- widthFactor 和 heightFactor 必须大于 0
- 嵌套多个 Center 通常是不必要的
- 对于复杂的对齐需求，直接使用 Align 组件
- 当没有子组件且因子为 null 时，尺寸可能变为 0

## 相关组件

- **Align**：提供更多对齐选项的父组件
- **Container**：可以通过 alignment 属性居中对齐
- **Positioned**：在 Stack 内定位
- **Padding**：当需要带边距的居中时
- **Column/Row**：通过 mainAxisAlignment 和 crossAxisAlignment 对齐
