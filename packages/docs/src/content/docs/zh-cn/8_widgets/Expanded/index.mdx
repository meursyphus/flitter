## 概述

Expanded 是一个在 Row、Column 或 Flex 组件中沿主轴将其子组件扩展以填充可用空间的组件。

Expanded 是 Flexible 组件应用 `fit: FlexFit.tight` 的特殊情况。这意味着它强制子组件占据所有分配的空间。当存在多个 Expanded 组件时，空间会按照它们的 flex 值按比例分配。

## 何时使用？

- 当组件需要填充 Row/Column 中所有剩余空间时
- 当在多个组件之间按比例分配空间时
- 当让 TextField 或其他输入组件使用所有可用水平空间时
- 当创建响应式布局时
- 当使用 Spacer 将组件推开时

## 基本用法

```typescript
// 在 Row 中填充剩余空间
Row({
  children: [
    Container({ width: 100, height: 50, color: 'blue' }),
    Expanded({
      child: Container({ height: 50, color: 'red' })
    }),
    Container({ width: 100, height: 50, color: 'green' })
  ]
})

// 在 Column 中使用
Column({
  children: [
    Container({ height: 100, color: 'blue' }),
    Expanded({
      child: Container({ color: 'red' }) // 占据所有剩余的垂直空间
    }),
    Container({ height: 100, color: 'green' })
  ]
})
```

## 属性

### child（必需）

**值：Widget**

要扩展的子组件。

```typescript
Expanded({
  child: Container({ color: 'blue' })
})
```

### flex

**值：number**（默认值：**1**）

定义这个组件相对于其他 Expanded/Flexible 组件应该占据的空间比例。数值越大占据的空间越多。

- 必须是 0 或更大（不允许负值）
- 默认值为 1
- 空间作为与其他 flex 子组件的比例进行分配

```typescript
Row({
  children: [
    Expanded({
      flex: 2, // 占总空间的 2/3
      child: Container({ color: 'red' })
    }),
    Expanded({
      flex: 1, // 占总空间的 1/3
      child: Container({ color: 'blue' })
    })
  ]
})
```

## 高级用法

### 按比例分配空间

```typescript
Row({
  children: [
    Expanded({
      flex: 3, // 3/6 = 50%
      child: Container({ height: 100, color: 'red' })
    }),
    Expanded({
      flex: 2, // 2/6 = 33.33%
      child: Container({ height: 100, color: 'green' })
    }),
    Expanded({
      flex: 1, // 1/6 = 16.67%
      child: Container({ height: 100, color: 'blue' })
    })
  ]
})
```

### 与固定尺寸组件一起使用

```typescript
Row({
  children: [
    Icon({ icon: Icons.menu }), // 固定尺寸
    SizedBox({ width: 16 }), // 固定间距
    Expanded({
      child: Text('在可用空间内显示的长标题')
    }),
    IconButton({ // 固定尺寸
      icon: Icons.more_vert,
      onPressed: () => {}
    })
  ]
})
```

```typescript
const responsiveButtons = Container({
```

## 与 Flexible 的区别

Expanded 是 Flexible 的特殊情况：

```typescript
// 这两者是相同的
Expanded({ 
  flex: 2, 
  child: widget 
})

Flexible({ 
  flex: 2, 
  fit: FlexFit.tight, // 关键区别
  child: widget 
})
```

- **Expanded**：始终占据所有分配的空间（tight）
- **Flexible**：默认情况下仅占据所需空间（loose）

## 重要说明

- Expanded 必须是 Row、Column 或 Flex 的直接子组件。
- 不能将 Expanded 直接嵌套在另一个 Expanded 或 Flexible 内部。
- 如果父组件在主轴上具有无界尺寸，将发生错误。
- flex 值必须是 0 或更大；负值会导致错误。
- 在嵌套的 Column/Row 结构中使用 Expanded 时，可能需要将内部的 Column/Row 用 Expanded 包装。

## 相关组件

- **Flexible**：Expanded 基于的更灵活的组件
- **Spacer**：Expanded 的特殊用法，用于创建空间
- **Row**：在水平布局中使用 Expanded
- **Column**：在垂直布局中使用 Expanded
- **Flex**：Row 和 Column 的基础组件
