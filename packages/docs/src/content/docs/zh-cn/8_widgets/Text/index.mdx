## 概述

Text 是一个显示样式化文本的基本组件。

Text 组件显示具有单一样式的文本。字符串可能根据布局约束换行显示或在同一行显示。您可以使用 style 属性自定义文本的外观。如果需要使用多种样式，可以使用 Text.rich 构造函数或直接使用 RichText 组件。

## 何时使用？

- 当在屏幕上显示文本时
- 当显示标题、正文、标签等时
- 当需要单一样式的文本时
- 当需要处理文本溢出时
- 当需要文本对齐时

## 基本用法

```typescript
// 基本文本
Text('你好，Flitter！')

// 样式化文本
Text('样式化文本', {
  style: TextStyle({
    fontSize: 24,
    fontWeight: 'bold',
    color: 'blue'
  })
})

// 多样式文本（Text.rich）
Text.rich(
  TextSpan({
    text: '你好 ',
    children: [
      TextSpan({
        text: 'Flitter',
        style: TextStyle({ color: 'blue', fontWeight: 'bold' })
      }),
      TextSpan({ text: '！' })
    ]
  })
)
```

## 构造函数

### Text(data, props?)

默认构造函数创建单一样式的文本。

```typescript
Text('基本文本')
Text('样式化文本', { style: TextStyle({ fontSize: 18 }) })
```

### Text.rich(textSpan, props?)

创建具有多种样式的文本。

```typescript
Text.rich(
  TextSpan({
    text: '基本文本 ',
    style: TextStyle({ fontSize: 16 }),
    children: [
      TextSpan({
        text: '强调文本',
        style: TextStyle({ fontWeight: 'bold', color: 'red' })
      })
    ]
  })
)
```

## 属性

### style

**值: TextStyle | undefined**

定义文本样式。如果为 null，则使用默认文本样式。

```typescript
Text('样式化文本', {
  style: TextStyle({
    fontSize: 20,
    fontWeight: 'bold',
    color: '#333333'
  })
})
```

### textAlign

**值: TextAlign | undefined**

定义文本的水平对齐方式。

可用值：
- `TextAlign.left`: 左对齐
- `TextAlign.right`: 右对齐
- `TextAlign.center`: 居中对齐
- `TextAlign.justify`: 两端对齐
- `TextAlign.start`: 起始方向对齐（LTR 中为左）
- `TextAlign.end`: 结束方向对齐（LTR 中为右）

```typescript
Text('居中对齐文本', {
  textAlign: TextAlign.center
})
```

### overflow

**值: TextOverflow | undefined**

当文本超出空间时如何处理文本溢出。

可用值：
- `TextOverflow.clip`: 裁剪文本（默认）
- `TextOverflow.fade`: 淡出
- `TextOverflow.ellipsis`: 显示省略号（...）
- `TextOverflow.visible`: 允许溢出

```typescript
Text('这是一段非常长的文本，将在这里显示...', {
  overflow: TextOverflow.ellipsis
})
```

### softWrap

**值: boolean | undefined**（默认值: **true**）

文本是否应该在软换行处断开。

```typescript
Text('长文本将自动换行到下一行', {
  softWrap: true  // 允许换行
})

Text('此文本将仅在一行上显示', {
  softWrap: false  // 不换行
})
```

### textDirection

**值: TextDirection | undefined**

文本的方向性。

可用值：
- `TextDirection.ltr`: 从左到右
- `TextDirection.rtl`: 从右到左

```typescript
Text('مرحبا بالعالم', {
  textDirection: TextDirection.rtl
})
```

### textWidthBasis

**值: TextWidthBasis | undefined**

定义如何测量渲染文本的宽度。

可用值：
- `TextWidthBasis.parent`: 父组件宽度（默认）
- `TextWidthBasis.longestLine`: 最长行的宽度

```typescript
Text('多行\n文本', {
  textWidthBasis: TextWidthBasis.longestLine
})
```

## TextStyle 属性

TextStyle 定义文本的视觉属性。

### color

**值: string | undefined**

文本颜色。

```typescript
TextStyle({ color: 'blue' })
TextStyle({ color: '#FF5733' })
TextStyle({ color: 'rgba(255, 0, 0, 0.5)' })
```

### fontSize

**值: number | undefined**

以像素为单位的字体大小。

```typescript
TextStyle({ fontSize: 16 })  // 16px
TextStyle({ fontSize: 24 })  // 24px
```

### fontWeight

**值: string | undefined**

字体粗细。

可用值：
- `'normal'` 或 `'400'`
- `'bold'` 或 `'700'`
- `'100'` 到 `'900'`（以 100 为增量）

```typescript
TextStyle({ fontWeight: 'bold' })
TextStyle({ fontWeight: '600' })
```

### fontStyle

**值: FontStyle | undefined**

字体样式。

可用值：
- `FontStyle.normal`: 正常
- `FontStyle.italic`: 斜体

```typescript
TextStyle({ fontStyle: FontStyle.italic })
```

### fontFamily

**值: string | undefined**

要使用的字体系列。

```typescript
TextStyle({ fontFamily: 'Roboto' })
TextStyle({ fontFamily: 'Arial, sans-serif' })
```

### height

**值: number | undefined**

作为字体大小倍数的行高。

```typescript
TextStyle({ 
  fontSize: 16,
  height: 1.5  // 行高为 24px（16 * 1.5）
})
```

### inherit

**值: boolean**（默认值: **true**）

是否继承父组件的文本样式。

```typescript
TextStyle({ 
  inherit: false,  // 忽略父样式
  fontSize: 20
})
```

## 重要说明

- 当 softWrap 为 false 或文本限制为一行时，overflow 属性最为有效。
- 使用 fontFamily 时，请确保字体已安装在系统中或包含在应用中。
- height 属性调整行间距，作为 fontSize 的倍数工作。
- 使用 Text.rich 时，所有 TextSpan 都会继承基础样式（当 inherit 为 true 时）。

## 相关组件

- **RichText**: 用于更复杂的文本样式需求
- **TextField**: 用于用户输入
- **SelectableText**: 当需要可选择文本时
- **DefaultTextStyle**: 用于为子树定义默认文本样式
