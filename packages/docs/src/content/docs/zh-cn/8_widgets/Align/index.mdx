## 概述

Align 是一个在自身内部对齐子组件的组件，并可选择根据子组件的尺寸调整自身尺寸。它使用标准化的坐标系统来灵活地定位子组件。

## 何时使用

- 当需要在父组件内将子组件对齐到特定位置时
- 当创建子组件周围的特定比例边距时
- 当在对话框或弹出窗口中居中对齐内容时
- 当在特定位置放置按钮或图标时
- 当根据子组件的尺寸按比例调整父组件尺寸时

## 基本用法

```typescript
// 居中对齐（默认）
Align({
  child: Text('居中文本')
})

// 右上角对齐
Align({
  alignment: Alignment.topRight,
  child: Icon(Icons.close)
})

// 使用尺寸因子
Align({
  widthFactor: 2.0,
  heightFactor: 1.5,
  child: Container({
    width: 100,
    height: 100,
    color: 'blue'
  })
})
```

## 属性

### child（可选）
**类型：Widget | undefined**

要对齐的子组件。

### alignment（可选）
**类型：Alignment**（默认值：**Alignment.center**）

指定子组件的对齐位置。Alignment 由 x 和 y 值组成，每个值的范围为 -1.0 到 1.0。

主要的 Alignment 常量：
- `Alignment.topLeft`：(-1.0, -1.0)
- `Alignment.topCenter`：(0.0, -1.0)
- `Alignment.topRight`：(1.0, -1.0)
- `Alignment.centerLeft`：(-1.0, 0.0)
- `Alignment.center`：(0.0, 0.0)
- `Alignment.centerRight`：(1.0, 0.0)
- `Alignment.bottomLeft`：(-1.0, 1.0)
- `Alignment.bottomCenter`：(0.0, 1.0)
- `Alignment.bottomRight`：(1.0, 1.0)

```typescript
// 自定义对齐
Align({
  alignment: Alignment.of({ x: 0.5, y: -0.5 }), // 偏向右上方
  child: Text('自定义对齐')
})
```

### widthFactor（可选）
**类型：number | undefined**

将此组件的宽度设置为子组件宽度的倍数。如果为 null，则扩展到可用宽度。

```typescript
Align({
  widthFactor: 1.5, // 子组件宽度的 1.5 倍
  child: Container({
    width: 100,
    height: 50,
    color: 'red'
  })
})
// Align 的宽度变为 150
```

### heightFactor（可选）
**类型：number | undefined**

将此组件的高度设置为子组件高度的倍数。如果为 null，则扩展到可用高度。

```typescript
Align({
  heightFactor: 2.0, // 子组件高度的 2 倍
  child: Container({
    width: 100,
    height: 50,
    color: 'green'
  })
})
// Align 的高度变为 100
```

## 布局行为

### 尺寸约束处理

1. **在有界约束下**：
   - 如果 widthFactor 和 heightFactor 为 null，则扩展到可用尺寸
   - 以松弛的约束布局子组件
   - 根据 alignment 定位子组件

2. **在无界约束下**：
   - 如果 widthFactor 和 heightFactor 为 null，则收缩到子组件尺寸
   - 如果指定了因子，则尺寸由子组件尺寸 × 因子决定

3. **使用尺寸因子时**：
   - 始终调整为子组件尺寸 × 因子
   - 独立于父组件约束工作

### 示例 4：工具提示对齐

```typescript
class TooltipWidget extends StatefulWidget {
  message: string;
  child: Widget;
  alignment: Alignment;

  constructor({ message, child, alignment = Alignment.topCenter }) {
    super();
    this.message = message;
    this.child = child;
    this.alignment = alignment;
  }

  createState(): State<TooltipWidget> {
    return new TooltipWidgetState();
  }
}

class TooltipWidgetState extends State<TooltipWidget> {
  isVisible = false;

  build(): Widget {
    return Stack({
      clipBehavior: Clip.none,
      children: [
        GestureDetector({
          onMouseEnter: () => {
            this.setState(() => {
              this.isVisible = true;
            });
          },
          onMouseLeave: () => {
            this.setState(() => {
              this.isVisible = false;
            });
          },
          child: this.widget.child
        }),
        if (this.isVisible) Align({
          alignment: this.widget.alignment,
          widthFactor: 1.0,
          child: Transform.translate({
            offset: { x: 0, y: this.widget.alignment.y < 0 ? -30 : 30 },
            child: Container({
              padding: EdgeInsets.symmetric({ horizontal: 12, vertical: 6 }),
              decoration: BoxDecoration({
                color: 'rgba(0, 0, 0, 0.8)',
                borderRadius: BorderRadius.circular(4)
              }),
              child: Text(this.widget.message, {
                style: TextStyle({
                  color: 'white',
                  fontSize: 14
                })
              })
            })
          })
        })
      ]
    });
  }
}
```

## 重要注意事项

- widthFactor 和 heightFactor 必须大于 0
- alignment 的 x 和 y 值必须在 -1.0 到 1.0 之间
- 当没有子组件且 widthFactor 或 heightFactor 为 null 时，尺寸可能变为 0
- 在 Stack 中使用时，要理解 Align 和 Positioned 之间的区别
- 使用尺寸因子可能会影响布局性能
- 放松约束以允许子组件拥有其期望的尺寸

## 相关组件

- **Center**：Align 的特殊情况，始终居中内容
- **Positioned**：在 Stack 内的绝对定位
- **Container**：可以使用 alignment 属性对齐子组件
- **FractionallySizedBox**：根据父组件尺寸比例调整尺寸
- **AnimatedAlign**：对齐之间的动画过渡
