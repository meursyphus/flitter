## 概述

AnimatedContainer 是 Container 的动画版本，当属性值发生变化时会自动应用动画。

AnimatedContainer 在属性值发生变化时，使用提供的曲线和持续时间自动在旧值和新值之间进行动画。null 属性不会被动画化。其子组件和后代不会被动画化。这个类对于在 Container 的不同参数之间生成简单的隐式过渡非常有用，它使用内部的 AnimationController。

## 何时使用？

- 当需要平滑过渡组件大小、颜色、内边距等时
- 当需要为用户交互提供视觉反馈时
- 当需要平滑地表达状态变化时
- 当需要简单动画而不需要复杂的 AnimationController 时
- 当需要表达悬停效果或选中状态时

## 基本用法

```typescript
// 创建一个 StatefulWidget 来管理状态
class AnimatedContainerExample extends StatefulWidget {
  createState() {
    return new AnimatedContainerExampleState();
  }
}

class AnimatedContainerExampleState extends State<AnimatedContainerExample> {
  isExpanded = false;

  build() {
    return GestureDetector({
      onTap: () => {
        this.setState(() => {
          this.isExpanded = !this.isExpanded;
        });
      },
      child: AnimatedContainer({
        duration: 300, // 300毫秒
        curve: Curves.easeInOut,
        width: this.isExpanded ? 200 : 100,
        height: this.isExpanded ? 200 : 100,
        color: this.isExpanded ? 'blue' : 'red',
        child: Center({
          child: Text('点击我')
        })
      })
    });
  }
}

// 导出为工厂函数
export default classToFunction(AnimatedContainerExample);
```

## 属性

### duration（必需）

**值：number**

动画化此容器参数的持续时间（以毫秒为单位）。

```typescript
AnimatedContainer({
  duration: 500, // 0.5 秒
  width: 100,
  height: 100
})
```

### curve

**值：Curve**（默认值：**Curves.linear**）

定义动画进程曲线。有各种内置曲线可用。

```typescript
AnimatedContainer({
  duration: 300,
  curve: Curves.easeInOut, // 平滑开始和结束
  width: expanded ? 200 : 100
})
```

可用曲线：
- **Curves.linear**：匀速
- **Curves.easeIn**：缓慢开始
- **Curves.easeOut**：缓慢结束
- **Curves.easeInOut**：缓慢开始和结束
- **Curves.bounceIn**：开始时弹跳
- **Curves.bounceOut**：结束时弹跳
- **Curves.bounceInOut**：开始和结束时弹跳
- **Curves.anticipate**：先后退然后前进
- **Curves.backIn**：先拉回然后开始
- **Curves.backOut**：超过目标然后返回

### width

**值：number | undefined**

容器的宽度。改变时会动画化。

```typescript
AnimatedContainer({
  duration: 200,
  width: isSelected ? 150 : 100,
  height: 50
})
```

### height

**值：number | undefined**

容器的高度。改变时会动画化。

```typescript
AnimatedContainer({
  duration: 200,
  width: 100,
  height: isExpanded ? 200 : 100
})
```

### color

**值：string | undefined**

容器的背景颜色。不能与 decoration 一起使用。

```typescript
AnimatedContainer({
  duration: 300,
  color: isActive ? 'blue' : 'gray',
  child: Text('状态指示器')
})
```

### decoration

**值：Decoration | undefined**

在子组件后面绘制的装饰。所有 BoxDecoration 属性都会动画化。

```typescript
AnimatedContainer({
  duration: 400,
  decoration: BoxDecoration({
    color: isHovered ? 'lightblue' : 'white',
    borderRadius: BorderRadius.circular(isHovered ? 20 : 10),
    boxShadow: isHovered ? [
      BoxShadow({
        color: 'rgba(0, 0, 0, 0.2)',
        blurRadius: 10,
        offset: { x: 0, y: 5 }
      })
    ] : []
  })
})
```

### margin

**值：EdgeInsets | undefined**

容器周围的空白空间。改变时会动画化。

```typescript
AnimatedContainer({
  duration: 300,
  margin: EdgeInsets.all(isSelected ? 20 : 10),
  color: 'blue'
})
```

### padding

**值：EdgeInsets | undefined**

容器内部的空白空间。改变时会动画化。

```typescript
AnimatedContainer({
  duration: 300,
  padding: EdgeInsets.all(isExpanded ? 20 : 10),
  child: Text('内容')
})
```

### alignment

**值：Alignment | undefined**

在容器内对齐子组件。改变时会动画化。

```typescript
AnimatedContainer({
  duration: 500,
  alignment: isLeft ? Alignment.centerLeft : Alignment.centerRight,
  child: Icon({ icon: Icons.star })
})
```

### constraints

**值：Constraints | undefined**

应用于子组件的额外约束。最小/最大尺寸会动画化。

```typescript
AnimatedContainer({
  duration: 300,
  constraints: Constraints({
    minWidth: 100,
    maxWidth: isExpanded ? 300 : 150,
    minHeight: 50,
    maxHeight: isExpanded ? 200 : 100
  })
})
```

### clipped

**值：boolean**（默认值：**false**）

是否将子组件裁剪到容器的边界内。

```typescript
AnimatedContainer({
  duration: 300,
  clipped: true,
  width: 100,
  height: 100,
  child: Image({ src: 'large-image.jpg' })
})
```

### transform

**值：Matrix4 | undefined**

要应用的变换矩阵。旋转、缩放和平移会动画化。

```typescript
AnimatedContainer({
  duration: 600,
  transform: isRotated 
    ? Matrix4.rotationZ(Math.PI / 4) // 45 度旋转
    : Matrix4.identity(),
  child: Icon({ icon: Icons.refresh })
})
```

### transformAlignment

**值：Alignment | undefined**

变换原点的对齐方式。与 transform 一起使用。

```typescript
AnimatedContainer({
  duration: 500,
  transform: Matrix4.rotationZ(angle),
  transformAlignment: Alignment.center, // 围绕中心旋转
  child: Text('旋转中')
})
```

### child

**值：Widget | undefined**

子组件，不会被动画化。

```typescript
AnimatedContainer({
  duration: 300,
  width: 100,
  height: 100,
  child: Icon({ icon: Icons.favorite })
})
```

### onEnd

**值：() => void | undefined**

动画完成时调用的回调函数。

```typescript
AnimatedContainer({
  duration: 500,
  width: expanded ? 200 : 100,
  onEnd: () => {
    console.log('动画完成');
    // 触发下一个动画或状态变化
  }
})
```

## 常见用例

### 基于状态的 UI 变化

AnimatedContainer 擅长在不同 UI 状态之间平滑过渡：

```typescript
// 主题切换
AnimatedContainer({
  duration: 300,
  decoration: BoxDecoration({
    color: isDarkMode ? '#212121' : '#FFFFFF',
    borderRadius: BorderRadius.circular(8)
  }),
  child: content
})

// 选中状态
AnimatedContainer({
  duration: 200,
  decoration: BoxDecoration({
    border: Border.all({
      color: isSelected ? 'blue' : 'transparent',
      width: isSelected ? 2 : 0
    })
  })
})

// 加载状态
AnimatedContainer({
  duration: 400,
  height: isLoading ? 200 : 0,
  opacity: isLoading ? 1 : 0,
  child: LoadingIndicator()
})
```

### 交互组件

创建具有平滑过渡的吸引人的交互元素：

```typescript
// 可展开卡片
AnimatedContainer({
  duration: 300,
  height: isExpanded ? null : 100,
  child: content
})

// 悬停效果
AnimatedContainer({
  duration: 200,
  transform: Matrix4.identity()
    .scaled(isHovered ? 1.05 : 1.0),
  boxShadow: isHovered ? elevatedShadow : flatShadow
})

// 按压反馈
AnimatedContainer({
  duration: 100,
  transform: Matrix4.identity()
    .scaled(isPressed ? 0.95 : 1.0)
})
```

```typescript
class LoadingSkeleton extends StatefulWidget {
  createState() {
    return new LoadingSkeletonState();
  }
}

class LoadingSkeletonState extends State<LoadingSkeleton> {
  animationPhase = 0;
  Timer? timer;

  initState() {
    super.initState();
    this.timer = Timer.periodic(Duration({ milliseconds: 800 }), () => {
      this.setState(() => {
        this.animationPhase = (this.animationPhase + 1) % 3;
      });
    });
  }

  dispose() {
    this.timer?.cancel();
    super.dispose();
  }

  build() {
    return AnimatedContainer({
      duration: 800,
      curve: Curves.easeInOut,
      width: 300,
      height: 100,
      decoration: BoxDecoration({
        gradient: LinearGradient({
          colors: ['#E0E0E0', '#F5F5F5', '#E0E0E0'],
          stops: [0, 0.5, 1],
          begin: Alignment.centerLeft.add(Alignment(-1 + this.animationPhase * 0.5, 0)),
          end: Alignment.centerRight.add(Alignment(-1 + this.animationPhase * 0.5, 0))
        }),
        borderRadius: BorderRadius.circular(8)
      })
    });
  }
}
```

```typescript
    return new ResponsiveGridItemState();
  }
}

class ResponsiveGridItemState extends State<ResponsiveGridItem> {
  isPressed = false;
  isHovered = false;
  
  build() {
    return GestureDetector({
      onTapDown: () => this.setState(() => { this.isPressed = true; }),
      onTapUp: () => this.setState(() => { this.isPressed = false; }),
      onTapCancel: () => this.setState(() => { this.isPressed = false; }),
      onMouseEnter: () => this.setState(() => { this.isHovered = true; }),
      onMouseLeave: () => this.setState(() => { this.isHovered = false; }),

        duration: 200,
        curve: Curves.easeOut,
        margin: EdgeInsets.all(this.isPressed ? 12 : 8),
        transform: Matrix4.identity()

        transformAlignment: Alignment.center,
        decoration: BoxDecoration({
          color: this.widget.item.color,
          borderRadius: BorderRadius.circular(this.isHovered ? 20 : 12),
```

```typescript
class DebouncedAnimation extends StatefulWidget {

class DebouncedAnimationState extends State<DebouncedAnimation> {
  Timer? debounceTimer;
  bool isExpanded = false;

  handleChange(bool value) {

    });
```

### 4. 考虑为复杂动画使用 AnimatedBuilder

对于需要更多控制的复杂动画：

```typescript
class ComplexAnimation extends StatefulWidget {
  createState() => new ComplexAnimationState();
}

class ComplexAnimationState extends State<ComplexAnimation> 
    with SingleTickerProviderStateMixin {
  late AnimationController controller;
  late Animation<double> scaleAnimation;
  late Animation<double> rotationAnimation;

  initState() {
    super.initState();
    this.controller = AnimationController({
      duration: Duration({ seconds: 2 }),
      vsync: this
    });
    
    this.scaleAnimation = Tween<double>({
      begin: 1.0,
      end: 1.5
    }).animate(CurvedAnimation({
      parent: this.controller,
      curve: Curves.easeInOut
    }));
    
    this.rotationAnimation = Tween<double>({
      begin: 0,
      end: 2 * Math.PI
    }).animate(this.controller);
  }

  build() {
    return AnimatedBuilder({
      animation: this.controller,
      builder: (context, child) => {
        return Transform.scale({
          scale: this.scaleAnimation.value,
          child: Transform.rotate({
            angle: this.rotationAnimation.value,
            child: Container({
              width: 100,
              height: 100,
              color: 'blue'
            })
          })
        });
      }
    });
  }
}
```

## 重要注意事项

- duration 是必需属性。您必须指定动画持续时间。
- color 和 decoration 不能同时使用。
- 子组件不会被动画化。要动画化子组件，请使用单独的 AnimatedWidget。
- 同时动画化太多属性可能会影响性能。
- 当状态快速变化时，当前动画会被中断并开始新的动画。
- transform 不会改变布局大小。对于需要占用空间的动画，请使用 width/height。
- 复杂的装饰动画可能会影响性能，因此请谨慎使用。

## 故障排除

### 动画不流畅

如果动画显得卡顿：

```typescript
// ❌ 问题：持续时间太短
AnimatedContainer({
  duration: 50,  // 太快
  width: expanded ? 300 : 100
})

// ✅ 解决方案：使用适当的持续时间
AnimatedContainer({

  width: expanded ? 300 : 100
```

### 动画未触发

确保状态变化被正确管理：

```typescript
// ❌ 问题：直接修改

    return GestureDetector({
```
