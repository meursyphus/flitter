## 概述

Row 是一个将其子组件水平排列的布局组件。

Row 是 Flex 组件的便利包装器，方向固定为水平。它用于将多个组件并排放置，并提供各种对齐选项。默认情况下，Row 占用所有可用的水平空间，但您可以调整 `mainAxisSize` 以仅占用所需的空间。

## 何时使用？

- 当水平排列按钮、图标或文本时
- 当创建导航栏或工具栏时
- 当将表单字段和标签并排放置时
- 当为卡片或列表项构建水平布局时
- 当在文本旁边显示图标时

## 基本用法

```typescript
// 简单示例
const row = Row({
  children: [
    Text('第一个'),
    Text('第二个'),
    Text('第三个')
  ]
});

// 使用对齐选项
const alignedRow = Row({
  mainAxisAlignment: MainAxisAlignment.spaceBetween,
  crossAxisAlignment: CrossAxisAlignment.start,
  children: [
    Icon({ icon: Icons.home }),
    Text('首页'),
    Icon({ icon: Icons.settings })
  ]
});
```

## 属性

### children（必需）

**值: Widget[]**

要在 Row 中显示的子组件数组。它们按数组顺序从左到右排列。

```typescript
Row({
  children: [
    Container({ width: 50, height: 50, color: 'red' }),
    Container({ width: 50, height: 50, color: 'green' }),
    Container({ width: 50, height: 50, color: 'blue' })
  ]
})
```

### mainAxisAlignment

**值: MainAxisAlignment**（默认值: **MainAxisAlignment.start**）

定义子组件的水平对齐。

- **start**: 左对齐（默认）
- **end**: 右对齐
- **center**: 居中对齐
- **spaceBetween**: 将第一个和最后一个组件放在边缘，平均分配剩余空间
- **spaceAround**: 在每个组件周围分配相等空间
- **spaceEvenly**: 在所有组件和边缘之间分配相等空间

```typescript
// 居中对齐
Row({
  mainAxisAlignment: MainAxisAlignment.center,
  children: [
    Text('A'),
    Text('B'),
    Text('C')
  ]
})

// 间距分布
Row({
  mainAxisAlignment: MainAxisAlignment.spaceBetween,
  children: [
    Text('左'),
    Text('右')
  ]
})
```

### crossAxisAlignment

**值: CrossAxisAlignment**（默认值: **CrossAxisAlignment.center**）

定义子组件的垂直对齐。

- **start**: 顶部对齐
- **end**: 底部对齐
- **center**: 垂直居中对齐（默认）
- **stretch**: 拉伸以填满可用的垂直空间

```typescript
Row({
  crossAxisAlignment: CrossAxisAlignment.start,
  children: [
    Container({ width: 50, height: 50, color: 'red' }),
    Container({ width: 50, height: 100, color: 'green' }),
    Container({ width: 50, height: 75, color: 'blue' })
  ]
})
```

### mainAxisSize

**值: MainAxisSize**（默认值: **MainAxisSize.max**）

控制 Row 占用的水平空间量。

- **max**: 占用所有可用的水平空间（默认）
- **min**: 仅占用子组件所需的最小空间

```typescript
// 仅占用必要空间
Container({
  color: 'lightgray',
  child: Row({
    mainAxisSize: MainAxisSize.min,
    children: [
      Text('紧凑'),
      Icon({ icon: Icons.star })
    ]
  })
})
```

### verticalDirection

**值: VerticalDirection**（默认值: **VerticalDirection.down**）

定义子组件的垂直布局顺序。

- **down**: 从上到下（默认）
- **up**: 从下到上

此属性主要与 `crossAxisAlignment` 一起使用。

## 高级用法

### 与 Expanded 一起使用

```typescript
Row({
  children: [
    Container({ width: 50, height: 50, color: 'red' }),
    Expanded({
      child: Container({ height: 50, color: 'green' })
    }),
    Container({ width: 50, height: 50, color: 'blue' })
  ]
})
// 绿色 Container 占用所有剩余空间
```

### 响应式布局

```typescript
Row({
  mainAxisAlignment: MainAxisAlignment.spaceEvenly,
  children: [
    Flexible({
      flex: 2,
      child: Container({ height: 50, color: 'red' })
    }),
    Flexible({
      flex: 1,
      child: Container({ height: 50, color: 'green' })
    }),
    Flexible({
      flex: 1,
      child: Container({ height: 50, color: 'blue' })
    })
  ]
})
// 红色占 50%，绿色和蓝色各占 25%
```

## 实际示例

### 示例 1：导航栏

```typescript
const navbar = Container({
  padding: EdgeInsets.symmetric({ horizontal: 16, vertical: 8 }),
  color: 'white',
  child: Row({
    mainAxisAlignment: MainAxisAlignment.spaceBetween,
    children: [
      Row({
        mainAxisSize: MainAxisSize.min,
        children: [
          Icon({ icon: Icons.menu }),
          SizedBox({ width: 16 }),
          Text('我的应用', { style: TextStyle({ fontSize: 20, fontWeight: 'bold' }) })
        ]
      }),
      Row({
        mainAxisSize: MainAxisSize.min,
        children: [
          IconButton({ icon: Icons.search, onPressed: () => {} }),
          IconButton({ icon: Icons.notifications, onPressed: () => {} }),
          IconButton({ icon: Icons.account_circle, onPressed: () => {} })
        ]
      })
    ]
  })
});
```

### 示例 2：表单字段

```typescript
const formField = Container({
  padding: EdgeInsets.all(16),
  child: Row({
    crossAxisAlignment: CrossAxisAlignment.center,
    children: [
      Container({
        width: 100,
        child: Text('姓名:', { style: TextStyle({ fontWeight: 'bold' }) })
      }),
      Expanded({
        child: TextField({
          decoration: InputDecoration({
            hintText: '请输入您的姓名',
            border: OutlineInputBorder()
          })
        })
      })
    ]
  })
});
```

### 示例 3：卡片布局

```typescript
const card = Container({
  margin: EdgeInsets.all(8),
  padding: EdgeInsets.all(16),
  decoration: BoxDecoration({
    color: 'white',
    borderRadius: BorderRadius.circular(8),
    boxShadow: [
      BoxShadow({
        color: 'rgba(0, 0, 0, 0.1)',
        blurRadius: 4,
        offset: { x: 0, y: 2 }
      })
    ]
  }),
  child: Row({
    children: [
      Container({
        width: 60,
        height: 60,
        decoration: BoxDecoration({
          shape: 'circle',
          color: 'blue'
        })
      }),
      SizedBox({ width: 16 }),
      Expanded({
        child: Column({
          crossAxisAlignment: 'start',
          children: [
            Text('标题', { style: TextStyle({ fontSize: 16, fontWeight: 'bold' }) }),
            Text('子标题', { style: TextStyle({ color: 'gray' }) })
          ]
        })
      }),
      Icon({ icon: Icons.arrow_forward })
    ]
  })
});
```

## 重要说明

- 如果子组件超出水平空间，会发生溢出错误。在这种情况下使用 `Flexible` 或 `Expanded`。
- 使用 `crossAxisAlignment.stretch` 时，如果子组件的高度没有约束，它们可能会无限扩展。
- Row 不支持滚动。如果需要滚动，请与 `SingleChildScrollView` 一起使用。
- 使用 `Column` 组件进行垂直布局。

## 相关组件

- **Column**: 垂直排列子组件
- **Flex**: Row 和 Column 基于的更灵活的布局组件
- **Wrap**: 当空间不足时自动换行
- **Stack**: 将子组件叠放在一起
- **Expanded**: 在 Row 内占用剩余空间
- **Flexible**: 允许在 Row 内灵活调整尺寸
