## 概述

SizedBox 是一个创建具有特定宽度和高度的盒子的简单组件。

SizedBox 是一个专为尺寸设置而设计的单一目的组件，比 Container 更轻量、更高效。它通常用于在组件之间创建间距、限制子组件尺寸或在条件渲染中创建空空间。在内部，它使用带严格约束的 ConstrainedBox。

## 何时使用？

- 当在组件之间创建固定间距时
- 当强制子组件为固定尺寸时
- 当在条件渲染中需要空空间时
- 当您不需要 Container 的其他功能（颜色、内边距、装饰等）时
- 当性能很重要且您只需要指定尺寸时

## 基本用法

```typescript
// 固定尺寸盒子
SizedBox({
  width: 200,
  height: 100,
  child: Text('固定尺寸')
})

// 创建间距（最常见的用法）
Column({
  children: [
    Text('顶部'),
    SizedBox({ height: 20 }), // 20 像素垂直间距
    Text('底部')
  ]
})

// 水平间距
Row({
  children: [
    Icon({ icon: Icons.star }),
    SizedBox({ width: 8 }), // 8 像素水平间距
    Text('星号')
  ]
})
```

## 属性

### width

**值: number | undefined**

以像素为单位指定盒子的宽度。如果未指定，则取决于子组件的宽度。

```typescript
SizedBox({
  width: 100,
  child: Text('宽度 100px')
})
```

### height

**值: number | undefined**

以像素为单位指定盒子的高度。如果未指定，则取决于子组件的高度。

```typescript
SizedBox({
  height: 50,
  child: Text('高度 50px')
})
```

### child

**值: Widget | undefined**

要放置在 SizedBox 内的子组件。如果没有子组件，则创建空空间。

```typescript
SizedBox({
  width: 200,
  height: 200,
  child: Container({ color: 'blue' })
})
```

## 静态方法

### SizedBox.shrink()

创建一个尺寸为零的 SizedBox。在条件渲染中不想显示任何内容时很有用。

```typescript
// 条件渲染
const widget = showButton 
  ? ElevatedButton({ child: Text('点击') })
  : SizedBox.shrink();

// 基本用法
SizedBox.shrink() // width: 0, height: 0

// 带子组件
SizedBox.shrink({
  child: Text('不可见') // 由于尺寸为零而不显示
})
```

### SizedBox.expand()

创建一个占用所有可用空间的 SizedBox。

```typescript
// 占用所有空间
SizedBox.expand({
  child: Container({ color: 'red' })
})

// 仅在一个方向上扩展
SizedBox.expand({
  width: 100, // 固定宽度
  child: Container({ color: 'blue' }) // 仅高度扩展
})
```

### SizedBox.fromSize()

从 Size 对象创建 SizedBox。

```typescript
const size = Size({ width: 150, height: 75 });

SizedBox.fromSize({
  size: size,
  child: Text('使用 Size 对象')
})
```

### SizedBox.square()

创建一个正方形的 SizedBox。

```typescript
// 100x100 正方形
SizedBox.square({
  dimension: 100,
  child: Container({ color: 'green' })
})
```

## 实际示例

### 示例 1：列表项间距

```typescript
const listWithSpacing = Column({
  children: [
    ListTile({ title: Text('项目 1') }),
    SizedBox({ height: 8 }),
    ListTile({ title: Text('项目 2') }),
    SizedBox({ height: 8 }),
    ListTile({ title: Text('项目 3') })
  ]
});
```

### 示例 2：按钮组

```typescript
const buttonGroup = Row({
  mainAxisAlignment: MainAxisAlignment.center,
  children: [
    ElevatedButton({
      onPressed: () => {},
      child: Text('上一个')
    }),
    SizedBox({ width: 16 }), // 按钮之间的间距
    ElevatedButton({
      onPressed: () => {},
      child: Text('下一个')
    })
  ]
});
```

### 示例 3：条件间距

```typescript
const conditionalSpacing = Column({
  children: [
    Text('标题'),
    hasSubtitle ? SizedBox({ height: 8 }) : SizedBox.shrink(),
    hasSubtitle ? Text('子标题') : SizedBox.shrink(),
    SizedBox({ height: 16 }),
    Text('正文')
  ]
});
```

### 示例 4：固定尺寸图像容器

```typescript
const imageGrid = GridView({
  gridDelegate: SliverGridDelegateWithFixedCrossAxisCount({
    crossAxisCount: 3,
    spacing: 8
  }),
  children: images.map(img => 
    SizedBox.square({
      dimension: 100,
      child: Image({
        src: img,
        fit: 'cover'
      })
    })
  )
});
```

### 示例 5：约束加载指示器

```typescript
const loadingIndicator = Center({
  child: SizedBox({
    width: 50,
    height: 50,
    child: CircularProgressIndicator()
  })
});
```

## 与 Container 的区别

### 使用 SizedBox
```typescript
// 当您只需要尺寸时
SizedBox({ 
  width: 100, 
  height: 50,
  child: widget 
})
```

### 使用 Container
```typescript
// 当您除了尺寸还需要其他样式时
Container({ 
  width: 100, 
  height: 50,
  padding: EdgeInsets.all(8),
  color: 'blue',
  child: widget 
})
```

**性能差异**: SizedBox 仅创建一个 ConstrainedBox，而 Container 组合多个组件，使 SizedBox 更高效。

## 重要说明

- 如果只指定了宽度或高度，另一个维度将跟随子组件的尺寸。
- 如果父组件允许无限尺寸，SizedBox.expand() 可能会导致错误。
- 没有子组件的 SizedBox 会创建指定尺寸的空空间。
- 不允许负数尺寸。

## 相关组件

- **Container**: 当您除了尺寸还需要各种样式时
- **ConstrainedBox**: 当您需要最小/最大尺寸约束时
- **AspectRatio**: 当您需要保持纵横比时
- **FractionallySizedBox**: 当基于父组件尺寸百分比进行尺寸设置时
- **Spacer**: 当在 Row/Column 中创建灵活空间时
