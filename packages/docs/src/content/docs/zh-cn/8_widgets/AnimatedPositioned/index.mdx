## 概述

AnimatedPositioned 是一个在 Stack 组件中子组件的位置和尺寸发生变化时自动进行动画的组件。这个组件受 Flutter 的 AnimatedPositioned 组件启发。

> 仅在作为 Stack 的子组件时才能工作。
>
> 如果子组件的尺寸会因此动画而改变，这个组件是一个好选择。如果尺寸意图保持不变，只有位置随时间变化，那么请考虑使用 SlideTransition。SlideTransition 只会在动画的每一帧触发重绘，而 AnimatedPositioned 也会触发重新布局。

## 何时使用？

- 当需要在 Stack 中动态移动组件位置时
- 当实现拖放或移动动画时
- 当动画化模态框或弹窗位置过渡时
- 当将浮动操作按钮移动到不同位置时
- 当实现基于移动名牌或石工布局的微交互时
- 当实现带动画的调整手柄或尺寸更改效果时

## 基本用法

```typescript
import { AnimatedPositioned, Stack, Container, StatefulWidget } from '@flitter/core';

class PositionedExample extends StatefulWidget {
  createState() {
    return new PositionedExampleState();
  }
}

class PositionedExampleState extends State<PositionedExample> {
  isTopLeft = true;

  build() {
    return Column({
      children: [
        ElevatedButton({
          onPressed: () => {
            this.setState(() => {
              this.isTopLeft = !this.isTopLeft;
            });
          },
          child: Text("移动位置"),
        }),
        Container({
          width: 300,
          height: 300,
          child: Stack({
            children: [
              Container({
                width: 300,
                height: 300,
                color: "lightgray",
              }),
              AnimatedPositioned({
                top: this.isTopLeft ? 20 : 220,
                left: this.isTopLeft ? 20 : 220,
                width: 60,
                height: 60,
                duration: 1000, // 1 second
                child: Container({
                  color: "blue",
                  child: Center({
                    child: Text("移动", {
                      style: TextStyle({ color: "white" })
                    }),
                  }),
                }),
              }),
            ],
          }),
        }),
      ],
    });
  }
}
```

## 属性

### duration（必需）
**值：number**

指定动画持续时间（毫秒）。

### top（可选）
**值：number | undefined**

指定从 Stack 顶部的距离。不能与 bottom 同时使用。

### left（可选）
**值：number | undefined**

指定从 Stack 左侧的距离。不能与 right 同时使用。

### right（可选）
**值：number | undefined**

指定从 Stack 右侧的距离。不能与 left 同时使用。

### bottom（可选）
**值：number | undefined**

指定从 Stack 底部的距离。不能与 top 同时使用。

### width（可选）
**值：number | undefined**

指定组件的宽度。如果未指定，则使用子组件的固有宽度。

### height（可选）
**值：number | undefined**

指定组件的高度。如果未指定，则使用子组件的固有高度。

### curve（可选）
**值：Curve**（默认值：**Curves.linear**）

指定动画进程曲线。可用曲线：
- `Curves.linear`：匀速
- `Curves.easeIn`：缓慢开始
- `Curves.easeOut`：缓慢结束
- `Curves.easeInOut`：缓慢开始和结束
- `Curves.circIn`：圆形加速开始
- `Curves.circOut`：圆形减速结束
- `Curves.circInOut`：圆形加速/减速
- `Curves.backIn`：先后退然后开始
- `Curves.backOut`：超过目标然后返回
- `Curves.backInOut`：backIn + backOut
- `Curves.anticipate`：在继续之前的预期运动
- `Curves.bounceIn`：开始时弹跳
- `Curves.bounceOut`：结束时弹跳
- `Curves.bounceInOut`：开始/结束时弹跳

### child（可选）
**值：Widget | undefined**

将进行位置动画的子组件。

### key（可选）
**值：any**

组件的唯一标识符。

## 实际示例

### 示例 1：拖放模拟

```typescript
import { AnimatedPositioned, Stack, Container, GestureDetector, Curves } from '@flitter/core';

class DragDropSimulation extends StatefulWidget {
  createState() {
    return new DragDropSimulationState();
  }
}

class DragDropSimulationState extends State<DragDropSimulation> {
  boxPosition = { x: 50, y: 50 };
  targetPosition = { x: 200, y: 200 };
  isAtTarget = false;

  build() {
    return Container({
      width: 400,
      height: 400,
      color: "#f0f0f0",
      child: Stack({
        children: [
          // Target area
          Positioned({
            left: this.targetPosition.x,
            top: this.targetPosition.y,
            child: Container({
              width: 100,
              height: 100,
              decoration: BoxDecoration({
                color: this.isAtTarget ? "green" : "lightgreen",
                borderRadius: BorderRadius.circular(8),
                border: Border.all({ 
                  color: "green", 
                  width: 2, 
                  style: "dashed" 
                }),
              }),
              child: Center({
                child: Text(
                  "放置区域",
                  { style: TextStyle({ color: "darkgreen", fontWeight: "bold" }) }
                ),
              }),
            }),
          }),
          
          // Draggable box
          AnimatedPositioned({
            left: this.boxPosition.x,
            top: this.boxPosition.y,
            width: 60,
            height: 60,
            duration: 500,
            curve: Curves.easeInOut,
            child: GestureDetector({
              onTap: () => this.moveToTarget(),
              child: Container({
                decoration: BoxDecoration({
                  color: "blue",
                  borderRadius: BorderRadius.circular(8),
                  boxShadow: [
                    BoxShadow({
                      color: "rgba(0,0,0,0.3)",
                      blurRadius: 4,
                      offset: Offset({ x: 2, y: 2 }),
                    }),
                  ],
                }),
                child: Center({
                  child: Icon({
                    icon: Icons.touch_app,
                    color: "white",
                    size: 24,
                  }),
                }),
              }),
            }),
          }),
          
          // Instruction text
          Positioned({
            bottom: 20,
            left: 20,
            child: Container({
              padding: EdgeInsets.all(12),
              decoration: BoxDecoration({
                color: "rgba(0,0,0,0.7)",
                borderRadius: BorderRadius.circular(8),
              }),
              child: Text(
                "点击蓝色方块移动它",
                { style: TextStyle({ color: "white", fontSize: 14 }) }
              ),
            }),
          }),
        ],
      }),
    });
  }

  moveToTarget() {
    this.setState(() => {
      if (!this.isAtTarget) {
        this.boxPosition = { x: this.targetPosition.x + 20, y: this.targetPosition.y + 20 };
        this.isAtTarget = true;
      } else {
        this.boxPosition = { x: 50, y: 50 };
        this.isAtTarget = false;
      }
    });
  }
}
```

### 示例 2：多组件编排

```typescript
import { AnimatedPositioned, Stack, Container, Curves } from '@flitter/core';

class MultiWidgetOrchestration extends StatefulWidget {
  createState() {
    return new MultiWidgetOrchestrationState();
  }
}

class MultiWidgetOrchestrationState extends State<MultiWidgetOrchestration> {
  pattern = 0; // 0: circle, 1: square, 2: diagonal, 3: wave
  
  getPositions(pattern: number) {
    switch (pattern) {
      case 0: // circle
        return [
          { x: 150, y: 50 },   // top
          { x: 250, y: 150 },  // right
          { x: 150, y: 250 },  // bottom
          { x: 50, y: 150 },   // left
        ];
      case 1: // square
        return [
          { x: 100, y: 100 },  // top-left
          { x: 200, y: 100 },  // top-right
          { x: 200, y: 200 },  // bottom-right
          { x: 100, y: 200 },  // bottom-left
        ];
      case 2: // diagonal
        return [
          { x: 50, y: 50 },
          { x: 120, y: 120 },
          { x: 190, y: 190 },
          { x: 260, y: 260 },
        ];
      case 3: // wave
        return [
          { x: 50, y: 200 },
          { x: 120, y: 120 },
          { x: 190, y: 180 },
          { x: 260, y: 100 },
        ];
      default:
        return [
          { x: 150, y: 150 },
          { x: 150, y: 150 },
          { x: 150, y: 150 },
          { x: 150, y: 150 },
        ];
    }
  }

  build() {
    const positions = this.getPositions(this.pattern);
    const colors = ["#FF6B6B", "#4ECDC4", "#45B7D1", "#96CEB4"];
    const icons = [Icons.star, Icons.favorite, Icons.diamond, Icons.hexagon];
    
    return Column({
      children: [
        // Pattern selection buttons
        Padding({
          padding: EdgeInsets.all(16),
          child: Row({
            mainAxisAlignment: MainAxisAlignment.spaceEvenly,
            children: [
              ElevatedButton({
                onPressed: () => this.changePattern(0),
                child: Text("圆形"),
                style: ButtonStyle({
                  backgroundColor: this.pattern === 0 ? "blue" : "gray",
                }),
              }),
              ElevatedButton({
                onPressed: () => this.changePattern(1),
                child: Text("方形"),
                style: ButtonStyle({
                  backgroundColor: this.pattern === 1 ? "blue" : "gray",
                }),
              }),
              ElevatedButton({
                onPressed: () => this.changePattern(2),
                child: Text("对角线"),
                style: ButtonStyle({
                  backgroundColor: this.pattern === 2 ? "blue" : "gray",
                }),
              }),
              ElevatedButton({
                onPressed: () => this.changePattern(3),
                child: Text("波浪"),
                style: ButtonStyle({
                  backgroundColor: this.pattern === 3 ? "blue" : "gray",
                }),
              }),
            ],
          }),
        }),
        
        // Animation area
        Container({
          width: 350,
          height: 350,
          decoration: BoxDecoration({
            color: "#2C3E50",
            borderRadius: BorderRadius.circular(16),
          }),
          child: Stack({
            children: positions.map((pos, index) => {
              return AnimatedPositioned({
                key: ValueKey(index),
                left: pos.x,
                top: pos.y,
                width: 50,
                height: 50,
                duration: 800 + (index * 100), // Staggered animation
                curve: Curves.easeInOut,
                child: Container({
                  decoration: BoxDecoration({
                    color: colors[index],
                    borderRadius: BorderRadius.circular(25),
                    boxShadow: [
                      BoxShadow({
                        color: "rgba(0,0,0,0.3)",
                        blurRadius: 8,
                        offset: Offset({ x: 0, y: 4 }),
                      }),
                    ],
                  }),
                  child: Center({
                    child: Icon({
                      icon: icons[index],
                      color: "white",
                      size: 28,
                    }),
                  }),
                }),
              });
            }),
          }),
        }),
      ],
    });
  }

  changePattern(newPattern: number) {
    this.setState(() => {
      this.pattern = newPattern;
    });
  }
}
```

### 示例 3：模态对话框动画

```typescript
import { AnimatedPositioned, Stack, Container, Card, Curves } from '@flitter/core';

class ModalAnimation extends StatefulWidget {
  createState() {
    return new ModalAnimationState();
  }
}

class ModalAnimationState extends State<ModalAnimation> {
  showModal = false;

  build() {
    return Stack({
      children: [
        // Main content
        Container({
          width: double.infinity,
          height: double.infinity,
          color: "#f5f5f5",
          child: Center({
            child: ElevatedButton({
              onPressed: () => {
                this.setState(() => {
                  this.showModal = true;
                });
              },
              child: Text("打开模态框"),
            }),
          }),
        }),
        
        // Modal background
        if (this.showModal) AnimatedOpacity({
          opacity: this.showModal ? 0.7 : 0.0,
          duration: 300,
          child: Container({
            width: double.infinity,
            height: double.infinity,
            color: "black",
          }),
        }),
        
        // Modal dialog
        AnimatedPositioned({
          left: 50,
          right: 50,
          top: this.showModal ? 150 : 600, // Slide up from bottom
          duration: 400,
          curve: Curves.easeOut,
          child: this.showModal ? Card({
            child: Container({
              padding: EdgeInsets.all(20),
              child: Column({
                mainAxisSize: MainAxisSize.min,
                children: [
                  Text(
                    "模态对话框",
                    { style: TextStyle({ fontSize: 24, fontWeight: "bold" }) }
                  ),
                  SizedBox({ height: 16 }),
                  Text(
                    "这是一个动画模态对话框，会从底部以上滑效果出现。"
                  ),
                  SizedBox({ height: 20 }),
                  Row({
                    mainAxisAlignment: MainAxisAlignment.end,
                    children: [
                      TextButton({
                        onPressed: () => {
                          this.setState(() => {
                            this.showModal = false;
                          });
                        },
                        child: Text("取消"),
                      }),
                      SizedBox({ width: 8 }),
                      ElevatedButton({
                        onPressed: () => {
                          this.setState(() => {
                            this.showModal = false;
                          });
                        },
                        child: Text("确认"),
                      }),
                    ],
                  }),
                ],
              }),
            }),
          }) : SizedBox.shrink(),
        }),
      ],
    });
  }
}
```

### 示例 4：尺寸和位置同时动画

```typescript
import { AnimatedPositioned, Stack, Container, Curves } from '@flitter/core';

class SizeAndPositionAnimation extends StatefulWidget {
  createState() {
    return new SizeAndPositionAnimationState();
  }
}

class SizeAndPositionAnimationState extends State<SizeAndPositionAnimation> {
  isExpanded = false;

  build() {
    return GestureDetector({
      onTap: () => {
        this.setState(() => {
          this.isExpanded = !this.isExpanded;
        });
      },
      child: Container({
        width: 400,
        height: 400,
        color: "#34495e",
        child: Stack({
          children: [
            AnimatedPositioned({
              left: this.isExpanded ? 50 : 175,
              top: this.isExpanded ? 50 : 175,
              width: this.isExpanded ? 300 : 50,
              height: this.isExpanded ? 300 : 50,
              duration: 1000,
              curve: Curves.elasticOut,
              child: Container({
                decoration: BoxDecoration({
                  gradient: LinearGradient({
                    colors: this.isExpanded 
                      ? ["#e74c3c", "#c0392b"]
                      : ["#3498db", "#2980b9"],
                    begin: Alignment.topLeft,
                    end: Alignment.bottomRight,
                  }),
                  borderRadius: BorderRadius.circular(this.isExpanded ? 16 : 25),
                  boxShadow: [
                    BoxShadow({
                      color: "rgba(0,0,0,0.3)",
                      blurRadius: this.isExpanded ? 20 : 10,
                      offset: Offset({ x: 0, y: this.isExpanded ? 10 : 5 }),
                    }),
                  ],
                }),
                child: Center({
                  child: Icon({
                    icon: this.isExpanded ? Icons.close : Icons.add,
                    color: "white",
                    size: this.isExpanded ? 48 : 24,
                  }),
                }),
              }),
            }),
            
            // Instruction text
            Positioned({
              bottom: 20,
              left: 20,
              right: 20,
              child: Container({
                padding: EdgeInsets.all(12),
                decoration: BoxDecoration({
                  color: "rgba(255,255,255,0.9)",
                  borderRadius: BorderRadius.circular(8),
                }),
                child: Text(
                  "点击屏幕查看尺寸和位置动画",
                  { 
                    style: TextStyle({ 
                      color: "#2c3e50", 
                      fontSize: 14,
                      textAlign: "center"
                    }) 
                  }
                ),
              }),
            }),
          ],
        }),
      }),
    });
  }
}
```

## 注意事项

- **必须是 Stack 的直接子组件**：AnimatedPositioned 只能作为 Stack 组件的直接子组件使用
- **冲突属性**：top/bottom 和 left/right 不能同时设置
- **性能考虑**：位置变化会触发布局重新计算，因此同时应用于多个组件可能影响性能
- **动画中断**：如果在动画期间设置新的属性值，它会从当前值平滑过渡到新值
- **允许负值**：left、top、right、bottom 属性可以接受负值

## 相关组件

- **Positioned**：在 Stack 中指定位置的基本组件，无动画
- **AnimatedAlign**：动画化对齐过渡
- **SlideTransition**：当仅动画化位置而保持布局不变时使用
- **Stack**：使用 AnimatedPositioned 所需的父组件
- **AnimatedContainer**：同时动画化多个属性的通用组件
