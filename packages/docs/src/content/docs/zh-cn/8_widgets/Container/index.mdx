## 概述

Container 是一个便利组件，它为其子组件结合了常见的绘制、定位和尺寸调整功能。

Container 将几个基本组件（Padding、Align、ColoredBox、DecoratedBox、ConstrainedBox、Transform 等）组合成一个单一组件，简化了常见的布局和样式任务。空的 Container 会尝试占用尽可能多的空间，但当它有子组件时，会根据子组件调整自身大小。

## 何时使用？

- 为组件应用背景色、边框、阴影等样式时
- 为组件添加外边距或内边距时
- 限制或固定组件尺寸时
- 同时应用多个布局属性时
- 创建卡片 UI、按钮背景、区域分隔符等时

## 基本用法

```typescript
// 最简单的例子
const widget = Container({
  width: 200,
  height: 100,
  color: 'blue',
  child: Text('你好 Container！')
});

// 使用内边距和外边距
const paddedContainer = Container({
  margin: EdgeInsets.all(10),
  padding: EdgeInsets.symmetric({ horizontal: 20, vertical: 10 }),
  color: 'lightgray',
  child: Text('有内边距的文本')
});
```

## 属性

### width

**值：number | undefined**

以像素为单位指定 Container 的宽度。如果未指定，则由子组件的大小或父组件的约束决定。

```typescript
Container({ width: 300, color: 'red' })
```

### height

**值：number | undefined**

以像素为单位指定 Container 的高度。如果未指定，则由子组件的大小或父组件的约束决定。

```typescript
Container({ height: 150, color: 'green' })
```

### constraints

**值：Constraints | undefined**

指定 Container 的最小/最大宽度和高度。提供比 width/height 更灵活的尺寸控制。

```typescript
Container({
  constraints: Constraints({
    minWidth: 100,
    maxWidth: 300,
    minHeight: 50,
    maxHeight: 200
  }),
  color: 'orange'
})
```

### padding

**值：EdgeInsets**（默认值：**无**）

Container 边缘与其子组件之间的间距。

```typescript
// 所有边相同的内边距
Container({
  padding: EdgeInsets.all(16),
  color: 'lightblue',
  child: Text('有内边距')
})

// 每边不同的内边距
Container({
  padding: EdgeInsets.only({ top: 20, left: 10, right: 10, bottom: 5 }),
  color: 'pink'
})
```

### margin

**值：EdgeInsets**（默认值：**无**）

Container 与其外部其他组件之间的间距。

```typescript
Container({
  margin: EdgeInsets.symmetric({ horizontal: 20, vertical: 10 }),
  color: 'yellow',
  child: Text('有外边距')
})
```

### alignment

**值：Alignment | undefined**

指定子组件在 Container 内的对齐位置。x 和 y 值范围从 -1 到 1。

```typescript
Container({
  width: 200,
  height: 200,
  color: 'gray',
  alignment: Alignment.center,
  child: Text('居中')
})

// 可用的对齐常量
// Alignment.topLeft, Alignment.topCenter, Alignment.topRight
// Alignment.centerLeft, Alignment.center, Alignment.centerRight
// Alignment.bottomLeft, Alignment.bottomCenter, Alignment.bottomRight
```

### color

**值：string | undefined**

指定 Container 的背景颜色。不能与 decoration 一起使用。

⚠️ **警告**：与 decoration 属性一起使用会导致错误。

```typescript
Container({
  width: 100,
  height: 100,
  color: '#FF5733'
})
```

### decoration

**值：Decoration | undefined**

为 Container 指定复杂样式（边框、圆角、阴影等）。

⚠️ **警告**：不能与 color 属性一起使用。请在 decoration 内部指定颜色。

```typescript
Container({
  width: 150,
  height: 150,
  decoration: BoxDecoration({
    color: 'white',
    border: Border.all({ color: 'black', width: 2 }),
    borderRadius: BorderRadius.circular(10),
    boxShadow: [
      BoxShadow({
        color: 'rgba(0, 0, 0, 0.3)',
        blurRadius: 10,
        offset: { x: 5, y: 5 }
      })
    ]
  }),
  child: Text('装饰过的')
})
```

### clipped

**值：boolean | undefined**（默认值：**false**）

决定是否根据 decoration 的形状裁剪子组件。

⚠️ **警告**：当 clipped 为 true 时，必须提供 decoration。

```typescript
Container({
  width: 100,
  height: 100,
  clipped: true,
  decoration: BoxDecoration({
    shape: 'circle',
    color: 'blue'
  }),
  child: Image({ src: 'photo.jpg', fit: 'cover' })
})
```

### transform

**值：Matrix4 | undefined**

对 Container 应用旋转、缩放、倾斜等变换。

```typescript
Container({
  color: 'purple',
  transform: Matrix4.rotationZ(Math.PI / 4), // 45 度旋转
  child: Text('旋转的')
})
```

### transformAlignment

**值：Alignment | undefined**

指定变换的原点。默认为 Container 的中心。

```typescript
Container({
  width: 100,
  height: 100,
  color: 'green',
  transform: Matrix4.rotationZ(Math.PI / 6),
  transformAlignment: Alignment.topLeft, // 围绕左上角旋转
  child: Text('变换')
})
```

### child

**值：Widget | undefined**

要在 Container 内显示的子组件。

```typescript
Container({
  padding: EdgeInsets.all(20),
  color: 'lightgray',
  child: Column({
    children: [
      Text('标题'),
      Text('副标题')
    ]
  })
})
```

## 实际示例

### 创建卡片 UI

```typescript
const card = Container({
  margin: EdgeInsets.all(16),
  padding: EdgeInsets.all(16),
  decoration: BoxDecoration({
    color: 'white',
    borderRadius: BorderRadius.circular(12),
    boxShadow: [
      BoxShadow({
        color: 'rgba(0, 0, 0, 0.1)',
        blurRadius: 8,
        offset: { x: 0, y: 2 }
      })
    ]
  }),
  child: Column({
    crossAxisAlignment: 'start',
    children: [
      Text('卡片标题', { style: TextStyle({ fontSize: 18, fontWeight: 'bold' }) }),
      SizedBox({ height: 8 }),
      Text('卡片内容在这里...')
    ]
  })
});
```

### 创建圆形头像

```typescript
const avatar = Container({
  width: 80,
  height: 80,
  clipped: true,
  decoration: BoxDecoration({
    shape: 'circle',
    border: Border.all({ color: 'blue', width: 3 })
  }),
  child: Image({
    src: 'profile.jpg',
    fit: 'cover'
  })
});
```

### 设计按钮样式

```typescript
const customButton = GestureDetector({
  onTap: () => console.log('按钮被点击'),
  child: Container({
    padding: EdgeInsets.symmetric({ horizontal: 24, vertical: 12 }),
    decoration: BoxDecoration({
      color: 'blue',
      borderRadius: BorderRadius.circular(8)
    }),
    child: Text('点击我', {
      style: TextStyle({ color: 'white', fontSize: 16 })
    })
  })
});
```

## 重要注意事项

- 不能同时使用 `color` 和 `decoration`。使用 decoration 时，请在其内部指定颜色。
- 当 `clipped` 设置为 true 时，必须提供 `decoration`。
- 没有子组件且没有尺寸约束的 Container 会尝试占用尽可能多的空间。
- 使用 `transform` 时，请注意变换后的 Container 可能会与其他组件重叠。
- 在 decoration 中使用 border 会自动添加内边距。

## 相关组件

- **DecoratedBox**：仅需要装饰时使用
- **ColoredBox**：仅需要背景颜色时使用
- **Padding**：仅需要外边距或内边距时使用
- **SizedBox**：仅需要固定尺寸时使用
- **ConstrainedBox**：仅需要尺寸约束时使用
- **Align**：仅需要对齐时使用
