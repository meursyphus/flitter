## 约束系统的核心

Flitter 的布局系统遵循一个简单的规则：

> **“约束向下传递，尺寸向上传递”**

父节点向子节点传递约束，子节点在这些约束内确定自身尺寸并向父节点报告。

## 约束向下传递，尺寸向上传递

```
        父组件
             │
    ┌────────▼────────┐
    │   约束条件     │ (向下传递)
    │   最小: 0x0    │
    │   最大: 300x200│
    └────────┬────────┘
             │
        子组件
             │
    ┌────────▼────────┐
    │   决定尺寸    │ (向上报告)
    │   选择: 150x80│
    └─────────────────┘
```

### BoxConstraints 的组成部分

```typescript
class BoxConstraints {
  minWidth: number;   // 最小宽度
  maxWidth: number;   // 最大宽度  
  minHeight: number;  // 最小高度
  maxHeight: number;  // 最大高度
}
```

子节点可以在这些约束内选择自身尺寸：
- `minWidth ≤ width ≤ maxWidth`
- `minHeight ≤ height ≤ maxHeight`

## 主要约束模式

### 1. 紧约束（Tight Constraints）
```typescript
Constraints.tight(new Size(100, 50))
// minWidth = maxWidth = 100
// minHeight = maxHeight = 50
```
```
┌─────────────┐
│ 精确 100x50 │  ← 子节点被强制为这个尺寸
└─────────────┘
```

### 2. 松约束（Loose Constraints）  
```typescript
Constraints.loose(new Size(100, 50))
// minWidth = minHeight = 0
// maxWidth = 100, maxHeight = 50
```
```
┌─────────────┐
│ 0x0 ~ 100x50│  ← 子节点在范围内自由选择
└─────────────┘
```

### 3. 扩展约束（Expand Constraints）
```typescript
Constraints.expand()
// minWidth = maxWidth = ∞
// minHeight = maxHeight = ∞
```
```
┌─────────────┐
│ 尽可能最大尺寸│  ← 占满父节点空间
└─────────────┘
```

### 4. 无约束（Unconstrained）
```typescript
UnconstrainedBox({
  child: Container({ width: 1000 })  // 忽略父节点约束
})
```
```
父节点: 最大 300px
    │
    ▼
UnconstrainedBox  ──→  子节点: 1000px (可能溢出)
```

## 理解实际行为

### Container vs SizedBox

```typescript
// Container 的 width/height 是“愿望”
Container({
  width: 200,   // ← 如果父节点只允许 100px，则变为 100px
  height: 100,
  child: Text("你好")
})

// SizedBox “强制”其尺寸
SizedBox({
  width: 200,   // ← 对子节点强制精确 200px
  height: 100,
  child: Text("你好")
})
```

### Column 内的约束

```
Column (高度: ∞)
  │
  ├─ 子节点 1 (高度: 紧贴自然尺寸)
  ├─ 子节点 2 (高度: 紧贴自然尺寸)  
  └─ 子节点 3 (高度: 紧贴自然尺寸)
```

Column 不会对子节点“紧约束”高度。每个子节点可以占用它想要的高度。

## 常见问题及解决方案

### 问题 1：无限尺寸错误
```typescript
// ❌ Column 内的 Column 接收到无限高度
Column({
  children: [
    Column({ children: [...] })  // RenderFlex 溢出！
  ]
})

// ✅ 使用 Expanded 限制尺寸
Column({
  children: [
    Expanded({
      child: Column({ children: [...] })
    })
  ]
})
```

### 问题 2：组件未获得期望尺寸
```typescript
// ❌ 父节点传递紧约束
Container({
  width: 100,
  height: 100,
  child: Container({
    width: 200,  // 被忽略！（被强制为 100px）
    height: 200
  })
})

// ✅ 使用 UnconstrainedBox 释放约束
Container({
  width: 100,
  height: 100,
  child: UnconstrainedBox({
    child: Container({
      width: 200,  // 被应用（可能发生溢出）
      height: 200
    })
  })
})
```

### 问题 3：居中对齐不起作用
```typescript
// ❌ Container 适应父节点尺寸
Row({
  children: [
    Container({
      color: 'red',
      child: Text('你好')  // Container 只占文本尺寸
    })
  ]
})

// ✅ 明确尺寸或使用 Expanded
Row({
  children: [
    Expanded({
      child: Container({
        color: 'red',
        alignment: Alignment.center,
        child: Text('你好')
      })
    })
  ]
})
```

## 关键要点

1. **父节点传递约束** → 子节点决定尺寸 → 向父节点报告
2. **约束 = 尺寸范围**（最小/最大 宽度/高度）
3. **紧约束**：强制精确尺寸，**松约束**：仅限制最大尺寸
4. **理解这一点可以轻松解决布局问题**
