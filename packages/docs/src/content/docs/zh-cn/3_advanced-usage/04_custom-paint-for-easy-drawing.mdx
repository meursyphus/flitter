## CustomPaint 组件的背景

我们之前学习的 RenderObjectWidget 虽然强大但很复杂。即使您只是想简单地绘制一些东西，也需要继承 RenderObject，实现 createRenderObject，并重写 paint 方法。

CustomPaint 解决了这种复杂性。只需将绘制行为作为一级函数传递即可！

### CustomPaint 的优势

1. **简单的 API**：只需传递绘制函数
2. **快速原型开发**：不需要复杂的类结构
3. **可重用性**：易于替换绘制函数
4. **性能**：使用内部优化的 RenderObject

### 基本用法

```typescript
// 为 SVG 渲染器
CustomPaint({
  size: new Size(300, 200),
  painter: {
    svg: {
      createDefaultSvgEl(context) {
        return {
          circle: context.createSvgEl('circle')
        };
      },
      paint(els, size) {
        els.circle.setAttribute('cx', `${size.width / 2}`);
        els.circle.setAttribute('cy', `${size.height / 2}`);
        els.circle.setAttribute('r', '50');
        els.circle.setAttribute('fill', '#3B82F6');
      }
    }
  }
})

// 为 Canvas 渲染器
CustomPaint({
  size: new Size(300, 200),
  painter: {
    canvas: {
      paint(context, size) {
        const ctx = context.canvas;
        ctx.fillStyle = '#3B82F6';
        ctx.beginPath();
        ctx.arc(size.width / 2, size.height / 2, 50, 0, Math.PI * 2);
        ctx.fill();
      }
    }
  }
})
```

### shouldRepaint 优化

您可以控制何时重绘以优化性能：

```typescript
CustomPaint({
  painter: {
    dependencies: myData, // 依赖数据
    shouldRepaint: (oldPainter) => {
      // 返回 true 以重绘
      // 返回 false 以保持之前的绘制
      return oldPainter.dependencies !== myData;
    },
    svg: {
      // SVG 实现
    },
    canvas: {
      // Canvas 实现
    }
  }
})
```

## SVG vs Canvas 渲染

Flitter 的 CustomPaint 支持两种渲染方法：

### SVG 渲染
- **缩放时保持质量**
- **适合矢量图形**
- **使用 createDefaultSvgEl() 创建 SVG 元素**
- **在 paint() 中使用 setAttribute 设置属性**

```typescript
svg: {
  createDefaultSvgEl(context) {
    return {
      line: context.createSvgEl('path'),
      point: context.createSvgEl('circle')
    };
  },
  paint(els, size) {
    els.line.setAttribute('d', pathData);
    els.line.setAttribute('stroke', '#3B82F6');
    els.point.setAttribute('cx', '50');
    els.point.setAttribute('cy', '50');
  }
}
```

### Canvas 渲染
- **适合复杂的像素操作**
- **高性能动画的优势**
- **与 Web Canvas API 相同的方法**

```typescript
canvas: {
  paint(context, size) {
    const ctx = context.canvas;
    ctx.fillStyle = '#3B82F6';
    ctx.fillRect(0, 0, size.width, size.height);
    ctx.strokeStyle = '#FF0000';
    ctx.lineWidth = 2;
    ctx.beginPath();
    ctx.moveTo(0, 0);
    ctx.lineTo(100, 100);
    ctx.stroke();
  }
}
```

## 关键总结

1. **CustomPaint 隐藏了 RenderObject 的复杂性**
2. **在 painter 对象中提供单独的 svg/canvas 实现**
3. **可以使用 dependencies 和 shouldRepaint 优化性能**
4. **支持 SVG 和 Canvas 两种渲染方法**
5. **您只需要为使用的渲染器提供实现**
6. **可以轻松与动画结合**
