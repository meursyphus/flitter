# 动画基础

## 概述

Flitter 提供了与 Flutter 相同的强大动画系统。通过组合 AnimationController、Tween 和 Curve，您可以轻松实现流畅自然的动画。

## 为什么动画很重要？

精心设计的动画可以极大地改善用户体验：

- **视觉反馈**：为用户操作提供即时响应
- **状态转换**：流畅地表达界面或元素的变化
- **注意力引导**：将用户的注意力吸引到重要信息或变化上
- **品牌形象**：通过独特的动画表达应用的个性
- **认知连续性**：自然地展示元素的移动或变形

## 核心概念

### 1. AnimationController

控制动画播放、停止、重复等的核心类：

```typescript
class MyWidgetState extends State<MyWidget> {
  controller!: AnimationController;
  
  initState(context: BuildContext) {
    super.initState(context);
    // duration 以毫秒为单位
    this.controller = new AnimationController({
      duration: 1000  // 1 秒
    });
  }
  
  dispose() {
    this.controller.dispose();
    super.dispose();
  }
}
```

### 2. Tween

定义开始值和结束值之间的插值：

```typescript
// 数字 Tween
const sizeTween = new Tween({
  begin: 50,
  end: 200
});

// 颜色 Tween
const colorTween = new ColorTween({
  begin: '#3b82f6',
  end: '#ef4444'
});

// 偏移 Tween（位置移动）
const positionTween = new Tween({
  begin: new Offset(0, 0),
  end: new Offset(100, 100)
});
```

### 3. Animation

连接 Tween 和 AnimationController 来生成实际的动画值：

```typescript
const animation = sizeTween.animated(this.controller);

// 使用 CurvedAnimation 应用缓动效果
const curvedAnimation = new CurvedAnimation({
  parent: this.controller,
  curve: Curves.easeInOut
});

const animation = sizeTween.animated(curvedAnimation);
```

### 4. 动画监听器

添加监听器以在动画值发生变化时重建组件：

```typescript
class MyWidgetState extends State<MyWidget> {
  controller!: AnimationController;
  animation!: Animation<number>;
  
  initState(context: BuildContext) {
    super.initState(context);
    this.controller = new AnimationController({ duration: 1000 });
    this.animation = new Tween({ begin: 0, end: 100 }).animated(this.controller);
    
    // 添加监听器 - 动画值改变时调用 setState
    this.controller.addListener(() => {
      this.setState();
    });
  }
  
  build(context: BuildContext): Widget {
    return Container({
      width: this.animation.value,
      height: this.animation.value,
      color: '#3b82f6'
    });
  }
}
```

```typescript
// 开始动画
this.controller.forward();

// 反向动画
this.controller.reverse();

// 重复动画
this.controller.repeat();

// 动画到特定值
this.controller.animateTo(0.5);

// 停止动画
this.controller.stop();

// 重置动画
this.controller.reset();
```

## 实际示例

### 1. 脉冲动画

```typescript
class PulseAnimation extends StatefulWidget {
  createState() {
    return new PulseAnimationState();
  }
}

class PulseAnimationState extends State<PulseAnimation> {
  controller!: AnimationController;
  animation!: Animation<number>;
  
  initState(context: BuildContext) {
    super.initState(context);
    
    this.controller = new AnimationController({
      duration: 1000  // 1 秒
    });
    
    this.animation = new Tween({
      begin: 1.0,
      end: 1.2
    }).animated(new CurvedAnimation({
      parent: this.controller,
      curve: Curves.easeInOut
    }));
    
    this.controller.repeat({ reverse: true });
  }
  
  dispose() {
    this.controller.dispose();
    super.dispose();
  }
  
  build(context: BuildContext): Widget {
    return Transform.scale({
      scale: this.animation.value,
      child: Container({
        width: 100,
        height: 100,
        decoration: new BoxDecoration({
          color: '#3b82f6',
          shape: 'circle'
        })
      })
    });
  }
}
```

### 2. 顺序动画

```typescript
class SequentialAnimation extends StatefulWidget {
  createState() {
    return new SequentialAnimationState();
  }
}

class SequentialAnimationState extends State<SequentialAnimation> {
  controller!: AnimationController;
  slideAnimation!: Animation<Offset>;
  fadeAnimation!: Animation<number>;
  
  initState(context: BuildContext) {
    super.initState(context);
    
    this.controller = new AnimationController({
      duration: 2000  // 2 秒
    });
    
    // 滑动动画
    this.slideAnimation = new Tween({
      begin: new Offset(-1, 0),
      end: new Offset(0, 0)
    }).animated(new CurvedAnimation({
      parent: this.controller,
      curve: Curves.easeOut
    }));
    
    // 淡入动画
    this.fadeAnimation = new Tween({
      begin: 0.0,
      end: 1.0
    }).animated(new CurvedAnimation({
      parent: this.controller,
      curve: Curves.easeIn
    }));
    
    // 添加动画监听器
    this.controller.addListener(() => {
      this.setState();
    });
    
    this.controller.forward();
  }
  
  dispose() {
    this.controller.dispose();
    super.dispose();
  }
  
  build(context: BuildContext): Widget {
    return Transform.translate({
      offset: new Offset(
        this.slideAnimation.value.dx * 200,  // x 轴移动
        this.slideAnimation.value.dy * 0     // y 轴移动
      ),
      child: Opacity({
        opacity: this.fadeAnimation.value,
        child: Container({
          width: 200,
          height: 100,
          color: '#10b981',
          child: Center({
            child: Text("顺序动画", {
              style: new TextStyle({
                color: '#ffffff',
                fontSize: 18
              })
            })
          })
        })
      })
    });
  }
}
```

### 3. 自定义曲线动画

```typescript
class CustomCurveAnimation extends StatefulWidget {
  createState() {
    return new CustomCurveAnimationState();
  }
}

class CustomCurveAnimationState extends State<CustomCurveAnimation> {
  controller!: AnimationController;
  bounceAnimation!: Animation<number>;
  
  initState(context: BuildContext) {
    super.initState(context);
    
    this.controller = new AnimationController({
      duration: 1500  // 1.5 秒
    });
    
    // 用于弹跳效果的自定义曲线
    this.bounceAnimation = new Tween({
      begin: 0,
      end: 300
    }).animated(new CurvedAnimation({
      parent: this.controller,
      curve: Curves.bounceOut
    }));
    
    // 添加动画监听器
    this.controller.addListener(() => {
      this.setState();
    });
    
    this.controller.forward();
  }
  
  dispose() {
    this.controller.dispose();
    super.dispose();
  }
  
  build(context: BuildContext): Widget {
    return Transform.translate({
      offset: new Offset(this.bounceAnimation.value, 0),
      child: Container({
        width: 50,
        height: 50,
        decoration: new BoxDecoration({
          color: '#10b981',
          shape: 'circle'
        })
      })
    });
  }
}
```

## 重要注意事项

### 1. 性能优化

动画可能会影响性能，因此优化很重要：

```typescript
// ❌ 错误示例：重建整个 widget 树
class MyWidgetState extends State<MyWidget> {
  build(context: BuildContext): Widget {
    return Column({
      children: [
        ComplexWidget({}),  // 每次都重新创建
        Container({
          width: this.animation.value,
          height: 100
        })
      ]
    });
  }
}

// ✅ 正确示例：仅分离受动画影响的部分
class MyWidgetState extends State<MyWidget> {
  complexWidget = ComplexWidget({});  // 只创建一次
  
  build(context: BuildContext): Widget {
    return Column({
      children: [
        this.complexWidget,  // 重复使用
        Container({
          width: this.animation.value,
          height: 100
        })
      ]
    });
  }
}
```

### 2. 内存管理

AnimationController 必须被释放：

```typescript
dispose() {
  this.controller.dispose();  // 必需！
  super.dispose();
}
```

### 3. vsync 配置

您应该使用 SingleTickerProviderStateMixin 或 TickerProviderStateMixin：

```typescript
// Flitter 不使用 mixins
// 直接创建和管理 AnimationController
class MyState extends State<MyWidget> {
  controller!: AnimationController;
  
  initState(context: BuildContext) {
    super.initState(context);
    this.controller = new AnimationController({
      duration: 1000
    });
  }
  
  dispose() {
    this.controller.dispose();
    super.dispose();
  }
}
```

## 内置动画组件

Flitter 为常用动画提供了内置组件：

- **AnimatedContainer**：属性改变时自动动画
- **AnimatedOpacity**：不透明度动画
- **AnimatedPositioned**：Stack 内的位置动画
- **AnimatedScale**：尺寸动画
- **AnimatedRotation**：旋转动画
- **AnimatedSlide**：滑动动画

这些组件无需 AnimationController 即可实现简单的动画。
