## 什么是 headless-chart？

`@meursyphus/headless-chart` 是一个无 UI 图表库。它只提供数据和逻辑，而实际的 UI 由开发者直接使用 Flitter 组件实现。这使得创建完全可定制的图表成为可能。

- **GitHub**: [https://github.com/meursyphus/headless-chart](https://github.com/meursyphus/headless-chart)
- **安装**: `npm install @meursyphus/headless-chart`

## 核心概念

headless-chart 的核心由**数据结构**和**自定义渲染函数**组成：

- **数据结构**：由标签和数据集组成
- **自定义函数**：将图表的每个部分（坐标轴、刻度、柱状图、线条等）渲染为 Flitter 组件

### 关键自定义要点

1. **布局自定义**
   - 使用 `custom.layout` 函数定义整体图表结构
   - 使用 Stack 和 Positioned 自由定位元素

2. **坐标轴标签样式**
   - 使用 `custom.xAxisLabel` 和 `custom.yAxisLabel` 应用文本样式
   - 随意设置字体、大小和颜色

3. **柱状图设计**
   - 在 `custom.bar` 函数中使用 Container 和 BoxDecoration
   - 自由设计颜色、圆角、阴影等

4. **图例自定义**
   - 将图例定位为图表内的浮动框
   - 使用 BoxShadow 增加深度

### 柱状图实现代码示例

```javascript
const Bar = (...[{ legend, value }, { data }]) => {
  const index = data.datasets.findIndex((d) => d.legend === legend);
  const backgroundColor = backgroundColors[index];
  
  return Container({
    width: Infinity,
    height: 14,
    alignment: Alignment.centerRight,
    decoration: new BoxDecoration({
      color: backgroundColor,
      borderRadius: BorderRadius.only({
        topRight: Radius.circular(7),
        bottomRight: Radius.circular(7),
      }),
    }),
    child: FractionalTranslation({
      translation: { x: 1, y: 0 },
      child: Padding({
        padding: EdgeInsets.only({ left: 6 }),
        child: Text(value.toLocaleString("ko-KR").replace(",", " "), {
          style: new TextStyle({
            fontFamily: "Noto Sans JP",
            fontSize: 12,
            fontWeight: "bold",
            color: "#111827",
          }),
        }),
      }),
    }),
  });
};
```

在这段代码中：
- 使用 Flitter 的 Container 和 BoxDecoration 绘制柱状图
- 使用 FractionalTranslation 将数值文本定位在柱状图末端
- 为每个数据集应用不同颜色

### 折线图自定义

1. **使用 CustomPaint 绘制线条**
   ```javascript
   custom.line: (...[{ values, index }, { scale }]) => {
     return CustomPaint({
       painter: {
         svg: {
           paint({ line, point }, { height, width }) {
             const linePath = new Path();
             const pointPath = new Path();
             
             // Calculate data points
             const points = values.map((value, index) => {
               const y = height - (height * (value - scale.min)) / (scale.max - scale.min);
               const x = (index * width) / (values.length - 1);
               return { x, y };
             });
             
             // Draw lines
             linePath.moveTo(points[0]);
             points.slice(1).forEach((point) => {
               linePath.lineTo(point);
             });
             
             // Draw points
             points.forEach((point) => {
               pointPath.addOval(
                 Rect.fromCircle({ center: new Offset(point), radius: 5 })
               );
             });
             
             // Set SVG attributes
             line.setAttribute("fill", "none");
             line.setAttribute("stroke", colors[index]);
             line.setAttribute("stroke-width", "2");
             line.setAttribute("d", linePath.getD());
             
             point.setAttribute("fill", "#1f2937");
             point.setAttribute("stroke", colors[index]);
             point.setAttribute("stroke-width", "1");
             point.setAttribute("d", pointPath.getD());
           }
         }
       }
     });
   }
   ```

2. **调色板使用**
   - 为每个数据集应用不同颜色
   - 协调线条和点之间的颜色

3. **布局灵活性**
   - 使用 Row 并排排列图表和图例
   - 使用 Flexible 实现响应式布局

## headless-chart 的优势

1. **完全自定义**：使用 Flitter 组件控制所有视觉元素
2. **一致的开发体验**：按原样使用 Flitter 的组件系统
3. **性能优化**：仅渲染必要部分
4. **可重用性**：轻松重用自定义组件

## 如何使用 headless-chart

### 1. 安装
```bash
npm install @meursyphus/headless-chart
```

### 2. 基本使用
```javascript
import { BarChart, LineChart } from "@meursyphus/headless-chart";

// 定义数据
const data = {
  labels: ["A", "B", "C", "D"],
  datasets: [
    {
      legend: "数据集 1",
      values: [10, 20, 30, 40],
    },
  ],
};

// 创建图表
const chart = BarChart({
  data,
  custom: {
    // 使用 Flitter 组件自定义每个元素
    bar: (...args) => Container({ /* ... */ }),
    xAxisLabel: (...args) => Text(/* ... */),
    // ... 其他自定义
  },
});
```

### 3. 支持的图表类型
- **BarChart**：柱状图（垂直/水平）
- **LineChart**：折线图
- **PieChart**：饼图
- **ScatterChart**：散点图
