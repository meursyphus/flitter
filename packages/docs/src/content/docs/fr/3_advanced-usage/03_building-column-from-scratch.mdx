## Pratique avec RenderObjectWidget

Utilisons maintenant le système RenderObject et de contraintes que nous avons appris pour créer réellement des widgets. Nous implémenterons une version simplifiée de Column pour comprendre le fonctionnement interne de Flitter.

## Types de RenderObjectWidget

**SingleChildRenderObjectWidget**
- Widgets avec un seul enfant (Container, Padding, etc.)
- `createRenderObject()` : Crée le RenderObject
- `updateRenderObject()` : Met à jour les propriétés

**MultiChildRenderObjectWidget**
- Widgets avec plusieurs enfants (Row, Column, Stack, etc.)
- Gère une liste d'enfants
- Coordonne la mise en page de chaque enfant

### Quand les utiliser ?

- Quand vous avez besoin de mises en page personnalisées impossibles avec les widgets existants
- Quand une logique de rendu complexe critique pour les performances est nécessaire
- Quand un comportement de peinture spécial est requis

## Implémenter SimpleColumn

### Définir la classe Widget

```typescript
class SimpleColumn extends MultiChildRenderObjectWidget {
  constructor(props: { children: Widget[] }) {
    super(props);
  }
  
  createRenderObject(): RenderObject {
    return new RenderSimpleColumn();
  }
  
  updateRenderObject(renderObject: RenderSimpleColumn) {
    // Mettre à jour RenderObject quand les propriétés changent
    // Cet exemple n'a pas de propriétés spéciales, donc laissé vide
  }
}

export default function SimpleColumn(props: { children: Widget[] }): Widget {
  return new _SimpleColumn(props);
}
```

### Implémentation de la classe RenderObject

```typescript
class RenderSimpleColumn extends RenderBox {
  performLayout() {
    let height = 0;
    let maxWidth = 0;
    
    // Effectuer la mise en page pour chaque enfant
    for (const child of this.children) {
      // Passer les contraintes à l'enfant (relâcher la contrainte de hauteur)
      child.layout(constraints.loosen({ height: true }));
      
      // Définir la position de l'enfant (organiser verticalement dans l'ordre)
      child.offset = new Offset(0, height);
      
      // Calculer la position du prochain enfant
      height += child.size.height;
      maxWidth = Math.max(maxWidth, child.size.width);
    }
    
    // Déterminer sa propre taille
    this.size = constraints.constrain(new Size(maxWidth, height));
  }
  
  // Test de collision pour les enfants (événements de clic, etc.)
  hitTestChildren(result: HitTestResult, position: Offset): boolean {
    return this.defaultHitTestChildren(result, position);
  }
  
  // Peindre les enfants
  paint(context: PaintingContext, offset: Offset) {
    this.defaultPaint(context, offset);
  }
}
```

### Analyse détaillée du processus de mise en page

1. **Passage des contraintes** :
   ```typescript
   // Passer les contraintes du parent avec seulement la contrainte de hauteur relâchée
   child.layout(constraints.loosen({ height: true }));
   ```

2. **Calcul de position** :
   ```typescript
   // Déterminer la position Y en accumulant les hauteurs des enfants précédents
   child.offset = new Offset(0, height);
   height += child.size.height;
   ```

3. **Détermination de la taille** :
   ```typescript
   // Largeur de l'enfant le plus large et somme des hauteurs de tous les enfants
   this.size = constraints.constrain(new Size(maxWidth, height));
   ```

## Différences avec Column réel

Le Column réel fournit des fonctionnalités plus complexes :

### MainAxisAlignment
```typescript
enum MainAxisAlignment {
  start,    // Aligner au début
  center,   // Aligner au centre  
  end,      // Aligner à la fin
  spaceBetween,  // Distribution uniforme
  spaceAround,   // Inclure l'espace environnant
  spaceEvenly    // Distribution complètement uniforme
}
```

### CrossAxisAlignment
```typescript
enum CrossAxisAlignment {
  start,    // Début de l'axe transversal
  center,   // Centre de l'axe transversal
  end,      // Fin de l'axe transversal
  stretch   // Remplir tout l'axe transversal
}
```

### Gestion des enfants Flex
- **Expanded** : Prend l'espace restant
- **Flexible** : Ne prend que ce qui est nécessaire

### Gestion du débordement
- Gère quand la taille totale des enfants dépasse le parent
- Fournit le découpage ou le défilement

## Créer des widgets de peinture

Vous pouvez aussi effectuer des opérations de dessin directement dans RenderObject. Flitter utilise un pattern Painter basé sur des classes comme DecoratedBox :

```typescript
class RenderCustomShape extends RenderBox {
  constructor() {
    super({ isPainter: true }); // Indiquer que c'est un painter
  }
  
  performLayout() {
    this.size = constraints.biggest;
  }
  
  // Créer le painter SVG
  protected override createSvgPainter() {
    return new CustomShapeSvgPainter(this);
  }
  
  // Créer le painter Canvas
  protected override createCanvasPainter() {
    return new CustomShapeCanvasPainter(this);
  }
}
```

### Implémentation du Painter SVG

```typescript
class CustomShapeSvgPainter extends SvgPainter {
  protected override createDefaultSvgEl({ createSvgEl }: SvgPaintContext) {
    return {
      shape: createSvgEl("path"),
      border: createSvgEl("path"),
    };
  }
  
  protected override performPaint(svgEls: { shape: SVGPathElement; border: SVGPathElement }) {
    const { shape, border } = svgEls;
    
    // Générer les données du chemin SVG
    const pathData = `M 10,10 L ${this.size.width-10},10 L ${this.size.width-10},${this.size.height-10} L 10,${this.size.height-10} Z`;
    
    shape.setAttribute('d', pathData);
    shape.setAttribute('fill', '#3b82f6');
    
    border.setAttribute('d', pathData);
    border.setAttribute('fill', 'none');
    border.setAttribute('stroke', '#1e40af');
    border.setAttribute('stroke-width', '2');
  }
}
```

### Implémentation du Painter Canvas

```typescript
class CustomShapeCanvasPainter extends CanvasPainter {
  override performPaint(context: CanvasPaintingContext, offset: Offset) {
    const ctx = context.canvas;
    
    ctx.save();
    ctx.translate(offset.x, offset.y);
    
    // Dessiner le rectangle
    ctx.fillStyle = '#3b82f6';
    ctx.fillRect(10, 10, this.size.width - 20, this.size.height - 20);
    
    // Dessiner la bordure
    ctx.strokeStyle = '#1e40af';
    ctx.lineWidth = 2;
    ctx.strokeRect(10, 10, this.size.width - 20, this.size.height - 20);
    
    ctx.restore();
  }
}
```

### Besoin d'une peinture simple ?

Au lieu d'une implémentation RenderObject complexe, utiliser le [widget CustomPaint](/docs/widgets/CustomPaint) est plus simple :

```typescript
CustomPaint({
  painter: {
    svg: {
      createDefaultSvgEl: (context) => ({
        shape: context.createSvgEl('rect')
      }),
      paint: (els, size) => {
        els.shape.setAttribute('width', `${size.width}`);
        els.shape.setAttribute('height', `${size.height}`);
        els.shape.setAttribute('fill', '#3b82f6');
      }
    },
    canvas: {
      paint: (context, size) => {
        context.canvas.fillStyle = '#3b82f6';
        context.canvas.fillRect(0, 0, size.width, size.height);
      }
    }
  }
})
```
