## Qu'est-ce que headless-chart ?

`@meursyphus/headless-chart` est une bibliothèque de graphiques sans UI. Elle fournit uniquement les données et la logique, tandis que l'interface utilisateur réelle est implémentée directement par les développeurs en utilisant les widgets Flitter. Cela permet de créer des graphiques entièrement personnalisables.

- **GitHub** : [https://github.com/meursyphus/headless-chart](https://github.com/meursyphus/headless-chart)
- **Installation** : `npm install @meursyphus/headless-chart`

## Concepts fondamentaux

Le cœur de headless-chart se compose de **structure de données** et de **fonctions de rendu personnalisées** :

- **Structure de données** : Composée d'étiquettes et de jeux de données
- **Fonctions personnalisées** : Rendre chaque partie du graphique (axes, graduations, barres, lignes, etc.) sous forme de widgets Flitter

### Points de personnalisation clés

1. **Personnalisation de la mise en page**
   - Définir la structure globale du graphique avec la fonction `custom.layout`
   - Positionnement libre des éléments avec Stack et Positioned

2. **Style des étiquettes d'axes**
   - Appliquer des styles de texte avec `custom.xAxisLabel` et `custom.yAxisLabel`
   - Définir la police, la taille et la couleur selon vos souhaits

3. **Design des barres**
   - Utiliser Container et BoxDecoration dans la fonction `custom.bar`
   - Concevoir librement les couleurs, coins arrondis, ombres, etc.

4. **Personnalisation de la légende**
   - Positionner la légende comme une boîte flottante à l'intérieur du graphique
   - Ajouter de la profondeur avec BoxShadow

### Exemple de code d'implémentation d'un graphique à barres

```javascript
const Bar = (...[{ legend, value }, { data }]) => {
  const index = data.datasets.findIndex((d) => d.legend === legend);
  const backgroundColor = backgroundColors[index];
  
  return Container({
    width: Infinity,
    height: 14,
    alignment: Alignment.centerRight,
    decoration: new BoxDecoration({
      color: backgroundColor,
      borderRadius: BorderRadius.only({
        topRight: Radius.circular(7),
        bottomRight: Radius.circular(7),
      }),
    }),
    child: FractionalTranslation({
      translation: { x: 1, y: 0 },
      child: Padding({
        padding: EdgeInsets.only({ left: 6 }),
        child: Text(value.toLocaleString("ko-KR").replace(",", " "), {
          style: new TextStyle({
            fontFamily: "Noto Sans JP",
            fontSize: 12,
            fontWeight: "bold",
            color: "#111827",
          }),
        }),
      }),
    }),
  });
};
```

Dans ce code :
- Dessiner des barres en utilisant Container et BoxDecoration de Flitter
- Positionner le texte de valeur à la fin des barres avec FractionalTranslation
- Appliquer différentes couleurs pour chaque jeu de données

### Personnalisation du graphique linéaire

1. **Dessiner des lignes avec CustomPaint**
   ```javascript
   custom.line: (...[{ values, index }, { scale }]) => {
     return CustomPaint({
       painter: {
         svg: {
           paint({ line, point }, { height, width }) {
             const linePath = new Path();
             const pointPath = new Path();
             
             // Calculer les points de données
             const points = values.map((value, index) => {
               const y = height - (height * (value - scale.min)) / (scale.max - scale.min);
               const x = (index * width) / (values.length - 1);
               return { x, y };
             });
             
             // Dessiner les lignes
             linePath.moveTo(points[0]);
             points.slice(1).forEach((point) => {
               linePath.lineTo(point);
             });
             
             // Dessiner les points
             points.forEach((point) => {
               pointPath.addOval(
                 Rect.fromCircle({ center: new Offset(point), radius: 5 })
               );
             });
             
             // Définir les attributs SVG
             line.setAttribute("fill", "none");
             line.setAttribute("stroke", colors[index]);
             line.setAttribute("stroke-width", "2");
             line.setAttribute("d", linePath.getD());
             
             point.setAttribute("fill", "#1f2937");
             point.setAttribute("stroke", colors[index]);
             point.setAttribute("stroke-width", "1");
             point.setAttribute("d", pointPath.getD());
           }
         }
       }
     });
   }
   ```

2. **Utilisation de la palette de couleurs**
   - Appliquer différentes couleurs pour chaque jeu de données
   - Harmoniser les couleurs entre les lignes et les points

3. **Flexibilité de la mise en page**
   - Arrangement côte à côte du graphique et de la légende avec Row
   - Implémentation d'une mise en page responsive avec Flexible

## Avantages de headless-chart

1. **Personnalisation complète** : Contrôler tous les éléments visuels avec les widgets Flitter
2. **Expérience de développement cohérente** : Utiliser le système de widgets de Flitter tel quel
3. **Optimisation des performances** : Rendre uniquement les parties nécessaires
4. **Réutilisabilité** : Réutiliser facilement les composants personnalisés

## Comment utiliser headless-chart

### 1. Installation
```bash
npm install @meursyphus/headless-chart
```

### 2. Utilisation de base
```javascript
import { BarChart, LineChart } from "@meursyphus/headless-chart";

// Définir les données
const data = {
  labels: ["A", "B", "C", "D"],
  datasets: [
    {
      legend: "Jeu de données 1",
      values: [10, 20, 30, 40],
    },
  ],
};

// Créer le graphique
const chart = BarChart({
  data,
  custom: {
    // Personnaliser chaque élément avec des widgets Flitter
    bar: (...args) => Container({ /* ... */ }),
    xAxisLabel: (...args) => Text(/* ... */),
    // ... autres personnalisations
  },
});
```

### 3. Types de graphiques supportés
- **BarChart** : Graphiques à barres (vertical/horizontal)
- **LineChart** : Graphiques linéaires
- **PieChart** : Graphiques en secteurs
- **ScatterChart** : Graphiques en nuage de points
