# Système de Widgets

## Vue d'ensemble

Le Widget de Flitter est l'unité de base qui compose l'interface utilisateur. Comme Flutter, chaque élément affiché à l'écran est composé de widgets. Les boutons, le texte, les mises en page et même l'application elle-même sont tous des widgets.

## Pourquoi est-ce important ?

Comprendre le système de widgets permet :

- **Composants réutilisables** : Réutiliser les widgets n'importe où une fois créés
- **Structure composable** : Construire des interfaces complexes en combinant de petits widgets
- **Gestion d'état claire** : Distinguer les modèles de gestion d'état avec StatelessWidget et StatefulWidget
- **Comportement prévisible** : Développement systématique grâce au cycle de vie des widgets

## Concepts fondamentaux

### Types de Widgets

Flitter a trois types de widgets principaux :

1. **StatelessWidget** : Widget statique sans état
2. **StatefulWidget** : Widget dynamique avec état
3. **RenderObjectWidget** : Widget de bas niveau responsable du rendu direct

### StatelessWidget

Un widget sans état qui ne change pas une fois créé :

```typescript
import { StatelessWidget, Text, Container, EdgeInsets, Colors, type BuildContext, type Widget } from '@meursyphus/flitter';

class Greeting extends StatelessWidget {
  constructor(private props: { name: string }) {
    super();
  }

  build(context: BuildContext): Widget {
    return Container({
      padding: EdgeInsets.all(16),
      color: Colors.blue.shade100,
      child: Text(`Bonjour, ${this.props.name} !`)
    });
  }
}

// Exporter en tant que fonction factory
export default function GreetingWidget(props: { name: string }): Widget {
  return new Greeting(props);
}
```

### StatefulWidget

Un widget qui a un état et met automatiquement à jour l'interface quand l'état change :

```typescript
import { 
  StatefulWidget, 
  State, 
  Container, 
  Column, 
  Text, 
  GestureDetector,
  EdgeInsets,
  Colors,
  TextStyle,
  type BuildContext,
  type Widget 
} from '@meursyphus/flitter';

class Counter extends StatefulWidget {
  createState(): State<Counter> {
    return new CounterState();
  }
}

class CounterState extends State<Counter> {
  count = 0;

  build(context: BuildContext): Widget {
    return Column({
      children: [
        Text(`Compteur : ${this.count}`, {
          style: TextStyle({ fontSize: 24 })
        }),
        GestureDetector({
          onClick: () => {
            this.setState(() => {
              this.count++;
            });
          },
          child: Container({
            margin: EdgeInsets.only({ top: 16 }),
            padding: EdgeInsets.symmetric({ horizontal: 24, vertical: 12 }),
            color: Colors.blue,
            child: Text("Incrémenter", {
              style: TextStyle({ color: Colors.white })
            })
          })
        })
      ]
    });
  }
}

// Exporter en tant que fonction factory
export default function CounterWidget(): Widget {
  return new Counter();
}
```

### Cycle de vie des Widgets

#### Cycle de vie de StatefulWidget

```typescript
class MyWidgetState extends State<MyWidget> {
  // 1. Appelé une fois quand l'objet d'état est créé
  initState(): void {
    super.initState();
    console.log("Widget initialisé");
    // Initialiser les contrôleurs d'animation, les abonnements aux flux, etc.
  }

  // 2. Quand le widget parent change et que ce widget doit être mis à jour
  didUpdateWidget(oldWidget: MyWidget): void {
    super.didUpdateWidget(oldWidget);
    console.log("Configuration du widget modifiée");
    // Mettre à jour l'état en fonction des changements de props
  }

  // 3. Exécuté à chaque fois que setState est appelé
  build(context: BuildContext): Widget {
    console.log("Rendu de l'interface");
    return Container({ /* ... */ });
  }

  // 4. Quand l'objet d'état est supprimé
  dispose(): void {
    console.log("Widget supprimé");
    // Nettoyer les contrôleurs d'animation, les abonnements aux flux, etc.
    super.dispose();
  }
}
```

### 2. StatefulWidget avec État Complexe

```typescript
class TodoApp extends StatefulWidget {
  createState(): State<TodoApp> {
    return new TodoAppState();
  }
}

class TodoAppState extends State<TodoApp> {
  todos: Array<{ id: number; text: string; done: boolean }> = [];
  nextId = 1;
  inputText = "";

  addTodo(text: string): void {
    if (text.trim() === "") return;
    
    this.setState(() => {
      this.todos.push({
        id: this.nextId++,
        text: text,
        done: false
      });
      this.inputText = "";
    });
  }

  toggleTodo(id: number): void {
    this.setState(() => {
      const todo = this.todos.find(t => t.id === id);
      if (todo) {
        todo.done = !todo.done;
      }
    });
  }

  deleteTodo(id: number): void {
    this.setState(() => {
      this.todos = this.todos.filter(t => t.id !== id);
    });
  }

  build(context: BuildContext): Widget {
    return Container({
      padding: EdgeInsets.all(16),
      child: Column({
        children: [
          Text("Liste de tâches", {
            style: TextStyle({ 
              fontSize: 24, 
              fontWeight: FontWeight.bold,
              color: Colors.white 
            })
          }),
          SizedBox({ height: 16 }),
          
          // Champ de saisie (utiliser normalement le widget TextField)
          Container({
            padding: EdgeInsets.all(12),
            color: Colors.grey.shade800,
            child: Text(this.inputText || "Entrez une nouvelle tâche...", {
              style: TextStyle({ color: Colors.grey.shade400 })
            })
          }),
          
          SizedBox({ height: 16 }),
          
          // Liste des tâches
          ...this.todos.map(todo => 
            Container({
              margin: EdgeInsets.only({ bottom: 8 }),
              padding: EdgeInsets.all(12),
              color: todo.done ? Colors.grey.shade800 : Colors.grey.shade700,
              child: Row({
                children: [
                  GestureDetector({
                    onClick: () => this.toggleTodo(todo.id),
                    child: Icon(
                      todo.done ? Icons.check_box : Icons.check_box_outline_blank,
                      { color: Colors.white }
                    )
                  }),
                  SizedBox({ width: 12 }),
                  Expanded({
                    child: Text(todo.text, {
                      style: TextStyle({
                        color: Colors.white,
                        decoration: todo.done ? TextDecoration.lineThrough : TextDecoration.none
                      })
                    })
                  }),
                  GestureDetector({
                    onClick: () => this.deleteTodo(todo.id),
                    child: Icon(Icons.delete, { color: Colors.red.shade400 })
                  })
                ]
              })
            })
          )
        ]
      })
    });
  }
}

export default function TodoAppWidget(): Widget {
  return new TodoApp();
}
```

### 3. Exemple d'utilisation du cycle de vie

```typescript
class TimerWidget extends StatefulWidget {
  constructor(private props: { duration: number }) {
    super();
  }

  createState(): State<TimerWidget> {
    return new TimerWidgetState();
  }
}

class TimerWidgetState extends State<TimerWidget> {
  timeLeft = 0;
  timer?: NodeJS.Timeout;

  initState(): void {
    super.initState();
    this.timeLeft = this.widget.props.duration;
    this.startTimer();
  }

  startTimer(): void {
    this.timer = setInterval(() => {
      this.setState(() => {
        if (this.timeLeft > 0) {
          this.timeLeft--;
        } else {
          this.stopTimer();
        }
      });
    }, 1000);
  }

  stopTimer(): void {
    if (this.timer) {
      clearInterval(this.timer);
      this.timer = undefined;
    }
  }

  didUpdateWidget(oldWidget: TimerWidget): void {
    super.didUpdateWidget(oldWidget);
    if (oldWidget.props.duration !== this.widget.props.duration) {
      this.stopTimer();
      this.timeLeft = this.widget.props.duration;
      this.startTimer();
    }
  }

  dispose(): void {
    this.stopTimer();
    super.dispose();
  }

  build(context: BuildContext): Widget {
    const minutes = Math.floor(this.timeLeft / 60);
    const seconds = this.timeLeft % 60;
    
    return Container({
      padding: EdgeInsets.all(24),
      color: this.timeLeft === 0 ? Colors.red.shade900 : Colors.grey.shade900,
      child: Column({
        children: [
          Text("Minuteur", {
            style: TextStyle({ 
              fontSize: 20, 
              color: Colors.white 
            })
          }),
          SizedBox({ height: 16 }),
          Text(
            `${minutes.toString().padStart(2, '0')}:${seconds.toString().padStart(2, '0')}`,
            {
              style: TextStyle({ 
                fontSize: 48, 
                fontWeight: FontWeight.bold,
                color: this.timeLeft === 0 ? Colors.red : Colors.white 
              })
            }
          ),
          if (this.timeLeft === 0)
            Text("Temps écoulé !", {
              style: TextStyle({ 
                fontSize: 24, 
                color: Colors.red.shade400 
              })
            })
        ]
      })
    });
  }
}

export default function TimerWidgetExample(props: { duration: number }): Widget {
  return new TimerWidget(props);
}
```

## Points importants

### 1. Règles de gestion d'état

```typescript
// ❌ Incorrect - Changement d'état sans setState
this.count++;  // L'interface ne se mettra pas à jour !

// ✅ Correct - Utiliser setState
this.setState(() => {
  this.count++;
});

// ❌ Incorrect - Changement d'état en dehors de setState
this.items.push(newItem);
this.setState(() => {});  // setState vide

// ✅ Correct - Tous les changements à l'intérieur de setState
this.setState(() => {
  this.items.push(newItem);
});
```

### 2. Réutilisation des Widgets

```typescript
// ❌ Incorrect - Créer des widgets dans la méthode build
build(context: BuildContext): Widget {
  // Création d'une nouvelle instance de widget à chaque fois (inefficace)
  const button = new MyButton();
  return Container({ child: button });
}

// ✅ Correct - Séparer correctement les widgets
build(context: BuildContext): Widget {
  return Container({
    child: MyButton({ onClick: this.handleClick })
  });
}
```

### 3. Props vs État

- **Props** : Données immuables passées par le parent
- **État** : Données mutables gérées au sein du widget

```typescript
class MyWidget extends StatefulWidget {
  constructor(private props: { initialCount: number }) {
    super();
  }

  createState(): State<MyWidget> {
    return new MyWidgetState();
  }
}

class MyWidgetState extends State<MyWidget> {
  // les props sont utilisées uniquement comme valeurs initiales
  count = this.widget.props.initialCount;

  build(context: BuildContext): Widget {
    // les props peuvent être lues directement
    return Text(`Initial : ${this.widget.props.initialCount}, Actuel : ${this.count}`);
  }
}
```
