# Bases de l'Animation

## Vue d'ensemble

Flitter fournit le même système d'animation puissant que Flutter. Vous pouvez facilement implémenter des animations fluides et naturelles en combinant AnimationController, Tween et Curve.

## Pourquoi les animations sont-elles importantes ?

Des animations bien conçues améliorent grandement l'expérience utilisateur :

- **Feedback visuel** : Fournir une réponse immédiate aux actions de l'utilisateur
- **Transitions d'état** : Exprimer en douceur les changements d'écrans ou d'éléments
- **Guidage de l'attention** : Attirer l'attention de l'utilisateur sur des informations ou changements importants
- **Identité de marque** : Exprimer la personnalité de l'application à travers des animations uniques
- **Continuité cognitive** : Montrer naturellement le mouvement ou la transformation des éléments

## Concepts fondamentaux

### 1. AnimationController

La classe principale qui contrôle la lecture, l'arrêt, la répétition, etc. de l'animation :

```typescript
class MyWidgetState extends State<MyWidget> {
  controller!: AnimationController;
  
  initState(context: BuildContext) {
    super.initState(context);
    // la durée est spécifiée en millisecondes
    this.controller = new AnimationController({
      duration: 1000  // 1 seconde
    });
  }
  
  dispose() {
    this.controller.dispose();
    super.dispose();
  }
}
```

### 2. Tween

Définit l'interpolation entre les valeurs de début et de fin :

```typescript
// Tween de nombre
const sizeTween = new Tween({
  begin: 50,
  end: 200
});

// Tween de couleur
const colorTween = new ColorTween({
  begin: '#3b82f6',
  end: '#ef4444'
});

// Tween d'Offset (mouvement de position)
const positionTween = new Tween({
  begin: new Offset(0, 0),
  end: new Offset(100, 100)
});
```

### 3. Animation

Connecte Tween et AnimationController pour générer les valeurs d'animation réelles :

```typescript
const animation = sizeTween.animated(this.controller);

// Appliquer des effets d'accélération avec CurvedAnimation
const curvedAnimation = new CurvedAnimation({
  parent: this.controller,
  curve: Curves.easeInOut
});

const animation = sizeTween.animated(curvedAnimation);
```

### 4. Écouteurs d'Animation

Ajouter des écouteurs pour reconstruire les widgets à chaque changement de valeur d'animation :

```typescript
class MyWidgetState extends State<MyWidget> {
  controller!: AnimationController;
  animation!: Animation<number>;
  
  initState(context: BuildContext) {
    super.initState(context);
    this.controller = new AnimationController({ duration: 1000 });
    this.animation = new Tween({ begin: 0, end: 100 }).animated(this.controller);
    
    // Ajouter un écouteur - appeler setState à chaque changement de valeur d'animation
    this.controller.addListener(() => {
      this.setState();
    });
  }
  
  build(context: BuildContext): Widget {
    return Container({
      width: this.animation.value,
      height: this.animation.value,
      color: '#3b82f6'
    });
  }
}
```

### Contrôle de l'Animation

```typescript
// Démarrer l'animation
this.controller.forward();

// Inverser l'animation
this.controller.reverse();

// Répéter l'animation
this.controller.repeat();

// Animer vers une valeur spécifique
this.controller.animateTo(0.5);

// Arrêter l'animation
this.controller.stop();

// Réinitialiser l'animation
this.controller.reset();
```

## Exemples pratiques

### 1. Animation de pulsation

```typescript
class PulseAnimation extends StatefulWidget {
  createState() {
    return new PulseAnimationState();
  }
}

class PulseAnimationState extends State<PulseAnimation> {
  controller!: AnimationController;
  animation!: Animation<number>;
  
  initState(context: BuildContext) {
    super.initState(context);
    
    this.controller = new AnimationController({
      duration: 1000  // 1 seconde
    });
    
    this.animation = new Tween({
      begin: 1.0,
      end: 1.2
    }).animated(new CurvedAnimation({
      parent: this.controller,
      curve: Curves.easeInOut
    }));
    
    this.controller.repeat({ reverse: true });
  }
  
  dispose() {
    this.controller.dispose();
    super.dispose();
  }
  
  build(context: BuildContext): Widget {
    return Transform.scale({
      scale: this.animation.value,
      child: Container({
        width: 100,
        height: 100,
        decoration: new BoxDecoration({
          color: '#3b82f6',
          shape: 'circle'
        })
      })
    });
  }
}
```

### 2. Animation séquentielle

```typescript
class SequentialAnimation extends StatefulWidget {
  createState() {
    return new SequentialAnimationState();
  }
}

class SequentialAnimationState extends State<SequentialAnimation> {
  controller!: AnimationController;
  slideAnimation!: Animation<Offset>;
  fadeAnimation!: Animation<number>;
  
  initState(context: BuildContext) {
    super.initState(context);
    
    this.controller = new AnimationController({
      duration: 2000  // 2 secondes
    });
    
    // Animation de glissement
    this.slideAnimation = new Tween({
      begin: new Offset(-1, 0),
      end: new Offset(0, 0)
    }).animated(new CurvedAnimation({
      parent: this.controller,
      curve: Curves.easeOut
    }));
    
    // Animation de fondu
    this.fadeAnimation = new Tween({
      begin: 0.0,
      end: 1.0
    }).animated(new CurvedAnimation({
      parent: this.controller,
      curve: Curves.easeIn
    }));
    
    // Ajouter un écouteur d'animation
    this.controller.addListener(() => {
      this.setState();
    });
    
    this.controller.forward();
  }
  
  dispose() {
    this.controller.dispose();
    super.dispose();
  }
  
  build(context: BuildContext): Widget {
    return Transform.translate({
      offset: new Offset(
        this.slideAnimation.value.dx * 200,  // mouvement sur l'axe x
        this.slideAnimation.value.dy * 0     // mouvement sur l'axe y
      ),
      child: Opacity({
        opacity: this.fadeAnimation.value,
        child: Container({
          width: 200,
          height: 100,
          color: '#10b981',
          child: Center({
            child: Text("Animation séquentielle", {
              style: new TextStyle({
                color: '#ffffff',
                fontSize: 18
              })
            })
          })
        })
      })
    });
  }
}
```

### 3. Animation avec courbe personnalisée

```typescript
class CustomCurveAnimation extends StatefulWidget {
  createState() {
    return new CustomCurveAnimationState();
  }
}

class CustomCurveAnimationState extends State<CustomCurveAnimation> {
  controller!: AnimationController;
  bounceAnimation!: Animation<number>;
  
  initState(context: BuildContext) {
    super.initState(context);
    
    this.controller = new AnimationController({
      duration: 1500  // 1,5 secondes
    });
    
    // Courbe personnalisée pour l'effet de rebond
    this.bounceAnimation = new Tween({
      begin: 0,
      end: 300
    }).animated(new CurvedAnimation({
      parent: this.controller,
      curve: Curves.bounceOut
    }));
    
    // Ajouter un écouteur d'animation
    this.controller.addListener(() => {
      this.setState();
    });
    
    this.controller.forward();
  }
  
  dispose() {
    this.controller.dispose();
    super.dispose();
  }
  
  build(context: BuildContext): Widget {
    return Transform.translate({
      offset: new Offset(this.bounceAnimation.value, 0),
      child: Container({
        width: 50,
        height: 50,
        decoration: new BoxDecoration({
          color: '#10b981',
          shape: 'circle'
        })
      })
    });
  }
}
```

## Points importants

### 1. Optimisation des performances

Les animations peuvent impacter les performances, l'optimisation est donc importante :

```typescript
// ❌ Mauvais exemple : Reconstruction de tout l'arbre de widgets
class MyWidgetState extends State<MyWidget> {
  build(context: BuildContext): Widget {
    return Column({
      children: [
        ComplexWidget({}),  // Recréé à chaque fois
        Container({
          width: this.animation.value,
          height: 100
        })
      ]
    });
  }
}

// ✅ Bon exemple : Séparer uniquement les parties affectées par l'animation
class MyWidgetState extends State<MyWidget> {
  complexWidget = ComplexWidget({});  // Créé une seule fois
  
  build(context: BuildContext): Widget {
    return Column({
      children: [
        this.complexWidget,  // Réutilisé
        Container({
          width: this.animation.value,
          height: 100
        })
      ]
    });
  }
}
```

### 2. Gestion de la mémoire

AnimationController doit être supprimé :

```typescript
dispose() {
  this.controller.dispose();  // Obligatoire !
  super.dispose();
}
```

### 3. Configuration vsync

Vous devriez utiliser SingleTickerProviderStateMixin ou TickerProviderStateMixin :

```typescript
// Flitter n'utilise pas les mixins
// Créer et gérer AnimationController directement
class MyState extends State<MyWidget> {
  controller!: AnimationController;
  
  initState(context: BuildContext) {
    super.initState(context);
    this.controller = new AnimationController({
      duration: 1000
    });
  }
  
  dispose() {
    this.controller.dispose();
    super.dispose();
  }
}
```

## Widgets d'animation intégrés

Flitter fournit des widgets intégrés pour les animations couramment utilisées :

- **AnimatedContainer** : Animation automatique lors du changement de propriétés
- **AnimatedOpacity** : Animation d'opacité
- **AnimatedPositioned** : Animation de position dans un Stack
- **AnimatedScale** : Animation de taille
- **AnimatedRotation** : Animation de rotation
- **AnimatedSlide** : Animation de glissement

Ces widgets permettent des animations simples sans AnimationController.
