## 위젯 문서 작성 템플릿

각 위젯 문서는 다음 구조를 따릅니다:

```markdown
# [위젯명]

## 개요
[위젯의 기능과 목적]

## 사용 시기
[이 위젯을 사용해야 하는 상황]

## 기본 사용법
[간단한 코드 예제]

## 생성자 파라미터
[모든 파라미터 설명]

## 예제
### 기본 예제
[코드]

### 고급 예제
[코드]

## 관련 위젯
[관련 위젯 링크]
```
