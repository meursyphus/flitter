# Starter style

The CLI copies `FlowDiagram`, a basic xyflow composition, into your project. Its familiar boxes, edges and controls are a starting point. Every visual part is source code you can replace.

For different compositions, start in the [gallery](/diagram/gallery). For the builder contracts, see [Builders & Context](/diagram/api).

## Follow the source

| File | What it owns |
| --- | --- |
| `flow-diagram/index.ts` | Assembles `Flow`, the default type maps, custom builders and panels. Change the composition here. |
| `config.ts` | The starter's design tokens and defaults. Edit these along with the parts that consume them. |
| `parts/node.ts` | Default node shapes and contents |
| `parts/edge.ts` | Edge drawing, labels, markers and the connection preview |
| `parts/handle.ts`, `parts/resize.ts` | Connection, resize and reconnect visuals |
| `parts/background.ts`, `parts/selection.ts` | Scene background and selection feedback |
| `parts/controls.ts`, `parts/minimap.ts` | Widgets that use the controller, assembled as panels |
| `parts/paint.ts`, `parts/icons.ts` | Drawing helpers you can reuse or replace |

The assembled builders are exported as `xyflowCustom`; the named types as `xyflowNodeTypes` and `xyflowEdgeTypes`. Individual builders are exported too. These exports come from your copied files, so you can compose them directly with [Headless Flow](/diagram/headless).

## Config is a shortcut for the starter

Use `config` when the existing parts already have the structure you want. It is a deep partial of `XyflowFlowConfig`; `createXyflowConfig()` resolves it against the starter defaults. `colorMode` selects a palette before your color overrides are applied.

```typescript
import { FlowDiagram } from "@/components/diagram/flow-diagram";

export const diagram = FlowDiagram({
  nodes: [],
  config: {
    colorMode: "dark",
    colors: { background: "#0d0f13", edgeStroke: "#64748b" },
    minimap: { visible: false },
  },
});
```

The full config type lives beside the source in `config.ts`. It describes what these particular starter builders read. For a card with an image, a custom edge label or a different control layout, edit or replace the relevant builder. You can also add your own style inputs there.

## Replace shared parts

```typescript
import { FlowDiagram } from "@/components/diagram/flow-diagram";

export const diagram = FlowDiagram({
  nodes: [],
  custom: {
    background: () => null,
    edgeLabel: () => null,
  },
  config: { controls: { visible: false }, minimap: { visible: false } },
});
```

Use `panels` to add your own widgets around the graph. To replace a built-in node or edge type, override its entry in `nodeTypes` or `edgeTypes`; registered types take precedence over the fallback `custom.node` and `custom.edge` builders.

See [Customization](/diagram/customization) for the full workflow and [A style from scratch](/diagram/gallery/headless) for a composition with its own config and no starter imports.
