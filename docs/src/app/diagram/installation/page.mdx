# Installation

## React

```bash
npm install flitterjs @flitterjs/adapter-react
npx @flitterjs/cli@latest init
npx @flitterjs/cli@latest add flow-diagram
```

`add` copies one theme into `aliases.diagrams`. There is no `--style` flag.

```
src/components/diagram/flow-diagram/
├── index.ts       # default FlowDiagram export
├── base/          # structural slots and BaseFlowDiagram
└── style/
    ├── index.ts   # defaultStyleConfig { custom, createConfig }
    ├── config.ts  # DefaultFlowConfig, light and dark colours
    └── parts/     # defaultNode, defaultEdge, defaultControls, ...
```

| Flag | Effect |
| --- | --- |
| `--overwrite` | Replace an existing `flow-diagram` folder |
| `--skip-install` | Skip installing `flitterjs` and `@flitterjs/diagram` |
| `--cwd <path>` | Run in another project |

## Svelte

```bash
npm install flitterjs @flitterjs/adapter-svelte
npx @flitterjs/cli@latest init
npx @flitterjs/cli@latest add flow-diagram
```

```svelte
<script>
  import Widget from "@flitterjs/adapter-svelte";
  import FlowDiagram from "@/components/diagram/flow-diagram";

  const diagram = FlowDiagram({ data: { nodes: [], edges: [] } });
</script>

<Widget widget={diagram} width="100%" height="480px" />
```

## Imports

| From | Names |
| --- | --- |
| `@/components/diagram/flow-diagram` | `FlowDiagram` (default), `defaultStyleConfig`, `DefaultFlowConfig`, every part |
| `@flitterjs/diagram` | `FlowDiagram`, `FlowDiagramController`, types, layouts, path helpers |
| `flitterjs` | Widgets such as `Container` and `Text` |

Your bundler must resolve `@/` the way `tsconfig.json` paths do.
