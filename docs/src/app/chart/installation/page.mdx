# Installation

## Prerequisites

- **Node.js** 18 or later
- **React** 18+ or **Svelte** 4+
- A package manager: npm, pnpm, or yarn

## Quick setup

Initialize Flitter in your project:

```bash
npx flitter-ui init
```

This command will:
1. Install the core rendering engine (`@meursyphus/flitter`)
2. Install the framework adapter (`@meursyphus/flitter-react` or `@meursyphus/flitter-svelte`)
3. Create a `flitter.config.ts` in your project root

## Add your first chart

```bash
npx flitter-ui add bar-chart
```

This pulls the full chart source code into your project. You get:
- The chart component file
- All sub-widgets (axis, tooltip, legend, etc.)
- Type definitions

## Choose a style

Each chart comes with multiple visual styles. Pick one during install:

```bash
npx flitter-ui add bar-chart --style toast
npx flitter-ui add bar-chart --style ag
```

If you don't specify a style, you'll be prompted to choose.

## Framework setup

### React

```tsx
import { Widget } from "@meursyphus/flitter-react";
import BarChart from "./charts/bar-chart";

export default function App() {
  return (
    <Widget
      widget={BarChart({ data: [...] })}
      width="100%"
      height={400}
    />
  );
}
```

### Svelte

```svelte
<script>
  import Widget from "@meursyphus/flitter-svelte";
  import BarChart from "./charts/bar-chart";
</script>

<Widget
  widget={BarChart({ data: [...] })}
  width="100%"
  height={400}
/>
```
