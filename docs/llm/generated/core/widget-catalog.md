# Widget Catalog For Charting

Generated: 2026-03-07

This is the chart-relevant Flitter widget list. Use it when leaving preset-only work and composing custom chart shells, overlays, or novel composites.

## Layout

- `column`: Vertical layout primitive for chart shells, legends, and stacked panels. Doc: `/llm/core/widgets/column.md`
- `row`: Horizontal layout primitive for legends, paired metrics, and x-axis label rows. Doc: `/llm/core/widgets/row.md`
- `stack`: Layer children visually in the same space. Doc: `/llm/core/widgets/stack.md`
- `positioned`: Place a child precisely within a Stack. Doc: `/llm/core/widgets/positioned.md`
- `expanded`: Let a child take remaining space within Flex, Row, or Column. Doc: `/llm/core/widgets/expanded.md`
- `sized-box`: Fixed spacing or fixed-size placeholder widget. Doc: `/llm/core/widgets/sized-box.md`
- `container`: General-purpose box for size, decoration, alignment, and background. Doc: `/llm/core/widgets/container.md`
- `padding`: Inset content from its edges. Doc: `/llm/core/widgets/padding.md`
- `align`: Align one child within its available box. Doc: `/llm/core/widgets/align.md`
- `flex`: Lower-level flex primitive when Row or Column is too specific. Doc: `/llm/core/widgets/flex.md`
- `flexible`: Participate in flex layout without forcing full expansion. Doc: `/llm/core/widgets/flexible.md`
- `fractionally-sized-box`: Size a child as a fraction of available space. Doc: `/llm/core/widgets/fractionally-sized-box.md`
